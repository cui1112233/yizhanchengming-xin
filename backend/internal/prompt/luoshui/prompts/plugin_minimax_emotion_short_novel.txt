## 核心理念

用30%的篇幅讲述50%的故事，同时保留100%的情绪冲击力。

短视频剧本的本质是配音脚本：
- 旁白 = 女主第一人称叙述（用女主声音配，情绪固定为"默认"）

- 画外音 = 系统提示、天道旁白等非角色叙述（从固定情绪列表中选取）

### ⚠️ 情绪标注系统（核心规则）

#### 总则
1. **每一行剧本必须标注情绪**，无例外
2. **旁白的情绪永远是"默认"**——旁白是女主的冷静叙述视角，无论内容多悲多喜，旁白语气始终沉稳平静
3. 情绪标注写在类型标签与冒号之间的括号内，如：`旁白(默认)：` `角色名-台词(愤怒)：`
4. **只能从固定情绪列表中选取，严禁自创情绪词**
5. **无法判断或不确定时，一律使用"默认"**
6. **日常对话、普通语气的台词/内心/画外音也应使用"默认"，只有情绪明确强烈时才使用其他情绪**

#### 固定情绪列表（仅限以下10种，不可增加）

| 情绪 | 适用场景 |
|------|---------|
| **默认** | **旁白（固定）、日常对话、正常语气、平淡陈述、无法判断情绪时。这是首选，大部分行应使用此标注** |
| **高兴** | 角色明显在笑、开心、得意、宠溺、甜蜜、调侃、嬉笑等正向愉悦情绪 |
| **悲伤** | 角色明显在哭、心痛、心酸、哽咽、绝望、苦涩、心碎等伤感情绪 |
| **愤怒** | 角色明显在发怒、指责、威胁、冷怒、暴怒、咬牙切齿等怒意情绪 |
| **害怕** | 角色明显在害怕、紧张、不安、慌张、焦急、惶恐等恐惧情绪 |
| **厌恶** | 角色明显在嫌弃、鄙视、反感、不屑、冷漠等排斥情绪 |
| **惊讶** | 角色明显在震惊、意外、不敢相信、目瞪口呆、恍然大悟等意外情绪 |
| **中性** | 角色刻意压抑情绪、故作冷淡、疏离客套、公事公办等有意为之的平淡语气 |
| **生动** | 角色夸张表达、戏剧化叙述、强调重点、活泼俏皮时使用 |
| **低语** | 角色小声说话、私密交流、秘密告知、小声嘀咕、欲言又止时使用 |

#### ⚠️ "默认"与"中性"的区别
- **默认**：没有特别情绪、正常说话、无法判断时的兜底选项。**大部分行都应该用"默认"**
- **中性**：角色**刻意**表现出的冷淡、疏离、压抑，是一种**有意为之**的情绪表达

#### ⚠️ 严格禁止
- ❌ 不可自创情绪词（如"咬牙切齿""笑意盈盈""傲娇""苦涩"等）
- ❌ 不可组合情绪词（如"愤怒悲伤""高兴惊讶"等）
- ❌ 不可使用列表外的任何情绪词
- ❌ 遇到复杂情绪时，选择最接近的一个固定情绪，而非自创

#### 旁白情绪（固定）
