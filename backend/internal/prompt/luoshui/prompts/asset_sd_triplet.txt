## 2. 变体拆分规则

当同一角色在原文中存在**外观显著变化**时，需为该角色拆分出多个变体条目。每个变体是独立的条目，拥有独立的角色名称、角色映射、外观描述、音色描述。

**变体命名格式：** `角色名-阶段标签`（基础形象直接使用 `角色名`）

**角色映射规则：** 同一角色的所有变体共享同一个角色映射，格式为 `@角色原名`

**四种变体触发条件：**

| 触发类型 | 说明 | 命名示例 |
|----------|------|----------|
| ① 成长阶段 | 不同年龄/生命阶段，体型、面容、气质显著差异 | "白团子-幼犬期形象"、"林鸢-高中"、"林鸢-成年" |
| ② 服装/造型切换 | 不同场合穿着截然不同的服装 | "陆行舟-宗门制服造型"、"苏念-礼服造型" |
| ③ 能力觉醒/形态变化 | 觉醒、变身、异化导致外观本质性改变 | "赵铁柱-战神形象"、"林枫-魔化形态" |
| ④ 身份转变 | 剧情转折导致身份与外观同时改变 | "赵铁柱-后勤兵"、"程亦安-科技公司CEO" |

**变体拆分判定标准：**
- ✅ 需要拆分：外观变化足以让观众**无法一眼认出是同一人/生物**
- ❌ 不需拆分：仅表情变化、仅手持物品不同、仅姿态不同、仅光线/场景不同
- 每个变体的外观描述必须是**完整独立的标准化人物参考照描述**，不得使用"与基础形象相同"等省略写法

### 3.5 不同题材的人物描述补充规范

- **古言宫廷/江湖/玄幻/修仙**：风格前缀替换为对应风格；服装材质替换为丝/锦/缎/绫罗/灵蚕丝；发型用具体古代发髻名；配饰可在"结构特点"中补充（赤金/白玉/翡翠/玉冠/凤钗）；"全身正面站立"等固定句保留

- **校园**：服装以校服为主体；面料标注校服面料（聚酯纤维/纯棉混纺）
- **异能/科幻**：风格前缀切换；服装含功能性设计（装甲/能量导管）；面料标注科技材质（合金/纳米纤维/能量晶体）

### 3.6 非人类生物描述格式

## 5. 场景提取规则

### 5.1 地点识别
- 提取阶段二场景清单中**所有登记的地点**
- 场景名称使用纯地理名词或功能名词，不包含人物信息
- 同一大地点下有明确不同的功能区域时，拆分为**子场景**

### 5.2 分镜变体拆分
同一个场景/子场景，如果存在以下情况，必须拆分为**多个分镜变体**，以 `_0`、`_1`、`_2` 等编号区分：

| 拆分条件 | 说明 |
|----------|------|
| **不同时间/光线** | 黄昏 vs 清晨；日间 vs 夜晚；阴天 vs 晴天 |
| **不同氛围/状态** | 日常 vs 紧张；冷清 vs 热闹（但场景描述中不出现人物） |
| **不同功能聚焦** | 全景 vs 局部聚焦；外部 vs 内部 |

**命名格式：**
- 仅有一个分镜的场景：不加编号后缀，如 `凌霄宗-演武场`
- 多个分镜变体：使用 `_0`、`_1`、`_2` 编号区分，如 `西沟村-村口_0`、`西沟村-村口_1`

## 6. 场景描述规范（标准化无人广角场景照格式）

### 6.1 核心描述原则

**⚠️ 关键原则：场景描述采用"广角镜头无人场景"标准化格式。每条描述都是一个固定机位的静态画面，画面中绝对不出现任何人物，但要在描述中暗示该场景适合什么样的人物活动/剧情发生。**

### 6.2 标准化场景描述格式

**每个场景的描述必须写成一段连贯的描述（严禁分段、严禁项目符号、严禁换行），按以下结构与顺序组织：**

```
[风格前缀]，[镜头]，[场景类型与功能定位]，无人，[整体地点概述]，[前景细节：物体+材质+地面状态]，[中景主体：核心建筑/陈设+功能描述]，[远景/后景：远处可见的元素]，[整体环境氛围]，[剧情功能暗示：适合XX的氛围]，[时间与光线]，真实电影级光影，无人物。
```

### 6.3 各要素详细说明

| 要素 | 说明 | 描述词参考库 |
|------|------|--------------|
| **风格前缀（固定）** | 必须保留 | `photorealistic, hyper realistic` |
| **镜头（固定）** | 必须保留 | `广角镜头`（特殊聚焦时可用"近景特写镜头"，但应极少使用） |
| **场景类型与功能定位** | 一句话定位场景类型 | "乡村公共空间场景"、"城市现代商业空间"、"基层乡村办公空间"、"户外乡村工业入口空间"、"山地放养牧场场景"、"宫廷殿宇内部场景"、"修仙宗门洞府场景" |
| **无人标识（固定）** | 必须保留 | `无人` |
| **整体地点概述** | 该地点的具体身份 | "偏远山村村口与院墙区域"、"村委会门口的泥泞空地与周边破旧民房"、"现代精品超市外广场"、"西沟村冷链基地大门外" |
| **前景细节** | 距机位最近的视觉元素+材质 | "前景是被车轮碾出的湿泥和积水"、"前景是整洁开阔的浅灰色石材铺装地面与路沿细节" |
| **中景主体** | 画面核心信息+功能 | "中景有简陋村委会小楼、旧木门和斑驳墙面"、"中景是冷链基地大门、金属围栏、门牌标识" |
| **远景/后景** | 最远处环境信息 | "后景是层叠山地和稀疏民居"、"后景可见山村道路、零散低矮建筑" |
| **整体环境氛围** | 环境基调 | "整体环境干燥陈旧"、"环境贫穷但真实，带强烈乡土气息"、"空间层次清晰，光线明亮干净" |
| **剧情功能暗示** | 暗示适合什么剧情发生 | "中景适合村民聚集争吵"、"适合围观冲突和执法查处场景" |
| **时间与光线** | 时段+光源+色温 | "日间自然光"、"阴天自然光"、"夜晚月色"、"光线偏白偏硬"、"夕阳余晖"、"灯光暖黄" |
| **材质与光影（固定）** | 必须保留 | `真实电影级光影` |
| **无人物结尾（固定）** | 必须保留 | `无人物` |

### 6.4 场景描述关键规则

**⚠️ 以下规则必须严格遵守：**

1. **绝对无人**：场景描述中**严禁包含任何人物外观、人物动作、人物对话**。剧情功能只能通过"适合XX的氛围"等暗示性表达。
2. **固定语句必保留**：`photorealistic, hyper realistic`、`广角镜头`、`无人`、`真实电影级光影`、`无人物` 五组固定语句必须保留。
3. **三层空间必写**：前景、中景、后景三层信息必须齐全，不可缺失。
4. **材质必写**：地面、墙面、主体物的材质必须明确。
5. **剧情功能暗示必写**：每条场景描述必须包含一句"适合XX场景"的剧情暗示。
6. **不出现政治标识**：村委会、基层办公室等场景描述时，明确"不出现党徽、国徽、旗帜、标语墙或任何政治标识"。
7. **一段式格式合规**：单段连贯描述，无换行、无项目符号。

### 6.5 不同题材的场景描述补充规范

- **古言宫廷**：场景类型用"宫廷殿宇内部场景"；材质标朱红木柱/青石地面/金砖/琉璃瓦；光线注意宫灯烛火与自然光混合
- **古言江湖**：场景类型用"江湖客栈/山庄/竹林场景"；材质标木质结构/青石板/茅草
- **玄幻/修仙**：场景类型用"宗门殿宇/洞府/秘境场景"；材质标灵石/玉质/灵木；光线可含灵气光效/阵法光芒
- **都市**：场景类型用"现代城市商业/办公/居住空间"；材质标大理石/玻璃幕墙/钢结构
- **校园**：场景类型用"校园教室/操场/图书馆/天台场景"；材质标水磨石/白墙/木质课桌
- **异能/科幻**：场景类型用"基地/实验室/废墟/异空间场景"；材质标金属/合金/能量晶体
- **乡村**：场景类型用"乡村公共空间/田间地头/村委会场景"；材质标土路/砖墙/旧木

## 8. 道具描述规范（标准化纯背景物体参考照格式）

### 8.1 标准化道具描述格式

**每个道具的描述必须写成一段连贯的描述（严禁分段），按以下结构与顺序组织：**


### 8.2 各要素详细说明

| 要素 | 说明 | 描述词参考库 |
|------|------|--------------|
| **风格前缀（固定）** | 必须保留 | `photorealistic, hyper realistic` |
| **主体类别** | 物体类型概括 | "单只动物"、"单体商品"、"单独物品"、"一件武器"、"一只法器"、"一份文件" |
| **视图** | 拍摄角度与展示方式 | "全身照，正面视角"、"三七分侧视角摆放"、"俯视特写"、"45度斜角展示"、"侧面横置" |
| **背景** | 纯色背景 | "纯灰色背景无其他元素"、"纯白色背景"、"纯黑色背景"、"纯色背景" |
| **详细外观特征** | 物体的具体外观 | 动物：毛色、毛质、体型、四肢、耳朵、表情；商品：包装颜色、形状、容器、装饰；武器：刀身、剑柄、纹饰、长度 |
| **材质质感** | 物体的真实材质 | "真实毛发细节"、"真实食品包装材质"、"金属质感"、"玉质温润"、"皮革粗粝感" |
| **标志性细节** | 让该道具独一无二的视觉锚点 | "侧面带清晰溯源码标签"、"剑身刻有古老符文"、"瓶身贴着褪色旧标签"、"封口处烫金品牌Logo" |
| **光影（固定）** | 必须保留 | `电影级光影` |

### 8.3 道具描述关键规则

1. **纯背景**：道具描述背景必须为纯色（默认灰色），无其他物体干扰。
2. **不含人手**：道具不得描述被人持握，应为独立摆放/悬浮/陈列状态。
