你的任务是将给定小说内容划分为角色和内容，并输出为结构化剧本格式。

步骤1：完整阅读文案中的小说内容
===========================================
分析小说的大致剧情，分析小说题材，提取出角色信息

===========================================
步骤2：阅读下面规则
===========================================

## 一、台词识别规则

1. 提取角色对话内容。识别所有带引号（""）、破折号（——）、感叹号（！）、冒号（：）等常见台词标记的文本。
2. 若角色在已知角色列表`<possible_characters>`中，则直接使用该角色名；若不在列表中，则根据上下文合理判断角色身份。
3. **相邻台词如属同一角色，必须合并为一条，无字数上限**。
4. **取消单条台词150字上限限制**——无论多长都保留为一整条，不得拆分。

## 二、旁白识别规则

1. 所有非台词的叙述性内容（包括心理活动、环境描写、动作描写、场景过渡等）均标记为"旁白"。
2. **相邻的旁白内容必须合并为一条整段，无字数上限**。哪怕连续几百字全是旁白，也只能是一段，不得拆分。
3. **取消单条旁白150字上限限制**。
4. 排版结构遵循：**一段旁白 → 一段台词 → 一段旁白 → 一段台词** 的交替形式（除非连续多人对话）。

## 三、⚠️ 智能整理规则（核心新增）

### 规则1：删除不必要内容（净化文本）
整理时**主动删除**以下内容：
- ❌ **粗俗骂人话**：脏字、人身攻击性词汇、低俗辱骂等
- ❌ **男女调情类描写**：暧昧挑逗、肉麻情话、亲密身体描写等
- ❌ **冗余无意义动作**：不影响剧情理解的小动作（如"他摆摆手""他端起酒杯""她撩了撩头发"等）
- ❌ **对剧情推进无用的环境/动作描写**

### 规则2：对话中夹动作的处理（上移或删除）

当遇到 **"台词"+动作描写+"台词"** 的句式时：

#### 情况A：动作有用 → **上移合并**到前一段旁白中
**示例：**
```
原文：
"这次的事，其实是个试探，我想看看你到底是个什么样的人。"
我心里咯噔一下。
"你别紧张。"他摆摆手，"不是针对你，我习惯这么干。"

整理后：
旁白：我心里咯噔一下。他摆摆手，
台词：你别紧张。不是针对你，我习惯这么干。
```
（动作"他摆摆手"被上移合并到旁白中，原本断开的台词合并为一句）

#### 情况B：动作无用 → **直接删除**
**示例：**
```
原文：
"谢谢领导。"
"别谢来谢去的了。"他端起酒杯，"吃饭。"

整理后：
台词：谢谢领导。
台词：别谢来谢去的了。吃饭。
```
（动作"他端起酒杯"对剧情无影响，直接删除，前后台词合并）

### 规则3：判断动作"有用/无用"的标准

| 类型 | 处理 | 举例 |
|------|------|------|
| 反映情绪/态度的动作 | **上移保留** | 他冷笑一声、她皱起眉头、他猛地站起来 |
| 推动剧情的动作 | **上移保留** | 他掏出一把枪、她递过来一份文件 |
| 纯过渡性小动作 | **直接删除** | 他端起酒杯、她撩了撩头发、他摆摆手（语境不重要时） |
| 重复性废话动作 | **直接删除** | 他笑了笑（已通过台词体现高兴时） |

## 四、⚠️ 情绪标注系统（Minimax专用·核心规则）

### 总则
1. **每一行剧本必须标注情绪**，无例外（包括旁白）。
2. **旁白的情绪永远是"默认"**，不可更改。
3. 情绪标注写在类型标签与冒号之间的括号内，如：`角色名-台词(愤怒)：内容`、`旁白(默认)：内容`
4. **只能从以下固定10种情绪中选取，严禁自创情绪词。**
5. **无法判断或不确定时，一律使用"默认"。**
6. **日常对话、普通语气的台词/内心也应使用"默认"，只有情绪明确强烈时才使用其他情绪。**

### 固定情绪列表（仅限以下10种，不可增加、不可自创、不可组合）

| 情绪 | 适用场景 |
|------|---------|
| **默认** | **日常对话、正常语气、平淡陈述、无法判断情绪时。这是首选，大部分台词应使用此标注** |
| **高兴** | 角色明显在笑、开心、得意、宠溺、甜蜜、调侃、嬉笑等正向愉悦情绪 |
| **悲伤** | 角色明显在哭、心痛、心酸、哽咽、绝望、苦涩、心碎等伤感情绪 |
| **愤怒** | 角色明显在发怒、指责、威胁、冷怒、暴怒、咬牙切齿等怒意情绪 |
| **害怕** | 角色明显在害怕、紧张、不安、慌张、焦急、惶恐等恐惧情绪 |
| **厌恶** | 角色明显在嫌弃、鄙视、反感、不屑、冷漠等排斥情绪 |
| **惊讶** | 角色明显在震惊、意外、不敢相信、目瞪口呆、恍然大悟等意外情绪 |
| **中性** | 角色刻意压抑情绪、故作冷淡、疏离客套、公事公办等**有意为之**的平淡语气 |
| **生动** | 角色夸张表达、戏剧化叙述、强调重点、活泼俏皮时使用 |
| **低语** | 角色小声说话、私密交流、秘密告知、小声嘀咕、欲言又止时使用 |

### "默认"与"中性"的区别
- **默认**：没有特别情绪、正常说话、无法判断时的兜底选项。**大部分台词都应该用"默认"**
- **中性**：角色**刻意**表现出的冷淡、疏离、压抑，是一种**有意为之**的情绪表达

### 情绪选择指南

**默认原则：大部分情况使用"默认"。只有情绪非常明确且强烈时，才切换到其他情绪。**

| 场景判断 | 选择 |
|---------|------|
| 正常说话、日常对话 | 默认 |
| 无法判断是什么情绪 | 默认 |
| 角色明显在笑、开心、得意、撒娇 | 高兴 |
| 角色明显在哭、心痛、绝望 | 悲伤 |
| 角色明显在发怒、指责、威胁 | 愤怒 |
| 角色明显在害怕、紧张、慌乱 | 害怕 |
| 角色明显在嫌弃、鄙视、反感 | 厌恶 |
| 角色明显在震惊、意外、不敢相信 | 惊讶 |
| 角色刻意压抑、故作冷淡、疏离客套 | 中性 |
| 角色在夸张表达、俏皮活泼 | 生动 |
| 角色在小声说、私密交流 | 低语 |

### ⚠️ 严格禁止
- ❌ 不可自创情绪词（如"咬牙切齿""笑意盈盈""傲娇""苦涩""得意""冷笑""讽刺""温柔""撒娇"等）
- ❌ 不可组合情绪词（如"愤怒悲伤""高兴惊讶"等）
- ❌ 不可使用以上10种以外的任何情绪词
- ❌ 遇到复杂情绪时，选择最接近的一个固定情绪，而非自创

## 五、特殊情况处理

1. 多角色连续对话时，确保每条台词对应正确角色，避免角色错配。
2. 当段落中混合出现旁白与台词时，应拆分为独立记录：旁白合并为一整段，台词合并为一整段。
3. 输出结果不得出现遗漏、重复、合并错误的情况，**剧情主线必须100%完整**。
4. **整理操作仅限于：① 删除骂人/调情/废动作；② 上移有用的动作描写。其他原文内容必须100%保留。**
5. 台词与台词之间如属同一角色，必须合并；旁白与旁白之间必须合并为整段。

===========================================
步骤3：输出提取内容
===========================================

只有三种格式类型：

| 类型 | 格式写法 | 说明 |
|------|----------|------|
| 旁白 | `旁白(默认)：内容` | 叙述性内容，**情绪固定为"默认"**，**整段合并不限字数** |
| 台词 | `角色名-台词(情绪)：内容` | 角色说出口的话，**必须标注情绪**，**同角色相邻台词合并不限字数** |
| 内心 | `角色名-内心(情绪)：内容` | 角色内心独白，**必须标注情绪** |

格式规范：
- **每条旁白/台词无字数上限**，整段合并输出
- 旁白情绪固定为"默认"
- 台词和内心必须标注情绪
- **情绪仅限10种：默认/高兴/悲伤/愤怒/害怕/厌恶/惊讶/中性/生动/低语**
- 不确定就用"默认"
- 台词不加引号
- 排版采取**一段旁白一段台词交替**的形式

### 示例对照

**原文：**
```
我抬起头看她。她还是那副样子，眼珠子瞪得溜圆，脸红脖子粗，一副要吃人的架势。前世我就是被她这副架势吓住了。她太会吵了，嗓门大，气势足，一句接一句根本不给人插嘴的机会。我当时被她吵得脑仁疼，又觉得她说的好像都对。找不到反驳的话，只能听她的。结果呢？结果我女儿死了，她把钱败光跑了。我从医院楼顶跳下去的时候，脑子里全是女儿临死前那张惨白的小脸。此时她往前逼进了一步，
"你看什么看？我告诉你，这事儿没商量！五十万太多，最多送两条烟，你领导爱要不要！"
沉默了几秒后，我才开口：
"我决定了，不送五十万。送七十万。"
她还以为自己听错了。
"你说什么？七十万？你发什么神经？"
"我没发神经。"
"没发神经你送七十万？你是不是让谁给洗脑了？啊？难道你领导给你下药了？"
她越说越激动，手指快戳到我脸上。我把她的手拨开：
"我心里有数。"
她声音尖得能把房顶掀了，
"七十万你知道是多少吗？女儿手术费要多少你知道吗？钱都送出去了，女儿怎么办？你让她等死？"
```

**输出：**
```
===== 剧本正文 =====

她-台词(愤怒)：你看什么看？我告诉你，这事儿没商量！五十万太多，最多送两条烟，你领导爱要不要！

旁白(默认)：沉默了几秒后，我才开口：

我-台词(默认)：我决定了，不送五十万。送七十万。

旁白(默认)：她还以为自己听错了。

她-台词(惊讶)：你说什么？七十万？你发什么神经？

我-台词(默认)：我没发神经。

她-台词(愤怒)：没发神经你送七十万？你是不是让谁给洗脑了？啊？难道你领导给你下药了？
```

✅ **每条台词和内心都标注了情绪**
