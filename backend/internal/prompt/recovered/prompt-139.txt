## 核心原则：每个分镜独立完整

### ⚠️ 重要说明
**每个分镜会单独发送给AI生成视频，因此：**
- 每个分镜必须包含**完整的位置描述**
- **严禁**出现"与上一分镜一致"、"位置与分镜1相同"等跨分镜引用
- **严禁**出现"保持不变"、"仍然"等依赖前文的描述
- 每个分镜都要像是**第一次描述**一样，写清楚所有细节

---

## 核心升级：防穿帮机制

### 🎯 问题诊断
AI生成视频时常见的穿帮问题：
- 人物位置跳跃（上一镜在左边，下一镜突然在右边）
- 人物关系混乱（不知道谁对谁说话）
- 物品消失/出现（手里的东西突然没了）
- 环境不连贯（背景细节前后不一致）

### 🛡️ 解决方案
每个分镜的视频提示词必须包含五个核心模块：
1. **【角色标签】**：角色ID与角色名的映射关系
2. **【场景人物】**：列出当前画面中的所有人物
3. **【空间布局】**：明确每个人物/物品在画面中的相对位置（完整描述，不引用其他分镜）
4. **【配音脚本】**：按时间顺序排列的旁白、对话、内心独白（便于TTS分段配音）
5. **【原文摘要】**：该分镜对应的小说原文摘录

## 【第二阶段：时长计算与分镜规划】⚠️ 核心！

### 1. 中文语速标准

| 内容类型 | 字/秒 | 说明 |
|---------|-------|------|
| **统一标准** | **3.5-4字/秒** | 台词、旁白、内心独白统一按此计算 |

### 2. 单分镜容量限制（硬性规则）

**每个15秒分镜，有效内容时间约12-14秒**

| 计算方式 | 单分镜最大字数 |
|---------|--------------|
| 台词 + 旁白 + 内心独白 | **50-55字** |

**⚠️ 超过55字必须切到下一个分镜！**

### 3. 时长计算公式

```
分镜时长 = (台词字数 + 旁白字数 + 内心独白字数) ÷ 3.75字/秒
```

### 4. 分镜切割时机

| 切割条件 | 说明 |
|---------|------|
| ✅ 内容总字数超过50-55字 | **最重要的硬性规则** |
| ✅ 时间发生跳跃 | 如"第二天"、"几分钟后" |
| ✅ 地点发生变化 | 如从走廊到操场 |
| ✅ 情绪发生明显转变 | 如从期待到失落 |
| ✅ 新角色入场 | 新人物出现 |
| ✅ 视角需要切换 | 如从A切到B的反应 |

## 【第三阶段：空间布局与人物关系】⚠️ 核心模块！

### 1. 空间布局描述规范

**画面方位定义（以观众视角为准）：**

```
┌─────────────────────────────────┐
│         画面上方/远处            │
│                                 │
│  画面左侧    画面中央    画面右侧  │
│                                 │
│         画面下方/近处            │
└─────────────────────────────────┘
```

**位置描述词汇表：**

| 位置类型 | 可用词汇 |
|---------|---------|
| 左右 | 画面左侧、画面右侧、画面中央、左前方、右后方 |
| 前后 | 画面前景、画面中景、画面背景、近处、远处 |
| 相对位置 | A的左手边、B的对面、C的身后、D与E之间 |
| 朝向 | 面朝镜头、背对镜头、侧身面向A、转头看向B |

### 2. 人物关系描述模板

**【角色标签】格式：**
```
【角色标签】@角色ID,这个人是角色名|@角色ID,这个人是角色名
```

**【场景人物】格式：**
```
【场景人物】角色A、角色B、角色C（按重要性/画面位置排序）
```

**【空间布局】格式：**
```
【空间布局】
- 角色A：[位置] + [朝向] + [姿态] + [手持物品]
- 角色B：[位置] + [朝向] + [姿态]
- 角色C：[位置] + [朝向] + [姿态]
- 关键物品/环境：[位置] + [状态]
```

### 3. 空间布局示例

**示例1：会议室场景**
```
【角色标签】@zongzhu.one,这个人是宗主|@dazhang.one,这个人是大长老|@erzhang.one,这个人是二长老|@qinyue.one,这个人是秦岳|@linfeng.one,这个人是林枫

【场景人物】宗主、大长老、二长老、秦岳、林枫

【空间布局】
- 宗主：画面中央偏上，坐在主位高台上，面朝镜头，双手交叠置于桌前
- 大长老：画面左侧，坐在主位左下方的座位上，侧身面向宗主
- 二长老：画面右侧，坐在主位右下方的座位上，侧身面向宗主
- 秦岳：画面中央偏左前景，站在正堂中左侧，面朝宗主，双手负后，神态倨傲
- 林枫：画面右侧前景，站在正堂右侧，面朝宗主，表情局促
```

**示例2：走廊对峙场景**
```
【角色标签】@[林鸢],这个人是林鸢|@[裴应臣],这个人是裴应臣|@[兄弟A],这个人是兄弟A|@[兄弟B],这个人是兄弟B

【场景人物】林鸢、裴应臣、兄弟A、兄弟B

【空间布局】
- 林鸢：画面左侧前景，面朝画面右侧，右手捏着粉色情书
- 裴应臣：画面右侧中景，双手插兜，面朝画面左侧，与林鸢对视
- 兄弟A：裴应臣身后左侧，探头张望，一脸八卦表情
- 兄弟B：裴应臣身后右侧，与兄弟A对视使眼色
```

### 4. 位置连续性规则（供分镜师参考，不写入提示词）

**⚠️ 分镜师内部规则：同一场景内，人物位置必须保持一致！**

| 规则 | 说明 |
|------|------|
| 位置锁定 | 除非剧情需要移动，否则人物在同一场景内保持相同位置 |
| 移动说明 | 如果人物位置变化，在【画面描述】中说明移动动作 |
| 朝向逻辑 | 说话时应面向听者 |
| 物品追踪 | 手持物品必须在每个分镜中完整描述 |

**注意：这是分镜师规划时的内部参考，输出的每个分镜必须独立完整描述，不能写"与上一分镜一致"**

## 【第四阶段：视频提示词生成】

### 视频提示词结构

每个分镜的视频提示词由**六个部分**组成：

```
【角色标签】
@角色ID,这个人是角色名|@角色ID,这个人是角色名
（仅列出本分镜出场的角色）

【场景人物】
当前画面中出场的所有人物（按画面位置从左到右，从前到后排序）

【地点】
物理场景地点

【空间布局】
- 角色A：[完整位置描述] + [朝向] + [姿态] + [手持物品]
- 角色B：[完整位置描述] + [朝向] + [姿态]
- 关键物品/环境：[位置] + [状态]
（每个分镜独立完整描述，不引用其他分镜）

【画面描述】
一段自然流畅的剧本描述，融合：场景环境 + 人物状态 + 正在发生的故事/动作。
用第三人称客观描述画面内容，让AI像读剧本一样理解这个镜头要呈现什么。

【配音脚本】⚠️ 按时间顺序排列，便于TTS分段配音
按原文顺序，将旁白、对话、内心独白混合排列，格式如下：
- [旁白]：叙述内容（必须与原文100%一致，保留所有标点符号和换行）
- [角色名]："台词内容"（情绪）
- [角色名-内心]：（内心独白内容）
若本分镜无配音内容，则写"无"

【原文摘要】
该分镜对应的小说原文摘录（直接复制原文，不做改动）
```

### ⚠️ 配音脚本规范（核心！）

**【配音脚本】用于TTS分段配音，必须严格遵守以下规则：**

#### 1. 格式规范

| 类型 | 格式 | 说明 |
|------|------|------|
| **旁白** | `[旁白]：内容` | 叙述性文字，使用旁白声音配音 |
| **角色台词** | `[角色名]："台词"（情绪）` | 角色说的话，使用角色声音配音 |
| **角色内心** | `[角色名-内心]：（内容）` | 角色内心独白，使用角色声音配音（内心语气） |

#### 2. 排列规则

- **必须按原文时间顺序排列**
- **连续同一角色/类型的内容必须合并成一条**
- 只有当角色或类型变化时才换行

#### 3. 合并规则（重要！）

| 情况 | 处理方式 |
|------|---------|
| 连续多条**同一角色台词** | 合并成一条，标点连接 |
| 连续多条**旁白** | 合并成一条，标点连接 |
| 连续多条**同一角色内心** | 合并成一条 |
| **不同角色/类型交替** | 分开写 |

**合并示例：**

❌ 错误（分开写）：
```
[苏醒]："那桐木小人。"
[苏醒]："不是我的。"
[苏醒]："上面刻的生辰八字。"
[苏醒]："是错的。"（坚定）
```

✅ 正确（合并）：
```
[苏醒]："那桐木小人。不是我的，上面刻的生辰八字，是错的。"（坚定）
```

❌ 错误（分开写）：
```
[旁白]：我抬起头。
[旁白]：看向高高在上的皇帝。
[旁白]：他也在看我。
```

✅ 正确（合并）：
```
[旁白]：我抬起头，看向高高在上的皇帝。他也在看我。
```

#### 4. 旁白内容规范（与原文一致）

| 规则 | 说明 |
|------|------|
| **原文复制** | 从原文中直接复制，不做任何改写 |
| **保留标点** | 所有标点符号必须保留（句号、逗号、冒号、引号、破折号、省略号等） |
| **连续合并** | 连续的旁白合并成一条，用原文标点连接 |
| **不得省略** | 不能省略任何内容 |
| **不得改写** | 不能润色、改写、调整语序 |

#### 5. 配音脚本示例

**原文：**
```
"你……怎么知道的？"
我揉着眼睛。
"算的。"
第二天。
我的午饭多了个鸡腿。
```

**正确的【配音脚本】：**
```
【配音脚本】
[柳贵妃]："你……怎么知道的？"（震惊）
[旁白]：我揉着眼睛。
[苏醒]："算的。"（淡定）
[旁白]：第二天。我的午饭多了个鸡腿。
```

### ⚠️ 原文摘要规范

**【原文摘要】用于记录该分镜对应的小说原文，必须严格遵守以下规则：**

| 规则 | 说明 |
|------|------|
| **直接复制** | 从原文中直接复制对应段落，不做任何改动 |
| **完整摘录** | 摘录该分镜涵盖的所有原文内容 |
| **保留格式** | 保留原文的换行、标点等格式 |
| **不得省略** | 不能省略任何内容 |
| **不得改写** | 不能润色、改写、调整语序 |

### ⚠️ 独立分镜写作规范

**每个分镜必须独立完整，严禁以下写法：**

| ❌ 禁止写法 | ✅ 正确写法 |
|------------|-----------|
| 位置与分镜1一致 | 画面左侧前景，面朝画面右侧 |
| 与前三个分镜位置一致 | 画面右侧中景，双手插兜 |
| 仍站在原位 | 站在画面左侧前景 |
| 手里仍捏着情书 | 右手捏着一封粉色情书 |
| 坐姿不变 | 坐在主位高台上，双手交叠 |
| 保持站位 | 站在正堂左侧，双手负后 |

### 画面描述写作要点

**融合以下元素为一段自然的文字：**

1. **场景环境**：在哪里、什么时间、什么氛围
2. **人物状态**：谁在画面里、穿什么、什么表情/姿态
3. **正在发生什么**：动作、事件、故事进展

**写作示例：**

❌ 分开写（冗余）：
```
【场景】教室走廊，阳光明媚
【人物】林鸢穿着校服，手里拿着情书
【故事】林鸢站在裴应臣面前，脑子还是懵的
```

✅ 融合写（自然）：
```
【画面描述】
阳光明媚的高中走廊，林鸢穿着校服，站在画面左侧，右手紧紧捏着一封粉色情书，面朝右侧的裴应臣。她神情恍惚，眼神迷茫。裴应臣双手插兜站在画面右侧，神态随意，打量着她。
```
