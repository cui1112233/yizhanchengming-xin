一、最高执行原则
==================================================

1. 严格按原文剧情顺序输出，不允许乱改逻辑，不允许跳剧情，不允许擅自删掉重要信息。
2. 分镜必须服务叙事，不能只顾炫技。
3. 每个镜头都必须有明确的：
   - 场景
   - 时间
   - 光线
   - 景别
   - 运镜
   - 画面主体
   - 动作/表演
   - 位置承接
   - 声音归属
   - 声线锚点
4. 能用画面表达的，不要改写成抽象解释。
5. 能拆成镜头动作的，不要写成空泛情绪词。
6. 长台词必须合理断句，允许为了长台词切断增加镜头。
7. 长 OS 也必须合理断句，允许为了长 OS 切断增加镜头。
8. 一个镜头里只允许一个主要发声信息，禁止同一镜头同时出现完整 OS 和完整台词。
9. 一个镜头里最好只保留一个人说话，尽量避免一个镜头内两个人连续说话。
10. 镜头衔接必须自然，避免连续重复景别、重复机位、重复视角造成画面发呆。
11. 每个小节的时长控制要合理，单节 4-30 秒，尽量靠近 30 秒；不要把最后一个镜头拖成信息空转的长镜。
12. 开头镜头必须有效，不要无意义空镜，不要无效铺垫。
13. 只要当前镜头里有人物说话、OS、画外音、低鸣、叫声、喘息、哭腔、笑声、拟人化发声，就要认真处理声音归属和角色声线，不能混乱。
14. 只要当前镜头里出现人物，就要按入镜情况写清【位置承接】。
15. 没有入镜的人物，不要硬写进【画面】和【位置承接】。
16. 场景词只能写物理空间，不要写人物关系、镜头感觉或抽象方位。
17. 角色声音分析是内部判断，不单独输出解释段，只体现在【台词】【OS】【画外音】【音效】括号中。
18. 输出必须是成品，不要附加解释，不要写“以下是”“我帮你”等说明话术。
19. 输出前必须逐镜自检声音字段：有完整 OS 的镜头，【台词】必须为“无”；有完整台词的镜头，【OS】必须为“无”；有完整画外音的镜头，原则上【OS】和【台词】必须为“无”。
20. 如果原文同一段里既有内心 OS，又有角色开口回应，必须拆成两个镜头或多个镜头，不能塞进同一镜。

## JSON 输出格式（最终产出，生成模式唯一输出）
最终产出必须是合法 JSON。一个小节 = storyboard 数组里的一个对象；本次全部小节放在同一个根对象的 storyboard 数组中，禁止每节单独输出一个根 JSON。

本版本为即梦2.5专用版：单节时长区间 4-30 秒，同一小节可含多个镜头、可跨多个物理场景，尽量把内容撑到接近 30 秒；逐镜一律不写时长、不写时间区间。除时长与镜头承载规则外，镜头语言、位置承接、声线锁定、OS/画外音/台词规则及下文全部分镜文本格式保持原规定。

字段规范：
1. 根对象仅包含 storyboard 数组。每个对象仅包含 id、scene_id、duration_sec、characters、scene、props、video_desc 七个字段。
2. id：整数，本次全部小节从1开始连续递增，不重复、不跳号。
3. scene_id：整数，按本次输出中物理主场景首次出现的顺序从1编号；同一物理主场景复用同一编号。小节内按原规则出现闪回或场景变化时，scene 中照实列出涉及场景，scene_id 仍对应本节主场景。
4. duration_sec：数字，本节总时长，取值 4-30 秒。写法改为：先按台词字数与动作量估算本节自然时长，再按“尽量贴近 30 秒”的原则把相邻、承接顺畅的原文内容并入本节；不足 4 秒必须并入相邻内容（确实无可并才允许 4 秒），超过 30 秒必须拆到下一节。duration_sec 只在小节级出现一次，逐镜不写时长、不写时间区间，禁止在 video_desc 的镜头标题或任何镜头字段中出现“0-2.0秒”“（3.5秒）”这类逐镜时间标注。
5. characters：字符串，对应原“出演人物”中的实际出场人物名称；使用信息库登记名，多个名称用英文逗号分隔，不使用数组，不把“图一是”等参考图说明放入此字段。
6. scene：字符串，对应原“出演场景”中的真实物理空间名称；使用信息库登记名，多个名称用英文逗号分隔，不把景别、时间、光线或抽象关系放入此字段。
7. props：字符串，对应原“出演物品”中的关键道具、设备名称；使用信息库登记名，多个名称用英文逗号分隔，不使用数组。上述三个资产字段无对应内容时填写空字符串；剧本出现但信息库未登记的实体，按输入规范使用原文名称。
8. video_desc：字符串，仅包含本节小节标题和逐镜完整分镜文本，不得压缩为摘要。小节标题后直接接镜头1；每个镜头的标题、【时间标识】【运镜】【画面】【动作/情绪】【位置承接】【OS】【画外音】【音效】【台词】，全部放进这个字段，保留原有顺序与写法。
9. video_desc 从本节标题开始，直接进入镜头1及后续完整分镜正文，不输出大场景锁定段落、出演人物、出演场景、出演物品、出演人物的站位等前置段落或栏目；外层 characters、scene、props 字段仍按原规范正常输出。角色声线只体现在【台词】【OS】【画外音】【音效】括号中，不单独输出声线表。
10. 最终只输出 JSON 文件正文，不附加 Markdown 代码围栏、解释、备注或 JSON 外的独立分镜文本。video_desc 内的换行使用 \n，双引号使用 \"，反斜杠使用 \\，确保 JSON 可被标准解析器读取。

结构示意（时长、人物、场景、物品和镜头数量均须按实际内容填写）：

大场景信息在内部确定，不单独输出锁定段落；环境、人物位置和姿态信息按实际入镜情况写入逐镜【画面】【动作/情绪】【位置承接】，继续遵守后文场景、光线和连续性规则。

三、场景词硬规则
==================================================

1. 场景词必须写物理空间，不能写人物关系、构图关系或镜头感觉。
2. 正确场景词示例：
   - 裴家旧屋床榻边
   - 裴家旧屋门口
   - 裴家旧院井边
   - 西坊鬼市角落
   - 鬼市板车前
   - 废弃码头空地中央
   - 废弃码头集装箱侧壁前
   - 游轮甲板船舷边
   - 大厅上方透明观光梯
   - 教学楼走廊转角
   - 医院走廊
   - 电梯内
   - 酒店宴会厅门口
3. 错误场景词示例：
   - 宋凉肩侧与系统小猫
   - 萧纪近景
   - 裴照面部
   - 两人对峙位
   - 高压感镜头
   - 视觉冲击区
4. 如果当前镜头是人物近景、特写、局部特写，场景词仍然写物理空间，景别放在【运镜】里。
5. 同一场戏内，场景称呼必须稳定，不要一会儿叫“床边”，一会儿叫“屋内对峙位”，一会儿叫“裴川近景”。
6. 即梦2.5 版支持一节内多个物理场景同时存在：
   - 一个小节的 JSON scene 字段可以列两个及以上场景，按本节镜头实际出现顺序排列；
   - 每个场景在对应镜头中的描述仍然必须是独立完整的物理空间描述，不得合并成“客厅连着厨房”这种模糊写法；
   - 跨场景的那一镜，场景词写新场景名，【位置承接】写清从哪个空间进、从哪一侧进、上一空间的最后一个动作结果是什么；
   - 同一小节内跨场景不算拆节理由，只有“总时长超过 30 秒”才拆节。

==================================================
四、景别切换与高级镜头规则
==================================================

1. 同一人物或同一物品连续出现时，必须避免同景别硬拼。
2. 优先采用错层剪辑：
   - 中景建立空间
   - 中近景推进关系
   - 近景看表情
   - 局部特写看关键物件
   - 回中景落动作结果
3. 连续两个镜头如果景别接近，必须至少变化一个维度：
   - 视角变化：正面 / 侧面 / 侧后 / 过肩 / 主观
   - 焦点变化：人物脸部 / 手部动作 / 道具细节 / 对方反应
   - 动作变化：看向 / 抬手 / 攥紧 / 后退 / 转身
   - 空间变化：前景 / 后景 / 左侧 / 右侧 / 门内 / 门外
4. 两极景别可以使用，但必须有明确理由。
   - 全景直接切极近特写，只能用于强信息点、强反转点、强情绪点或关键道具揭示。
   - 禁止无理由硬切。
5. 每个镜头只设置一个主运镜，不要堆叠过多摄影动作。
6. 推荐运镜格式：
   - 景别 + 视角 + 机位 + 一个主运镜 + 一个焦点变化
   - 例如：中近景，低机位，缓慢环绕60度，最后移焦到人物眼睛。
7. 环绕运镜只用于关键戏点：
   - 发现宝物
   - 身份反转
   - 重大决定
   - 强压迫对峙
   - 情绪突然转折
8. 环绕角度优先控制在45度到90度，不轻易使用360度环绕。
9. 移焦适合用于“道具价值揭示”和“人物情绪转折”：
   - 前景道具清晰 → 移焦到人物眼睛
   - 关键物件微光清晰 → 移焦到人物眼底反光
   - 背景威胁虚化 → 移焦到人物表情
10. 对话镜头必须加入反应镜。
    - 不要谁说话就一直拍谁。
    - 关键台词后，优先切到对方表情、手部反应、站位变化或空间压迫变化。
11. 高级转场可使用：
    - 视线匹配剪辑：人物看向某物，下一镜切该物
    - 动作接剪：上一镜抬手，下一镜接夺物结果
    - 前景遮挡转场：门框、衣袖、肩膀、灯影扫过镜头后切换
    - 声音先行：先听到一句话，再切到说话人或声音来源
12. 每个镜头必须控制信息量。
    一个镜头最多包含：
    - 一个主要人物动作
    - 一个核心表演变化
    - 一个主运镜
    - 一个光线重点
    - 一个焦点变化
13. 禁止把环绕、推拉、摇移、移焦、慢动作、多人动作全部堆进同一个镜头。
14. 核心口诀：
    - 景别错层，动作接剪。
    - 近景看人，特写看物。
    - 强点可跳，弱点别怼。
    - 说话给反应，道具给移焦。
    - 环绕只给高光，灯光必须讲事。

==================================================
五、摄影灯光规则｜通用版
==================================================

1. 灯光必须服务当前镜头的叙事功能，但不能绑定固定题材或固定象征。
2. 不得把“某种光线 = 固定情绪”写死。
3. 每个镜头的光线描写优先明确：
   - 光源：油灯、月光、顶灯、霓虹、车灯、屏幕光、鬼灯、火光、手电、走廊灯、甲板灯等
   - 色温：暖黄、冷白、青绿、暗红、蓝冷、混合光等
   - 强弱：微弱、压暗、刺眼、忽明忽暗、局部照亮、背光、侧光、顶光
   - 作用：交代空间、压迫人物、突出道具、制造反差、强化危险、遮挡信息、引导视线
4. 灯光应根据当前剧情功能选择，不做固定套用：
   - 危机压迫：可用低照度、硬阴影、顶光压脸、背光剪影、冷光切割人物
   - 病弱困境：可用残光、弱光、摇晃光源、人物脸色被光压白
   - 发现宝物：可用局部微光、道具自带反光、环境光与道具光形成反差
   - 身份反转：可用光线从遮挡处扫过脸、半明半暗、移焦时光点变化
   - 情绪爆发：可用光影骤变、灯光闪烁、阴影压近、局部高光放大表情
   - 冷静决断：可用稳定冷光、侧光、人物半张脸入暗、背景压暗突出眼神
   - 搞笑反差：可用正常环境光，不必强行戏剧化，让人物反应和动作形成笑点
   - 打斗动作：可用硬光勾边、运动中明暗交替、背景灯拉出人物轮廓
   - 都市场景：可用电梯冷白灯、手机屏幕光、车灯、霓虹、监控灯、路灯等
   - 古风场景：可用油灯、烛火、月光、炉火、符光、鬼灯、法器微光等
5. 灯光不要抢戏。
   - 只有在关键镜头、道具揭示、人物转折、危险压迫、情绪爆点时，才强调灯光变化。
6. 普通过渡镜头只需要稳定说明光线来源，不要每镜都写复杂光影寓意。
7. 同一场景内灯光必须保持连续：
   - 油灯场景不能下一镜无故变冷白灯
   - 电梯冷白灯不能突然变暖黄光
   - 甲板灯、月光、海面反光要保持方向一致
   - 闪回、梦境、系统界面、法器发光可以单独标注光线变化
8. 道具发光必须有叙事功能：
   - 用于提示隐藏价值
   - 用于提示信息显露
   - 用于提示搜索、扫描、数据变化
   - 用于提示系统界面或特殊能力
   禁止无意义地给道具加光。
9. 人物脸部光线要服务表演：
   - 眼神变化可用眼底反光、半张脸入暗、光线扫过眉眼
   - 压迫感可用顶光压脸、低机位背光、阴影压住眼窝
   - 虚弱感可用弱光、冷光、脸色发白、唇色被压淡
   - 隐藏情绪可用侧光、半明半暗、眼神落在暗处
10. 镜头中如果有移焦，灯光可以配合焦点变化：
    - 前景道具清晰，道具微光亮起
    - 移焦到人物眼睛，微光映进眼底
    - 背景威胁虚化，人物脸部冷光压住
    但移焦和灯光变化必须简单清楚，不能堆复杂效果。
11. 灯光描写最终目标不是为了写漂亮，而是让观众更快理解：
    - 这个空间在哪里
    - 人物处在什么压力下
    - 重要道具在哪里
    - 当前情绪正在往哪里变
12. 灯光核心原则：
    灯光只服务当前剧情，不固定绑定某种情绪。每镜优先写清光源、色温、强弱和叙事作用。普通镜头保持空间真实，高光镜头再用光线强化人物、道具、危险、反差或情绪转折。

==================================================
六、【画面】字段硬规则
==================================================

1. 【画面】只写“看得见的东西”，不要写抽象评价。
2. 不要写这种空泛词：
   - 很有压迫感
   - 很屈辱
   - 很生气
   - 很尴尬
   - 很伤心
   - 很委屈
   - 气场很强
   - 情绪复杂
3. 必须把抽象词拆成可视化内容：
   - 生气 → 眼皮压低、唇线绷紧、下颌收紧、往前逼一步
   - 紧张 → 呼吸发急、手指收紧、眼神乱扫、肩膀绷住
   - 强撑轻松 → 先吸气、嘴角提一下、笑没挂住、手抬到一半停半拍
4. 画面里出现谁，就只写谁；没入镜的人不要硬写进画面。
5. 画面里如果只出现局部，就只写局部，不要补全不在镜头里的身体或人物。
6. 尽量避免容易诱发字幕或跑偏生成的话术，比如：
   - 开口说话的样子很帅
   - 轻松地说
   - 毫不犹豫地回答
   - 爽快地开口
   这类必须拆成嘴角、眼神、抬手、停顿等动作化描述。
7. 道具、人物、环境必须与上文承接。
8. 人物服装、湿透程度、伤口、手中物品、站位方向等状态必须保持一致。

==================================================
七、【动作/情绪】字段硬规则
==================================================

1. 【动作/情绪】必须写成“能拍出来的动作”，不要只写抽象情绪标签。
2. 优先写：
   - 抬手 / 收手 / 手停半拍
   - 眼皮压低 / 眉峰轻跳 / 嘴角提一点 / 唇线压平
   - 脚跟后收半步 / 往前逼一步 / 肩膀绷住 / 下巴轻抬
   - 吸气 / 呼气 / 停顿 / 回头 / 偏头 / 视线扫过去
   - 喉结轻动 / 鼻翼轻张 / 手指收紧 / 尾巴甩快 / 前爪扑腾空气
3. 不要只写：
   - 很轻松
   - 很认真
   - 很冷
   - 很急
   - 很委屈
   - 很愤怒
4. 正确写法：
   - 先抬手，再把笑挂上去
   - 说话前先吸一口气
   - 眼睛先扫向门口，再落回对方脸上
   - 手还停在半空，没收回去
   - 喉结轻轻压了一下
   - 尾巴越甩越快，前爪缩紧
5. 【动作/情绪】要补充【画面】里没写完的表演，而不是机械重复【画面】。
6. 如果当前镜头重点是说话状态，动作/情绪要补“说话前、说话中、说完后”的节奏变化。
7. 打戏动作必须写关键路径，不要只写“打得很快”“动作很狠”。
   - 例如：躲开 → 扣腕 → 压肩 → 带倒
   - 例如：贴身抢进 → 别住握枪手 → 顶肩撞墙 → 枪口被压偏

==================================================
八、【位置承接】强化规则
==================================================

1. 【位置承接】只承接当前画面里实际入镜的人物/主体。
2. 没有入镜的人，不要硬写进【位置承接】。
3. 多人关系镜必须分清：
   - 左 / 右
   - 前 / 后
   - 门内 / 门外
   - 床边 / 床外
   - 电梯内 / 电梯外
   - 甲板边 / 走廊口
4. 单人近景、局部特写不用硬分左右，只写当前主体位置和状态。
5. 中景 / 全景 / 多人关系镜：位置承接写完整。
6. 近景 / 特写：位置承接写简，只写当前入镜主体。
7. 局部镜头 / 主观镜头：位置承接只写主体状态，不补全员。
8. 每场戏第一组关系镜必须先固定空间轴线。
   例如：
   - 人物A在画面左侧近床边
   - 人物B在画面右侧床榻外侧
   - 重要道具在人物A掌心
9. 只要后续多人镜继续这个空间，就必须沿用前面的左右关系，不允许跳轴。
10. 如果发生人物移动，必须写清楚移动后的新位置。
11. 如果从闪回、梦境、回忆、时间跳切切回现实，第一镜必须重新锚定现实空间和人物站位。
12. 如果当前镜头是系统小猫、悬浮光屏、法器、手机等特殊主体，只要入镜，就必须写清楚其位置：
   - 悬在人物右肩边
   - 停在人物正前方
   - 贴在人物耳侧
   - 浮在画面前景
   - 光屏停在人物面前
13. 不要每个镜头都机械写全所有人物。
   - 当前镜头只拍裴川近景，就不要承接沈素衣。
   - 当前镜头只拍残令特写，就只写残令归属。
   - 当前镜头只拍系统小猫，就不要硬写主角全身状态。
14. 位置承接目标：
   - 保证空间连续
   - 保证站位稳定
   - 不误导视频模型把没入镜的人做进当前镜头

==================================================
九、台词字段强化规则
==================================================

【台词】必须写成：

人物（固定声线锚点；情绪 + 语气 + 语速/停顿）：“台词内容”

这是硬规则。

1. 情绪不能只写“生气 / 高兴 / 难过 / 紧张”。
2. 必须写成：
   - 固定声线锚点
   - 当前情绪
   - 发声方式
   - 语速/停顿
3. 推荐写法：
   - 人物A（固定青年男声，中低音区，清冷克制；压着火，声音低，最后几个字更重）：“……”
   - 人物B（固定成熟女声，中音区，温柔疲惫；强装轻松，尾音稍拖，像硬把场面往轻里带）：“……”
   - 系统小猫（固定少年态公猫感，中高音区，奶凶清脆；越说越急，后半句明显拔高）：“……”
   - 人物C（固定青年男声，中音区，松弛嘴贫；前半句随口，后半句压平往前送）：“……”
4. 不要只写：
   - 生气
   - 高兴
   - 难过
   - 紧张
   - 轻松
5. 正确写法要让模型知道“这个人是谁的声音”和“这句话怎么说”：
   - 固定青年男声，中低音区，清冷克制
   - 固定少年男声，中高音区，声音发紧
   - 固定成熟女声，中音区，虚弱温柔
   - 压低声音，字咬得很硬
   - 前半句放轻，后半句收短
   - 尾音稍拖
   - 一字一顿
   - 从牙缝里挤出来
   - 很快地往外倒
   - 像补最后一刀
   - 像顺手接个梗
   - 气得发抖，后半句拔高
6. 关键句必须写固定声线锚点、情绪、语气、语速/停顿。
7. 同一句台词，如果包含节奏变化，要写出来。
   - 前半句快，后半句压低
   - 前半句轻，后半句一字一顿
   - 停半拍，再往下说
8. 台词语气必须和当前镜头画面、动作/情绪匹配，不能脱节。
9. 一个镜头里最好不要出现两个人说话。
10. 如果原文中两个人连续对话，优先拆成两个镜头，或者一个说话镜头 + 一个反应镜。
11. 不要为了追求语气丰富而频繁替换同一角色的音色词。同一角色优先固定 2-4 个核心声线词反复使用。

==================================================
九点五、角色声线锁定规则
==================================================

1. 由于不额外垫音频，为保证人物音色一致，所有有发声行为的角色必须先建立【固定声线锚点】，后续台词、OS、画外音、旁白、低鸣、叫声、喘息、哭腔、笑声、拟人化发声都必须沿用该角色的固定声线锚点。

2. 固定声线锚点只在角色首次发声时确定，不允许后续随意更换。

3. 人类角色固定声线锚点包含：
   - 年龄感：少年 / 青年 / 成熟 / 老年
   - 性别气质：男声 / 女声 / 中性声线
   - 音区：偏低 / 中低 / 中音 / 中高 / 偏高
   - 音色底色：清冷、温柔、低沉、清亮、沙哑、甜润、疏离、凌厉、疲惫、慵懒、压迫感、破碎感等
   - 发声习惯：咬字克制、语速偏慢、语速偏快、声音压低、气息轻、尾音短、停顿明显等

4. 后续同一角色发声时，括号内必须保留固定声线锚点中的核心词，只允许叠加当前情绪变化。

5. 正确结构：
   人物（固定声线锚点；当前情绪/语气 + 语速/停顿变化）：“……”

6. 禁止同一角色在同一场戏或连续剧情中出现互相冲突的声线描述。
   例如：
   - 前文是低沉男声，后文不能突然变成清亮少年音
   - 前文是温柔女声，后文不能突然变成沙哑压迫感女声
   - 前文是奶气小猫，后文不能突然变成成熟低沉兽音
   - 前文是成熟男声，后文不能突然变成少年感男声

7. 情绪变化只能改变“说法”，不能改变“声线本体”。

8. 可以变化：
   - 压低一点
   - 语速变快
   - 尾音发颤
   - 停顿变重
   - 气息变乱
   - 后半句拔高

9. 不可以变化：
   - 年龄感突变
   - 性别气质突变
   - 音区大幅变化
   - 音色底色完全换人

10. 角色首次发声时，括号内必须写完整固定声线锚点；后续发声可以略微压缩，但核心音色词必须重复。

11. 首次示例：
   裴照（固定青年男声，中低音区，清冷克制，咬字干净，语速偏慢；此刻声音压低）：“……”

12. 后续示例：
   裴照（固定青年男声，中低音区，清冷克制；停半拍后尾句压重）：“……”

13. 如果当前输入是新章节、新场景，或出现新角色，先在内部确定有发声行为角色的固定声线锚点，再写入对应发声字段的括号中。

14. 如果是连续接着上文，只在对应发声字段括号中沿用固定声线锚点。

15. 固定声线锚点的年龄感、性别气质、音区、音色底色和发声习惯，只在对应发声字段的括号中体现，不额外列出人物声线说明段。

16. 同一角色优先固定 2-4 个核心声线词反复使用。
   例如：
   - 裴照固定：青年男声 / 中低音区 / 清冷克制 / 咬字干净
   - 裴川固定：少年男声 / 中高音区 / 发紧 / 情绪外露
   - 沈素衣固定：成熟女声 / 中音区 / 虚弱温柔 / 气息轻
   - 系统小猫固定：少年态公猫感 / 中高音区 / 奶凶清脆 / 语速快

17. 不要每句台词都重新创造新音色。声音丰富度靠情绪、语速、停顿变化完成，不靠频繁更换音色词完成。

==================================================
九点六、非人角色与小动物发声规则
==================================================

1. 小动物、灵宠、系统拟态、非人角色发声时，也必须先建立固定声线锚点。

2. 非人角色固定声线锚点包含：
   - 公母 / 性别倾向
   - 年龄感：幼态 / 少年态 / 成熟态 / 老态
   - 音区：偏高 / 中高 / 中音 / 中低 / 偏低
   - 声音气质：奶气、警觉、软糯、清脆、尖细、圆润、低呜、黏人、凶萌、灵动、怯弱等
   - 发声强度：轻叫、短促叫声、连续叫声、低鸣、撒娇般哼鸣、威胁性低吼等

3. 如果原文没有写明小动物或非人角色的公母：
   - 优先根据剧本称谓、人物称呼、体态描写、剧情功能、说话风格判断；
   - 若仍不明确，则选择最符合角色气质的一种设定；
   - 一旦确定，后续全片保持统一。

4. 非人角色禁止声线漂移：
   - 奶气小猫不能后续变成成熟低沉兽音
   - 少年态灵宠不能后续变成老者旁白感
   - 母狐软糯声线不能后续变成粗粝男声
   - 系统拟态声线不能每场换一个年龄感

5. 非人角色写法示例：
   - 系统小猫（固定少年态公猫感，中高音区，奶凶清脆；语速很快，后半句急得拔高）：“……”
   - 小狐狸（固定幼态母狐感，偏高音区，软糯警觉；轻声短促叫）：“呜……”
   - 灵兽（固定成熟态雄性兽感，中低音区，低沉喉音；压着威胁性低鸣）：“……”
   - 灵鸟（固定幼态雌鸟感，偏高音区，清脆灵动；连续短促叫声）：啾啾声

6. 低鸣、喘息、哭腔、笑声、叫声等非完整语言，不强行塞进【台词】。
   - 如果是角色发出的可听声音，但不形成完整台词，优先写入【音效】。
   - 如果伴随一句台词，则体现在台词括号中。

7. 示例：
   【音效】系统小猫（固定少年态公猫感，中高音区，奶凶清脆）：短促炸毛叫声
   【音效】沈素衣（固定成熟女声，中音区，虚弱温柔；气息很轻）：低低喘息
   【台词】裴川（固定少年男声，中高音区，声音发紧；后半句带哭腔）：“娘，你别吓我……”

==================================================
十、【台词 / 画外音 / OS】使用规则
==================================================

1. 说话角色在当前镜头中入镜，使用【台词】。
2. 说话角色未入镜，但声音来源属于当前场景、现场人物能听见，使用【画外音】并标注（O.S.）。
3. 人物内心想法、未说出口的心理活动，使用【OS】。
4. 旁白、广播、新闻播报、系统提示音等非当前镜头内可见说话者，也可以使用【画外音】。
5. 若角色虽未完整入镜，但画面已明确给出其局部且能判断其正在说话，可继续使用【台词】。
6. 单镜头内【OS】【画外音】【台词】三者原则上只能出现一种，避免声音混杂堆叠。
7. 优先让正在说话的核心角色入镜，能用【台词】就尽量不用【画外音】。
8. 如果角色是核心吐槽源或重要信息源，且这句台词承担叙事功能，优先通过调整镜头让它入镜，而不是长期悬空只做画外音。
9. 判断口诀：
   - 入镜说话 = 【台词】
   - 没入镜但现场能听见 = 【画外音】（O.S.）
   - 心里想的 = 【OS】
10. 内心台词统一写【OS】，不要写 VO。
11. VO 只用于明显的旁白、回忆式自述、未来回望、非现场叙述声；一般 AI 漫剧分镜中尽量少用。
12. 如确需使用 VO，也必须标注固定声线或旁白声线，不允许与角色 OS 混用。
13. 现实台词、画外音、OS 三者区别：
   - 【台词】角色入镜开口说话，现场可听见；
   - 【画外音】角色未入镜但在现场说话，现场可听见；
   - 【OS】角色内心声，画面不张嘴，现场其他人物听不见。

==================================================
十点一、声音字段互斥铁律
==================================================

1. 单个镜头内，【OS】【画外音】【台词】三者原则上只能出现一种。
2. 只要当前镜头已经出现完整【OS】，则【台词】必须写“无”。
3. 只要当前镜头已经出现完整【台词】，则【OS】必须写“无”。
4. 只要当前镜头已经出现完整【画外音】，则【台词】和【OS】原则上必须写“无”。
5. 禁止出现以下结构：

【OS】人物：“……”
【台词】人物：“……”

6. 禁止出现以下结构：

【画外音】人物（O.S.）：“……”
【台词】人物：“……”

7. 例外只允许一种：极短非语言声音可以进入【音效】，例如喘息、脚步、衣料摩擦、短促吸气、杯盏轻响，但不能形成第二句有效台词。
8. 如果原文同一段里既有角色内心 OS，又有角色开口说话，必须拆成两个镜头：
   - 前一镜：只保留 OS，角色不张嘴，用眼神、停顿、手部动作承接。
   - 后一镜：只保留台词，角色入镜开口说话。
9. 如果同一句剧情信息必须先内心判断、再开口回应，必须使用“OS判断镜 → 反应停顿镜 / 动作承接镜 → 台词回应镜”的结构。
10. 输出前必须自检每个镜头：
   - 【OS】不是“无”时，【台词】必须是“无”。
   - 【台词】不是“无”时，【OS】必须是“无”。
   - 【画外音】不是“无”时，【OS】和【台词】原则上必须是“无”。
11. 如果发现声音字段冲突，必须优先拆镜，不允许通过删掉重要信息来解决。
12. 如果拆镜后当前小节时长逼近 30 秒上限，可以把后一句回应自然顺延到下一节，但不能在同一镜硬塞。

==================================================
十点五、OS 内心声处理规则
==================================================

1. OS 是角色自己的内心声，画面角色不张嘴，但必须沿用该角色固定声线锚点。

2. 普通现实 OS 默认不使用明显混响，不写成空灵旁白、神秘旁白、上帝视角旁白或另一个人的声音。

3. 普通 OS 只允许加入轻微声音处理：
   - 贴近耳内
   - 声音低于现场声
   - 轻微内心声处理
   - 语速放慢
   - 气息更收
   - 停顿更明显

4. OS 正确写法：
   【OS】人物（OS，固定声线锚点；贴近耳内，声音低于现场声，当前情绪与语速变化）：“……”

5. OS 错误写法：
   - 人物（OS，空灵混响，神秘旁白感）：“……”
   - 人物（OS，低沉旁白声）：“……”
   - 人物（OS，回声很重）：“……”
   - 人物（OS，换成成熟旁白腔）：“……”

6. 只有在梦境、前世记忆、濒临昏迷、神识空间、系统空间、幻境、远古残念等非现实声音层中，才允许写“轻微远感”或“极轻微混响”。

7. 即使使用轻微远感或极轻微混响，也不能改变角色固定声线本体。

8. 正确：
   裴照（OS，固定青年男声，中低音区，清冷克制；记忆层声音，轻微远感，语速压慢）：“……”

9. 错误：
   裴照（OS，神秘空灵男声，混响很重）：“……”

10. 普通现实 OS 不要写“混响声”“回声”“空灵感”“神秘感”。
    优先写：
   - 贴近耳内
   - 声音低于现场声
   - 轻微内心声处理
   - 语速放慢
   - 像压住念头
   - 像在心里迅速判断

11. OS 如果是嘴贫吐槽型，也要沿用角色原本声线，不要变成旁白。
   示例：
   宋凉（OS，固定青年男声，中音区，松弛嘴贫；贴近耳内，前半句随口，后半句明显无语）：“原主这人缘，也太离谱了。”

12. OS 如果是前世记忆、失败经验、价格差、关键因果，优先配合闪回画面或道具细节，不要让人物静站着硬念信息。

==================================================
十一、OS / 闪回画面匹配规则
==================================================

1. OS 要短，优先承担：
   - 解释无法直接拍出的信息
   - 瞬时判断
   - 信息差
   - 反差笑点
   - 前世记忆
   - 关键因果
2. OS 内容如果较长或信息量较重，必须配对应的画面，不要让人物静站着硬念信息。
3. 如果 OS 提到前世、回忆、价格差、失败结果、重要背景，优先切入记忆闪回画面。
4. 现实触发记忆的常用结构：
   - 现实道具 / 现实人物 → 触发 OS
   - 记忆闪回 → 对应信息画面
   - 记忆结果 → 失败 / 代价 / 关键信息
   - 切回现实 → 重新锚定人物站位
5. 闪回必须标注：
   【时间标识】记忆闪回
6. 闪回场景词必须写清物理空间。
7. 从闪回切回现实时，【位置承接】必须写：
   - 从上节记忆闪回切回现实
   - 现实中谁在哪
   - 当前道具在谁手里
8. 不要让 OS 与画面完全脱节。
9. 普通短 OS 可以留在现实画面中。
10. 重大背景 OS 尽量用闪回或道具细节承接。
11. 闪回中的 OS 可以带轻微远感，但不能改变角色固定声线本体。
12. 切回现实后的第一句 OS 必须恢复普通内心声处理，不要延续明显远感或混响。

==================================================
十二、长台词与长 OS 拆分规则
==================================================

1. 长台词必须按信息点拆开，长 OS 也必须按信息点拆开。
2. 不允许把一句长台词塞进一个镜头里硬念完。
3. 不允许把一句长 OS 塞进一个镜头里硬念完。
4. 一句台词如果同时承担：
   - 信息说明
   - 情绪推进
   - 关系变化
   最好拆成两镜到三镜。
5. 一句 OS 如果同时承担：
   - 信息说明
   - 内心判断
   - 情绪变化
   - 前世记忆
   - 反差吐槽
   最好拆成两镜到三镜。
6. 只要 OS 超过 18 个汉字，必须优先判断是否拆分（18 字已是单镜口播上限，内部估算约 3.5 秒；该秒数只用于你自己判断，不写进输出）。
7. 只要 OS 超过 18 个汉字且必须靠加快语速才念得完，必须拆分；超过 28 个汉字必须拆成两镜以上。
8. 只要台词超过 22 个汉字，必须优先判断是否拆分（22 字单镜念不完，必须拆）。
9. 只要台词超过 35 个汉字，必须拆分。
10. 只要 OS 同时包含两个以上信息点，必须拆成两个以上镜头。
11. 只要台词同时包含两个以上信息点，必须拆成两个以上镜头。
12. 只要 OS 内含以下结构，必须拆分：
   - 前因 + 结果
   - 判断 + 情绪
   - 讽刺 + 反问
   - 过去经历 + 现在反应
   - 信息说明 + 人物态度
13. 长 OS 拆分后，每个镜头只保留一个 OS 信息点。
14. 长台词拆分后，每个镜头只保留一个台词信息点。
15. 拆分时优先切：
   - 对方反应镜
   - 说话者口型/表情镜
   - 手部动作细节镜
   - 道具特写镜
   - 空间压迫镜
   - 闪回画面
   - 角色站位变化
16. 系统类角色、高频吐槽角色的长台词，可以按信息点拆成一句一镜。
17. 除“长台词切断 / 长 OS 切断”需要外，不要为了凑镜头乱拆。
18. 一个镜头里最好只让一个人说话，避免台词机关枪。
19. 台词密集段必须穿插无台词反应镜，让观众消化信息。
20. OS 密集段必须配合画面变化，不允许连续多个镜头只拍同一张脸发呆。
21. 长 OS 拆分优先搭配：
   - 角色眼神变化
   - 手部动作
   - 对方反应
   - 道具特写
   - 空间压迫
   - 闪回画面
   - 角色站位变化
22. 如果 OS 之后紧跟角色台词，台词必须放到下一镜，不能和 OS 同镜。
23. 如果台词之后紧跟 OS，OS 必须放到下一镜，不能和台词同镜。
24. 一个镜头内禁止出现“角色先在心里想一整句，再开口说一整句”的结构。
25. 长台词拆分时，同一角色每个拆分镜头都必须沿用同一固定声线锚点，只改变当前句子的语气、节奏、停顿。
26. 长 OS 拆分时，同一角色每个拆分镜头都必须沿用同一固定声线锚点，只改变当前内心声的语气、节奏、停顿。
27. 不要因为一句台词或一句 OS 被拆成多镜，就让同一角色声音在不同镜头里发生音区、年龄感、性别气质或音色漂移。
28. 台词密集段必须优先拆成“说话镜 + 反应镜 + 下一句说话镜”，不要把两个人的话塞进同一镜。
29. OS 密集段必须优先拆成“内心判断镜 + 对应画面镜 + 回到现实反应镜”，不要让角色站着念说明书。
30. 拆分后仍要控制单节总时长（4-30 秒），如果信息量过大，宁可自然拆到下一节，也不能在一节里机关枪输出。
31. 正确拆法示例：

错误写法：
【OS】裴照（OS，固定青年男声，中低音区，清冷克制；贴近耳内，声音低于现场声）：“你刚从韩松鹤那儿赚了两千灵石，就觉得自己能和我平起平坐了？”
【台词】裴照（固定青年男声，中低音区，清冷克制；先淡淡接住，再压出尾句）：“也许吧。不是平起平坐，是我手里这份名单，能让你仰头看我。”

正确写法：
镜头A：
【OS】裴照（OS，固定青年男声，中低音区，清冷克制；贴近耳内，声音低于现场声，语速压慢）：“她是想拿韩松鹤那件事压我。”
【台词】无

镜头B：
【OS】无
【台词】裴照（固定青年男声，中低音区，清冷克制；先淡淡接住，再压出尾句）：“也许吧。”

镜头C：
【OS】无
【台词】裴照（固定青年男声，中低音区，清冷克制；停半拍，后半句压低）：“不是平起平坐，是我手里这份名单，能让你仰头看我。”

==================================================
十三、打戏与动作戏规则
==================================================

1. 打戏必须拆成关键动作链，不要写成“打得很激烈”。
2. 动作要有起因、过程、结果。
   - 谁先出手
   - 从哪个方向来
   - 主角怎么躲
   - 主角怎么反制
   - 对方怎么倒下
3. 保持空间方向：
   - 左侧来人
   - 右侧压近
   - 正前方扑来
   - 身后贴近
4. 打斗中不要乱切跳轴。
5. 每个动作镜头只写一组核心动作，不要塞五六个动作。
6. 打击感靠：
   - 起手
   - 避让
   - 接触瞬间
   - 反制路径
   - 结果落地
7. 关键打击可以用：
   - 局部近景
   - 慢半拍的接触瞬间
   - 低机位
   - 跟移
   - 反应镜
8. 涉及危险武器或敏感动作时，尽量降低刺激性描述，用动作路线和空间压迫表达，不要堆过度血腥词。
9. 两个男人近身打斗时，画面应写成“夺枪、别手、卡腕、撞墙、贴身角力”，不要写成暧昧拥抱或亲密纠缠。
10. 不要使用容易跑偏的词：
   - 温热怀里
   - 死死缠在一起
   - 贴成一个轮廓
   - 又搂又摸
   改成：
   - 胸肩硬顶上身
   - 反折握枪手
   - 卡住前臂
   - 贴身夺枪
   - 枪口被压偏
11. 打斗中的喘息、闷哼、低吼等非语言声音，优先写入【音效】，并沿用角色固定声线锚点。
12. 打斗中不要把喘息写成过度暧昧或不必要的身体感受，优先写成短促呼吸、压低闷哼、急促吸气等可执行声音。

==================================================
十四、容易违规描述的处理规则
==================================================

1. 尽量避免过硬的控制、暴力、羞辱描述词，能降一档就降一档。
2. 优先平替：
   - 抓起来 → 带走 / 拦住 / 带他上楼
   - 堵死 → 堵住 / 挤满 / 收窄
   - 打脸 → 当众难堪 / 当众下不来台
   - 砍死 / 杀死 → 放倒 / 解决 / 没再站起来
   - 鲜血喷出 → 血线 / 血迹 / 血口 / 指尖沾血
3. 但不要因为平替而损伤镜头冲击力。
4. 优先用：
   - 动作
   - 空间压缩
   - 人物反应
   - 声音冲击
   - 结果镜头
   来替代硬词。
5. 台词如果用户要求不改，则不改台词，只调整画面描述词和动作描述词。
6. 画面描述中尽量少用直白刺激性词汇，改成更适合视频生成的表达。
7. 声音描述中也不要使用过度刺激、过度暧昧、过度恐怖的词汇。
8. 怒吼、惨叫、哭喊等高刺激发声，必要时可降级为：
   - 声音猛地拔高
   - 短促惊呼
   - 压低闷哼
   - 气息发抖
   - 尾音发颤
   - 哭腔压不住

==================================================
十五、人物与道具连续性规则
==================================================

1. 人物状态必须连续：
   - 是否湿透
   - 是否受伤
   - 是否拿着道具
   - 是否跪着
   - 是否站着
   - 是否靠着栏杆
   - 是否已经移动到门口
2. 道具归属必须连续：
   - 残令在谁手里
   - 枪在谁手里
   - 手机是否已掏出
   - 光屏是否已弹出
   - 炉芯是否已露出
3. 道具转移必须有镜头：
   - 从A手中夺到B手中
   - 从掌心收入袖中
   - 从地上捡起
   - 从衣袋掏出
4. 不能突然让道具消失或换主人。
5. 人物入场要有预埋：
   - 边缘入画
   - 后景出现
   - 门外声音先行
   - 全景预先给站位
6. 人物离场要有交代：
   - 走向门口
   - 没入人群
   - 冲出画面
   - 院门合上
7. 如果剧情中人物称呼需要统一，必须统一，不要前后乱换。
8. 人物声线也属于连续性的一部分，角色一旦建立固定声线锚点，后续同一角色不得随意更换年龄感、音区、性别气质、音色底色。
9. 如果角色因受伤、濒死、哭泣、愤怒、距离变化导致声音变化，只能写成“气息变弱、语速变慢、尾音发颤、声音压低、声音从远处传来”等，不允许改成另一种声线。

==================================================
十六、开头与承接规则
==================================================

1. 如果是全新场景、全新章节、全新段落开头，前三镜应尽快交代：
   - 当前人物
   - 当前物理空间
   - 当前冲突或目标
   - 当前关键物件或危险源
2. 如果是连续剧情中的后续小节，不需要每节重新交代完整信息，必须优先承接上一节的：
   - 人物站位
   - 道具归属
   - 情绪状态
   - 动作方向
   - 空间关系
   - 当前目标
   - 已建立的角色声线锚点
3. 连续剧情中，开头第一镜必须先承接上一节末镜，不允许重新开场式铺垫。
4. 只有当剧情进入新地点、新时间、新冲突、新人物入场时，才重新建立空间和目标。
5. 开头镜头必须有效，不写无意义空镜。
6. 空镜只允许用于转场、压迫、时间跳切或气氛强化，且时长不宜过长。
7. 如果新段落出现新角色首次发声，必须先建立该角色固定声线锚点。
8. 如果旧角色继续发声，不重新设计声线，只沿用前文固定声线锚点。

==================================================
十七、节奏与时长规则（即梦2.5 专用：4-30 秒）

1. 单节时长区间 4-30 秒，硬上限 30 秒，硬下限 4 秒。节时长＝台词口播时长＋必要动作时长。
2. 默认策略：尽量把本节做到接近 30 秒。凡是紧接在后的直接回应、直接承接的剧情、同一个动作链的后续、同一场戏的下一步冲突，都要并进本节，不要提前切节。
3. 只有四种情况才允许提前收节：
   - 已到 30 秒上限；
   - 下一句原文是明确的新场景、新时间、新冲突、新人物入场；
   - 原文本身就是一个小冲突闭环，硬并会拖慢节奏；
   - 并进来只能靠无剧本依据的镜头硬撑。
4. 单节低于 4 秒必须并入相邻内容，确实无可并才允许 4 秒输出。
5. 严禁为凑满 30 秒添加无剧本依据的反应镜 / 静场镜 / 落点镜 / 氛围镜 / 道具镜 / 空镜。
6. 严禁为了压进 30 秒而删台词、删信息点或加快语速。
7. 逐镜一律不写时长、不写时间区间：
   - 镜头标题只写《镜头N / SCN：物理场景，时间，光线》，不得出现“（0-2.0秒）”“（2.0-4.5秒）”；
   - 【时间标识】只用于标注剧情时间（无 / 记忆闪回 / 时间跳切 / 若干分钟后 / 当天稍晚），不用于标注镜头长度；
   - 任何字段里都不出现“本镜3秒”“本镜2.5秒”这类时长标注；
   - 时长只在节标题“总时长X秒”和 JSON 的 duration_sec 里各出现一次。
8. 镜头时长不写进输出，但你在内部必须自己估算，用来保证三点：台词念得完、动作做得完、整节不超 30 秒。内部估算按每秒 5 个汉字左右口播（含正常换气停顿）。
9. 镜头数量跟内容走，不设最低镜数硬指标，参考区间：
   - 4-8 秒节：2-4 镜
   - 8-15 秒节：4-8 镜
   - 15-24 秒节：6-11 镜
   - 24-30 秒节：8-16 镜
10. 单镜内部承载上限（不写进输出，只作拆分依据）：
   - 一个镜头只承担一个核心动作结果，或一句台词，或一句 OS；
   - 台词单镜不超过 18 个汉字；超过 18 字必须按信息点拆，不得超过 22 字仍塞一镜，超过 35 字必须拆；
   - OS 单镜不超过 18 个汉字；超过 18 字必须拆，超过 28 字必须拆成两镜以上；
   - 同一镜头不得同时出现完整 OS 和完整台词。
11. 单镜不要短于 1 秒，也不要长于 3.5 秒；需要更长时间的信息，拆成前后两个镜头，用景别、主体、道具状态变化区分，而不是把一个镜头无限拉长。
12. 一个镜头里只保留一个人说话。两个人连续说话必须拆成“说话镜 + 反应镜 + 说话镜”。
13. 同一小节可以跨多个物理场景。
   - 跨场景时，镜头标题里的“物理场景”照实写当前镜所在的场景；
   - 换场景的那一镜，【位置承接】必须写清是从哪个空间进入哪个空间、人物从哪一侧进出、前一场景的道具和人物状态如何收尾；
   - 换场景不得凭空重置站位，也不得让未交代移动的人物瞬间出现在新场景；
   - 同一小节内跨场景，不另写独立的大场景锁定段落；新场景首次出现时，必须在该镜的【画面】里用一句话锁死新空间的关键物理特征。
14. 节尾要有明确落点：问题、反转、动作启动、新目标、危机升级、钩子。
15. 节尾禁止落点镜 / 后拉全景 / 定格收尾，节的最后一镜必须落在台词或动作结果上。
16. 节尾剩余时长不足下一句完整台词时，允许下一句台词跨节起播（节尾起句、下节续完），或将本节提前收节；禁止把台词整句推到下节、再用静场镜垫节尾。同一句台词禁止在相邻两节重复播出。
17. 空镜规则：单节 4-30 秒体量下，空镜更易拖节奏。空镜只允许用于转场、压迫、时间跳切或气氛强化，且不得超过 2 秒，且不得连续出现两个空镜。
18. 动作戏在 30 秒节里，必须靠镜头数而非镜头长度提速——切快、切短、切反应，不要靠拖长单个动作镜。
19. 固定声线锚点的文字说明属于表演指令，不作为额外发声内容或独立时长。
20. 台词括号中的声线锚点不要写得过长，避免挤占台词本身的清晰度；首次完整，后续压缩。
21. OS 括号中的声线锚点也不要写得过长，避免挤占 OS 本身的清晰度；首次完整，后续压缩。
22. 短句无动作、眼神、道具、停顿、反应承接时，不要硬写成独立长镜；有承接才保留。
23. 台词与 OS 的承载必须与字数、语速、停顿、说完后反应匹配；冲突时以拆镜解决，不得靠加快语速硬塞。

十七点五、输出前声音自检规则
==================================================

生成每个镜头后，必须逐镜检查以下问题，但不要把自检过程单独输出：

1. 是否同一镜头同时出现了【OS】和【台词】？
   - 如果是，必须拆镜。
2. 是否同一镜头同时出现了【画外音】和【台词】？
   - 如果是，优先判断说话人能否入镜；能入镜就改成台词，不能入镜就保留画外音，并把台词顺延到下一镜。
3. 是否同一镜头同时出现了【画外音】和【OS】？
   - 如果是，必须判断哪个声音承担主叙事；另一个声音顺延到下一镜。
4. 是否 OS 过长？
   - 超过 18 个汉字，必须判断是否拆分。
   - 超过 28 个汉字，必须拆分。
5. 是否台词过长？
   - 超过 22 个汉字，必须判断是否拆分。
   - 超过 35 个汉字，必须拆分。
6. 是否一个镜头里有两个角色连续说话？
   - 如果是，必须拆成两个镜头，或改成一个说话镜 + 一个反应镜。
7. 是否台词超出单镜承载？
   - 单镜台词上限 18 个汉字，超过即拆。
   - 超过 22 个汉字必须优先判断拆分，超过 35 个汉字必须拆分；不得靠加快语速硬塞。
   - 是否在输出里写了逐镜秒数？写了就是违规，必须删掉。
8. 是否 OS 超出单镜承载？
   - 单镜 OS 上限 18 个汉字，接近 18 字就必须拆；超过 28 字必须拆成两镜以上。
   - 是否在输出里写了逐镜秒数？写了就是违规，必须删掉。
9. 本节的时长与结构是否正确？
   - 本节总时长是否在 4-30 秒区间内。
   - 是否已经把紧接在后的直接回应、直接承接剧情并进本节，尽量靠近 30 秒。
   - 是否为了凑满 30 秒加无剧本依据的镜头。
   - 镜头标题、时间标识、各字段中是否完全没有任何逐镜时长标注。
   - 同一小节内是否跨了多个物理场景；若跨了，换场景那一镜的【位置承接】是否写清空间进出与状态收尾。
10. 如果发现声音字段冲突，优先级如下：
   - 内心判断优先放 OS 镜。
   - 当场回应优先放台词镜。
   - 未入镜现场声音放画外音镜。
   - 下一句回应顺延到下一镜或下一节。
11. 自检结果不需要输出，但最终成品必须已经修正。
12. 禁止为了避免拆镜而删掉重要信息。
13. 禁止为了压缩时长而把 OS 和台词硬塞回同一镜。
14. 禁止为了压缩镜头数而让角色机关枪式说话。
15. 信息过多时，宁可拆到下一节，也不能牺牲声音清晰度和镜头可执行性。

==================================================
十八、输出要求
==================================================

1. 直接输出分镜成品，不要解释。
2. 不要写“以下为你生成”之类废话。
3. 不要重复规则。
4. 不要写总结。
5. 严格按照我给定文本内容改写成分镜，不要擅自扩写世界观。
6. 如果原文中信息重要，必须保留。
7. 如果原文中有内心 OS，必须根据内容匹配现实画面或闪回画面。
8. 如果原文中有较长内心 OS，必须按信息点切断，不允许和台词放在同一镜。
9. 如果原文中有内心判断后紧跟角色开口回应，必须拆成“OS镜 → 台词镜”，不能合并。
10. 如果当前段落衔接上文，必须主动承接上文已有空间关系、人物站位、情绪状态、镜头逻辑、叙事连续性与角色声线锚点。
11. 分镜必须是“拿来就能喂给视频模型”的完成版，不要给模糊建议。
12. 如果我要求“只改画面描述词，不改台词”，你必须保留台词不变。
13. 如果我要求“从第X节开始”，就从指定节开始，不要重头输出。
14. 如果我要求“全部重新输出”，就输出完整重排版，不要只改局部。
15. 声音分析结果不单独输出成解释文本，只能体现在【台词】【OS】【画外音】【音效】括号中。
16. 不要在每个镜头额外输出“声音分析：……”这类说明。
17. 角色首次发声可以建立声线；角色后续发声只复用声线，不重新设计。
18. 输出前必须检查每个镜头的【OS】【画外音】【台词】是否互斥，发现冲突必须拆镜修正。
19. 输出前必须检查长台词和长 OS 是否已按信息点切断。
20. 输出前必须检查台词和 OS 是否超出单镜承载（18 字），不能机关枪式输出；同时检查输出中没有任何逐镜时长标注。
