<分镜拆分规则>

### 2.1 分镜定义与合并逻辑

* **分镜粒度**：一个分镜代表一个不切镜头的连续时空片段。
* **合并原则**：
* **动作伴随台词**：当同一角色的动作与台词具有因果关系时，必须合并。
* **反应镜头集成**：当A说话，B做出即时反应（如震惊、冷笑）且无需切场时，合并。


* **切割规则（最高优先级）**：
* **情绪拐点**：当角色情绪发生从“平静”到“爆发”或“得意”到“惊恐”的剧变时，必须切分。
* **视线/介质切换**：如从现实转入屏幕内容、从室内转入室外。



### 2.2 视觉演变逻辑

每个分镜内的4张图必须呈现以下一种或多种逻辑：

* **推进式逻辑**：全景 -> 中景 -> 近景 -> 特写（逐渐逼近角色内心）。
* **动作链逻辑**：准备动作 -> 启动 -> 过程 -> 结果。
* **情绪剥离逻辑**：伪装的笑 -> 笑容消失 -> 眼神冰冷 -> 爆发。
* **视角变换逻辑**：客观视角 -> 角色A视角 -> 角色B视角 -> 两人对峙。

</分镜拆分规则>

<图片提示词规范>

### 4.1 结构要求

每个分镜的 `image_prompt` 必须包含以下完整内容：

1. **引导词**：你需要在一个画面中展示当前2x2画面的关键帧，那么可以平均画出4个小图，按照顺序排列，图片中不能包含任何对话信息。
2. **推理（Reasoning）**：用1-2句话阐述这4张图如何服务于剧本的情绪表达或剧情推进。
3. **图1-图4（Individual Prompts）**：每张图需包含：**镜头类型 + 主体姿态 + 细节特征 + 光影氛围**。

### 4.2 细节颗粒度

* **图1 (Start)**：锚定分镜起始点。
* **图2 (Development)**：表现动作或情绪的中间态，改变景别或角度。
* **图3 (Climax)**：视觉核心。展示最剧烈的表情、最关键的眼神或决定性的手势。
* **图4 (End)**：动作定格。为下一分镜提供明确的视觉线索。

### 4.3 描写禁令

* 严禁在图片中出现任何文字、字幕、气泡。
* 严禁在 image_prompt 中使用映射代码（仅使用名字）。
* 严禁使用血腥、暴力、色情等一切违禁词，必须使用氛围词替代。

</图片提示词规范>

<视频描述规范>

### 5.1 动态捕捉

* 使用强有力的动词：攥紧、猛然转头、瞳孔微颤、身形摇晃。
* 明确镜头运动：镜头快速推进（Zoom In）、平滑摇过（Pan）、低角度跟随（Tracking）。

### 5.2 映射代码

* 在描述末尾，必须列出本分镜涉及的角色、场景、物品映射。

</视频描述规范>
