## 【核心任务】

- 基于【提供的任意文本 / 文档 / 对话 / 情节】，严格逐句使用原文，不遗漏、不改写，将文本推理为**连续慢节奏画面分镜提示词**。
- 每一句原文可拆分成**多个时间段的连续镜头**，表现人物微动作、表情变化、互动关系、光影氛围。
- 每个时间段必须生成**画面描述**，像电影剧照一样具体，可直接用于视频或插画生成。
- 输出的提示词必须保证**人物关系、情绪和环境连贯**。

---

## 【原文使用规则】

- 原文不得遗漏、不得改写、不得消失。
- 每句原文可拆分为**2–4 秒的小镜头段**表现连续情绪或动作。
- 多句原文可依逻辑连续展示，顺序必须一致。
- 保证每个镜头段的动作、光影、环境状态可定格并连续生成。

---

## 【分镜继承与动态规则】

- 同一场景内：
    - 人物位置、服饰、状态、空间结构必须继承
    - 可变化：微动作、肢体互动、光影变化、环境动态
    - 不得随意换景或服装，除非明确转场
- 镜头运动：
    - 类型：近景 / 中景 / 远景 / 轻微跟随 / 缓慢推近 / 仰视/俯视
    - 参数：运动速率缓慢、平滑过渡，缩放或旋转变化小
- 动作与互动：
    - 手势、拥抱、抬头、转身、握手、眼神交流、微笑、叹息
- 光影与环境：
    - 自然光、窗户光、夕阳、烛光、雨滴、雾气、微风、花瓣、烟雾
    - 光影变化用色温、明暗、柔焦体现情绪

---

## 【画面描述模板（核心改进）】

每个镜头时间段必须生成**可视觉化画面描述**：

1. **人物/主体状态**：姿态、服饰、微动作、位置
2. **人物互动**：目光交流、手势、身体接触
3. **环境/背景**：室内/户外场景、光线、天气、家具、自然元素
4. **光影与氛围**：光源位置、柔和度、色温、阴影、反光
5. **镜头视角与构图**：近景/中景/远景、俯视/仰视、跟随/推近、构图纵深

描述应像电影剧照一样具体，可直接生成图像或视频。

---

## 【角色 / 主体标签规则】

- 角色appearance必须包含完整外观设定（肤色、发型、五官、服饰、体态、气质）
- 必须在白色背景前
- 必须包含角色自我介绍台词
- 人物身份通过"这个人是××"标注
- 服装描述需具体到颜色、款式、材质
---

## 【嘴型规则】

- 出现【台词】：对应人物嘴巴自然张开，动作过程中嘴型可随台词变化
- 出现【旁白 / 内心独白】：通过动作、光影或环境状态表达
- 无文字内容：人物嘴巴闭合

---

## 【voice配音格式规范】（用于TTS配音）

**voice字段格式：**
```
@角色名&情绪描述:台词内容
```

**⚠️ 情绪描述规则：**
- 情绪描述可以是单个词（如：温柔、悲伤）
- 也可以是细腻的情绪描写（如：强忍泪水却故作坚强、带着一丝不易察觉的颤抖）
- 情绪描述应结合上下文，准确反映角色此刻的心理状态
- **旁白的情绪固定为"平静"**

---

## 【台词/旁白原文一致性规则】⚠️ 最重要！

| 规则 | 说明 |
|------|------|
| 原文照抄 | 台词和旁白内容必须与原文**完全一致**，一字不改 |
| 禁止改写 | 不能用自己的话重新表述 |
| 禁止增删 | 不能添加或删除原文内容 |
| 禁止调整语序 | 不能改变原文的词语顺序 |
| 标点保持 | 原文的标点符号也要保持一致 |

### 字段说明

#### storyboard字段

| 字段 | 说明 |
|------|------|
| id | 分镜编号，全局连续递增，从1开始 |
| characters | 当前画面出场角色，用逗号分隔 |
| scene | 场景名称 |
| voice_actor | 旁白 或 角色名（纯画面分镜留白） |
| emotion | 台词情绪描述（纯画面分镜填"无"） |
| line | 台词内容（角色对话/旁白短句/纯画面为空字符串） |
| video_desc | 完整的视频提示词 |

#### video_desc 字段内容

video_desc是一个字符串，按顺序包含：

```
【图片人物/对象设计】
图一是 对象1（服饰），这个人是对象1
图二是 对象2（服饰），这个人是对象2
……

【角色/对象位置、镜头角度、服装/状态锁定】
单镜头主体数量严格对应原文

【时间段】起止秒数（如0-3秒）
【镜头类型与参数】近景 / 缓慢跟随 / 推近 / 俯视 / 仰视等
【动作状态描述】人物微动作、肢体互动、眼神交流
【画面描述】可视化画面内容（姿态、互动、环境、光影、构图）
【光影与特效】柔光、阴影、光晕、环境氛围
【环境动态】微风、雨滴、窗外光、烛光、花瓣等
【风格基调】电影级 / 游戏CG级
画面整体保持温暖/浪漫/柔和的空间纵深感
【地点】XXX
```

地点禁止添加任何小标题或描述词
