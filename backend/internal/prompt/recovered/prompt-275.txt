## 第一原则：不允许增删原文任何内容，不要缺失原文所有关键信息，必须保留原文所有角色的台词，严格遵循"不增不删"的原则

1. **内容拆分**：
   - 请将本段剧本内容 **按时间/场景/情节转折点**，拆分成多个小节，每个小节控制在 **15秒左右** 的视频长度。
   - 每个小节的台词字数不超过30个字。
   - 每个小节都要独立输出完整的描述词，方便逐段生成视频。

2. **视频提示词原则**：

（1） **叙事优先原则：**
    * **逻辑：** 严格遵循"冲突铺垫 → 高潮爆发 → 结果呈现"的叙事节奏。充分结合原文的对于人物的描述，台词用于铺垫冲突和宣布判决，然后才是主角的反击和行动高潮。
    * **标准：** 台词内容与画面动作必须同步，确保观众情绪随台词的递进被有效调动。

（2）**AI模型视觉关键词密集度：**
    * **逻辑：** 为最大化 AI 模型对画面的控制力，必须使用大量具体的、高辨识度的视觉描述词汇。
    * **标准：** 场景、角色、光影、特效必须混合使用（例如："幽蓝色的霓虹线路"、"血红色的赛博月亮"、"凌厉的金色电光"、"数码化的爆炸效果"）。

（3） **情绪/氛围主导：**
    * **逻辑：** 明确指示画面应传达的情绪，帮助模型设定合适的色彩饱和度、景深和光照风格。
    * **标准：** 必须在描述中加入如"宏大、压抑"、"傲慢的冷笑"、"眼神中爆发怒火"等情绪词，并用"霓虹蓝和血月红对比"来强化这种氛围。

（4） **运镜的专业化和指令化：**
    * **逻辑：** 采用专业电影术语而非简单描述，以明确规定画面的动态行为。
    * **标准：** 严格使用【超广角】、【特写】等**景别**，以及【慢速推轨】、【环绕慢摇】、【动态手持】等**镜头运动**指令。

（5） **动作的分解与强调：**
    * **逻辑：** 复杂的动作不能一笔带过，必须分解成关键帧和关键特写，确保动作的冲击力。
    * **标准：** 使用【爆发式跃出】（远景）接【腰部极限扭转】（近景），再接【接触的瞬间】（慢动作特写），突出高速和高冲击。

（6） **时长与节奏的控制：**
    * **逻辑：** 为每个分镜设定一个合理的时长，以控制最终视频的节奏感。短时间用于高冲击特写，长时间用于场景铺垫或关键动作。
    * **标准：** 【特写/冲击】控制在 2.0 秒 - 3.0 秒；【场景/铺垫】控制在 3.5 秒 - 4.5 秒。

（7） **听觉元素的辅助：**
    * **逻辑：** 虽然 AI 主要生成视频，但提示音效可以帮助模型理解场景的"能量等级"和"密度"。
    * **标准：** 在关键动作后备注音效提示，如"尖锐的破空声与低沉的能量轰鸣"或"无台词，只有金属、能量、符文破碎的声音"。

3. **对白要求**：
   - 原文中的对话内容不允许进行擅自删改
   - 台词用引号""标注
   - 一个镜头只有一个人说话
   - 台词不允许以字幕的形式出现在视频中

4. **镜头节奏要求**：
   - 每一小节控制在1~3个镜头，节奏清晰，能在15秒内完整表现一段情节。
   - 开场镜头建议用空镜、航拍或缓推；高潮镜头用特写、跟拍、环绕；收尾用定格或远景。

5. **语言要求**：
   - 中文描述，逻辑清晰，画面感强，避免空洞抽象。
   - 每个小节都要独立成段，方便直接复制到 seedance2.0 使用。

## 最后强调，推理剧本分镜时不允许缺失原文任何内容。

## 输出格式

输出一个合法的JSON对象，结构如下：

```json
{
  "storyboard": [
    {
      "id": 1,
      "scene_id": 1,
      "duration_sec": 15,
      "characters": "出场角色（逗号分隔）",
      "props": "道具1, 道具2, 道具3",
      "scene": "场景名称",
      "video_desc": "完整的 seedance2.0 分镜提示词（详见下方 video_desc 内容规范）"
    }
  ]
}
```

### props 字段规范

`props` 字段用于列出该小节中出现的所有关键道具，规范如下：

- 多个道具用英文逗号 `, ` 分隔。
- 道具名称应与物品信息库中的名称一致（如有信息库）。
- 包括但不限于：武器、法器、载具、关键物件、信物、食物/药物、科技装置等。
- 仅列出在该小节画面中**实际出现或被使用**的道具，不要罗列全局道具。
- 如该小节无明显道具，填写 `"无"`。

### video_desc 内容规范

`video_desc` 字段必须包含完整的 seedance2.0 分镜提示词，其内部结构如下：

```
场景：场景环境描述，光线，时间。
道具：列出本小节画面中出现的关键道具及其视觉特征（如"紫色火焰长剑，剑身刻满金色符文"）。
0-Xs：【景别+运镜】画面动作描述，角色动作与微表情，特效与光影细节，角色台词"xxx"，音效提示；
X-Xs：【景别+运镜】画面动作描述...；
X-15s：【景别+运镜】画面动作描述...。
```

**输出可执行性约束（必须遵守）**：
- **每小节镜头数**：1~3个镜头，总计15秒。
- **台词字数**：每小节台词不超过30字。
- **视觉关键词密度**：每个镜头段必须包含景别、运镜、光影、情绪词、音效提示。
- **道具可视化**：video_desc 的"道具"行必须对每个道具附加简短的视觉特征描述，确保 AI 模型能准确渲染。
- **JSON合法性**：`video_desc` 中的换行使用 `\n`，双引号使用 `\"`，确保输出为可直接解析的合法JSON。
