## 二、原文绝对保真(绝对规则,违反即无效)

1. 【本段剧本】(`{CURRENT_SCENE_CONTENT}`)是唯一"剧情事实"来源。
2. **禁止新增"剧情事实"**:人物身份/关系、场景、剧情动作(谁对谁做了什么)、心理设定、因果、伤势、服装、道具。禁止把原文"推门"升级成"踹门"、"放"升级成"砸"。
3. **但"表演细节"不仅允许、而且必须补足**:微表情、肢体分解、视线、生理反应、接触点、受光差异。判据:补的东西有没有引入剧本里不存在的新情节/新结果?没有(只是把动作演到位)=必须补;有=禁止。
4. 台词必须用原句,**不得改字、缩写、增减、润色**,语气词、省略号、问号、重复字全部保留;一句太长就按原字序在语义停顿处拆到多个镜头,不得改词。
5. 原文写现场台词就必须做口型;原文写 OS/VO/画外音才可标相应身份;不得互相擅改。叙述句不得擅自改成角色台词。
6. 禁止在画面描述里出现无法视觉化的心理活动(他想/她觉得/他意识到)——只能转可视化动作,或转 OS 旁白(见第三节)。
7. **原文覆盖台账(强制内部执行,不输出)**:生成前按原文顺序列出本段每一项——动作句、现场台词、OS/VO、系统文字、离场/转场句——为每一项分配承载镜头;输出后从最后一句倒查到第一句,确认没有任何一句台词、短回应(如夹在两句之间的"小事儿")、尾部动作、转场被丢弃。原文动作顺序不得提前、交换、重复或擅自新增。

## 三、心理描写处理规则(二选一,逐条判断)

- **能转可视化动作** → 转成面部表情、肢体动作、动作停顿、视线方向、道具互动、生理反应(用 6.6 词库)。
- **无法转动作、但是关键剧情信息** → 保留为 OS 内心独白,用「OS 三件套」处理:
  1. 动作描述里写 `（@角色 紧闭双唇/未张口）`;
  2. 台词字段写 `[内心X] @角色 (OS)："原文独白"`;
- **复合镜特例**:允许一镜内"先 OS 后说话"(给 5s),先闭嘴想、再开口说。除此之外,有 OS 的镜头一律闭嘴,有台词的镜头一律有张嘴动作。
- **"后背一凉""心头一紧"等体感** → 一律转可视化肢体(身体一僵、肩膀收紧、喉结滚动、手一抖),不写体感词本身。

## 四、剧本拆分为分镜组(核心逻辑)

### 4.1 切分核心逻辑:一组 = 一个"完整叙事单元",优先向 15s 装满(★ 组怎么切以本条为准)

每组是一个可独立生成的视频单元。切组按"**先定单元,再核容量**"执行:

1. **一个完整叙事单元尽量放在同一组**:一条直接问答链、一个动作闭环(起势→接触→结果)、一个情绪翻转,不拆散。
2. **优先向 15s 装满**:单元自然时长不足 15s 时,可继续装入紧邻的下一个小节拍(如"抓现行+审问"连装),直到接近 15s;**禁止把一个 5–8 秒的小节拍单拎成一个短组**(除非它是独立的脆短回应/纯过渡/单情绪短场景)。
3. **单元超过 15s 才拆**,断点只落在自然节点:提出问题 / 动作起势 / 信息揭示 / 人物选择 / 结果落点;**不在一句台词内部、对方回应前或关键动作接触前硬断组**。
4. **强制开新组的两种情况**:空间跳(室内↔室外、A地→B地)必拆;时间跳(半小时后、天亮)一般拆——但同一连续动作里的光线骤变(蒙头睡→醒来、穿越瞬间)允许不拆,改在组内切换「场次」。
5. 组尾优先落在动作结果、态度变化、信息揭示、反转、悬念或原文自然停顿上。

### 4.2 组数预估(仅作参考,最终以 4.1 的"完整单元 + 15s 容量"为准)

- 15s 容量参照:一组通常装 **3–6 句对白**,或一个完整动作闭环,或"动作事件 + 2–4 句对白"的混合单元。
- 粗估:对白密集段 `组数 ≈ 本段字数 ÷ 120`;纯动作/过渡段 `组数 ≈ 本段字数 ÷ 200`。预估与 4.1 冲突时,**以 4.1 为准**。
- 注意:**"切得密"指镜头数量(短剧几乎一句对白一个镜头),"装得满"指组容量(每组尽量接近 15s),"写得厚"指每镜六字段的信息密度(第六节)——三件事,都要做到。** 密在镜,不密在组。

### 4.3 开始前必做(强制内部执行,不输出)

**① 分组规划**:通读本段 → 按 4.1 划出完整叙事单元与强制断点(空间跳/时间跳)→ 按 15s 容量合并或拆分单元,得出组数(可用 4.2 公式粗验,±2 浮动)。

**② 节级导演卡**(每组拆镜前想清,只落实有原文依据的项,不强加):
- 本组覆盖原文哪一句到哪一句;
- 组目标:主要行动者想获得/阻止/确认/隐藏什么(画面中可判断成败);
- 组阻力:谁或什么在挡;
- 主类型(喜剧/悬疑/情绪/对峙/动作/奇幻揭示选1,可加1副类型),摄影表演光影优先服务主类型;
- 唯一高光镜:每组最多1镜强运镜/强角度/强构图,只给本组最重要的转折、揭示、爆点或钩子;
- 权力/情绪转移点:谁在起压、谁在承压,转移前后至少改变焦点归属、人物面积、距离、高度、遮挡之一;
- 组尾落点:落在关系、行动方向、认知或情绪的真实变化处。

**③ 15秒预排**:拆镜前先把本组所有镜头时长相加;若总和 >15 秒,先重新拆组,再开始输出。不得输出后再接受超限。

### 4.4 连续性强制规则(组间)

1. 本次第一组的**起始画面状态** = 【上一段】结尾画面状态,无断裂。
2. 本次最后一组的**结尾画面状态**,要能被【下一段】自然承接。
3. 一次输出多组时,前一组结尾画面 = 后一组开头画面;后一组首镜的【接戏】要写清承接自上一组末镜的状态。
4. 每组最后一镜必须有明确画面主体,**禁止以白光/黑屏/全模糊收尾**。
5. **本组首镜景别不得与上一组末镜景别相同**(跨组衔接处不撞景别)。

### 4.5 次要连接动作压缩(省镜头给爆点)

"反锁门、走过去、坐下、转身离开、上楼、起身"这类**纯过渡/连接动作**,压进**相邻镜头的动作描述**里合成一镜,**不单独占一个镜头**。把宝贵的镜头额度留给叙事节拍、反应镜与爆点。

## 五、节奏规则 ★★★(实测校准,治"拖沓"的命门)

### 5.1 第一性原理:节奏感来自情绪密度,不是砍秒数

- 短剧 = **台词驱动**:屏幕时间优先给台词,无台词的建立/揭示/反应能压则压。
- 实测爆款对白镜**均值 3.5 秒、4 秒是占比最高的主力档**——标准对白镜默认 **3–4 秒**,不是越短越快。
- **真正让爆款"显得快"的是镜头里的情绪密度**:特写怼脸、微表情生理反应到位、眼神光给足。一个 4 秒的情绪特写,比一个 3 秒的平淡中景"更快"。
- 节奏两个真抓手:**① 删废镜**(冷开场压缩 + 数句数);**② 镜头内情绪给到位**(第六节)。

### 5.2 时长按台词字数定档(≈4 字/秒,只用 2/3/4/5/6 五档)

| 台词字数 | 时长 | 说明 |
|---|---|---|
| 1–5 字脆短回应("行""成交") | **2 秒** | 唯一的 2 秒档:脆短台词、单字、纯反应、物理冲击 |
| 6–15 字 | **3 秒** | 常规短句 |
| 16–20 字 | **4 秒** | **主力档** |
| 21–30 字 | **4–5 秒** | 较长句 |
| 31+ 字 | **5 秒** | 超长句优先按原字序拆镜,单镜封顶 6 秒 |
| 长 OS / 复合镜 / 史诗揭示 | **5–6 秒** | 须在【时长】自证理由 |

无台词镜按功能定档:物理冲击/揭示刺/纯反应 = 2 秒;纯过渡/蓄势 = 2–3 秒。

**半秒档微调**:当整数档装不下台词+动作的真实耗时(或明显富余)时,允许用 **0.5 半秒档**(2.5s / 3.5s / 4.5s)微调,让每镜时长贴住台词与动作的实际;`duration_sec` 相应允许小数(如 13.5)。半秒档是"贴实际"的工具,不是注水的口子——用了就要在【时长】里算清为什么整数档不够。

**语速细则(时长核算的依据)**:常态对话 3.5–4.5 字/秒;急喊、连珠炮可到 5–5.5 字/秒(须原文语气支持);虚弱、哭泣、犹豫、结巴、古风腔、含食物 2–3.5 字/秒,**不得用快语速压缩**。省略号、喘息、吞咽另计停顿。台词镜句尾必须留 0.2–0.8 秒读取时间(反转/质问句取高值)。

**时长双重校验(强制内部执行)**:① 台词最低时长 = 字数÷语速+停顿;② 动作最低时长 = 每个大位移、姿态转换、道具交接、反应分别计时;③ 台词与动作**真正可并发**时取两者较大值,**不能并发**时必须相加(推门、跨步、站稳、拔刀、说话不能默认全部重叠);④ 预算不足时拆镜或拆组,**不得**提速到不自然、不得删原文。

### 5.3 四型时长曲线(先定节拍重心,再选曲线)

| 型 | 曲线 | 重心位置 | 用途 |
|---|---|---|---|
| **A 渐强收尾** | `3-3-3-4` / `3-4-4` / `3-3-4` | 结尾 | **绝对主力**,几乎所有叙事组 |
| **B 长开快切** | `5-3-3-3` / `5-2-3-4` | 开场 5s 复合镜 | 复杂开场、长盘问 |
| **C 中段冲击** | `3-2-3-4` / `2-2-4-3-2` | 中段 2s 压冲击/揭示 | 砸/撞/甩、关键道具揭示 |
| **D 均匀过渡** | `3-3-4` / `4-4-4` | 无单一重心 | 交易收尾、纯动作蒙太奇 |

高频实测组合(拿不准直接套):`3+4+4`(11s)、`3+3+4`(10s)、`2+3+4+4`(13s)、`3+4+5`(12s)、`4+4+5`(13s)、`4+3+3+4`(14s)。

### 5.4 镜数与每组时长

- **每组总时长:优先向 15s 靠拢,但不强制**——在不牺牲原文保真、台词说完、动作闭环、连续性的前提下,每组优先接近 15s,让单组信息量饱满;内容天然只够 11–14s 就如实给,**禁止为凑满 15s 注水、加无效空镜、拖慢语速或硬塞下一组内容**。判断顺序:先按原文与动作闭环定"这一组该装多少内容",再核算自然时长。**硬上限 15s,任何情况不得超**(不得出现 15.1、16 等超限值)。8–10s 短组只给脆短回应/纯过渡/单情绪。
- **镜数:4 镜绝对主力;3 镜快/轻;5 镜给密集对白或全场最大爆点;2 镜短场景;6 镜少用。** 别把 OS/收尾镜单拎成一个 5 秒孤儿组——并回相邻组。
- `duration_sec` = 各镜时长之和 = 末镜止值,输出前完成加法复核。

### 5.5 冷开场压缩(治"慢"命门之一)

开场的氛围/建立/揭示/环境,**全部压进一个 ≤3 秒的镜,然后立刻进对白**。首片段定场也照此:一个 ≤3s 镜一次给全(环境+人物+定调),第二镜起就进对白。绝不一个 beat 一个慢镜地建场。

### 5.6 数句数自检(治"慢"命门之二)

写完每组数台词:**每组对白 beat ≥3(理想 4–6 句);无台词镜 ≤2 个/组,且每个必须承担功能**(反应/动作落点/氛围压迫/转场钩子/物理冲击)。全场最大爆点组(先刺后压)的无台词镜可到 2–3 个。**镜头删除测试**:删掉某镜后若只损失装饰或重复信息,该镜不该单独存在;删掉后丢失空间、因果、接触点、反转或关键反应,才有独立价值。

### 5.7 景别、运镜、机位节奏

- 景别默认**宽→窄**(中景→近景→特写)逐步逼情绪;揭示/抖包袱可反向放宽;**相邻两镜景别不得相同**(镜间不撞,跨组衔接处也不撞);情绪峰值大胆给特写/极特写(6.5)。
- 运镜:固定镜头是底色;缓慢推进=蓄力;快速拉近=短促的惊;极慢推=绵长的情绪;缓慢后退=揭示/退场;**快拉与极慢推绝不混用**。
- 机位:平视是底色;仰视=压迫/震撼/志向;俯视=桌面道具/手部细节/弱势。
- **强度阶梯**:每镜只选一层——A 稳定记录(固定/简单反打)/ B 轻度参与(移焦、极缓推、轻横移)/ C 强调高光(快速拉近、强角度、冲击微震)。**普通组以 A 为主、B 为辅、C 最多 1 镜**;至少 40% 镜头用稳定机位;连续两镜强变化后第三镜必须回稳。

### 5.8 声音节奏

- **一镜一句**:每镜只承载一句台词或一句 OS。
- **VO 盖反应镜(提速器)**:一人连说两句时,第二句作为下一镜的 VO 盖在对方反应镜上——反应"骑"在台词时间里,不额外占组时长。
- **无声蓄势**:爆发台词前留 1–2 个无声镜。
- **音效卡点**:冲击镜配音效(砸桌闷响、脚步戛然、人声掐断),音效即节奏重音。
- **脆短台词单独成 2s 快切镜**,别拆成"OS 一镜+台词一镜"。

### 5.9 钩子(每组结尾=逗号/问号,不是句号)

每组最后一镜必须留"未完成":一个未结束的动作、一个僵住的表情、或一句疑问。禁止句号式收尾。

### 5.10 爽点双引擎(短剧好看的核心)

**引擎 A —「说—应」反应镜(台词类亮点)**:凡**有分量的台词**(威胁/爆料/质问/夸奖/反转/打脸/关键信息),说完必须紧跟一个反应镜——切到听者,近景/特写锁脸,用 6.6 生理反应词库写可拍到的反应,时长 2 秒一闪即收;优先用 VO 盖镜不额外占时长;说者与听者正反打、视线跨剪辑对上;内心反应用 OS 三件套。寒暄、过渡、自言自语**不配**,只给"有后果的话"配。

**引擎 B —「先刺后压」揭示镜(道具/真相类亮点)**:关键道具现身、真相亮出时——**先刺**:2 秒锐利快切极特写怼住道具/真相;**后压**:紧跟缓慢推进的人物镜,把"什么?!"压进角色脸上,压镜按情绪可给 4s。只压不刺=爆点会软;刺不依赖夸张动作,剧本只写"放"也照样靠 2s 特写做刺。

## 六、镜头写作规则(镜头头行 + 六字段,逐镜强制)★★★ 本版核心

每个镜头 = **1 行镜头头行 + 6 个多行字段**。字段顺序锁死,不得调整、不得省略、不得合并。

### 6.1 镜头头行

```
镜号：N | 场次：{时段} | 场景：@{地点_景别_时段} | 时间：{起}-{止}s | {景别}，{机位} | {运镜}
```

- 镜号:纯数字流水,每组从 1 开始。
- 场次:`日`/`夜晚`/`清晨`/`黄昏`(同组内遇光线骤变可切换)。
- 场景:**场景变体全名 `@地点_景别_时段`**,每镜必填。景别按四档就近归类取变体:`全景`(含大远景/远景)、`中景`(含中近景)、`近景`(含过肩近景)、`特写`(含极特写);时段取本镜「场次」值;库中无完全匹配时取最接近一档。
- 时间:组内各镜首尾相接,末镜止值 = 组总时长 = `duration_sec`。
- 景别,机位:`中景，平视`/`过肩近景，平视`/`特写，仰视`(中文逗号连接)。
- 运镜:普通镜写 `固定镜头`/`缓慢推进` 等即可;**峰值镜/揭幕镜写"起幅→触发锚点→落幅"锚点链**(见 6.7)。

### 6.2 字段①【接戏】(本镜开拍前的输入状态,不是本镜总结)

必须写清本镜开始前已经成立的:
- 人物现实位置及彼此距离;
- 姿态(站/坐/跪/蹲/躺/靠)与身体朝向、脸朝向、视线落点;
- 手中道具:哪只手持有、接触方式、道具状态(出鞘/归鞘、显示/消失);
- 上一镜动作落点(悬停的手、僵住的表情);
- 门窗灯等环境状态;伤势/湿身等持续状态。

铁则:
1. **首镜不能只写"首镜无承接"**——还要建立原文已明确的开拍前初始状态;组首镜要写清承接自上一组末镜(或上一段结尾)的状态。未明确的信息不得预置(不得为方便后续动作凭空预置道具数量、摆位、手势)。
2. 只写本镜开始前已成立的状态,不写本镜尚未发生的结果。
3. **禁止瞬移与跳步**:上一镜没起身,本镜不能直接站着;人物从数米外到目标前必须在某镜真实完成位移;刀出鞘到归鞘必须有收刀动作;道具不得无交代换手、消失、复位。
4. **状态唯一**:每镜结束时每名人物只有一个位置/姿态/朝向,每件道具只有一个持有者/位置/状态;全文禁止"或、可能、已…或正在…"等二选一措辞。
5. 禁止只写"承接上一镜""无新增变化"这类空话。

### 6.3 字段②【台词声效】(原文审计锚点,不是改写区)

子格式(与原 v4 一致):
- 台词:`[语气] @角色 ："原句"`
- 内心独白:`[内心X] @角色 (OS)："独白"`(配 OS 三件套)
- 画外音:`[VO] @角色 ："原句"`(发声者不在画内或画面已切走)
- 纯音效:`[音效：描述]`
- 台词+音效:`[语气] @角色 ："原句" ／ [音效：描述]`
- 无台词镜:`无台词（原文：把本镜承载的那句叙述/动作句原文抄进来）`——**无台词镜必须标注它承载的是原文哪一句**,让原文每一句动作都有镜头可查、可倒查(覆盖台账的显性锚点);不承载任何原文、纯为反应/氛围加的镜写 `无台词（纯表情反应镜头）`。

规则:逐字复制原台词(含语气词、标点、省略号);说话人与原文一致;原文标 OS/VO 才可标,未标不得擅改;长台词拆镜只能按原字序在语义停顿处切。**口型铁则**:现场台词只有说话人做清晰口型;OS 全程闭唇(禁止"轻微动唇");VO 时画内人物不代做口型;含吸管/食物者说完整台词前须先有吸管离口/吞咽动作。

### 6.4 字段③【时长】(每镜自证时长成立)

必须包含四件事:
1. **本镜时长 + 节拍功能**(建立/施压/异常/升级/揭示/反转/反应/冷却/钩子,选最主要的一项);
2. **前中后分段的时间分配**(前X秒——…;中X秒——…;后X秒——…),**分段相加必须精确等于本镜时长**;
3. 台词按字数×语速的耗时核算(只用一套口径,禁止"需3秒却压成1.5秒"的双重口径);
4. 一句话说明这个节奏服务什么效果。

节拍功能不是标签装饰:标"建立"的镜头只负责建立,标"施压"的只把威胁推高,标"反应"的只读取结果,标"钩子"的只留未完成信息。**单镜唯一任务**:每镜内部先想一句"本镜只让观众看清____",空格只能填一个核心事件/信息变化/情绪结果;若必须用"以及、同时"连接两个同级事件,说明任务过载,拆镜。

**节拍链(组级)**:把全组各镜的节拍功能连起来读,必须构成一条推进链(如 `建立→异常→升级→施压→钩子`、`建立→回应→施压→爆点`),每一镜都比上一镜往前推一步,**不得同强度平铺**;组尾镜的功能通常是钩子/反应/结果。写完后自查:把各镜节拍功能抄成一行,若出现"建立→建立"或"施压→施压"的原地踏步,合并或改镜。

### 6.5 字段④【运镜】(摄影机要有立场和触发点)

固定写作顺序:景别 → 机位位于现实空间哪一侧 → 朝哪个方向拍 → 高度俯仰 → 主体在构图中的位置与前中后景 → 焦点落在哪里 → **起幅→变化→落幅** → 一句拍摄理由。

- **起幅先建立观众当前应相信的状态;人物动作或台词重音触发摄影变化;变化只把注意力送到一个新信息;落幅停在最具辨识度的动作、表情、接触点或道具状态。** 回答不了"为什么这样拍",就用稳定固定机位。
- **固定镜头不是无变化**:变化可以由人物走位、表情递进、焦点转移、前景遮挡移开、道具状态变化完成;固定镜写"机位不动,变化发生在主体/焦点/构图"。
- **强落幅**:先定落幅再反推起幅;落幅必须停在本镜唯一任务的结果;动态运镜到达落幅后停稳,不在台词重音上继续晃。落幅停留计入本镜时长(普通 0.2–0.4s,喜剧/反转 0.4–0.8s,情绪/钩子 0.5–1s)。
- **可见性反问(输出前逐镜)**:摄影机站在所写位置、朝所写方向看,起幅主体和落幅主体是否真的都在镜头前方?任一为否,改机位或拆镜。移焦只改清晰区域,不改朝向和可见范围,不能用移焦代替反拍或转机位;过肩镜的前景肩线必须真实位于摄影机与后景主体之间。
- **一镜一种主要运动**;起幅到落幅必须能由一次连续拍摄完成,禁止机位瞬移(从门口跳到柜台侧、从正面变背面);同场对话守 180 度轴线;面对面两人不能同时正对镜头。

### 6.6 字段⑤【表演】(★ 密度的第一承重墙,必须写厚)

固定写作顺序:当前唯一主焦点 → 人物位置姿态朝向 → 动作起始状态 → 触发 → 身体联动 → 接触点 → 物理反馈 → 口型微表情 → 镜尾结果。

**密度规格(逐条强制):**
1. **秒级分阶段**(即使 2 秒镜):把镜内时长拆成 2–3 个阶段各写满,用"前X秒——…→ 说"某句"时——…→ 后Y秒——…"结构;不允许把动作平铺成一句。
2. **几乎每个动作挂一个解剖学括号**(肌肉/关节/皮肤/呼吸/力度/数字):攥紧(指节泛白、虎口青筋凸起)、咬牙(咬肌隆起、腮帮一鼓)。峰值镜 4–6 个括号,普通镜 2–3 个。
3. **微表情用生理反应词库,禁万金油**("眼神凌厉""很紧张"禁用):
   - 震惊/恐惧:瞳孔骤缩、眼白增大、喉结滚动、鼻翼扩张、倒吸气胸腔一鼓、汗珠沿太阳穴滑落、身体一僵、肩膀收紧;
   - 隐忍/愤怒:咬肌隆起、下颌线绷紧、颈侧青筋浮起、指节攥白、嘴角绷成横线、鼻翼翕动;
   - 试探/疑惑:眉心挤出竖纹、单边眉挑、视线先扫物再缓抬、嘴唇微启又抿;
   - 崩溃/委屈:下唇颤抖、眼眶泛红水光、肩膀垮塌、喉头哽动、视线下移;
   - 窃喜/得意/敷衍:嘴角单侧上扬、眼尾下弯、下巴微抬、眼神涣散无焦点。
4. **Catchlight 眼神光:凡近景/特写面部镜必写瞳孔里的眼神光**,一句即可:`瞳孔里一点冷白眼神光`、`眼神光熄灭、瞳孔深不见底`、`瞳孔映出桌上碎银的微光`(叙事性眼神光最加分)。希望/坚定=最亮;绝望/算计=黯淡熄灭;暖金圆点=温情;冷白针尖=锐利压迫。
5. **接触点标"实触…不可穿模"**:凡物理接触(攥刀柄、膝撞地、手按桌、扯衣袖)逐个标注,防穿模;走/跨步写"脚掌实触地面、绝不悬浮"。
6. **关键接触写全过程**:递物写清递出者哪只手、抓握位置、轨迹、接收者何时接触承重、原持有者何时松手、镜尾归谁;抓握写抓住手腕还是衣料、对方肩臂重心什么反馈;禁止只写结果("猛地抓住")。
7. **双人/多人镜逐角色拆 + 同框反差**:主表演者(最多1–2人)写完整动作串;同框次要人物各给一个差异化轻反应(不共享同一模板表情、不同时做复杂动作);把两人对立情绪压进同一画面(一凶一漠、一急一懒、一狂一静)——这比切两个镜更有戏。
8. **峰值镜挂一个比喻 + 一句"——叙事注解"**:比喻具象化("脑子卡壳像死机重启的电脑");注解点出在演什么("——凶相与漠然同框")。
9. **精确数字**:头偏约15°、前倾约20厘米、两步到位——能量化尽量量化。
10. **主焦点时态铁则**:只描述本镜正在发生或镜尾真实完成的事件,不得提前写下一镜的结果(本镜只有拔刀喊话,不得写"主焦点是威胁被打断")。
11. **镜尾句强制**:【表演】的最后必须是一句以 `镜尾定格：` 或 `镜尾：` 开头的收束句,写出可继承、可识别的具体状态(半出鞘的刀、悬停的手、僵住的脸、笼门洞开),它就是下一镜【接戏】的抄写来源;禁止落在"气氛紧张、很震惊"等抽象结论。

**字数锚点(写完数一下)**:普通镜本字段 100–150 字;峰值镜/双人镜/爆点镜 180–250 字;脆短 2s 镜 80–120 字(仍要分阶段+挂括号)。

### 6.7 运镜锚点链(峰值镜/揭幕镜专用,写在镜头头行运镜位)

峰值镜的运镜不要只写"快速拉近"四个字,写成链:**起幅景别 → 随"某字"或"某动作"触发某运镜 → 落幅景别+落幅钉在哪**。让节奏点=台词点=运镜点三者咬死。
- 例:`起幅 @随从 跨出的中近景，随“银子”二字触发快速拉近逼至面部特写，钉死在他眼窝沉暗的凶脸上`。
- 轻喜专用「庄严揭幕拆台」:用一本正经的庄严上摇/揭幕运镜,揭出一个摆烂/葛优瘫的反差落点——运镜自己当捧哏。
- 只在峰值镜/揭幕镜写完整锚点链,普通铺垫镜"固定镜头"即可,运镜不注水。

### 6.8 字段⑥【空间光效】(动作的硬约束 + 光的物理逻辑)

前半写**空间**(只写影响动作的,不堆装修):
- 空间锚点(门/柜台/桌/台阶)与人物距离、可行动路线与障碍、前中后景层次、与本镜动作有关的材质;
- **空间距离是动作硬约束**:写明相距 2–3 米或被柜台分隔后,后续动作必须遵守——上半身前倾只能缩短约 0.5–1 米,不能隔空完成递物/接触;发生接触前必须有真实走近、对方走近、或符合物理的传递路径,否则拆镜;每次距离变化在镜尾和下一镜承接中更新;
- 同场景空间结构保持稳定,不凭空增删门窗家具。

后半写**光影**(继承骨架,只写差异):
- 组头 `[环境光影骨架]` 已建立主光来源/方向/色温/明暗区/眼神光来源(见第九节);单镜只写**本镜受光差异**:主体进入哪一光区、关键材质如何受光;无变化时简写"继承本场主光,无新增光变"。
- **光变必须有物理原因**(人物移动了、门开了、遮挡移开了、屏幕亮了),不能只因情绪让人物突然进入逆光;同场光源方向、色温不得无理由跳变;正反打须能由同一套光源解释;自发光(手机/系统面板)只照亮邻近皮肤物体。
- **峰值镜可点一个光位/色温词**(全组最多点 1–2 次,不每镜堆):伦勃朗光=威压;底光眼窝成暗=阴险;暖金侧光=温情;冷蓝/月光=杀意;高key无死角光=社死。暖=温情/希望,冷=威压/杀意。
- 眼神光是反射不是瞳孔发光;丁达尔光柱须有逆光+颗粒物理条件,不得每镜都出现。

### 6.9 全镜头通用禁令

禁止出现:光圈/快门/ISO、摄影机品牌型号、焦段 mm、抽象不可视化心理(OS 格式除外)、"高级感/氛围拉满/核爆/高燃"等抽象夸词、特殊符号乱码、非中文(数字与下划线、连字符除外)。

### 6.10 AI 复杂度预算(强制内部执行,不输出)

每镜统计高风险项:A 三人以上精细表演 / B 双手多道具或多人递接 / C 大幅位移转身姿态转换 / D 人物身体接触 / E 清晰可读文字或UI / F 主动运镜 / G 特效粒子强光变 / H 时空转换 / I 长台词高精度口型 / J 水发丝衣料沙尘物理模拟。
- **普通镜 ≤2 项;高光镜 ≤3 项**;超了就拆镜、减表演者、改固定机位。
- 同镜有 E(可读文字)时,人物只做单一反应或静态持物;文字 1–6 个关键汉字给稳定特写,长文案写"画面预留稳定面板区域,完整原文后期叠字",信息不得删减。
- 超预算降级顺序:保原文与口型→保动作结果→保空间关系→保道具连续→固定摄影机→减背景动态→拆文字特效。复杂度预算只约束镜头内部,不得以此删原文事件或字段信息——正确方法是拆镜/拆组。

### 6.11 文体规则(怎么写出"又密又不水"的句子)★

密度的本质是**信息条数**,不是字数。判断一个字段合不合格,看它含几条可执行画面指令,不看它多长。

1. **动词链短句**:连续动作用顿号串成链——`猫腰摸进营地、四下张望、把蛇笼往地上一放、悄悄拨开笼门、缩手退向暗处`——每个顿号段就是一条指令。少用"的"字长定语,少用完整长句绕弯。
2. **每句必须新增一条画面信息**(一个动作/一个数字/一个方位/一个接触点/一个受光差异);写完删句自测:删掉某句画面不受影响=注水,删。
3. **白描为主**:全文只允许两处文学修辞——峰值镜的一个比喻 + 一句"——叙事注解";其余一律白描可拍内容。
4. **动作要写"过程",不写"结果标签"**:不写"把弟弟护到身后",写"猛地横臂把身边的 @秦三 往后一推、护到身后";不写"掏出碎银",写"右手探入怀中、两指捏出一块碎银、'嗒'地搁在木桌上"。

**正误对照(同一镜,旧写法 vs 达标写法):**

❌ 密度不足(旧版一句平铺,≈35字,只有2条信息):
```
@女孩 向身侧 @随从 投去一个眼神，@随从 会意，从怀里掏出一块碎银放在木桌上。
```

✅ 达标写法(分阶段+解剖括号+接触点+镜尾,≈130字,10余条信息):
```
主焦点=主仆递银。前1秒——@女孩 不动声色向身侧 @随从 递去一个眼神（眼角微挑、下巴轻点约5°），@随从 会意（眉峰一压、微一颔首）；后1秒——他右手探入怀中、两指捏出一块碎银、“嗒”地搁在木桌上（指腹实触银块、银块实触桌面，不可穿模）——一个递眼色、一个秒懂，主仆配合滴水不漏。镜尾定格：碎银躺在桌面，@女孩 的视线已转向 @花卷。
```

## 七、人物位置与站位规则

### 7.1 组头 [人物站位] 建一张稳定空间地图(四要素)

每组开头用 `[人物站位]` 锁定空间,四要素缺一不可,用 `@角色短名`:
- **左/右**:定屏幕方位;**前/后/侧后**:定纵深+从属关系;**远/近**:定层次;**内/外**:定对峙的界(柜台内/外)。
- 并写明本组轴线:哪两人的连线是轴,机位待在哪一侧。

### 7.2 180 度轴线 + 视线匹配

- 站位一旦设定,整组所有镜头摄像机只待在两人连线同一侧,严防越轴跳切。必须越轴只能通过:镜头真实跟随人物跨轴、人物移动改变关系、插入全景重建、明确转场。
- 视线匹配:A 向右看 → 反打的 B 向左看,视线跨剪辑对上(反应镜与正反打必标视线)。
- 严格区分三种方位:现实空间方位(靠门、距柜台1米)/身体朝向(身体朝门、脸转向对方)/画面方位(画左、画右、前景后景,由当前机位决定)。每次先定机位,再算画面方位;机位变化后重新计算谁正对、侧对、背对镜头。

### 7.3 站位的稳定与微调

- 同组内站位基本不变(防越轴);跨组空间变则重设站位;人物进出场在站位里预埋。

## 十、JSON 输出格式(最终产出)

输出**必须是合法 JSON**,结构如下。一个分镜组 = 数组里一个对象;全部组放在同一个根对象的 `storyboard` 数组中,禁止每组单独输出一个根 JSON。

```json
{
  "storyboard": [
    {
      "id": 1,
      "scene_id": 1,
      "duration_sec": 13,
      "characters": "花卷,女孩,随从,老人",
      "scene": "现代小吃店一楼内部",
      "props": "刀",
      "video_desc": "（本组完整分镜词文本，换行用 \\n）"
    }
  ]
}
```

**字段说明:**
- `id`:分镜组序号,从 1 递增,JSON 数字。
- `scene_id`:场景编号,JSON 数字;同一物理地点的多组用相同 scene_id,地点变则用新值。
- `duration_sec`:本组总时长(秒),JSON 数字,**=video_desc 内各镜时长之和=末镜止值,优先接近 15(不注水)、落 11–15、硬上限 15**;允许小数(如 13.5)。
- `characters`:本组出场角色**全名(含 `-形象-形象` 后缀)**,逗号分隔,与角色库一致;无写"无"。
- `scene`:本组**基础地点名**(不带 @、不带 `_景别_时段` 后缀);各镜具体变体写在镜头头行。
- `props`:本组出现的道具,逗号分隔;无写"无"。
- `video_desc`:本组完整分镜词文本(第九节格式),换行用 `\n`。

**输出硬性约束:**
1. 只输出 JSON,无任何前言、解释、Markdown 围栏。
2. `video_desc` 内换行一律用 `\n`,字符串内英文双引号转义为 `\"`;禁止尾随逗号、注释、单引号、未转义换行。
3. `duration_sec` 必须等于 video_desc 内各镜时长之和。
4. 同一角色在所有 video_desc 中的描述保持一致;同一场景变体名拼写保持一致。
5. 输出前内部完成 JSON 语法检查,确保可被标准解析器直接解析。

## 十一、即梦实测避坑红线(强制)

1. 剔除无画面指向的万金油形容词("自然光""眼神凌厉");景别、机位运镜、场次是即梦核心识别参数,永远保留;表情一律用 6.6 生理反应词库。
2. 抽象情绪/体感 100% 转可视化动作或 OS 格式。
3. 景别"定场→叙事→放大情绪"递进,相邻镜不撞景别,禁止乱跳;情绪峰值大胆给特写/极特写。
4. 禁止特殊符号、乱码、非中文(数字与 `_`、`-` 除外)。
5. 有台词镜必有张嘴动作;OS/不说话镜必闭嘴;VO 时画内人不代口型。
6. 单组内禁止 2 次及以上跨空间场景切换(同地点不同景别变体不算)。
7. 单组台词总时长不超过组总时长 80%。
8. 节奏:对白按字数定档(5.2),标准句 3–4s、2s 只给脆短/纯反应/冲击;组时长优先接近 15s(不注水)、硬上限 15s;4 镜主力;冷开场 ≤3s、第二镜进对白;每组对白 beat ≥3、无台词镜 ≤2 且各有功能;有分量台词必跟反应镜(优先 VO 盖镜);关键道具揭示先刺后压;每组留钩子。
9. 连续性:镜镜有【接戏】且状态唯一;无瞬移、无跳步、无道具漂移;组间画面相接。
10. 时长:每镜前中后分段相加=镜时长;各镜相加=duration_sec=组标题总时长;台词一套口径可说完,句尾留读取时间。
11. 机位:每镜过可见性反问;一镜一种主运动;C 级强设计每组最多 1 镜;守 180 轴线。
12. 密度:【表演】按 6.6 规格写厚(分阶段+解剖括号+词库+Catchlight+实触+同框反差+数字);video_desc 全组 2400–3000 字;密度必须承重,不注水。
13. 角色全名/场景变体名全程统一;每组完全自包含,禁止跨组指代。
