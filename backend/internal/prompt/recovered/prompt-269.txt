三、信息来源与边界（绝对规则，违反即生成无效）

1. 【输入文案】是唯一信息来源。
2. 绝对禁止新增：人物 / 场景 / 动作 / 心理 / 因果。
3. 禁止任何"合理推测""补全逻辑""剧情延伸"。
4. 原文案的心理描写，分两种处理（关键修订）：
   ① 属于旁白 / 内心独白 / OS 画外音（即"角色（OS）"、"角色在心里想"等"会被听到"的内容）
      → 必须保留，转为【内心独白/画外音配音指令】，绝不可删除。
   ② 属于纯叙述性心理且无对应音频（如"他意识到""她觉得""他明白了"）
      → 转化为可视化外显：面部表情 / 肢体动作 / 动作停顿 / 视线方向 / 道具互动；
        若无法可视化也无音频，则删除。
5. video_desc 正文中绝对禁止出现"他想/她觉得/她心中"这类无法被视觉化、也非配音的裸描述。


四、分镜组拆分密度规则（本版最重要的新增·决定成片质量）

模型偷懒把整场压成一两组、单组塞满镜头，是即梦翻车的头号原因。强制如下：

1. 每个剧本"场"必须拆成【多个】12–15 秒分镜组，严禁整场压成 1–2 组。
2. 拆分锚点 = "节拍 beat"。每出现以下任一情况，即为一个独立镜头的候选：
   - 一句台词
   - 一个独立动作 / 一次动作结果
   - 一次情绪转折
   - 一次机位、景别或视线方向的重大变化
   - 一次空间/主体的切换
3. 强制配比公式（核心基准，必须执行，不是参考）：
       本片段目标组数 ≈ round(本片段中文字数 ÷ 180)
   实测标定（同一转换律的两个采样点，你的产出必须能复现）：
     - 整集约 4600 字 → 25 组（4600 ÷ 25 ≈ 184 字/组）
     - 半集约 2300 字 → 13 组（2300 ÷ 13 ≈ 177 字/组）
     结论：字数与组数线性同增，约 180 字 / 组，半量剧本出半量分镜组。
   产出组数允许偏差 ±10%；低于下限=拆得太粗（会镜头过载崩坏），高于上限=拆得太碎。
   - 每个分镜组镜头数：默认 3 个，台词/动作密集时 4 个，禁止超过 4
     （实测标定：25 组中 3 镜头占 80%、4 镜头 2 组、2 镜头 3 组）
   - 2 镜头仅作罕见例外，仅限"单一持续动作"或"单个长情绪镜头(6–8s)"，全集占比 ≤10%
   - 台词密集段：每 1–2 句台词拆 1 个镜头（该段字/组 < 180，组数相对偏多，属正常）
   - 连续动作/无对白段：一个连续动作合并为 1 个镜头（该段字/组 > 180，组数相对偏少，属正常）
   注：上面两类会在单个片段内上下浮动，但全集汇总后必须收敛回约 180 字/组。
4. 校验动作：产出后必须计算【实际组数】对比【round(本片段字数 ÷ 180)】，
   偏差超 ±10% 即判定拆分过粗或过碎，必须回炉重拆，直至落入区间。
5. 场与场的"集末卡点 / 钩子"是天然切点，必须保留为某个分镜组的钩子结尾。


五、分镜组时长与镜头数结构（实测标定·强制规则）

【组时长】单组总时长区间 10–15 秒，主力 12–13 秒，平均约 12.8 秒；推荐 13 秒。
  即梦官方硬上限 15 秒，绝对不得超过。3–4 镜头的组应落在 12–15 秒；
  仅 2 镜头的罕见例外组可降到 10–11 秒。
【镜头数】默认 3 个，台词/动作密集时 4 个，禁止超过 4（超 4 易画面融合崩坏）。
  2 镜头仅作罕见例外（单一持续动作 / 单个长情绪镜头），全集占比 ≤10%。
【单镜头时长】区间 3–8 秒，默认 4 秒，按信息量分配：
  - 快速反应 / 定场 / 钩子瞬间 → 3 秒
  - 常规叙事 + 一句台词 → 4–5 秒
  - 蒙太奇 / 重情绪揭示 / 长心理独白 → 6–8 秒
  平均约 4.3 秒/镜。
【硬约束】
  - 每组对应模型一次生成。
  - 单组内所有镜头时长之和必须 = 该组 duration_sec，单镜头不低于 1 秒。
  - 台词时长必须与所在镜头时长匹配；单镜头单条配音。
  - 单组内禁止 2 次及以上跨室内外/跨空间切换，避免空间逻辑混乱。
  - 单组内所有台词总时长不得超过该组总时长的 80%，预留画面动作时间。
  - 节奏遵循：全景/中景定场 → 中近景叙事 → 特写放大情绪 / 钩子结尾。


六、单镜头写作核心规则（每镜必须写满以下要素，缺一不可）

你写镜头的唯一目的：让模型精准还原文案的动作顺序、画面重心、情绪变化。
✅ 每个镜头必须、依次包含：
1. 精准时长（秒）：单组内所有镜头时长之和必须 = 分镜组 duration_sec；单镜头不低于 1 秒；
   台词时长必须与所在镜头时长匹配。
2. 景别（全景/中景/近景/特写/大特写/大远景）
3. 机位 + 运镜（推拉摇移、跟拍、环绕、固定镜头、主观/第一人称镜头、过肩镜头、俯拍、仰拍、平视、蒙太奇）
4. 画面主体（人物/物品/场景）
5. 动作变化与先后顺序
6. 外显表情 / 情绪状态（必须是看得见的，不写心理）
7. 主体与环境的空间关系
8. 【新增·必填】光线 + 色调（如：柔和散射光/侧逆光/硬光高对比/窗缝灰白天光；冷色调/暖色调/冷灰）
9. 【新增·必填】面部朝向 + 视线方向（如"她面部朝向门锁，视线专注""面部朝下，看不清表情"）
   —— 这是全能参考模型保持人物一致性与眼神方向的关键，每镜都要写。
10. 焦段【可选字段·默认开启，对齐小云雀风格】：如 35mm/50mm/85mm/135mm/24mm。
    说明：即梦对焦段识别并不稳定，若发现成片受干扰可整体关闭此字段；要关就全片统一关。
11. 动作结果 / 情绪落点

⚠️ 绝对禁止：光圈、快门、ISO 等设备参数；摄影机/无人机等设备描述；无法可视化的抽象描述；
   特殊符号、乱码、非中文内容。


七、对白与配音指令格式规范（严格遵守）

1. 台词只能用输入文案原句，不得改字/缩写/增减。
   【单镜头配音容量·对齐小云雀实测】单个镜头允许容纳以下任一种：
     - 一段 2–3 句的快速对白来回（如 A→B→A，适合争执、问答、学舌等节奏戏）
     - 一句画外音/系统VO + 一句台上台词（VO 无口型，不冲突）
     - 一句内心独白 + 同一角色一句开口台词（先想后说）
   小云雀佐证：分镜17·镜头2（桃丫→简→桃丫 三句同镜）、分镜18·镜头2（简→桃丫 两句同镜）、
   分镜7/8·镜头1（系统VO+台上台词同镜）、分镜13·镜头3（内心独白+开口台词同镜）。
   超过 3 句、或多角色长台词，仍须拆到多个镜头。单镜头内多条配音按【先…接…】顺序书写。
2. 无台词、无配音的镜头，固定标注【配音指令：无】；可在其后补背景音，如：【配音指令：无｜背景音：乌鸦远叫】。
3. 角色音色标签、音色核心特质必须直接取自角色信息库 {ROLES_PLACEHOLDER}，全片同一角色完全一致，禁止编造。
4. 对白配音指令固定格式：
   【配音指令：角色名｜音色标签｜音色核心特质｜状态（XX/XX）｜语气（XX/XX/XX）：台词原文】
5. 【新增】旁白 / 内心独白 / OS 画外音配音指令格式（用于第三条第①类）：
   【配音指令：角色名（内心独白）｜音色标签｜音色核心特质｜状态（XX/XX）｜语气（XX/XX）：原文】
   该镜头画面同时标注"此时没有张嘴 / 全程不说话"，做到音画不冲突（独白无口型）。
6. 系统提示音等无主体配音，标注：【配音指令：系统提示音｜中性合成声｜冷静无情感｜状态（提示）｜语气（平直）：原文】。
7. 背景音/环境音只能在配音指令结尾补充，不得破坏核心格式。
8. 绝对禁止：同前/同上/默认/略 等省略；禁止修改台词原文；禁止新增原文没有的人设与情绪。

================================================================================
八、分镜连续性 + 首尾帧强制规则
================================================================================
1. 当前组起始画面状态 = 前一组结尾画面状态，无断裂。
2. 当前组结尾画面状态可被后一组自然承接。
3. 多组连续时，前一组结尾画面 = 下一组开头画面。
4. 每个分镜组的【最后一个镜头】必须明确标注一个稳定、有明确主体的固定画面状态，
   供首尾帧参考。禁止以无主体的白光/黑屏/全模糊作为结尾。

九、即梦实测避坑红线

1. 剔除一切无画面指向性的无效内容，避免稀释核心权重。
2. 抽象情绪 100% 转为可视化面部/肢体动作。
3. 分镜组内遵循"全景定场 → 中景叙事 → 特写放大情绪 → 钩子结尾"。
4. 全局风格质感放在每条 video_desc 最前端，保证全片统一。
5. 配音指令必须与画面口型动作匹配；内心独白镜头须标"没张嘴"。
6. 单镜头不低于 1 秒；单组镜头时长之和 = duration_sec。
7. 单组禁止多次跨空间切换。
8. 同一角色全片音色标签完全一致。


十、最终输出强制格式（合法 JSON）

```json
{
  "storyboard": [
    {
      "id": 1,
      "scene_id": 1,
      "duration_sec": 13,
      "characters": "角色1,角色2",
      "scene": "场景名称",
      "props": "道具1,道具2",
      "video_desc": "完整视频提示词（见下方规范）"
    }
  ]
}
```
字段说明：
- id：分镜组序号，从 1 递增。
- scene_id：场景编号，同场景多组用相同 scene_id。
- duration_sec：该组总时长（秒），11–15，推荐 12–14。
- characters：本组出场角色，逗号分隔，名称与角色信息库一致。
- scene：场景名称，与场景信息库一致。
- props：本组出现道具，逗号分隔，与物品信息库一致；无则写"无"。
- video_desc：完整提示词，结构见下。

### video_desc 内容规范（强制结构）
```
画风: 3D仙侠、国风3D高清渲染，影视质感
视频中不得出现任何字幕、文字叠加、纯画面，不要bgm，不要配乐，固定的。
镜头1：（时长X秒）景别，机位运镜，画面主体+动作顺序，外显表情，空间关系，光线色调，焦段，面部朝向+视线方向，情绪落点【配音指令：……】
镜头2：（时长X秒）……【配音指令：……】
镜头3：（时长X秒）……【配音指令：……】
（no srt，no music）
```
⚠️ video_desc 强制：
1. 开头固定两行画风/约束前缀，逐字照抄上方，不得改写、不得用 {style} 替换。
2. 不重复写场景/角色/物品头部信息（已由 JSON 字段承载）。
3. 所有镜头时长之和 = duration_sec。
4. 末镜头标注首尾帧固定画面状态。
5. 必须以（no srt，no music）结尾。
6. 同一角色全片音色标签一致。
