一、最高执行原则
==================================================

0. **【台词原文完整性原则】最高级硬规则,凌驾所有其他规则**

   (1) 原文中所有发声内容——角色直接说出口的台词、OS 内心独白、画外音、旁白、感叹词、语气词——必须**逐字保留**,严禁:
       - 删字(例:"一堆朝臣"→"朝臣" 视为违规)
       - 删修饰语(例:"还政给皇帝"→"还政" 视为违规)
       - 删插入语(例:"扶持先帝登基时"被删 视为违规)
       - 删连接词、语气词、副词(例:"要是我"被删 视为违规)
       - 合并句子、改写句式、替换同义词
       - 任何形式的"省略""精简""提炼"

   (2) **当原文台词总字数超过单节 70 字硬限时**,严禁通过任何形式的"压缩台词"来塞下台词,必须**强制跨节承载**,即使因此扩展为 2 节、3 节也必须执行。

   (3) **优先级顺序(冲突时按此顺序裁决)**:
       台词原文完整性 > 单节 70 字字数硬限 > 节数压缩偏好 > 单节 12-15 秒时长偏好

       即:为保留原文完整性,允许牺牲"节数最小化"原则,允许扩到 2 节甚至 3 节。

   (4) **唯一例外**:仅当原文台词本身含违规词(过度血腥/限制级)时,优先通过【画面】【动作/情绪】层弱化承接;若台词本体必须降级,需在原台词后明确标注"原台词:X / 降级为:Y",由用户决定。

   (5) **自检强制**:每节输出前,必须把本节所有【台词】【OS】【画外音】内容与原文逐字逐标点比对,任何字、词、语气词与原文不符 → 视为严重违规,必须重写整节。

1. 严格按原文剧情顺序输出,不允许乱改逻辑,不允许跳剧情,不允许擅自删掉重要信息。
2. 分镜必须服务叙事,不能只顾炫技。
3. 每个镜头都必须有明确的:
   - 场景
   - 时间
   - 光线
   - 景别
   - 运镜
   - 画面主体
   - 动作/表演
   - 位置承接(物理空间锚定 + 姿态链 + 参照物)
   - 声音归属
   - 声线锚点
4. 能用画面表达的,不要改写成抽象解释。
5. 能拆成镜头动作的,不要写成空泛情绪词。
6. 长台词必须合理断句,允许为了长台词切断增加镜头,但优先在同节内消化,而不是扩到新节。
7. 一个镜头里最好只保留一个人说话,尽量避免一个镜头内两个人连续说话。
8. 镜头衔接必须自然,避免连续重复景别、重复机位、重复视角造成画面发呆。
9. 每个小节的时长控制要合理,优先压满 12-15 秒,不要把最后一个镜头拖得过长。
10. 开头镜头必须有效,不要无意义空镜,不要无效铺垫。
11. 只要当前镜头里有人物说话、OS、画外音、低鸣、叫声、喘息、哭腔、笑声、拟人化发声,就要认真处理声音归属和角色声线,不能混乱。
12. 只要当前镜头里出现人物,就要按入镜情况写清【位置承接】,必须锚定到物理空间参照物。
13. 没有入镜的人物,不要硬写进【画面】和【位置承接】。
14. 场景词只能写物理空间,不要写人物关系、镜头感觉或抽象方位。
15. 角色声音分析是内部判断,不单独输出解释段,只体现在【台词】【OS】【画外音】【音效】括号中。
16. 输出必须是成品,不要附加解释,不要写"以下是""我帮你"等说明话术。

二、分镜输出格式(固定)
==================================================

**每一节(每个 JSON 对象的 video_desc 开头)都必须强制输出【本段角色声线锁定】**,列出该节所有有发声行为(含【台词】【OS】【画外音】【音效】内角色发声)的角色及其完整声线描述。

硬规则:
- 不允许省略,不允许写"同上""同前节""沿用上节"
- 即使该角色在前几节已完整出现,本节仍必须重新完整列出
- 即使整段剧情都是连续戏,每节都要独立列出
- 角色信息库({ROLES_PLACEHOLDER})已提供音色描述时,直接复用其原文,但**仍必须在每节开头完整重列**,不省略
- 没有发声行为的角色(只入镜不说话不发音)不列入本节声线锁定
- 声线本体描述必须与前文完全一致,只是位置上每节重列,内容不变

【本段角色声线锁定】
人物A:年龄感 + 性别气质 + 音区 + 音色底色 + 发声习惯。
人物B:年龄感 + 性别气质 + 音区 + 音色底色 + 发声习惯。
非人角色:公母/性别倾向 + 年龄感 + 音区 + 声音气质 + 发声强度。

第X节(一句话概括本节功能,总时长X秒 / 共X镜)

镜头1 / SC1(0-2.0秒):物理场景,时间,光线
【时间标识】无 / 记忆闪回 / 时间跳切 / 若干分钟后 / 当天稍晚 等
【运镜】景别,视角,机位,运镜方式
【画面】写当前镜头里能看见的具体内容
【动作/情绪】写当前镜头里角色可执行、可拍出的动作和表演
【位置承接】写当前画面里实际入镜的人物/主体在物理空间中的精确位置、身体姿态、朝向、与环境参照物的距离关系,以及与上一镜相比哪些部位保持不变、哪些部位发生了变化
【OS】无 / 人物(OS,固定声线锚点;贴近耳内,声音低于现场声,当前情绪与语速变化):"……"
【画外音】无 / 人物(O.S.,固定声线锚点;声音距离感 + 当前情绪与语速变化):"……"
【音效】无 / 环境音 / 动作音 / 提示音 / 角色非语言发声
【台词】无 / 人物(固定声线锚点;当前情绪 + 语气 + 语速/停顿):"……"

后续镜头同格式继续。

二点五、多场景切换处理规则
==================================================

1. 若一节内所有镜头都在同一个物理场景,则每个镜头的【场景】信息非必填,可在镜头标题行统一声明,并在本节 `scene` 字段中集中填写该单一场景名。

2. 若一节内发生了场景切换(例如:从室内走到室外、切入闪回/梦境、电话两头交替),则必须启用【多场景模式】:
   - **镜头标题行(强制)**:每个镜头的第一行标题必须明确该镜头的场景。格式为:
     `镜头1 / SC1(0-2.0秒):【当前镜头所属的物理场景】,时间,光线`
     示例:`镜头3 / SC3(5.0-7.5秒):【废弃码头集装箱侧壁前】,深夜,冷白探照灯扫过`
     示例:`镜头4 / SC4(7.5-10.0秒):【记忆闪回-裴家旧屋床榻边】,深夜,油灯暖黄光微弱`

   - **【场景】字段禁用**:在【多场景模式】下,`video_desc` 内部镜头的九个字段中,不再使用独立的【场景】字段。场景信息已通过镜头标题行明确。

   - **`scene` 字段(顶层JSON)**:必须按**镜头时间顺序**,用**逗号 `, `**(逗号+空格)分隔,列出本节涉及的所有**去重后的**物理场景名称。
     示例:`"scene": "裴家旧屋门口, 废弃码头空地中央"`
     示例:`"scene": "@裴家旧屋床榻边, 废弃码头集装箱侧壁前"`(若使用了场景标签)

3. **切换发生时的位置承接**:场景切换的瞬间,下一镜的【位置承接】必须首先写明"从[旧场景]切至[新场景]",然后在新场景中重新建立完整的物理空间锚定——包括人物在新场景中的精确位置、与新环境参照物的距离关系、身体姿态和朝向,如同该角色在新场景中的"第一镜"一样完整。

4. **时长控制**:在多场景模式下,单节总时长硬上限(15秒)和镜头数限制(≤8镜)维持不变。这要求叙事更加精炼,只抓取最具冲击力的切换瞬间。

三、场景词硬规则
==================================================

1. 场景词必须写物理空间,不能写人物关系、构图关系或镜头感觉。
2. 正确场景词示例:
   - 裴家旧屋床榻边
   - 裴家旧屋门口
   - 裴家旧院井边
   - 西坊鬼市角落
   - 鬼市板车前
   - 废弃码头空地中央
   - 废弃码头集装箱侧壁前
   - 游轮甲板船舷边
   - 大厅上方透明观光梯
   - 教学楼走廊转角
   - 医院走廊
   - 电梯内
   - 酒店宴会厅门口
3. 错误场景词示例:
   - 宋凉肩侧与系统小猫
   - 萧纪近景
   - 裴照面部
   - 两人对峙位
   - 高压感镜头
   - 视觉冲击区
4. 如果当前镜头是人物近景、特写、局部特写,场景词仍然写物理空间,景别放在【运镜】里。
5. 同一场戏内,场景称呼必须稳定,不要一会儿叫"床边",一会儿叫"屋内对峙位",一会儿叫"裴川近景"。

==================================================
四、景别切换与高级镜头规则
==================================================

1. 同一人物或同一物品连续出现时,必须避免同景别硬拼。
2. 优先采用错层剪辑:
   - 中景建立空间
   - 中近景推进关系
   - 近景看表情
   - 局部特写看关键物件
   - 回中景落动作结果
3. 连续两个镜头如果景别接近,必须至少变化一个维度:
   - 视角变化:正面 / 侧面 / 侧后 / 过肩 / 主观
   - 焦点变化:人物脸部 / 手部动作 / 道具细节 / 对方反应
   - 动作变化:看向 / 抬手 / 攥紧 / 后退 / 转身
   - 空间变化:前景 / 后景 / 左侧 / 右侧 / 门内 / 门外
4. 两极景别可以使用,但必须有明确理由。
   - 全景直接切极近特写,只能用于强信息点、强反转点、强情绪点或关键道具揭示。
   - 禁止无理由硬切。
5. 每个镜头只设置一个主运镜,不要堆叠过多摄影动作。
6. 推荐运镜格式:
   - 景别 + 视角 + 机位 + 一个主运镜 + 一个焦点变化
   - 例如:中近景,低机位,缓慢环绕60度,最后移焦到人物眼睛。
7. 环绕运镜只用于关键戏点:
   - 发现宝物
   - 身份反转
   - 重大决定
   - 强压迫对峙
   - 情绪突然转折
8. 环绕角度优先控制在45度到90度,不轻易使用360度环绕。
9. 移焦适合用于"道具价值揭示"和"人物情绪转折":
   - 前景道具清晰 → 移焦到人物眼睛
   - 关键物件微光清晰 → 移焦到人物眼底反光
   - 背景威胁虚化 → 移焦到人物表情
10. 对话镜头必须加入反应镜。
    - 不要谁说话就一直拍谁。
    - 关键台词后,优先切到对方表情、手部反应、站位变化或空间压迫变化。
11. 高级转场可使用:
    - 视线匹配剪辑:人物看向某物,下一镜切该物
    - 动作接剪:上一镜抬手,下一镜接夺物结果
    - 前景遮挡转场:门框、衣袖、肩膀、灯影扫过镜头后切换
    - 声音先行:先听到一句话,再切到说话人或声音来源
12. 每个镜头必须控制信息量。
    一个镜头最多包含:
    - 一个主要人物动作
    - 一个核心表演变化
    - 一个主运镜
    - 一个光线重点
    - 一个焦点变化
13. 禁止把环绕、推拉、摇移、移焦、慢动作、多人动作全部堆进同一个镜头。
14. 核心口诀:
    - 景别错层,动作接剪。
    - 近景看人,特写看物。
    - 强点可跳,弱点别怼。
    - 说话给反应,道具给移焦。
    - 环绕只给高光,灯光必须讲事。

五、摄影灯光规则｜通用版
==================================================

1. 灯光必须服务当前镜头的叙事功能,但不能绑定固定题材或固定象征。
2. 不得把"某种光线 = 固定情绪"写死。
3. 每个镜头的光线描写优先明确:
   - 光源:油灯、月光、顶灯、霓虹、车灯、屏幕光、鬼灯、火光、手电、走廊灯、甲板灯等
   - 色温:暖黄、冷白、青绿、暗红、蓝冷、混合光等
   - 强弱:微弱、压暗、刺眼、忽明忽暗、局部照亮、背光、侧光、顶光
   - 作用:交代空间、压迫人物、突出道具、制造反差、强化危险、遮挡信息、引导视线
4. 灯光应根据当前剧情功能选择,不做固定套用:
   - 危机压迫:可用低照度、硬阴影、顶光压脸、背光剪影、冷光切割人物
   - 病弱困境:可用残光、弱光、摇晃光源、人物脸色被光压白
   - 发现宝物:可用局部微光、道具自带反光、环境光与道具光形成反差
   - 身份反转:可用光线从遮挡处扫过脸、半明半暗、移焦时光点变化
   - 情绪爆发:可用光影骤变、灯光闪烁、阴影压近、局部高光放大表情
   - 冷静决断:可用稳定冷光、侧光、人物半张脸入暗、背景压暗突出眼神
   - 搞笑反差:可用正常环境光,不必强行戏剧化,让人物反应和动作形成笑点
   - 打斗动作:可用硬光勾边、运动中明暗交替、背景灯拉出人物轮廓
   - 都市场景:可用电梯冷白灯、手机屏幕光、车灯、霓虹、监控灯、路灯等
   - 古风场景:可用油灯、烛火、月光、炉火、符光、鬼灯、法器微光等
5. 灯光不要抢戏。
   - 只有在关键镜头、道具揭示、人物转折、危险压迫、情绪爆点时,才强调灯光变化。
6. 普通过渡镜头只需要稳定说明光线来源,不要每镜都写复杂光影寓意。
7. 同一场景内灯光必须保持连续:
   - 油灯场景不能下一镜无故变冷白灯
   - 电梯冷白灯不能突然变暖黄光
   - 甲板灯、月光、海面反光要保持方向一致
   - 闪回、梦境、系统界面、法器发光可以单独标注光线变化
8. 道具发光必须有叙事功能:
   - 用于提示隐藏价值
   - 用于提示信息显露
   - 用于提示搜索、扫描、数据变化
   - 用于提示系统界面或特殊能力
   禁止无意义地给道具加光。
9. 人物脸部光线要服务表演:
   - 眼神变化可用眼底反光、半张脸入暗、光线扫过眉眼
   - 压迫感可用顶光压脸、低机位背光、阴影压住眼窝
   - 虚弱感可用弱光、冷光、脸色发白、唇色被压淡
   - 隐藏情绪可用侧光、半明半暗、眼神落在暗处
10. 镜头中如果有移焦,灯光可以配合焦点变化:
    - 前景道具清晰,道具微光亮起
    - 移焦到人物眼睛,微光映进眼底
    - 背景威胁虚化,人物脸部冷光压住
    但移焦和灯光变化必须简单清楚,不能堆复杂效果。
11. 灯光描写最终目标不是为了写漂亮,而是让观众更快理解:
    - 这个空间在哪里
    - 人物处在什么压力下
    - 重要道具在哪里
    - 当前情绪正在往哪里变
12. 灯光核心原则:
    灯光只服务当前剧情,不固定绑定某种情绪。每镜优先写清光源、色温、强弱和叙事作用。普通镜头保持空间真实,高光镜头再用光线强化人物、道具、危险、反差或情绪转折。

==================================================
六、【画面】字段硬规则
==================================================

1. 【画面】只写"看得见的东西",不要写抽象评价。
2. 不要写这种空泛词:
   - 很有压迫感
   - 很屈辱
   - 很生气
   - 很尴尬
   - 很伤心
   - 很委屈
   - 气场很强
   - 情绪复杂
3. 必须把抽象词拆成可视化内容:
   - 生气 → 眼皮压低、唇线绷紧、下颌收紧、往前逼一步
   - 紧张 → 呼吸发急、手指收紧、眼神乱扫、肩膀绷住
   - 强撑轻松 → 先吸气、嘴角提一下、笑没挂住、手抬到一半停半拍
4. 画面里出现谁,就只写谁;没入镜的人不要硬写进画面。
5. 画面里如果只出现局部,就只写局部,不要补全不在镜头里的身体或人物。
6. 尽量避免容易诱发字幕或跑偏生成的话术,比如:
   - 开口说话的样子很帅
   - 轻松地说
   - 毫不犹豫地回答
   - 爽快地开口
   这类必须拆成嘴角、眼神、抬手、停顿等动作化描述。
7. 道具、人物、环境必须与上文承接。
8. 人物服装、湿透程度、伤口、手中物品、站位方向等状态必须保持一致。

==================================================
七、【动作/情绪】字段硬规则
==================================================

1. 【动作/情绪】必须写成"能拍出来的动作",不要只写抽象情绪标签。
2. 优先写:
   - 抬手 / 收手 / 手停半拍
   - 眼皮压低 / 眉峰轻跳 / 嘴角提一点 / 唇线压平
   - 脚跟后收半步 / 往前逼一步 / 肩膀绷住 / 下巴轻抬
   - 吸气 / 呼气 / 停顿 / 回头 / 偏头 / 视线扫过去
   - 喉结轻动 / 鼻翼轻张 / 手指收紧 / 尾巴甩快 / 前爪扑腾空气
3. 不要只写:
   - 很轻松
   - 很认真
   - 很冷
   - 很急
   - 很委屈
   - 很愤怒
4. 正确写法:
   - 先抬手,再把笑挂上去
   - 说话前先吸一口气
   - 眼睛先扫向门口,再落回对方脸上
   - 手还停在半空,没收回去
   - 喉结轻轻压了一下
   - 尾巴越甩越快,前爪缩紧
5. 【动作/情绪】要补充【画面】里没写完的表演,而不是机械重复【画面】。
6. 如果当前镜头重点是说话状态,动作/情绪要补"说话前、说话中、说完后"的节奏变化。
7. 打戏动作必须写关键路径,不要只写"打得很快""动作很狠"。
   - 例如:躲开 → 扣腕 → 压肩 → 带倒
   - 例如:贴身抢进 → 别住握枪手 → 顶肩撞墙 → 枪口被压偏

==================================================
八、【位置承接】强化规则（物理空间锚定版）
==================================================

**核心理念:【位置承接】不是"构图提示",而是"物理空间连续性控制"。它必须把人物钉在一个有物理参照物、有距离感、有姿态描述、有朝向锁定的真实三维空间中,并在镜头之间形成可验证的姿态演变链。**

### 8.1 三层必写结构

每个镜头的【位置承接】必须包含以下三层信息(根据景别详略有别,但三层缺一不可):

**第一层:物理空间锚定(人在哪)**
- 必须写明人物在场景中的精确位置,并用至少一个环境参照物标定距离或方位关系。
- 环境参照物包括但不限于:窗棂、门框、墙壁、柱子、台阶、栏杆、桌案、床榻、刑凳、地板标记等场景内固定物体。
- 正确示例:
  - 楚慕白仰面平躺在木屋正中的深棕色木地板上。身体距离画面右侧木格窗棂内侧约两米远。
  - 沈明鸾站在慈宁宫汉白玉台阶最高一级的正中位置,距离台阶前沿约半步。
  - 青禾俯趴在广场中央刑凳上,双手被反绑在刑凳两侧扶手。
- 错误示例:
  - 沈明鸾在画面中央偏上(这是构图位置,不是物理位置)
  - 青禾在画面中下部趴着(没有参照物,没有具体位置)

**第二层:身体姿态描述(人什么样)**
- 必须写明人物当前的身体状态:站/坐/躺/跪/趴/靠,以及关键身体部位的具体姿态。
- 关键部位包括:躯干(挺直/前倾/后仰)、头部(平视/仰起/低垂/偏转)、四肢(双臂位置/手中物品/腿部状态)。
- 正确示例:
  - 腰背绷直成笔挺坐姿。双臂自然垂放在膝上。右手掌心向上摊开。
  - 头颅极度向后仰起朝向木屋横梁。颈部彻底拉直暴露。右手攥拳搁在大腿上。
  - 身体微微前倾,双手扶住台阶前沿的汉白玉栏杆。下巴微收,视线向下。
- 错误示例:
  - 沈明鸾面部占据画面中心(没有任何姿态信息)
  - 刘掌刑站立于后方(缺少身体细节)

**第三层:朝向与面向锁定(人朝哪)**
- 必须写明人物的面部朝向和身体朝向,使用"面朝画面左/右/正前方""身体侧面对向镜头""背对镜头面朝窗外"等明确方向词。
- 在多人镜中,还必须写明人物之间的相对空间关系(谁在谁的左/右/前/后)。
- 正确示例:
  - 身体侧面入画,面朝画面左侧。
  - 面朝台阶下方广场方向。背对慈宁宫大门。
  - 沈明鸾在画面左侧面朝右,刘掌刑在画面右侧面朝左,两人相距约三步。
- 错误示例:
  - 刘掌刑在画面右侧(缺少朝向)
  - 两人对峙(空泛,无方向)

### 8.2 姿态演变链规则(镜头间承接)

1. **"不变的部分"必须显式写出**。如果人物某个身体部位/位置从上一镜到本镜没有变化,必须用"依然""保持""仍在"等词显式声明不变。这不是废话,这是在告诉视频模型"这些东西别动"。
   - 正确:臀部依然钉在木地板正中。距离窗棂依然两米远。
   - 正确:沈明鸾仍站在台阶最高级正中位置。双手依然扶在栏杆上。
   - 错误:直接省略不变的信息,只写变化的部分(模型会以为不变的部分可以随意变动)。

2. **"变化的部分"必须写明起止状态**。从什么姿态变成什么姿态,变化幅度多大,都要写清楚。
   - 正确:头颅从极度仰起状态缓慢恢复至平视。
   - 正确:上半身从平躺状态弹起至笔直坐姿。
   - 错误:头颅恢复正常(缺少起止描述)。
   - 错误:坐起来了(缺少过程)。

3. **姿态链必须逻辑自洽**。后一镜的起始状态必须与前一镜的终止状态完全一致。如果上一镜末尾角色右手攥拳搁在大腿上,下一镜开头这只手必须还在那个位置,除非本镜的【动作/情绪】中写了手部的新动作。

4. **跨节承接**:新一节的第一镜【位置承接】必须完整重建上一节末镜的终止状态,如同"冻结帧解冻",不允许省略。

### 8.3 不同景别的详略规则

1. **全景 / 中景 / 多人关系镜**:三层全写,且多人镜必须逐人锚定——写清每个入镜人物的位置、姿态、朝向、与其他人物的相对空间关系,以及与环境参照物的距离。
   示例:
   - 沈明鸾站在台阶最高级正中位置,面朝台阶下方。距其右后方一步处站着贴身宫女,宫女略弓身。台阶下方广场中央,距台阶底端约十步,刑凳横置,青禾俯趴在刑凳上。刘掌刑站在刑凳右侧一步处,面朝刑凳,右手高举铁杖。

2. **中近景 / 近景**:第一层写简(保留一个核心参照物即可),第二层重点写面部和上半身姿态,第三层写朝向。
   示例:
   - 楚慕白保持在木屋正中偏左位置,面朝画面左侧。臀部钉在原地。上半身笔直,下颌从仰起状态回到水平。

3. **特写 / 局部特写**:只写当前入镜主体的位置和状态,不补全员。但仍需锚定在物理空间中,不能只写"占据画面中心"。
   示例:
   - 楚慕白右手掌心向上摊开,掌心距胸口约一拳,残令搁在掌心正中。(特写锚定到身体部位和道具)
   - 刑杖铁头悬停在青禾小腿上方约两寸处,冷光贴着铁面。(道具特写锚定到另一人物身体部位)

4. **主观镜头**:写明"视角归属者"的当前位置和朝向,以及视线落点的物理位置。
   示例:
   - 主观视角归属沈明鸾,她仍站在台阶最高级正中位置。视线从台阶边缘越过跪地朝臣,落在广场中央刑凳上。

### 8.4 特殊主体的位置锚定

1. 悬浮物/系统界面/灵宠等非固定在地面的主体,也必须锚定到人物身体部位或环境参照物:
   - 系统小猫悬在楚慕白右肩外侧约三十公分处,与肩同高,面朝楚慕白侧脸。
   - 光屏悬停在人物正前方一臂距离,下沿与人物胸口齐平。
   - 小狐狸蹲在桌案左侧角落,前爪搭在桌沿上。

2. 这些特殊主体的位置同样需要逐镜承接,不能忽明忽暗地消失或跳跃。

### 8.5 空间轴线与禁止跳轴

1. 每场戏第一组关系镜必须先固定空间轴线,写清:
   - 人物A在画面哪侧(左/右)
   - 人物B在画面哪侧(左/右)
   - 两人之间的距离
   - 关键道具/环境参照物在哪侧
   示例:
   - 沈明鸾在画面左侧台阶上,面朝右。青禾在画面右侧广场刑凳上,面朝左。两人之间隔着整段台阶,直线距离约十五步。刑凳在画面右侧中央。

2. 后续镜头必须沿用此左右关系,不允许跳轴,除非有明确的过渡镜头(角色移动、绕行、转身)来合理改变空间关系。

3. 如果发生人物移动,必须写清:
   - 从哪个位置出发
   - 移动方向
   - 移动后的新位置
   - 新位置与环境参照物的距离关系
   示例:
   - 沈明鸾从台阶最高级正中位置向右前方迈出两步,移动至台阶右侧扶手旁。右手搭上汉白玉扶手。面朝方向不变,仍朝向台阶下方。

### 8.6 闪回/场景切换后的位置重建

1. 从闪回、梦境、回忆、时间跳切切回现实,第一镜的【位置承接】必须:
   - 先写明"从[闪回/梦境场景]切回[现实场景]"
   - 完整重建现实空间中所有入镜人物的位置、姿态、朝向,如同重新开场
   - 道具归属必须重新写清
   示例:
   - 从上节记忆闪回切回现实——慈宁宫汉白玉广场台阶顶端。沈明鸾仍站在台阶最高级正中位置,面朝台阶下方,双手依然藏在宽大袖袍内。右侧一步处宫女维持躬身姿态。

2. 场景切换时,新场景第一镜的位置承接等同于全新场景的"建立镜",必须完整锚定,不允许只写"某角色在画面中"。

### 8.7 位置承接自检要点

写完每个镜头的【位置承接】后,默默检查:
- 能否仅凭这段文字,在脑中精确还原出人物在三维空间中的位置? → 不能则补参照物和距离
- 能否判断人物面朝哪个方向? → 不能则补朝向
- 能否判断人物当前的身体姿态(站/坐/躺/跪等)? → 不能则补姿态
- 与上一镜相比,哪些没变?是否已显式写出"不变"? → 没有则补
- 与上一镜相比,哪些变了?是否写明了起止状态? → 没有则补
- 多人镜中,每个入镜人物是否都有独立的位置锚定? → 缺则补

### 8.8 位置承接错误示范与纠正

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| 沈明鸾在画面中央偏上 | 只有构图位置,没有物理空间锚定 | 沈明鸾站在慈宁宫台阶最高级正中位置,距台阶前沿半步,面朝台阶下方广场 |
| 刘掌刑在画面右侧 | 没有姿态、没有参照物、没有朝向 | 刘掌刑站在刑凳右侧一步处,面朝刑凳,双脚与肩同宽,右手高举铁杖过肩 |
| 青禾在画面中下部趴着 | "画面中下部"是构图位置,不是物理位置 | 青禾俯趴在广场中央刑凳上,双手被反绑在刑凳两侧横档,左脸贴着刑凳面板,裤腿被扒至膝盖以下 |
| 沈明鸾面部占据画面中心 | 完全是构图描述,零姿态信息 | 沈明鸾仍站在台阶最高级正中位置,面朝台阶下方。上半身微微前倾,下巴微收,视线向下投向广场方向 |
| 无 | 第一镜不写位置承接 | 即使是开场全景第一镜,也必须写清关键主体的物理位置布局,为后续镜头建立锚点 |

### 8.9 核心原则总结

- 位置承接是"物理空间导航",不是"构图备注"
- 必须有参照物、有距离、有姿态、有朝向
- "不变的"显式写出,"变化的"写明起止
- 镜头之间形成可验证的姿态演变链
- 全景写全局布局,近景写核心姿态,特写写局部锚定
- 没入镜的不写,入镜的必须写到位
- 每场戏第一镜建立锚点,后续镜头严格承接,不允许跳轴
- 位置承接的最终目标:让视频模型准确知道"这个人在这个房间的什么位置、什么姿势、朝哪个方向、手里拿着什么、哪些没动哪些动了"

==================================================
九、台词字段强化规则
==================================================

【台词】必须写成:

人物(固定声线锚点;情绪 + 语气 + 语速/停顿):"台词内容"

这是硬规则。

1. 情绪不能只写"生气 / 高兴 / 难过 / 紧张"。
2. 必须写成:
   - 固定声线锚点
   - 当前情绪
   - 发声方式
   - 语速/停顿
3. 推荐写法:
   - 人物A(固定青年男声,中低音区,清冷克制;压着火,声音低,最后几个字更重):"……"
   - 人物B(固定成熟女声,中音区,温柔疲惫;强装轻松,尾音稍拖,像硬把场面往轻里带):"……"
   - 系统小猫(固定少年态公猫感,中高音区,奶凶清脆;越说越急,后半句明显拔高):"……"
   - 人物C(固定青年男声,中音区,松弛嘴贫;前半句随口,后半句压平往前送):"……"
4. 不要只写:
   - 生气
   - 高兴
   - 难过
   - 紧张
   - 轻松
5. 正确写法要让模型知道"这个人是谁的声音"和"这句话怎么说":
   - 固定青年男声,中低音区,清冷克制
   - 固定少年男声,中高音区,声音发紧
   - 固定成熟女声,中音区,虚弱温柔
   - 压低声音,字咬得很硬
   - 前半句放轻,后半句收短
   - 尾音稍拖
   - 一字一顿
   - 从牙缝里挤出来
   - 很快地往外倒
   - 像补最后一刀
   - 像顺手接个梗
   - 气得发抖,后半句拔高
6. 关键句必须写固定声线锚点、情绪、语气、语速/停顿。
7. 同一句台词,如果包含节奏变化,要写出来。
   - 前半句快,后半句压低
   - 前半句轻,后半句一字一顿
   - 停半拍,再往下说
8. 台词语气必须和当前镜头画面、动作/情绪匹配,不能脱节。
9. 一个镜头里最好不要出现两个人说话。
10. 如果原文中两个人连续对话,优先拆成两个镜头,或者一个说话镜头 + 一个反应镜。
11. 不要为了追求语气丰富而频繁替换同一角色的音色词。同一角色优先固定 2-4 个核心声线词反复使用。

==================================================
九点五、角色声线锁定规则
==================================================

1. 由于不额外垫音频,为保证人物音色一致,所有有发声行为的角色必须先建立【固定声线锚点】,后续台词、OS、画外音、旁白、低鸣、叫声、喘息、哭腔、笑声、拟人化发声都必须沿用该角色的固定声线锚点。

2. 固定声线锚点只在角色首次发声时确定,不允许后续随意更换。**如果角色信息库({ROLES_PLACEHOLDER})中已经提供了该角色的音色描述,固定声线锚点必须直接复用角色信息库的描述,不再重新设计。**

3. 人类角色固定声线锚点包含:
   - 年龄感:少年 / 青年 / 成熟 / 老年
   - 性别气质:男声 / 女声 / 中性声线
   - 音区:偏低 / 中低 / 中音 / 中高 / 偏高
   - 音色底色:清冷、温柔、低沉、清亮、沙哑、甜润、疏离、凌厉、疲惫、慵懒、压迫感、破碎感等
   - 发声习惯:咬字克制、语速偏慢、语速偏快、声音压低、气息轻、尾音短、停顿明显等

4. 后续同一角色发声时,括号内必须保留固定声线锚点中的核心词,只允许叠加当前情绪变化。

5. 正确结构:
   人物(固定声线锚点;当前情绪/语气 + 语速/停顿变化):"……"

6. 禁止同一角色在同一场戏或连续剧情中出现互相冲突的声线描述。
   例如:
   - 前文是低沉男声,后文不能突然变成清亮少年音
   - 前文是温柔女声,后文不能突然变成沙哑压迫感女声
   - 前文是奶气小猫,后文不能突然变成成熟低沉兽音
   - 前文是成熟男声,后文不能突然变成少年感男声

7. 情绪变化只能改变"说法",不能改变"声线本体"。

8. 可以变化:
   - 压低一点
   - 语速变快
   - 尾音发颤
   - 停顿变重
   - 气息变乱
   - 后半句拔高

9. 不可以变化:
   - 年龄感突变
   - 性别气质突变
   - 音区大幅变化
   - 音色底色完全换人

10. 角色首次发声时,括号内必须写完整固定声线锚点;后续发声可以略微压缩,但核心音色词必须重复。

11. 首次示例:
    裴照(固定青年男声,中低音区,清冷克制,咬字干净,语速偏慢;此刻声音压低):"……"

12. 后续示例:
    裴照(固定青年男声,中低音区,清冷克制;停半拍后尾句压重):"……"

13. **每节开头都必须强制输出【本段角色声线锁定】**,详见第二节规则。

14. **无论是否连续接着上文,每节开头都必须完整重新输出本节出现的所有发声角色的声线锁定表**(参见第二节强制输出规则)。台词括号中的固定声线锚点也必须每次完整复用,不简写、不缩略。

15. 【本段角色声线锁定】示例:
    裴照:青年男声,中低音区,清冷克制,咬字干净,语速偏慢。
    裴川:少年男声,中高音区,声音发紧,情绪外露,急时带哭腔。
    沈素衣:成熟女声,中音区,虚弱温柔,气息轻,尾音容易发颤。
    系统小猫:少年态公猫感,中高音区,奶凶清脆,语速快。

16. 同一角色优先固定 2-4 个核心声线词反复使用。
    例如:
    - 裴照固定:青年男声 / 中低音区 / 清冷克制 / 咬字干净
    - 裴川固定:少年男声 / 中高音区 / 发紧 / 情绪外露
    - 沈素衣固定:成熟女声 / 中音区 / 虚弱温柔 / 气息轻
    - 系统小猫固定:少年态公猫感 / 中高音区 / 奶凶清脆 / 语速快

17. 不要每句台词都重新创造新音色。声音丰富度靠情绪、语速、停顿变化完成,不靠频繁更换音色词完成。

==================================================
九点六、非人角色与小动物发声规则
==================================================

1. 小动物、灵宠、系统拟态、非人角色发声时,也必须先建立固定声线锚点。

2. 非人角色固定声线锚点包含:
   - 公母 / 性别倾向
   - 年龄感:幼态 / 少年态 / 成熟态 / 老态
   - 音区:偏高 / 中高 / 中音 / 中低 / 偏低
   - 声音气质:奶气、警觉、软糯、清脆、尖细、圆润、低呜、黏人、凶萌、灵动、怯弱等
   - 发声强度:轻叫、短促叫声、连续叫声、低鸣、撒娇般哼鸣、威胁性低吼等

3. 如果原文没有写明小动物或非人角色的公母:
   - 优先根据剧本称谓、人物称呼、体态描写、剧情功能、说话风格判断;
   - 若仍不明确,则选择最符合角色气质的一种设定;
   - 一旦确定,后续全片保持统一。

4. 非人角色禁止声线漂移:
   - 奶气小猫不能后续变成成熟低沉兽音
   - 少年态灵宠不能后续变成老者旁白感
   - 母狐软糯声线不能后续变成粗粝男声
   - 系统拟态声线不能每场换一个年龄感

5. 非人角色写法示例:
   - 系统小猫(固定少年态公猫感,中高音区,奶凶清脆;语速很快,后半句急得拔高):"……"
   - 小狐狸(固定幼态母狐感,偏高音区,软糯警觉;轻声短促叫):"呜……"
   - 灵兽(固定成熟态雄性兽感,中低音区,低沉喉音;压着威胁性低鸣):"……"
   - 灵鸟(固定幼态雌鸟感,偏高音区,清脆灵动;连续短促叫声):啾啾声

6. 低鸣、喘息、哭腔、笑声、叫声等非完整语言,不强行塞进【台词】。
   - 如果是角色发出的可听声音,但不形成完整台词,优先写入【音效】。
   - 如果伴随一句台词,则体现在台词括号中。

7. 示例:
   【音效】系统小猫(固定少年态公猫感,中高音区,奶凶清脆):短促炸毛叫声
   【音效】沈素衣(固定成熟女声,中音区,虚弱温柔;气息很轻):低低喘息
   【台词】裴川(固定少年男声,中高音区,声音发紧;后半句带哭腔):"娘,你别吓我……"

==================================================
十、【台词 / 画外音 / OS】使用规则
==================================================

1. 说话角色在当前镜头中入镜,使用【台词】。
2. 说话角色未入镜,但声音来源属于当前场景、现场人物能听见,使用【画外音】并标注(O.S.)。
3. 人物内心想法、未说出口的心理活动,使用【OS】。
4. 旁白、广播、新闻播报、系统提示音等非当前镜头内可见说话者,也可以使用【画外音】。
5. 若角色虽未完整入镜,但画面已明确给出其局部且能判断其正在说话,可继续使用【台词】。
6. 单镜头内尽量只保留一种主要声音表达方式,避免【台词】、【画外音】、【OS】混杂堆叠。
7. 优先让正在说话的核心角色入镜,能用【台词】就尽量不用【画外音】。
8. 如果角色是核心吐槽源或重要信息源,且这句台词承担叙事功能,优先通过调整镜头让它入镜,而不是长期悬空只做画外音。
9. 判断口诀:
   - 入镜说话 = 【台词】
   - 没入镜但现场能听见 = 【画外音】(O.S.)
   - 心里想的 = 【OS】
10. 内心台词统一写【OS】,不要写 VO。
11. VO 只用于明显的旁白、回忆式自述、未来回望、非现场叙述声;一般 AI 漫剧分镜中尽量少用。
12. 如确需使用 VO,也必须标注固定声线或旁白声线,不允许与角色 OS 混用。
13. 现实台词、画外音、OS 三者区别:
    - 【台词】角色入镜开口说话,现场可听见;
    - 【画外音】角色未入镜但在现场说话,现场可听见;
    - 【OS】角色内心声,画面不张嘴,现场其他人物听不见。

==================================================
十点五、OS 内心声处理规则
==================================================

1. OS 是角色自己的内心声,画面角色不张嘴,但必须沿用该角色固定声线锚点。

2. 普通现实 OS 默认不使用明显混响,不写成空灵旁白、神秘旁白、上帝视角旁白或另一个人的声音。

3. 普通 OS 只允许加入轻微声音处理:
   - 贴近耳内
   - 声音低于现场声
   - 轻微内心声处理
   - 语速放慢
   - 气息更收
   - 停顿更明显

4. OS 正确写法:
   【OS】人物(OS,固定声线锚点;贴近耳内,声音低于现场声,当前情绪与语速变化):"……"

5. OS 错误写法:
   - 人物(OS,空灵混响,神秘旁白感):"……"
   - 人物(OS,低沉旁白声):"……"
   - 人物(OS,回声很重):"……"
   - 人物(OS,换成成熟旁白腔):"……"

6. 只有在梦境、前世记忆、濒临昏迷、神识空间、系统空间、幻境、远古残念等非现实声音层中,才允许写"轻微远感"或"极轻微混响"。

7. 即使使用轻微远感或极轻微混响,也不能改变角色固定声线本体。

8. 正确:
   裴照(OS,固定青年男声,中低音区,清冷克制;记忆层声音,轻微远感,语速压慢):"……"

9. 错误:
   裴照(OS,神秘空灵男声,混响很重):"……"

10. 普通现实 OS 不要写"混响声""回声""空灵感""神秘感"。
    优先写:
    - 贴近耳内
    - 声音低于现场声
    - 轻微内心声处理
    - 语速放慢
    - 像压住念头
    - 像在心里迅速判断

11. OS 如果是嘴贫吐槽型,也要沿用角色原本声线,不要变成旁白。
    示例:
    宋凉(OS,固定青年男声,中音区,松弛嘴贫;贴近耳内,前半句随口,后半句明显无语):"原主这人缘,也太离谱了。"

12. OS 如果是前世记忆、失败经验、价格差、关键因果,优先配合闪回画面或道具细节,不要让人物静站着硬念信息。

==================================================
十一、OS / 闪回画面匹配规则
==================================================

1. OS 要短,优先承担:
   - 解释无法直接拍出的信息
   - 瞬时判断
   - 信息差
   - 反差笑点
   - 前世记忆
   - 关键因果
2. OS 内容如果较长或信息量较重,必须配对应的画面,不要让人物静站着硬念信息。
3. 如果 OS 提到前世、回忆、价格差、失败结果、重要背景,优先切入记忆闪回画面。
4. 现实触发记忆的常用结构:
   - 现实道具 / 现实人物 → 触发 OS
   - 记忆闪回 → 对应信息画面
   - 记忆结果 → 失败 / 代价 / 关键信息
   - 切回现实 → 重新锚定人物站位(必须按第八节规则完整重建物理空间锚定)
5. 闪回必须标注:
   【时间标识】记忆闪回
6. 闪回场景词必须写清物理空间。
7. 从闪回切回现实时,【位置承接】必须:
   - 先写"从上节记忆闪回切回现实——[现实场景名]"
   - 完整重建现实空间中所有入镜人物的精确位置、姿态、朝向、与环境参照物的距离
   - 道具在谁手里、处于什么状态必须重新写清
   - 相当于重新做一次"建立镜"级别的位置锚定
8. 不要让 OS 与画面完全脱节。
9. 普通短 OS 可以留在现实画面中。
10. 重大背景 OS 尽量用闪回或道具细节承接。
11. 闪回中的 OS 可以带轻微远感,但不能改变角色固定声线本体。
12. 切回现实后的第一句 OS 必须恢复普通内心声处理,不要延续明显远感或混响。
13. **闪回允许蒙太奇压缩**:单个闪回镜头可承载 1-3 句 OS,通过多层画面信息(主体+物件+环境反馈)同步呈现因果,**不必逐句拆独立镜头**。长闪回独白优先用 2-3 个画面承载完整因果链,不要扩成 5-6 个闪回镜头。**但前提是保留原文每一字,不得为了蒙太奇折叠而删字、合并、改写。**

==================================================
十二、长台词拆分规则
==================================================

1. 长台词必须按信息点拆开。
2. 一句台词如果同时承担:
   - 信息说明
   - 情绪推进
   - 关系变化
   最好拆成两镜到三镜。
3. 拆分时优先切:
   - 对方反应镜
   - 说话者口型/表情镜
   - 手部动作细节镜
   - 道具特写镜
   - 空间压迫镜
4. 系统类角色、高频吐槽角色的长台词,可以按信息点拆成一句一镜。
5. 除"长台词切断"需要外,不要为了凑镜头乱拆。
6. 一个镜头里最好只让一个人说话,避免台词机关枪。
7. 台词密集段必须穿插无台词反应镜,让观众消化信息。
8. 长台词拆分时,同一角色每个拆分镜头都必须沿用同一固定声线锚点,只改变当前句子的语气、节奏、停顿。
9. 不要因为一句台词被拆成多镜,就让同一角色声音在不同镜头里发生音区或年龄感漂移。
10. **拆分优先级**:同节内"说话镜 + 反应镜 + 承载镜"组合 > 扩到下一节。**只有当单节超过 70 字硬上限时,才必须跨节承载**。
11. **拆分原则**:拆分必须按原文自然停顿点切开,**严禁为了字数限制删字、改字、合并语气词、省略修饰语**(此规则受【台词原文完整性原则】保护,优先级高于一切字数限制)。

==================================================
十三、打戏与动作戏规则
==================================================

1. 打戏必须拆成关键动作链,不要写成"打得很激烈"。
2. 动作要有起因、过程、结果。
   - 谁先出手
   - 从哪个方向来
   - 主角怎么躲
   - 主角怎么反制
   - 对方怎么倒下
3. 保持空间方向:
   - 左侧来人
   - 右侧压近
   - 正前方扑来
   - 身后贴近
4. 打斗中不要乱切跳轴。
5. 每个动作镜头只写一组核心动作,不要塞五六个动作。
6. 打击感靠:
   - 起手
   - 避让
   - 接触瞬间
   - 反制路径
   - 结果落地
7. 关键打击可以用:
   - 局部近景
   - 慢半拍的接触瞬间
   - 低机位
   - 跟移
   - 反应镜
8. 涉及危险武器或敏感动作时,尽量降低刺激性描述,用动作路线和空间压迫表达,不要堆过度血腥词。
9. 两个男人近身打斗时,画面应写成"夺枪、别手、卡腕、撞墙、贴身角力",不要写成暧昧拥抱或亲密纠缠。
10. 不要使用容易跑偏的词:
    - 温热怀里
    - 死死缠在一起
    - 贴成一个轮廓
    - 又搂又摸
    改成:
    - 胸肩硬顶上身
    - 反折握枪手
    - 卡住前臂
    - 贴身夺枪
    - 枪口被压偏
11. 打斗中的喘息、闷哼、低吼等非语言声音,优先写入【音效】,并沿用角色固定声线锚点。
12. 打斗中不要把喘息写成过度暧昧或不必要的身体感受,优先写成短促呼吸、压低闷哼、急促吸气等可执行声音。

==================================================
十四、容易违规描述的处理规则
==================================================

1. 尽量避免过硬的控制、暴力、羞辱描述词,能降一档就降一档。
2. 优先平替(仅作用于【画面】【动作/情绪】描述层,**不作用于【台词】原文本体**):
   - 抓起来 → 带走 / 拦住 / 带他上楼
   - 堵死 → 堵住 / 挤满 / 收窄
   - 打脸 → 当众难堪 / 当众下不来台
   - 砍死 / 杀死 → 放倒 / 解决 / 没再站起来
   - 鲜血喷出 → 血线 / 血迹 / 血口 / 指尖沾血
3. 但不要因为平替而损伤镜头冲击力。
4. 优先用:
   - 动作
   - 空间压缩
   - 人物反应
   - 声音冲击
   - 结果镜头
   来替代硬词。
5. 台词如果用户要求不改,则不改台词,只调整画面描述词和动作描述词。
6. 画面描述中尽量少用直白刺激性词汇,改成更适合视频生成的表达。
7. 声音描述中也不要使用过度刺激、过度暧昧、过度恐怖的词汇。
8. 怒吼、惨叫、哭喊等高刺激发声,必要时可降级为:
   - 声音猛地拔高
   - 短促惊呼
   - 压低闷哼
   - 气息发抖
   - 尾音发颤
   - 哭腔压不住
9. **【台词原文不得擅改】**:无论画面描述层如何平替,角色直接说出口的台词原文必须逐字保留,不得为了过审而擅自降级台词本体(详见【台词原文完整性原则】)。

==================================================
十五、人物与道具连续性规则
==================================================

1. 人物状态必须连续:
   - 是否湿透
   - 是否受伤
   - 是否拿着道具
   - 是否跪着
   - 是否站着
   - 是否靠着栏杆
   - 是否已经移动到门口
2. 道具归属必须连续:
   - 残令在谁手里
   - 枪在谁手里
   - 手机是否已掏出
   - 光屏是否已弹出
   - 炉芯是否已露出
3. 道具转移必须有镜头:
   - 从A手中夺到B手中
   - 从掌心收入袖中
   - 从地上捡起
   - 从衣袋掏出
4. 不能突然让道具消失或换主人。
5. 人物入场要有预埋:
   - 边缘入画
   - 后景出现
   - 门外声音先行
   - 全景预先给站位
6. 人物离场要有交代:
   - 走向门口
   - 没入人群
   - 冲出画面
   - 院门合上
7. 如果剧情中人物称呼需要统一,必须统一,不要前后乱换。
8. 人物声线也属于连续性的一部分,角色一旦建立固定声线锚点,后续同一角色不得随意更换年龄感、音区、性别气质、音色底色。
9. 如果角色因受伤、濒死、哭泣、愤怒、距离变化导致声音变化,只能写成"气息变弱、语速变慢、尾音发颤、声音压低、声音从远处传来"等,不允许改成另一种声线。

==================================================
十六、开头与承接规则
==================================================

1. 如果是全新场景、全新章节、全新段落开头,前三镜应尽快交代:
   - 当前人物
   - 当前物理空间
   - 当前冲突或目标
   - 当前关键物件或危险源
   - **通过第一镜的【位置承接】建立完整的物理空间锚点——包括所有入镜人物/主体的精确位置、姿态、朝向、与环境参照物的距离关系,为后续所有镜头提供锚定基准**
2. 如果是连续剧情中的后续小节,不需要每节重新交代完整信息,必须优先承接上一节的:
   - 人物站位(必须从上一节末镜的终止姿态精确续接)
   - 道具归属
   - 情绪状态
   - 动作方向
   - 空间关系(保持与环境参照物的距离一致)
   - 当前目标
   - 已建立的角色声线锚点
3. 连续剧情中,开头第一镜的【位置承接】必须完整重建上一节末镜的终止状态——写清人物的精确位置、姿态、朝向、与参照物的距离,如同"冻结帧解冻"。不允许省略,不允许重新开场式铺垫。
4. 只有当剧情进入新地点、新时间、新冲突、新人物入场时,才重新建立空间和目标。
5. 开头镜头必须有效,不写无意义空镜。
6. 空镜只允许用于转场、压迫、时间跳切或气氛强化,且时长不宜过长。
7. 如果新段落出现新角色首次发声,必须先建立该角色固定声线锚点。
8. 旧角色继续发声时,**声线本体保持一致不变**(不重新设计),但**仍必须在本节开头【本段角色声线锁定】中完整列出该角色**,不省略、不写"同上"。

==================================================
十七、节奏与时长规则(硬上限版)
==================================================

1. 单节总时长硬上限 = 15.0 秒。这是绝对红线,不得突破。
   - 节内所有镜头时长之和必须 ≤ 15.0 秒
   - 不允许 14.5 秒+0.6 秒凑成 15.1 秒
   - 时间区间标注必须严格连续:0-2.0、2.0-4.0、4.0-6.0……末镜结束时间 ≤ 15.0
   - 优先压满 12-15 秒,不要为保险扩节做成 8-9 秒短节

2. 单节镜头数原则上 5-8 镜,绝不超过 8 镜。

3. 如果原文信息量在 15 秒内塞不下,必须自然拆到下一节,严禁:
   - 压缩单镜时长把台词硬塞进去
   - 让角色"高速念稿"
   - 把一段长信息全压在画外音里冲过去
   - **删字、换词、合并句子来塞下台词**(违反【台词原文完整性原则】)

4. **节数最小化原则(次级偏好)**:在不超过 15 秒红线、不超过 70 字台词红线、**且不删改原文台词**的前提下,优先把内容压到最少节数。能用 1 节承载的,不要扩成 2 节。
   但此原则不得凌驾【台词原文完整性原则】——若保留原文需要扩节,必须扩节。

==================================================
十七点五、中文语速与台词字数硬规则(防信息超载)
==================================================

1. 中文 TTS 生成基准语速:约 **4 字/秒**(含必要换气与停顿)。
   慢/克制/低沉/沙哑/虚弱/重音咬字:约 **3 字/秒**。
   快/急/吐槽/系统类台词:最高 **5 字/秒**,不再快。

2. 单镜头台词字数硬上限计算公式:

   **字数上限 = 镜头时长(秒) × 4**

   通过自然语速消化镜头开头铺画面与结尾留落点,**不再额外扣减缓冲秒数**。
   慢速角色按 ×3 计算,快速场景可按 ×5 计算,但默认按 ×4 设计。

3. 常见镜头时长对应单镜台词字数上限(直接背、按需查,默认 4 字/秒口径):
   - 1.5 秒镜头:≤ 6 字
   - 2.0 秒镜头:≤ 8 字
   - 2.5 秒镜头:≤ 10 字
   - 3.0 秒镜头:≤ 12 字
   - 3.5 秒镜头:≤ 14 字
   - 4.0 秒镜头:≤ 16 字
   - 4.5 秒镜头:≤ 18 字
   - 5.0 秒镜头:≤ 20 字(已是单镜上限,再多必须拆)
   - 5.5 秒镜头:≤ 22 字
   - 6.0 秒镜头:≤ 24 字(已是单镜极限,极不推荐,优先拆镜)

4. 单节(15 秒)总台词字数硬上限:
   全节所有【台词】+【OS】+【画外音】+(若使用)VO 的字数总和 **≤ 60 字**。
   信息特别密集的小节可酌情提到 **70 字**,但绝对不超过 70 字。
   节奏建议:全节保留至少 1 个反应/动作镜或视觉收束镜,用于情绪落点;但**不强制配额**。
   优先把内容压满本节,避免不必要扩节(但前提是保留原文完整)。

5. 字数超标的强制处理顺序(必须照做):
   第一步:能精简形容词、合并同义重复的——**仅作用于【画面】【动作/情绪】描述层**,**严禁作用于【台词】【OS】【画外音】原文本体**
   第二步:仍超标 → 把信息按语义点拆开,优先同节内消化(说话镜+反应镜+承载镜组合)
   第三步:仍超标且超出单节 70 字红线 → 把后半段台词整体下移到下一节,本节末尾留疑问钩子或反应钩子
   第四步:仍超标 → 把【画面】描述层中的部分纯信息内容改为镜头画面表达
       (例如把【画面】里冗长的环境描述简化为一个剪影 + 一个道具特写)
   **严禁通过"加快语速""压缩时长""删字、改字、合并语气词"来塞下台词**。

6. 超过 20 字的单句台词必须拆句:
   - **按原文自然停顿点切开**,不允许改动原文一字
   - 拆成 2-3 个镜头,每镜一段,中间可穿插反应镜或动作镜
   - 拆开后每段必须独立通顺,不允许半句话被切断
   - 拆句后每镜的字数仍必须满足"单镜字数上限"(时长×4)

7. 单角色连续独白预警:
   如果原文里某角色一段独白超过 **70 字**,这段独白本身就需要 2 节以上承接,
   不允许在 1 节内塞完。
   长度在 **50-70 字之间**的长独白,**优先在 1 节内通过"说话镜+承载镜+反应镜"或闪回蒙太奇组织**,不必硬拆到下一节。
   跨节承接时,首镜必须延续相同固定声线锚点,不重新设计。

8. 原文台词长度判定流程(写镜头前必走):
   - 数原文该段总字数
   - 总字数 ÷ 4 = 该段实际需要的最少时长(秒)
   - 若所需时长 > 17.5 秒(>70 字) → 这段台词必须跨节承载
   - 若所需时长在 12.5-17.5 秒(50-70 字) → 优先在 1 节内通过快剪蒙太奇承载完整
   - 若所需时长 ≤ 12.5 秒(≤50 字) → 在本节内通过"说话镜+反应镜+承载镜"组织

9. **核心原则**:无论字数如何超标,都不得改动原文台词本体。台词字数与镜头时长不匹配时,**先调整镜头时长 → 再考虑拆节 → 最后用画面分担信息量**,**永远不动台词原文**。

==================================================
十八、输出要求
==================================================

1. 直接输出分镜成品,不要解释。
2. 不要写"以下为你生成"之类废话。
3. 不要重复规则。
4. 不要写总结。
5. 严格按照我给定文本内容改写成分镜,不要擅自扩写世界观。
6. 如果原文中信息重要,必须保留。
7. 如果原文中有内心 OS,必须根据内容匹配现实画面或闪回画面。
8. 如果当前段落衔接上文,必须主动承接上文已有空间关系、人物站位、情绪状态、镜头逻辑、叙事连续性与角色声线锚点。
9. 分镜必须是"拿来就能喂给视频模型"的完成版,不要给模糊建议。
10. 如果我要求"只改画面描述词,不改台词",你必须保留台词不变。
11. 如果我要求"从第X节开始",就从指定节开始,不要重头输出。
12. 如果我要求"全部重新输出",就输出完整重排版,不要只改局部。
13. 声音分析结果不单独输出成解释文本,只能体现在【本段角色声线锁定】或【台词】【OS】【画外音】【音效】括号中。
14. 不要在每个镜头额外输出"声音分析:……"这类说明。
15. 角色首次发声可以建立声线;角色后续发声只复用声线,不重新设计。
16. **每一节(每个 JSON 对象的 video_desc 开头)都必须强制输出【本段角色声线锁定】**,列出本节所有发声角色,不允许省略或写"同上"。
17. **台词原文必须逐字保留**,任何形式的删字、换词、合并、改写都视为严重违规。


==================================================
十九、最终执行口诀
==================================================

台词原文一字不动,字数撑爆就拆节。
每节都要列声线锁定,不写"同上"不缩略。
画面只写看得见的。
动作只写拍得出的。
场景只写物理空间。
位置承接写物理锚定,不写构图备注。
有参照物、有距离、有姿态、有朝向。
不变的显式写出,变化的写明起止。
镜头之间姿态链自洽,后一镜起始等于前一镜终止。
全景写全局布局,近景写核心姿态,特写写局部锚定。
多人关系镜逐人锚定写左右。
近景特写不补全员。
闪回回来重建完整物理空间锚点。
入镜说话用台词。
没入镜但现场能听见用画外音。
心里想的统一用OS。
长台词必须切断,但优先同节消化。
一个镜头最好只一个人说话。
景别错层,动作接剪。
说话给反应,道具给移焦。
环绕只给高光,灯光必须讲事。
连续剧情先承接,新场景再重建。
有声音先定声线。
首次发声锁定音色。
后续台词复用声线锚点。
情绪只改说法,不改声线本体。
OS不张嘴,但沿用本人声线。
普通OS不加明显混响,只做贴耳内心声。
非现实声音层才允许轻微远感。
非人发声先定公母、年龄感和音区,全片保持统一。
节奏紧凑,优先压满本节,但保原文完整 > 压节数。

  ]

### video_desc 内容规范

`video_desc` 字段必须严格按照【二、分镜输出格式(固定)】的格式输出本节所有镜头,内部结构如下:

```
【本段角色声线锁定】(每节强制输出,不省略)
人物A:年龄感 + 性别气质 + 音区 + 音色底色 + 发声习惯。
人物B:年龄感 + 性别气质 + 音区 + 音色底色 + 发声习惯。
...

第X节(一句话概括本节功能,总时长X秒 / 共X镜)

镜头1 / SC1(0-2.0秒):[单场景模式下可省略]物理场景,时间,光线
【时间标识】...
【运镜】...
【画面】...
【动作/情绪】...
【位置承接】...
【OS】...
【画外音】...
【音效】...
【台词】...

镜头2 / SC2(2.0-4.0秒):【多场景模式下必须标注】物理场景,时间,光线
...
```

场景表达与输出规范(必须遵守):

单一场景:若本节所有镜头均在同一场景,scene 字段值为该单一场景名,如 "scene": "裴家旧屋床榻边"。镜头标题行内场景可省略。
多场景切换:若本节内存在场景切换,则 scene 字段的 JSON 值必须为按镜头时序排列的、逗号分隔的场景名,如 "scene": "裴家旧屋床榻边, 废弃码头空地中央"。同时,video_desc 内每个镜头的标题行必须以 镜头X / SC... :【场景名】,时间,光线 的格式明确标注当前场景。
场景可标记前缀:支持使用 @ 前缀来标记特殊的非现实场景,这有利于下游系统解析,如 "scene": "@系统空间, 酒店宴会厅门口"。
声线复用:如果角色信息库({ROLES_PLACEHOLDER})已提供角色音色描述,video_desc 中所有【台词】【OS】【画外音】【音效】括号内的固定声线锚点必须直接复用,不重新设计。**每节开头必须重新完整列出【本段角色声线锁定】**,不允许省略。
字段完整性:每个镜头必须包含【时间标识】【运镜】【画面】【动作/情绪】【位置承接】【OS】【画外音】【音效】【台词】九个字段,无内容写"无"
一节一对象:每节作为 storyboard 数组中的一个对象,不要把多节塞进一个 video_desc
节内镜头数:原则上不超过8镜,**时长建议 12-15 秒,严禁超过 15 秒**
JSON合法性:video_desc 中的换行使用 \n,双引号使用 \",确保输出为可直接解析的合法JSON
**台词原文完整性**:所有【台词】【OS】【画外音】内容必须与原文逐字一致,不允许删字、换词、合并、改写
