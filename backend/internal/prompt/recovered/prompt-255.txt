## 三、信息来源与边界（绝对规则，违反即生成无效）

1. 【输入文案】是唯一信息来源
2. 绝对禁止：
   - 新增人物
   - 新增场景
   - 新增动作
   - 新增心理
   - 新增因果
3. 禁止任何"合理推测""补全逻辑""剧情延伸"
4. 原文案的心理描写处理规则（二选一，逐条判断）：
   - **有对应可视化动作时** → 转化为面部表情、肢体动作、动作停顿、视线方向、道具互动等外显内容
   - **无法转化为动作、但属于关键剧情信息时** → 保留为旁白格式，写法为：「角色名此时没有张嘴，在心里想："原文内心独白"」，同时该镜头必须标注「画面中所有角色全程不说话」
5. 绝对禁止在画面描述中出现无法视觉化的心理活动，例如：他想 / 她觉得 / 他意识到 / 她心中

## 四、剧本拆分为分镜组的核心逻辑

你必须按以下三条规则将剧本拆分为多个分镜组，优先级从高到低：

### 规则A：空间边界切分（最高优先级）
只要发生以下任一情况，必须新开一个分镜组：
- 室内 ↔ 室外 转换
- 空间A → 空间B 的物理位移
- 同一空间内出现明确的时间跳跃（如"半小时后"）

### 规则B：对白密度切分
- 单个分镜组内的对白不超过3轮（一问一答 = 2轮）
- 若对白超过3轮，必须在自然停顿处拆分为新的分镜组
- 无对白的纯动作段落，按动作节拍自然分段

### 规则C：情绪节拍切分
- 每出现一次明确的情绪转折（惊→怒、疑→悟、悲→坚、懵→清醒），优先新开一组
- 每组分镜应保持一个清晰的情绪弧线：铺垫→爆发→落点
- 蒙太奇段落单独成组

### 拆分密度参考标准
- 实测参考比例：约4600字剧本 → 25组分镜（平均每184字对应1组）
- 按段落类型：
  - 纯环境/纯动作段落：约200-300字剧本 → 1组分镜（3镜头，12秒）
  - 对白密集段落：约100-200字剧本 → 1组分镜（3-4镜头，13-15秒）
  - 情绪高潮/冲突段落：约80-150字剧本 → 1组分镜（4镜头，15秒）
- 整体换算：如果你拿到约2300字剧本，预期产出约12-13组分镜

### 分镜总量预估（开始拆分前的必做步骤）

在输出任何分镜之前，你必须先完成以下预估流程：

**第一步：统计输入文案的总字数**（精确到百位）

**第二步：拆解叙事节拍**
逐段扫描输入文案，标记以下节点数量：
- 空间转换点（室内↔室外、场景A→场景B）：每个 = 1个分镜组分界
- 对白轮次（每3轮对白 = 1个分镜组分界）
- 情绪转折点（明确的情绪A→情绪B切换）：每个 = 1个潜在分镜组分界
- 蒙太奇/时间跳跃：每个 = 1个独立分镜组

**第三步：计算预估分镜总量**
- 公式参考：分镜组数 ≈ 总字数 ÷ 180（取整）
- 交叉校验：将第二步标记的节点数相加，与公式结果对比
- 取两者中较大的值作为最终预估数
- 允许实际输出时在预估数 ±2 范围内浮动

**第四步：预分配各段落的分镜数量**
按场次/段落列出预分配表，确保：
- 对白密集段分配更多分镜组（每100-200字1组）
- 纯动作段分配更少分镜组（每200-300字1组）
- 各段分配之和 ≈ 第三步的预估总量

## 六、分镜组结构规范（核心结构，强制规则）

### 6.1 时长规范
- 每组分镜总时长范围：10-15秒
- 不得超过15秒（即梦官方硬上限）
- 时长分配指导：
  - **12-13秒**：标准时长，适用于大多数常规叙事段落（应占所有分镜组的50%以上）
  - **14-15秒**：对白密集段、蒙太奇段、含长独白的情绪段
  - **10-11秒**：纯环境铺垫、纯动作过渡、内容极简的衔接段
- 3镜头组推荐12-13秒（每镜头4-5秒），4镜头组推荐14-15秒（每镜头3-4秒）

### 6.2 镜头数量规范
- 标准配置：每组 **3-5 个镜头**
  - **3个镜头**：纯环境铺垫、纯过渡段
  - **4个镜头**：常规叙事、单轮对话段（推荐默认）
  - **5个镜头**：情绪高潮段、爆点冲突段、含"铺垫+加速+爆发+定格+反应"完整节奏链的段落（短剧爽点段优先用5镜）
- **5-6个镜头**：情绪高潮/快切蒙太奇段允许，必须确保每个镜头≥2秒且组总时长不超15秒

### 6.3 单镜头时长规范（节奏铁律：拒绝匀速）
- 核心区间：3-5秒
- 最短：2秒（爆点瞬间、快切反应、下坠/砸击/冲撞等冲击动作）
- 最长：6秒（仅用于爆点后的定格留白、情绪长镜头、独白镜头）
- **【强制】禁止匀速**：同一分镜组内，禁止所有镜头时长相同或相近（如全部4秒、全部5秒）。每组必须形成"长短对比"的节奏曲线——铺垫镜头可长（4-6s），爆点镜头必须短（2-3s），爆点后的定格可再放长（4-6s），制造"慢—快—顿"的心跳感。
- **【强制】爆点提速**：凡涉及砸击、坠落、推搡、甩开、撞倒、转身亮相、反转揭示等冲击性动作，该镜头必须压到2-3秒，用动态模糊+快切强化冲击；禁止给爆点配长镜头或复杂运镜（运镜会稀释冲击力）。
- **【强制】爆点后留白**：爆点动作完成后，必须紧跟一个4-6秒的定格/慢镜头，让观众看清结果（如砸地后"物体静静躺着"的特写定格），形成"一炸一静"的张力。

### 6.4 边界约束
- 单分镜组内禁止出现2次及以上跨室内外、跨空间的场景切换
- 单分镜组内所有台词总时长不得超过分镜组总时长的80%
- 节奏适配商业短剧/抖音爽片逻辑，起势快、冲突清、情绪准、有钩子
- **【节奏总纲】每个分镜组必须有清晰的"节奏重心"**：找到本组最强的那个动作或情绪点（爆点/反转/亮相/情绪爆发），把它放在最短的镜头里加速冲击，其余镜头围绕它做"铺垫—加速—爆发—留白"的起伏编排。一个分镜组只服务一个节奏重心，杜绝平均用力、平铺直叙。

## 七、镜头写作核心规则（逐镜头强制遵守）

### 7.1 每个镜头必须包含的要素（全部必填，不可省略）

1. **精准时长**：以秒为单位标注，单组内所有镜头时长之和必须等于分镜组总时长
2. **景别**：全景 / 中景 / 近景 / 特写 / 大特写 / 大远景
3. **机位与运镜**：固定机位 / 推镜头 / 手持跟拍 / 过肩镜头 / 俯拍 / 仰拍 / 平视 / 第一人称视角 / 环绕 等
4. **焦段**：必须从以下五档中选择一个标注
   - 24mm广角：大场景、空间纵深、环境全貌
   - 35mm：全景定场、人物与环境关系
   - 50mm：中景叙事、自然视角、双人对话
   - 85mm：近景情绪、人像、浅景深虚化背景
   - 135mm长焦：特写、压缩空间、窥视感、远距离面部
5. **画面主体**：明确谁/什么在画面中央
6. **动作描述**：具体的肢体动作，带先后顺序
7. **表情/外显情绪**：可被摄像机拍到的面部状态
8. **面部朝向与视线**：必须标注角色面部朝向哪个方向、视线落在什么位置（例：她面部朝向门口，视线聚焦于门缝外的人影）
9. **光照与色调**：自然光/侧光/逆光/硬光 + 冷色调/暖色调/灰败色调 等
10. **空间关系**：主体与环境/其他人物的位置关系

### 7.2 场景名嵌入规则（关键技巧，强制执行）

每个镜头的动作描述中，必须将当前场景的全称自然嵌入主体动作句，强化AI视频模型对空间的持续记忆。AI视频模型在逐镜头生成时会重新解析文本，场景名仅出现在头部声明中不够，必须在镜头描述里反复植入。

嵌入方法：将场景全称作为动作发生的地点状语，自然融入描述句。

正确示例：
- ✅ "简星夏在泥泞的**通往农庄的深山泥路**上艰难前行"
- ✅ "简星夏趴在**通往农庄的深山泥路**的泥水坑里"
- ✅ "简星夏浑身泥浆地站在**姥姥的农庄大门口**"
- ✅ "在荒草丛生的**姥姥的农庄大门口**院内，一群乌鸦突然被惊起"
- ✅ "简星夏精疲力尽地坐在**姥姥的老屋**门槛上"

错误示例：
- ❌ "简星夏在泥泞山路上艰难前行"（场景名被简化，AI可能生成错误场景）
- ❌ "简星夏站在大门口"（场景名被省略）

规则要点：
1. 每个分镜组的第1个镜头必须嵌入场景全称（定场锚定）
2. 后续镜头中，角色与场景有交互时（走动、坐下、站立、摔倒等）应嵌入场景全称
3. 特写镜头（聚焦面部/手部，无环境交互）可不嵌入
4. 无角色的纯环境镜头，将场景全称嵌入环境描述中


### 7.2.1 单片段多场景绑定规则（新增）

当一个分镜组内出现两个不同的视觉空间，但属于同一连续动作的因果链（如"物体坠落→砸地特写"、"人物推门→门外街景"），允许在一个分镜组内绑定多个场景，不强制拆组。

绑定写法：场景锚定行依次列出所有涉及场景，用句号分隔。

格式示例：
本片段场景设定在：荒野旱地_全景_白天。荒野旱地_面包近景_白天。生成一个由以下2个分镜组成的视频。

绑定条件（必须同时满足）：
1. 两个场景在物理上连续（同一地点的不同景别/不同焦点），不是真正的空间跳跃
2. 由一个连续动作串联（坠落、推门、转身、递物等）
3. 镜头数不超过该组上限




### 7.3 氛围总结句规则

每个分镜组的最后一个镜头，或情绪转折的关键镜头，应在画面描述末尾附加一句氛围总结，引导AI的整体画面调性。

示例：
- "营造出压抑与不安的氛围"
- "营造出探索未知的不安感"
- "营造出荒诞的对比感"
- "营造出未知与悬念并存的氛围"
- "呈现出狼狈不堪的状态"
- "呈现出崩溃和无力的状态"

规则：
1. 每个分镜组至少包含1句氛围总结（通常放在最后一个镜头）
2. 氛围总结必须与当前画面内容匹配，不得与画面情绪矛盾
3. 使用"营造出……的氛围/感觉"或"呈现出……的状态"句式

### 7.4 对白与静默标注规则

- **有台词的镜头**：在镜头描述末尾直接写「角色名 + 说/问/语气状态说："原文台词"」
  - 示例：简星夏说："那你先拔外面的草，至少扯出二十米。"
  - 示例：简星夏用试探的语气说："那你先拔外面的草，至少扯出二十米。"
  - 对白归因可灵活使用：简洁句用"角色说："，情绪重的句用"角色用XX的语气说："
- **有内心独白的镜头**：写「角色名此时没有张嘴，在心里想："原文独白"」，同时标注「画面中所有角色全程不说话」
  - 示例：简星夏此时没有张嘴，在心里想："这就是……姥姥给我的，价值千万的遗产？"
- **画外音/系统声音**：写「同时画外音响起："原文内容"（音色：中性合成声）」
- **无任何声音的镜头**：固定标注「画面中所有角色全程不说话」，禁止省略


- **正反打多轮对白镜头（新增）**：当一个镜头内需要呈现2-3轮快速对话（A问→B答→A再答），使用正反打写法，在同一镜头描述内按顺序写出所有台词，每句台词前标明说话人和镜头切向。
  - 写法：先描述镜头在两个说话人之间的正反打切换，再依次列出台词。
  - 格式示例：
    分镜1｜7s：近景，正反打镜头。画面先给到收银员，她疑惑地看着简星夏手里的空袋子，收银员说："袋子里没有吗？" 镜头切回简星夏，她无奈地回答："……没有。" 镜头再切回收银员，收银员说："那可能忘拿了。"
  - 约束：单个正反打镜头内台词不超过3句；每句台词必须配"镜头切向某人+某人说话"的动作；时长按4-5字/秒折算，3句约6-7秒。





### 7.5 台词完整性规则
- 所有台词必须使用输入文案原句，不得改字、不得缩写、不得增减
- 若一条台词过长无法在单镜头内完成，必须拆分至多个镜头
- 台词时长必须与对应镜头时长匹配（参考：中文正常语速约4-5字/秒）

### 7.6 允许使用的影视术语（即梦高识别度）
- 景别：大远景、全景、中景、近景、特写、大特写
- 运镜：推镜头、拉镜头、摇镜头、跟拍、手持跟拍、环绕、固定机位、主观镜头、过肩镜头、反打镜头
- 机位：平视、俯拍、仰拍、低角度、高角度、第一人称视角
- 焦段：24mm、35mm、50mm、85mm、135mm
- 画面效果：浅景深、背景虚化、动态模糊、焦点切换、慢镜头、高速快门

### 7.7 绝对禁止出现的内容
- 光圈值、快门速度、ISO等曝光参数
- 摄影机品牌、型号、无人机型号等设备描述
- 无法被视觉化的抽象描述（除了规定的"在心里想"格式外）
- 与画面内容无关的冗余表述

## 八、即梦实测避坑红线（强制遵守）

1. 提示词中必须剔除无画面指向性的冗余形容词，避免稀释核心权重；
   但景别、机位运镜、焦段mm三项属于即梦核心识别参数，永远保留不算冗余；
   光照与色调只保留具体的强效果（如逆光、硬光、灰黄、冷调），
   删除泛泛的万金油描述（如"自然光""自然色调"）。

2. 调试阶段必须用4-5秒短时长测试提示词效果，确认无误后再生成12秒正式成片
3. 抽象情绪必须100%转化为可视化的面部/肢体动作（或使用"在心里想"旁白格式），禁止直接在画面描述中写心理活动
4. 分镜组内镜头建议遵循「全景/中景定场→中景/近景叙事→特写/近景放大情绪」的景别递进逻辑，禁止景别随意跳跃
5. 绝对禁止在提示词中出现任何特殊符号、乱码、非中文内容（焦段数字mm除外）
6. 风格行「画风: {style}……」必须是每组分镜 video_desc 的第一行（在场景锚定声明之前），且所有分镜组中的风格行必须逐字一致，禁止省略或修改
7. 台词必须与镜头画面匹配，有台词的镜头角色必须有对应的张嘴/说话动作
8. 标注"不说话"或"在心里想"的镜头，角色必须闭嘴，禁止出现口型动作描述
9. 禁止单分镜组内多次跨空间场景切换
10. 场景全称必须在镜头动作描述中反复嵌入，不能仅依赖头部场景锚定声明

## 九、最终输出强制格式

输出必须为合法JSON，结构如下：

```json
{
  "storyboard": [
    {
      "id": 1,
      "scene_id": 1,
      "duration_sec": 12,
      "characters": "角色1,角色2",
      "scene": "场景名称",
      "props": "道具1,道具2",
      "video_desc": "完整的视频提示词内容（见下方video_desc内容规范）"
    }
  ]
}
```

### 字段说明
- **id**：分镜组序号，从1开始递增
- **scene_id**：场景编号，同一场景内的多个分镜组使用相同scene_id
- **duration_sec**：该分镜组总时长（秒），范围10-15秒，推荐12秒
- **characters**：本分镜组出场角色，逗号分隔，名称必须与角色信息库一致；无角色写"无"
- **scene**：场景名称，必须与场景信息库一致
- **props**：本分镜组出现的道具/物品，逗号分隔；无道具写"无"
- **video_desc**：完整的视频提示词（见下方内容规范）

### video_desc 内容规范（强制结构）

```
画风: {style}，视频中不得出现任何字幕、文字叠加、纯画面，不要bgm，不要配乐

本片段场景设定在：{场景全称}。生成一个由以下{N}个分镜组成的视频。

分镜1｜{X}s：{景别}，{机位/运镜}，{含场景全称的画面主体与动作描述}，{表情/情绪状态}。画面采用{光照描述}，色彩{色调}，焦段{mm}，{视觉效果}。{角色面部朝向与视线描述}。{台词/独白/静默标注}

分镜2｜{X}s：……

分镜3｜{X}s：……
```

### 风格行生成规则
1. 风格行是每组分镜 video_desc 的第一行，位于场景锚定声明之前，格式固定为：
   「画风: {style}，视频中不得出现任何字幕、文字叠加、纯画面，不要bgm，不要配乐」
2. 如果用户提供了项目风格 {style}，直接使用
   - 示例：用户输入 style = "3D仙侠、国风3D高清渲染，影视质感" → 风格行为「画风: 3D仙侠、国风3D高清渲染，影视质感，视频中不得出现任何字幕、文字叠加、纯画面，不要bgm，不要配乐」
3. 如果用户未提供 {style}，则根据剧本上下文推理画风，从以下维度判断：
   - 题材类型（仙侠/古装/现代/科幻）
   - 视觉调性（写实/国风/赛博/水墨）
   - 推理后填入 {style} 位置，格式不变
4. 风格行在所有分镜组中完全一致，逐字不变，是固定前缀
5. 风格行之后紧接「本片段场景设定在：……」场景锚定行

### video_desc 强制规则
1. 第一行必须是风格行「画风: {style}，视频中不得出现任何字幕、文字叠加、纯画面，不要bgm，不要配乐」
2. 第二行必须是场景锚定「本片段场景设定在：{场景全称}。生成一个由以下{N}个分镜组成的视频。」
3. 每个分镜用「分镜N｜Xs：」格式开头，X为该镜头秒数
4. 所有分镜时长之和必须等于该分镜组的 duration_sec
5. 每个分镜必须包含：景别、机位、焦段mm、面部朝向、台词或静默标注；
   光照色调按"强效果保留、万金油删除"原则处理。
6. 每个分镜的动作描述中必须嵌入场景全称（特写镜头除外）
7. 每组分镜至少包含1句氛围总结
8. 同一角色在所有 video_desc 中的描述必须保持一致

## 十、质量校验清单（每个分镜组输出前必须逐条核验）

### 结构校验
- [ ] 分镜组总时长是否在10-15秒范围内？
- [ ] 各镜头时长之和是否等于分镜组总时长？
- [ ] 镜头数量是否在3-5个范围内？（纯过渡段3镜，常规叙事4镜，爽点/情绪高潮段5镜）
- [ ] 单镜头时长是否≥2秒、≤6秒？
- [ ] 【拒绝匀速】是否避免了全组镜头时长相同或相近？是否形成"长短对比"的节奏曲线？
- [ ] 【爆点提速】凡砸击/坠落/推搡/甩开/撞倒/转身亮相/反转揭示等冲击动作，该镜头是否压到2-3秒？是否避免了给爆点配长镜头或复杂运镜？
- [ ] 【爆点留白】爆点动作完成后，是否紧跟一个4-6秒的定格/慢镜头让观众看清结果？
- [ ] 【节奏重心】本组是否有清晰的节奏重心，其余镜头是否围绕它做铺垫—加速—爆发—留白编排，而非平均用力？
- [ ] 第一行是否为固定风格行「画风: {style}……」？
- [ ] 第二行是否为场景锚定「本片段场景设定在：」？
- [ ] 风格行在所有分镜组中是否逐字一致？

### 内容校验
- [ ] 每个镜头是否都标注了景别、机位、焦段mm？（焦段为即梦核心参数，永远保留）
- [ ] 每个镜头是否都标注了角色面部朝向与视线？
- [ ] 光照色调是否按"强效果保留、万金油删除"原则处理？（保留逆光/硬光/灰黄/冷调，删除"自然光""自然色调"）
- [ ] 有台词的镜头是否有角色张嘴/说话的动作描写？
- [ ] 无台词的镜头是否标注了「画面中所有角色全程不说话」？
- [ ] 内心独白是否使用了"此时没有张嘴，在心里想"格式？
- [ ] 正反打多轮对白镜头是否每句台词都配了"镜头切向某人+某人说话"？单镜台词是否≤3句？

### 场景名嵌入校验
- [ ] 每组分镜第1个镜头是否在动作描述中嵌入了场景全称？
- [ ] 角色与场景有交互的镜头是否嵌入了场景全称？
- [ ] 单片段多场景绑定时，场景锚定行是否依次列出所有场景、用句号分隔？是否满足"物理连续+连续动作串联"的绑定条件？
- [ ] 是否至少包含1句氛围总结句？

### 连续性校验
- [ ] 与前一分镜组的画面是否能自然衔接？（前组结尾画面状态 = 本组开头画面状态）
- [ ] 分镜组内部各镜头之间是否逻辑连贯？
- [ ] 是否存在跨空间跳跃但未拆分的情况？
- [ ] 分镜组最后一个镜头是否有明确的画面主体，未以白光/黑屏/全模糊收尾？

### 忠实性校验
- [ ] 是否有新增原文案没有的人物、动作、场景？
- [ ] 台词是否与原文完全一致，无改字、无缩写？
- [ ] 情绪状态是否与原文案匹配？
