【文生图的提示词要求】
1. 生成一段完整的字符串提示词，作为后续视频生成的关键帧参考图，方便进行3x3网格出图。
2. 提示词以固定开头开始："Generate a single image in a seamless 3x3 grid layout. \n"
3. 在固定开头之后，先提取并描述共通的项目风格、场景设定和角色特征（确保角色特征完全对齐登场角色设定内容，场景细节基本符合参考提示），然后换行。
4. 接着，分别描述这9个不同视角的画面细节，定义该片段（及后续连贯剧情）中关键画面的静态视觉效果。请充分利用提供的多段内容，让九宫格画面剧情丰富、有推进感。每个画面一行。 
5. 不要使用抽象描述，少用“强调...”、“突出...”这类对模型无意义词汇，描述越具体越好。
6. 对于画面中正面出现的角色的描述，必须在无上下文的情况下让文生图模型能准确生图，保持角色一致性。
7. 需要遵循物理视角的逻辑一致性，剔除当前视角下不可见元素，避免文生图模型信息混乱。
8. 需要背对镜头的角色，不要描述面部，而且需要明确的在提示词中写出该角色背对镜头。
9. 登场角色的配饰与物件，如果与当前场景明显冲突，可舍去（比如室内不会打伞，会议室开会时不可能背着书包）。
10. 文生图的构图极为重要，尽可能多用过肩镜头、前景遮挡、低角度仰拍等技巧打破画面的AI感，避免平铺直叙的证件照式构图。
11. 不要显示字幕。

【图生视频的提示词要求(video_desc)】
1. 图生视频的参考图片可能是文生图的九宫格，也可能是图片编辑的九宫格，为了兼容性并且让视频模型有发挥空间，不要具体指定使用某一个关键帧。
2. 不要重复描述静态画面细节，这些在九宫格参考图中已经全部包含了。
3. 重点是以导演思维告诉视频模型如何去演绎（视频模型没有上下文信息，只能通过你的提示词和九宫格参考图片来生成视频），你需要让视频模型能够配合九宫格参考图，实现15秒内包含多个分镜的流畅视频生成。
4. 如果需要角色对白，请使用引号将内容括起，并确保对白口语化、简单、自然流畅，以便于后期配音。但如果场景中只有一个角色，不要自言自语。
5. 为了方便片段视频之间的自然拼接，提示词需要强调不要有背景音乐，只能有音效和对话。
6. 如果有对话，需要将角色的声学特征简单描述出来。


【图片编辑的提示词要求(image_desc)】
1. 确定该片段的主要角色是1个还是2个（超过2个则按2个算）。然后生成一段九宫格的图片编辑提示词，前面1到2格直接输出作为角色图，后面7到8格用于生成关键帧。
2. 提示词以固定开头开始："Generate a single image in a seamless 3x3 grid layout. \n"
3. 在固定开头之后，先提取并描述共通的项目风格、场景设定和角色特征（这里角色只需要简单描述，因为有参考图），然后换行。
4. 接着，按照九宫格顺序描述画面：
   - 画面1(固定文字)：请直接输出 “画面1：直接显示【图1】（图1是@角色xxx）。\n”
   - 画面2(2个主要角色的场合)：请直接输出 “画面2：直接显示【图2】（图2是@角色yyy）。\n”
   - 画面2或3至画面9：分别描述这7-8个不同视角的剧情关键帧画面细节，定义该片段（及后续连贯剧情）的静态视觉效果。
5. 不要使用抽象描述，少用“强调...”、“突出...”这类对模型无意义词汇，描述越具体越好。
6. 需要遵循物理视角的逻辑一致性，剔除当前视角下不可见元素，避免文生图模型信息混乱。
7. 需要背对镜头的角色，不要描述面部，而且需要明确的在提示词中写出该角色背对镜头。
8. 画面构图极为重要，尽可能多用过肩镜头、前景遮挡、低角度仰拍等技巧打破画面的AI感，避免平铺直叙的证件照式构图。

【最后的注意点】
你必须抛弃自己对AI模型能力的固有观点，因为模型能力每天都在变化，
目前所有模型都支持中文提示词，为了方便用户二次编辑，请三段全部输出为中文（除了固定英文开头）。
随着AI模型能力的提升，目前已不需要SD1.5版本那种关键词式写法，不需要“8K画质”这种毫无意义的表述，用自然语言描述就好。


【生成前的必要分析】
在生成提示词之前，你必须先完成以下分析（分析结果直接填入JSON对应字段）：
1. **出场角色识别**：从本段剧本中提取所有出场角色的名称，填入 characters 字段
2. **场景识别**：确定本段剧本发生的场景名称，填入 scene 字段
3. **对白提取**：提取完整台词，填入 line 字段，并确定说话角色填入 voice_actor
4. **情绪判断**：根据剧情上下文确定情绪标签，填入 emotion

完成以上分析后，再依次生成 image_desc、image_prompt、video_desc 三段提示词。
