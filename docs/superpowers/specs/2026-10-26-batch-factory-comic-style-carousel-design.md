# 批量工厂画风库 Cover Flow 选择设计

## 目标

让用户一眼看出当前选择的漫画画风，同时用单排 3D 透视轮播展示 25 张画风卡，避免在单书配置和统一配置弹窗中占用过多纵向空间。

## 交互

- 画风卡固定为一排 Cover Flow，不再自动换行或显示多行网格。
- 当前卡片始终居中并适度放大；左右卡片向中心倾斜、逐级缩小和降低亮度，形成 3D 透视层次。
- 桌面端支持拖拽、触摸板横向滚动、鼠标滚轮、左右按钮和方向键；触屏支持左右滑动。
- 每次只切换一个画风，首尾循环衔接。
- 切换时背景预览、当前画风标题和简介同步淡入过渡。
- 点击卡片后只更新当前弹窗草稿，不立即写入后端。
- 单书配置仍需点击“保存当前书覆盖”；统一配置仍需点击“保存统一配置”。
- 选择画风与“设为漫画全局参考图”保持为两个独立操作。

## 选中状态

- 居中的当前卡片就是已选画风，保留蓝色描边并增加右上角勾选标记。
- 已选卡片名称区显示“已选择”。
- 画风库标题旁显示“当前画风：画风名称”；没有选择时显示“尚未选择画风”。
- 使用现有 `presetId` 作为唯一选中依据，不改变后端数据结构。

## 布局

- 每张卡使用稳定的固定宽度，预览图继续保持 3:4。
- 舞台使用 CSS 3D 透视和变换实现，不引入新的轮播依赖。
- 横向舞台必须限制在弹窗内容宽度内，不能把弹窗或页面撑宽。
- 移动端减少同时可见的侧边卡片数量，保留居中选择和滑动能力。
- 系统开启“减少动态效果”时取消长过渡，直接完成状态切换。
- 参考图、全局前后缀和保存按钮继续位于画风横向列表下方。

## 验证

- 单元测试确认循环索引、相对位置和拖动切换方向。
- 源码测试确认画风列表为单排 3D 舞台，卡片不会换行或撑宽弹窗。
- 源码测试确认当前卡具有勾选和“已选择”标识，标题显示当前画风名称。
- 浏览器验证点击、拖动、滚轮、按钮和方向键均能切换，并且背景与标题同步更新。
- 前端生产构建通过。
- Go 嵌入式本地程序重新构建并启动后，在统一配置和单书配置中浏览器验证 Cover Flow 切换、选中反馈和保存入口。
