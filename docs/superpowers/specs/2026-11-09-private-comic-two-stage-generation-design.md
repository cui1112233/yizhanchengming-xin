# 私人定制漫画两阶段生成设计

## 目标

私人定制漫画属于单本精细制作。资产提取完成后，主操作必须明确分成“生成漫画提示词”和“生成漫画图片”两个阶段，不再使用含义模糊的“开始生成”。

## 交互流程

1. 正文不足或资产尚未提取时，主按钮显示“生成漫画提示词”，但保持禁用，并提示先粘贴正文或提取资产。
2. 资产已存在、漫画提示词尚未全部生成时，主按钮显示“生成漫画提示词”或“补齐漫画提示词”，只调用现有提示词生成动作。
3. 全部分页的漫画提示词与图片提示词均已就绪时，主按钮切换为“生成漫画图片”，只调用现有批量分镜生图动作，并仅生成缺失图片。
4. 全部分页图片完成后，主按钮显示“漫画图片已完成”并禁用，避免重复提交。单页重生、重新生成提示词等高级操作继续保留在现有页面卡片和“更多操作”菜单中。

## 状态口径

- 提示词完成：存在漫画页，且每一页同时具有 `comicPrompt` 和 `imagePrompt`。
- 图片完成：存在漫画页，且每一页至少有一张图片。
- 资产图仍是可选增强项，不阻塞提示词阶段。
- 当前有任务运行时，主按钮显示对应阶段的“生成中…”并禁用。

## 调用边界

- 主按钮不再调用会混合创建任务、补资产和生成提示词的 `onSubmit`。
- 提示词阶段调用现有 `onGeneratePrompts`。
- 图片阶段调用现有 `onGenerateAllPageImages`。
- 资产提取继续由左侧“提取资产”按钮负责；首次提取时由现有逻辑创建任务并保存设置。

## 验收标准

- 本地私人定制漫画页不再出现主按钮“开始生成”。
- 有资产、无提示词时显示可点击的“生成漫画提示词”。
- 提示词全部就绪、图片未齐时显示可点击的“生成漫画图片”。
- 图片全部就绪时显示禁用的“漫画图片已完成”。
- 不触发真实模型调用，仅通过自动测试和现有本地数据进行可见状态验收。
