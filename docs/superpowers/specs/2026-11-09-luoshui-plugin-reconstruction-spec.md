# 洛水 v2.9.0 插件证据与独立重写规格

## 1. 适用边界

本规格只把发布包中可观察到的行为转换成可验证规则。一战晟铭使用自己的 React、Go、Agent 图片任务、模型配置和存储实现；不得复制洛水源码、密钥、私有接口、服务地址、付费权限逻辑或专有图片资源。

原版证据文件：`F:\脚本测试\work\洛水2026-v2.9.0-反编译分析\recovered\frontend\index-DszfAkKD.js`。

REA 对 50.7 MB 前端包完成了制品登记，但 JavaScript 全量关系图因内存限制只有部分覆盖；因此下列结论同时使用“REA 制品身份”与“目标文件逐行静态核对”，不能把 REA 未解析到的内容解释为功能不存在。

## 3. 资产参考（首个完成重写的插件）

### 3.1 原版观察链路

`插件市场 -> 点击资产参考 -> 权限检查 -> 打开工作台 -> 并行读取生成记录和参考库 -> 选择模型/分辨率/比例/数量 -> 添加参考图或输入提示词 -> 每张图提交一次生成 -> 保存成功或失败记录 -> 搜索、下载或删除结果`

证据：

- 入口、权限检查和并行初始化：465199-465201、465346-465374、465700-465748 行。
- 默认模型、1K、16:9、数量和本地偏好：457730-457798 行。
- 可选比例 16:9、9:16、21:9、1:1、3:4、4:3：457730-457798 行。
- 上传、拖拽和粘贴参考图片：465490-465660 行。
- 参考库导入、添加、重命名和读取：465750-465833 行。
- 输入校验和运行环境失败：465976-466035 行。
- 单张请求字段：465976-466050 行。
- 按选择数量逐张调用、收集部分成功、保存记录和失败提示：466051-466130 行。

### 3.2 输入

- 必选：一战晟铭中已配置且可用的图片模型。
- 内容：提示词、1 至 10 张参考图片，二者至少有一个。
- 分辨率：1K、2K、4K，默认 1K。
- 图片比例：16:9、9:16、21:9、1:1、3:4、4:3，默认 16:9。
- 数量：1 至 20，默认 5。实现时拆成 N 个独立的单张 Agent 图片任务。
- 参考图片只接收图片文件；去重后的项目素材 ID 传给图片任务。

### 3.3 输出

- 每个成功任务输出一张一战晟铭 Agent 素材图片。
- 结果卡片保存图片 ID、受保护资源 URL、提示词、模型 ID、分辨率、比例和生成时间。
- 支持搜索、逐张下载和全部删除本地记录。
- 生成 5 张时允许部分成功，例如显示“成功 4 张，失败 1 张”，不得丢弃已成功图片。

### 3.4 边界

- 提示词为空但有参考图：允许。
- 参考图为空但有提示词：允许。
- 二者都为空：拒绝，不创建任务。
- 数量小于 1 归一为 1，大于 20 归一为 20。
- 非法分辨率回退 1K；非法比例回退 16:9。
- 重复点击：正在执行时拒绝第二次提交。
- 每个子任务使用独立幂等键，格式为 `asset-reference:<task>:<operation>:<index>`。
- 取消：停止继续轮询，并尽力取消所有已经取得任务 ID 的子任务；晚到结果不得写入本地结果列表。

### 3.5 失败提示

- 未配置模型：`请选择图片模型`。
- 内容为空：`请输入提示词或添加参考图片`。
- 非图片文件：`只能添加图片文件`。
- 参考图超过 10 张：`参考图片最多 10 张`。
- 上传无素材：`上传结果缺少素材`。
- 服务未返回图片：`生成服务没有返回图片`。
- 后端有明确错误时原样显示；没有明确错误时显示 `图片生成失败，请稍后重试`。
- 部分失败用数量提示，不把整个批次报成失败。

### 3.6 一战晟铭实现映射

- 页面入口：`frontend/src/user/pages/PluginCenterPage.jsx`。
- 工作台：`frontend/src/user/components/AssetReferenceWorkbench.jsx`。
- 纯规则：`frontend/src/user/pages/asset-reference-workbench.js`。
- 上传：一战晟铭 Agent 素材上传接口。
- 生成：一战晟铭 Agent 图片生成任务接口；不调用洛水的 `window.pywebview`，也不使用洛水模型别名。
- 记录：图片本体由 Agent 素材持久化；当前工作台检索元数据保存在本机浏览器 localStorage。清理浏览器数据会丢失检索元数据，这是当前已知差异。

## 5. 同输入验收表

| 场景 | 原版可观察规则 | 一战晟铭预期 |
|---|---|---|
| 正常：提示词 + 1 张参考图 + 5 张 + 21:9 | 逐张提交，记录成功和失败 | 5 个独立单张任务，部分成功可保留 |
| 空值 | 无提示词且无参考图时拒绝 | 同样拒绝，零任务 |
| 重复操作 | 运行中不能重复开始同一批 | 同样拒绝 |
| 错误模型/服务错误 | 显示明确错误并写失败状态 | 显示后端错误；不伪造结果 |
| 取消 | 停止当前批次，后续结果不入列表 | 取消全部已知子任务并忽略晚到结果 |

不进行付费图片调用时，只能完成规则、请求形状和界面状态对照，不能声称实际画质或模型输出与原版一致。
