# 自动化预设与批量音频匹配修复设计

## 目标

修复自动化预设列表因 MySQL 联表字段名不明确而无法读取的问题，并让“自动化预设”和“统一配置”里的音频匹配方式固定为“按风格自动匹配”。

## 范围

- 修复自动化预设列表 SQL：联表查询中的字段全部明确来自主表或修订表。
- 批量统一配置固定保存 `audioCategorySelectionMode: "auto"`。
- 新建或更新自动化预设时，固定保存自动音频模式，并清除手动分类、手动音频及候选音频残留值。
- 载入旧预设时也按自动音频模式使用，避免历史手动值重新进入统一配置。
- 单本配置继续允许选择分类和指定音频，不改变原有能力。
- 不删除、不重建现有批次及其 15 本小说；修复只影响配置读取、保存和后续未完成步骤。

## 数据流

1. 前端打开自动化预设管理器，请求预设列表。
2. 后端用带表别名的 SQL 返回主表名称、当前修订配置和主表时间。
3. 前端保存统一配置或自动化预设前，若不是单本配置，则把漫画发布设置归一化为自动音频模式。
4. 单本配置仍可显式切换到手动模式并保存指定音频。

## 错误处理

- SQL 读取错误继续显示后端真实错误，但不再出现字段名歧义。
- 历史预设里的手动音频字段不会导致打开失败；载入批量草稿时会自动清理。
- 不对现有生产结果做删除或重新生成。

## 验收

- 自动化预设可以正常打开、保存、重命名和载入。
- 批量统一配置只显示“按风格自动匹配”，保存值为 `auto`。
- 自动化预设保存和载入后，仍是 `auto`，不存在手动分类或指定音频残留。
- 单本配置仍显示手动指定入口。
- 后端专项测试、前端专项测试及前端构建通过。
