# V88 Agent 自适应节点输入框与模型执行设计

日期：2026-10-20

范围：本机 V88 `/agent/canvas`。本设计统一图片、视频、文字节点的输入体验，并把统一 API 配置中的已启用模型接入真实生成链路。保留 V88 现有颜色和品牌，不复制 Liblib 的源码、CSS、品牌或云端业务。

## 1. 目标

1. 图片、视频、文字节点共用一套轻量、自适应的悬浮编辑器。
2. 用户点击节点预览才展开编辑器；点击画布空白、切换节点或删除节点时，编辑器及其所有弹层一起关闭。
3. 模型列表来自当前账号的统一 API 配置，前端不硬编码可执行模型。
4. 模型选择不是装饰：文字生成后回填当前文字节点，图片生成后保存为 Agent 项目素材并回填当前图片节点，视频继续使用现有 Agent 视频任务并回填当前视频节点。
5. 未配置、配置不完整、模型不支持参数、上游失败和节点版本冲突都显示真实原因，不显示假成功。

## 2. 已确认现状

- `AgentCanvas.jsx` 已读取图片和视频模型列表，但没有读取文字模型。
- 现有 Agent 真实生成任务只有视频任务。
- 图片生成控件目前明确禁用；项目已有 Go 生图服务，可以复用其统一模型解析和提供方调用。
- 文字模型已有账号级配置和 Go `TextProvider`，但 Agent 文字节点没有按模型执行并回填的接口。
- 当前媒体编辑面板固定宽度为 800px，控制项会换行；素材库是独立浮层，因此可能在编辑器关闭后残留。

## 3. 交互设计

### 3.1 统一编辑器外壳

建立一个共享的自适应编辑器，只由当前 `activeEditorNodeID` 控制。图片、视频、文字节点复用相同的布局和关闭规则，按节点类型注入不同工具。

- 桌面默认宽度约 680px，受视口和画布边界限制，不能超出可视区域。
- 编辑器在节点预览下方居中展开，不改变预览卡片宽度。
- 点击节点预览打开；点击同一预览保持；点击另一个节点切换。
- 点击编辑器内部、模型弹层、参数弹层和素材库不关闭。
- 点击画布空白、按 Escape、删除当前节点或切换项目时，编辑器、模型弹层、参数弹层和素材库同时关闭。
- 打开编辑器时自动调整可视区域，避免编辑器被画布边缘裁切。

### 3.2 信息层级

编辑器分为四层，默认只显示常用内容：

1. 顶部能力栏：参考素材、标记、特效、角色库、运镜；未实现的能力不显示可点击假入口。
2. 参考区：已选素材显示为带编号缩略图；连接带来的素材和手动选择素材统一去重。
3. 提示词区：无额外边框的多行输入区；引用素材显示为可识别的小标签。
4. 底部工具栏：模型、生成模式、参数摘要、辅助工具、状态或消耗提示、圆形提交按钮，保持单行。

模型、生成模式和详细参数使用锚定在底栏上方的弹层。高级设置在同一编辑器内向下展开，不另开笨重表单。

### 3.3 节点差异

- 文字：提示词、文字模型、翻译入口、生成状态、提交。生成结果直接回填当前节点正文。
- 图片：参考图、提示词、图片模型、比例、生成数量、高级设置、提交。生成结果先保存为项目素材，再回填当前节点。
- 视频：图片/视频参考、提示词、视频模型、生成模式、比例、清晰度、时长、数量、声音、高级设置、提交。继续使用现有视频任务状态和确认回填。

## 4. 模型目录与选择规则

三类节点分别读取：

- `GET /api/models?kind=text`
- `GET /api/models?kind=image`
- `GET /api/models?kind=video`

前端显示统一 API 配置中的展示名称，提交时只传模型目录 ID。后端必须再次验证：

1. 模型属于当前账号；
2. 模型已启用；
3. 模型类型与节点一致；
4. 必填地址、真实模型 ID、凭证或本地执行器配对状态完整；
5. 当前参数和参考素材类型受该模型支持。

没有可执行模型时，下拉框显示“尚未配置可用的文字/图片/视频模型”，提交按钮禁用，并提供前往 API 配置的明确入口。不能用内置假模型兜底。

## 5. 真实执行链路

### 5.1 文字

新增 Agent 文字生成 Go 接口。请求包含项目、节点、节点版本、模型 ID、用户提示词和幂等键。

后端按当前账号和指定模型解析文字提供方，调用模型后返回生成内容。结果只能回填请求时的同一节点版本；如果用户在生成期间修改过节点，返回版本冲突并保留生成结果供用户复制，不能覆盖新内容。

成功后更新节点正文、状态和版本，并写入 Agent 执行记录。刷新页面后结果仍存在。

### 5.2 图片

新增 Agent 图片生成 Go 接口，复用现有统一图片模型解析与提供方调用，不复制一套密钥读取逻辑。

请求包含项目、节点、节点版本、模型 ID、提示词、比例/尺寸、数量、参考素材 ID 和幂等键。后端校验参考素材属于当前账号和项目，并按模型能力决定是否接受参考图。

提供方返回图片后，Go 下载并校验媒体类型和大小，将图片写入 TOS 或本机已配置的 Agent 对象存储，再写入 `agent_assets`。只有素材保存成功后，才允许把素材引用回填到当前节点。数据库失败时回滚刚写入的对象。

### 5.3 视频

保留现有 `/api/agent/tasks/{id}/video-jobs` 任务链路和状态机。新编辑器只替换参数收集和展示方式，不绕过现有模型解析、素材权限、结果入库、确认、重试和取消逻辑。

统一模型选择必须使用用户选择的目录 ID；后端继续验证实际提供方配置。本地豆包执行器只有在配对可用时才能提交。

## 6. 状态与错误

每个节点独立显示：准备中、排队中、生成中、等待确认、已完成、已取消、失败。切换节点不能丢失任务状态。

- 模型列表失败：显示加载失败并允许重试。
- 模型配置不完整：说明缺少什么，并指向 API 配置。
- 参考素材不支持：阻止提交，说明当前模型支持的素材类型。
- 提供方失败：保留用户输入和参数，显示可读错误并允许重试。
- 节点版本冲突：不覆盖当前节点，提示用户查看生成结果后手动采用。
- 项目素材保存失败：节点保持原内容，不显示完成。

## 7. 前端边界

将编辑器拆成职责清晰的组件：

- 共享编辑器外壳：开关、定位、外部点击和 Escape。
- 参考素材条：编号、缩略图、删除、连接同步和素材选择。
- 提示词编辑区：文本和引用标签。
- 底部工具栏：模型、参数摘要、提交和状态。
- 模型弹层、参数弹层、高级设置：只负责各自选择，不拥有独立关闭状态。

节点与画布保存仍使用现有 revision 合同。系统预设提示词继续放在 Go 后端，不在 React 中硬编码。

## 8. 测试与验收

### 8.1 自动测试

- 三类模型列表只显示当前账号对应类型的已启用模型。
- 后端拒绝跨账号模型、错误类型模型、禁用模型和配置不完整模型。
- 文字生成回填、幂等和节点版本冲突。
- 图片生成、结果下载校验、对象存储、素材记录、失败回滚和节点回填。
- 视频现有提交、轮询、确认、取消、重试和参考素材测试不回归。
- 打开一个节点时关闭另一个节点；画布空白和 Escape 同时关闭编辑器及素材库。
- 工具栏在目标宽度保持单行，模型名称可完整查看或通过弹层完整显示。

### 8.2 本机真实验收

重建 React，再通过 Go embed 构建并重启本机 4001。在已登录浏览器中逐项验证：

1. 图片、视频、文字节点点击预览均能打开对应编辑器。
2. 点击画布空白后输入框和“我的收藏”等弹层一起消失。
3. 三类模型均来自 API 配置，切换后保存到节点。
4. 使用当前账号真实可用的文字模型生成一次，刷新后正文仍在。
5. 使用当前账号真实可用的图片模型生成一次，结果进入项目素材并回填节点。
6. 使用当前账号真实可用的视频模型或已配对豆包执行器提交一次，任务状态能恢复并最终回填。
7. 没有有效凭证或外部服务不可用时，验收结论必须写明“配置/上游不可用”，不能把接口返回、构建成功或按钮可点击说成生成成功。
