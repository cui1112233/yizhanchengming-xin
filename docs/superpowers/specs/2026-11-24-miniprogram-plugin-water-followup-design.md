# 插件实测补充与水货生成范围

沿用已批准的逐功能对齐、紧凑手机排版。此次只影响插件三视图预览、水货配音和整部视频操作及相应合同测试。

实测：/api/presets/resolve 只返回元数据，不提供body。不能假设读到系统模板正文，也不能在小程序硬编码。增加后端POST /api/plugins/character-turnaround/prompt，按已发布、shuihuo-production模块、character-sheet槽位严格校验模板，将角色描述与后端模板组装成prompt；不调用AI、不创建项目。线上未更新此接口时，页面提示需服务端更新，仍保留用户自行填写最终要求，不能冒充模板已成功加载。

水货分镜配音独立按钮，使用服务端实际默认音色/参数，手机不显示无效模型选择。整部视频独立作品级入口，说明覆盖全部分镜并使用作品已保存的视频配置；提交requestId用于服务端幂等。都须明确费用确认，同步锁防连点、未知结果不自动再发。配音无幂等能力，未知时仅能核对任务。请求成功必须有真实task/job凭据，后续读取失败不能误显示为未提交。保留真实任务状态、无伪造百分比。

方案取舍：不将现有解析目录改成泄漏提示词正文的通用接口，不复用前端硬编码模板，不把整部视频伪装成分镜生成。后端新接口本地测试，线上部署仍待单独授权。手机构建更新不等于线上服务已更新。

实施：先写失败合同测试，再实现专用组装接口和手机调用；水货分离audio/video客户端和按钮，补连点、取消、未知结果测试；构建、样式清理、完整测试、原生只读验收并提交明确文件。
