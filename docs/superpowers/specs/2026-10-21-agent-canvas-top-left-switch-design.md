# Agent Canvas 左上角项目与视图入口

## 目标

把 Agent Canvas 现在占空间较大的“工作流 / 故事板”切换入口，收拢为画布左上角的一条紧凑工具条。布局参考用户提供的界面，但使用项目自己的图标和组件，不复制对方的网站资源。

## 左上角排列

从左到右固定为：

1. 一战晟铭品牌 Logo 按钮。
2. 当前项目名称选择器。
3. 当前副本名称选择器。
4. 工作流图标按钮。
5. 故事板图标按钮。

该工具条位于画布左上方，不覆盖节点编辑区，不新增第二行大标题或大尺寸标签。

## Logo 菜单

点击品牌 Logo 打开项目导航菜单，依次包含：

1. 回到主页。
2. 全部项目。
3. 创建新项目。
4. 删除项目。

“删除项目”保留现有数据处理方式，但必须先弹出确认提示；取消不做任何修改。

## 视图切换

工作流和故事板使用两个同尺寸的方形图标按钮。当前视图只通过低对比度底色和描边表示选中；鼠标悬停或键盘聚焦时显示“工作流”或“故事板”提示文字。按钮切换继续使用当前 URL 视图状态，保留刷新、后退、分享链接与原有工作流/故事板内容。

## 样式与适配

- 复用现有深色画布颜色、边框和圆角，不引入高饱和新颜色。
- 使用项目现有品牌 Logo 文件与现有图标库的通用线框图标。
- 工具条内容过长时，项目/副本名称优先省略，Logo 和两个视图按钮始终可点击。
- 小屏幕下不横向溢出；必要时隐藏副本完整文字，但保留可点击选择器与可访问名称。

## 验收

- 工作流和故事板都可从左上角切换，且 URL 的 `view` 参数正确更新。
- Logo 菜单四项均可见；删除动作先要求确认。
- 项目和副本选择不受影响。
- 桌面与小屏均不遮挡画布主要内容，也没有横向出界。
- 通过前端构建，并在本地 `http://localhost:4001` 的已登录页面实际点击验证。
