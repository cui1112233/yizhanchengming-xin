# AI-CUT 文字、字幕、特效与转场设计规格

## 目标

在现有 AI-CUT 编辑器中交付第一批可操作、可保存、可预览、可导出的文字、字幕、特效和转场；复用已经存在的 ASR 任务链，不再增加只有展示卡片而没有实际结果的入口。

## 产品原则

- 卡片只有在能够加入时间线并产生真实结果时才显示为可用。
- 前端预览与后端导出读取同一套效果编号、时间和参数。
- 深色、浅色及其他主题中的弹窗、下拉框和提示框必须跟随编辑器主题。
- 系统预设和提示词由 Go 后端管理，前端不得保存真实密钥或硬编码系统提示词。
- 素材和识别输入采用流式读取；不把完整视频长期保存在服务内存中。

## 第一批能力

### 转场

交叉溶解、淡入淡出、黑场、白闪、左右推拉、上下推拉、缩放、模糊。转场只允许放在同一视频轨道中两个相邻片段的连接处，支持持续时间、替换和删除。

### 特效

模糊、黑白、暖色、冷色、暗角、发光、镜头抖动、呼吸缩放、闪烁、全画面马赛克。特效可调整强度、速度和持续时间；第一阶段允许把参数保存到视频片段，后续再扩展独立特效轨。

### 文字

普通文字、标题、副标题、描边、阴影、背景框、渐变、竖排。支持字体、字号、颜色、对齐、字距、位置、旋转、透明度、描边、阴影和背景；播放器可直接拖动定位。

### 字幕

支持手动创建、SRT 导入导出、查找替换、纠错、合并、拆分、调整时间和批量样式。首批样式为经典白字黑边、黄色强调、白字半透明底、短剧大字、上下双色、逐字高亮；首批动画为淡入淡出、弹入、上浮、打字机、逐字高亮。

### 识别字幕

复用现有 `backend/internal/aicut` ASR 服务：从项目音频或视频创建任务，MySQL 持久化状态，Redis 唤醒执行器，调用已启用的 OpenAI 兼容 ASR 模型，返回带时间戳字幕。界面必须展示排队、运行、取消、成功和失败；成功结果写入新字幕轨，不能静默覆盖现有字幕。

## 数据规则

- 时间统一使用整数毫秒。
- 每种效果使用稳定 ID，不使用中文显示名作为持久化键。
- 转场保存于目标视频片段，包含 `transition` 与 `transitionMs`。
- 视觉效果保存于视频片段的 `visualEffect`，所有数值由前后端共同限制范围。
- 字幕样式保存于字幕轨设置；单条字幕保存文本、开始时间和持续时间。
- ASR 重复提交按项目、素材和运行状态拦截；取消后不得写入半成品字幕。

## 失败与边界

- 无媒体时识别字幕提示先导入视频或音频。
- 无 ASR 模型时提供前往 API 配置的入口。
- 转场没有两个相邻片段时拒绝添加并说明原因。
- 锁定轨道不允许修改。
- 参数非法时前端即时纠正，后端仍进行最终校验。
- 工程版本冲突时保留用户当前内容并要求刷新或重试，不覆盖较新版本。
- 导出不支持的效果不能静默忽略，任务应失败并指出具体效果。

## 验收

每个显示为可用的功能都必须通过添加、修改、撤销、重做、复制、删除、刷新持久化、播放器预览和成品导出检查。还要覆盖空值、重复操作、错误位置、模型缺失、任务失败与用户取消。未完成整条链路的功能显示为开发中或不展示。
