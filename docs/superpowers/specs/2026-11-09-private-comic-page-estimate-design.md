# 私人定制漫画预计张数设计

## 目标

在“私人定制 → 漫画生成”的正文输入区实时显示预计漫画张数，让用户粘贴正文后、生成前就能判断工作量。

## 展示规则

- 正文为空时不显示预计张数，保留现有“尚未读取”。
- 正文存在时显示：`已读取 N 字 · 预计约 X～Y 张`。
- 预计范围与批量工厂使用同一规则：每张目标 90～120 字，最多 35 张。
- 分镜已经生成后，创作画布顶部继续以服务端返回的真实页数为准；预计值不覆盖真实页数。
- 预计只是本地即时计算，不请求接口、不调用 AI、不要求先提取资产，也不产生费用。

## 实现边界

- 复用现有 `comicEstimatedPageRange` 计算函数，不在私人定制页面复制第二套公式。
- 只调整私人定制漫画输入区的展示，不改变资产提取、分镜生成、生图、发布和重试逻辑。
- 保留完整句子和段落边界的后端分页逻辑，因此最终真实张数可以在预计范围附近小幅变化。

## 验收标准

- 输入 2000 字时显示 `预计约 17～23 张`。
- 清空正文后预计张数消失。
- 已生成分镜时仍显示服务端真实页数。
- 前端相关测试和生产构建通过。
- Go 嵌入式前端重新打包，本地 4001 运行版本与最新本地提交一致。
