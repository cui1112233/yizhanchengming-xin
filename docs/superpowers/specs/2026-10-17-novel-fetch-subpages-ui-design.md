# 小说获取子页面 UI 整理设计

## 目标

整理小说获取工作台中的任务、知识库、配置、提交与记录页面，让用户能快速找到返回入口、当前页面的主要操作和低频操作，同时保持现有数据与业务接口不变。

本次只修改用户前台的 React + Antd 页面和配套样式，不修改 Go 接口、数据库结构、队列、Redis 或 TOS。

## 现状问题

- 任务页把视图切换、日期筛选、选择、重试、改文、规则、提交、入厂和删除混在两排按钮中。
- 知识库页缺少返回处理页入口，并把知识库编辑和处理规则完整堆在同一长页面。
- 配置页重复显示“配置”标题，四组配置默认全部展开，常用配置和低频配置没有层级。
- 提交页缺少返回处理页入口，并把提交操作、当次结果、历史记录和操作日志连续堆叠。
- 处理页右侧按钮在窄栏中存在裁切，长文字按钮没有稳定的响应式布局。

## 总体结构

除处理页以外，四个入口统一使用子页面壳：

1. 左侧为带箭头图标的“返回处理页”按钮。
2. 中间显示页面标题和一句简短说明。
3. 右侧只放当前页面最常用的主要操作。
4. 页面内容按任务流程分区，不再用一整排按钮表达所有功能。
5. URL 继续使用现有 `?tab=` 参数，刷新后仍停留在当前页面。

处理页保留三个快捷入口：知识库、配置、提交与记录。右侧四个批次操作改为稳定的两列布局；窄屏时变为单列，不能横向裁切。

## 任务页

### 页面头部

- 标题：任务
- 说明：查看、筛选和批量处理小说任务
- 右侧主要操作：刷新

### 内容分区

- 使用页内标签切换“当前任务”和“历史批次”。
- 日期筛选独立为一行，包含前一天、日期、今天、后一天和恢复默认视图。
- 选中任务后显示批量操作条；未选中时不展示无效的批量按钮堆。
- 常用批量操作直接显示：重试、生成 AI 改文、敏感词修复、规则处理。
- 跨系统操作集中到“提交与流转”：提交、重新提交、进入批量工厂。
- 删除选中、删除失败、删除全部放进“更多操作”的危险区，并保留二次确认。
- 表格行操作保留“详情”为主要操作，重新抓取和恢复原文放进更多菜单。

### 状态规则

- 没有选中任务时，依赖选择的操作禁用或隐藏。
- 批量 AI 数量和规则作用范围与对应操作放在一起。
- 当前显示数量、已选数量和日期范围放在表格上方，避免混入按钮区。

## 知识库页

### 页面头部

- 标题：知识库
- 说明：维护改文参考资料和自动处理规则
- 左上始终显示返回处理页按钮。

### 页内标签

- “资料库”：知识库提示词、统计、资料列表和条目编辑。
- “处理规则”：现有处理规则编辑器完整迁入，业务逻辑不变。

### 资料库布局

- 顶部用紧凑统计条显示各类资料数量。
- 知识库使用提示词放入可折叠的“使用说明”区域，默认收起。
- 主区域保持左侧资料列表、右侧条目编辑。
- 左侧顶部包含资料库类型切换和搜索；新增为主要按钮，复制和删除为次要操作。
- 爆款开头拆解只在选择“爆款开头”时显示，并作为单独分区放在主编辑区下方。

### 数据保护

- 继续使用现有知识库加载、选择和保存方法。
- 加载失败或返回空数据时不自动保存，不用空值覆盖账户已有知识库。
- 本次不改变任何知识库字段结构。

## 配置页

### 页面头部

- 标题：配置
- 说明：设置抓取、改文、模型与提交方式
- 右侧主要操作：保存配置

### 页内标签

- “基础流程”：抓取与工作流开关。
- “AI 参数”：模型请求参数和额外 JSON。
- “提交配置”：版本对应配置档和同步操作。
- “平台目录”：平台与风格 JSON，标明为高级配置。

进入页面默认打开“基础流程”，不再同时展开全部配置。移除内容区域重复的“配置”标题。测试文本模型放在 AI 参数页，目录编辑与普通用户常用配置分开。

保存仍调用现有保存方法；切换页内标签不能清空尚未保存的表单值。

## 提交与记录页

### 页面头部

- 标题：提交与记录
- 说明：检查提交条件、执行提交并查看结果
- 左上始终显示返回处理页按钮。

### 页内标签

- “提交准备”：环境检测、同步、组织归属、最少字数、失败重试和提交预览。
- “本次结果”：只展示当前提交产生的结果和失败重试入口。
- “提交历史”：历史记录、状态和刷新操作。
- “操作日志”：按任务查看日志或查看全局记录。

“开始自动提交”仍需确认，并且只有选择任务后才可用。页面初次进入不触发真实提交。

## 视觉与响应式规则

- 延续当前小说获取工作台的深色风格和 Antd 控件，不新造另一套配色。
- 页面标题、说明、主要操作保持固定层级。
- 内容区不使用卡片套卡片；统计条、工具栏和表格使用清晰分隔。
- 桌面端工具栏允许换行但保持分组；手机端每组改为单列或菜单。
- 表格允许自身横向滚动，页面整体不能产生横向滚动。
- 所有文字按钮必须完整显示，不能出现截图中的按钮裁切。

## 高级交互

高级动效只用于能提升选择效率的区域，不在任务表格、提交历史或操作日志中使用形变。

### 知识库圆柱滚动

- 知识库资料列表在桌面端使用圆柱滚动效果。
- 列表项根据自身中心点与列表视区中心点的距离，连续计算旋转角度、缩放、亮度和透明度。
- 中心项保持正面、原始字号和最高亮度；越靠近上下边缘，旋转和缩小越明显，并逐渐淡出。
- 旋转角度限制在正负 48 度以内，缩放最低不小于 0.78，透明度最低保留 0.18，避免条目完全不可辨认。
- 支持鼠标滚轮、触控滚动、点击条目和键盘上下键；停止滚动后自动吸附到最近条目。
- 中心项成为当前选择后更新右侧编辑器。切换前必须保留当前条目的本地草稿，不能因滚动丢失未保存内容。
- 圆柱效果只改变视觉呈现，不改变条目的 DOM 顺序、搜索结果顺序和接口数据。
- 使用 `requestAnimationFrame` 合并滚动计算，避免每次滚动事件直接触发大量页面更新。

### 动效边界

- 页面切换、页内标签、按钮悬停和批量操作条使用 160 至 220 毫秒的短过渡。
- 危险操作确认、表格行、日志正文和长文本编辑区保持稳定，不使用位移或 3D 动画。
- 窄屏下圆柱列表退化为吸附式平面列表，确保触控选择准确。
- 用户系统启用“减少动态效果”时，关闭旋转、缩放和自动平滑滚动，只保留中心高亮。
- 动画过程中不得改变页面整体宽高，不得造成表格、标题或操作按钮跳动。

## 验收范围

- 验证四个入口都能进入并返回处理页。
- 验证 `?tab=tasks`、`?tab=knowledge`、`?tab=config`、`?tab=submit` 刷新后仍显示正确页面。
- 验证页内标签切换不会丢失已加载数据或未保存表单内容。
- 验证任务选择会正确控制批量操作状态。
- 验证知识库空态不会触发保存或覆盖。
- 验证圆柱列表滚轮、点击、键盘选择和中心吸附正常，切换条目不会丢失未保存草稿。
- 验证窄屏和“减少动态效果”模式使用稳定的平面列表。
- 验证提交按钮在未选任务时禁用，且不会在页面加载时自动提交。
- 在桌面和窄屏尺寸检查按钮、表格、标题和返回入口没有重叠或裁切。
- 运行前端相关测试、生产构建，并通过 Go embed 本地服务重新检查页面。

## 不在本次范围

- 不新增或修改后端接口。
- 不修改 MySQL、Redis、队列或 TOS。
- 不执行真实视频管理系统提交。
- 不删除真实任务、知识库数据或配置。
- 不发布公网。
