# 漫剧制作：内容入口、解析程度与画风选择

状态：待用户确认。范围为 /comic-screenplay 的新建窗口、项目设置及画风向后续生成的传递，不包含付费生成或公开部署。

## 当前核查

- 新建 submitCreate 强制 sourceFile，作品内原文编辑区虽可粘贴，新建时却无法直接输入。文件在创建项目后才解析，解析失败可能留下空项目。
- 解析程度已有 master/master_real/more_diff/standard 四档，但细胶囊选中状态与背景接近。
- 当前画风是前端六个固定名称加渐变预览；项目保存 ArtStyle/StyleDesc/SelectedStyle，分镜会读项目风格。资产链路仍需逐项验证。
- 洛水本机发行包中可见所选画风包含名称及缩略展示、可清除选择，生成配置携带风格描述。既有证据报告记录四档解析程度。未复制其专有素材、提示词或私有服务。

## 推荐方案

1. 新建窗口提供“直接输入 / 上传文件”，默认直接输入。输入区支持粘贴小说正文、已有剧本和大纲，显示字数；文件仅接受 TXT/DOCX，先解析为可预览、可编辑的内容，再提交创建。两种入口最终保存同一份原文，提交校验当前内容，避免隐藏文件覆盖输入。
2. 四档解析改为响应式选择卡片，含档位名、实际解析范围、选中勾和明确边框，键盘可操作。说明以真实后端行为为准：大师两档处理人物/场景/道具，差异化及标准档的人物处理范围须检查，不凭视觉杜撰差异。
3. 画风采用图片预览卡、名称、当前选择、重新选择和清除操作；优先复用本系统后端管理的画风预设，按能力筛选可用于漫剧的项目。空库和图片失败展示明确状态，不拿渐变色充当画风效果图。画风描述由后端预设解析，前端不硬编码系统提示词。
4. 画风名称、预设标识与后端生成所需描述持久保存；验证资产解析与分镜实际请求读取同一画风。历史仅保存名称的项目继续正确显示，不能静默替换为另一画风；预设失效给出重新选择提示。

## 其他方案与取舍

- 只补输入并提高按钮对比度：改动小，画风仍是六个名称，无法满足本次完整需求。
- 新建独立漫剧画风管理库：可完全定制，但重复维护现有预设，范围更大。本次优先统一现有库，必要时只补漫剧适用范围。

## 验收

- 不上传文件，填写名称、原文及必要配置即可创建，刷新后原文一致；空白内容不能提交。
- 上传 TXT/DOCX 后可查看、修改内容；读取失败不创建空项目。
- 深浅主题下四档选中状态清楚，刷新后档位保留。
- 画风展示真实可用预设，选择持久化并进入资产/分镜请求；缺图、空库、失效预设有明确反馈。
- 运行相关前后端测试、构建 Go embed 并在本地 4001 真实页面核验。不调用付费模型；如需实际生成须另行确认预算。
