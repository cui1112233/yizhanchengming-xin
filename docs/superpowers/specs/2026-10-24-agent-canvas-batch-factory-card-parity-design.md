# Agent 画布与批量工厂卡片一致化设计

日期：2026-10-24

## 目标

让批量工厂作品进入 Agent 画布后，画布中的剧本、图片、视频、音频和最终合成卡可以完成当前批量工厂已经支持的同一条生产链。画布与批量工厂不是两份数据，也不是跳转关系；它们读写同一本书、同一组素材、同一批生产记录和同一份发布状态。

本阶段只接入已经存在且能实际执行的功能。尚未具备后端执行链路的“查资料”和漫画提取、漫画生成不显示为可执行菜单项。

## 范围

### 本阶段包含

- 小说前贴剧本对应的批量工厂书籍投影到画布。
- 剧本卡：编辑正文、保存生产行数、选择文本模型和提示词模板、提取图片资产、生成视频分镜、生成爆款候选、采用爆款候选。
- 图片卡：编辑资产资料与图片提示词、选择图片模型和画幅、生成图片、选择主图。
- 视频卡：编辑视频提示词、选择视频模型和时长、使用已连线图片作为引用、生成或重试视频、查看实际输入。
- 音频卡：生成配音并同步真实时长。
- 最终合成卡：合成或重新合成、选择视频管理系统组织、上传最终视频、显示上传状态。
- 所有成功或失败后的状态同步回批量工厂和当前画布。

### 本阶段不包含

- 正常剧本模式的资料检索功能。
- 漫画分镜提取和漫画图片生成。
- 新的模型、提示词、资产或发布后端接口。
- 在画布内复制一份批量工厂数据。

## 卡片结构

每类投影卡使用用户确认的紧凑创作框骨架，视觉结构与参考图一致，而不是传统的“标题栏 + 多段表单 + 一排操作按钮”。

1. 卡片本体不再单独显示标题栏、素材预览区或说明文字；画布上的节点类型和连线已经说明它是什么。
2. 顶部是一排紧凑功能入口。只出现该卡已经具备的真实操作；“更多”点击后展开菜单，按钮本身不显示下拉箭头。
3. 中间是可编辑的剧本正文、图片提示词、视频提示词、音频文字，或最终合成的当前状态。
4. 底部是一行紧凑选择项和执行按钮：模型、画幅、时长、音色、生产行数或组织归属按卡片类型出现。最右侧是该卡的主执行按钮。
5. 不显示固定的版本号、积分、费用、模式或功能图标，除非当前项目已有对应真实数据和动作。

## 顶部操作对应表

| 卡片 | 直接显示 | 收进更多 |
| --- | --- | --- |
| 剧本 | 选择提示词、提取图片资产、生成视频分镜、生成爆款候选 | 保存生产行数、采用爆款候选、失败信息 |
| 图片 | 添加参考素材、选择提示词 | 选择主图、重新生成、查看实际输入、失败信息 |
| 视频 | 添加参考素材、选择提示词 | 查看实际输入、失败后重试、失败信息 |
| 音频 | 选择提示词 | 失败后重试、状态信息 |
| 最终合成 | 选择视频管理系统组织 | 重新合成、上传状态和失败信息 |

图片和视频节点的连线素材会自动作为参考素材使用；画布中不存在另一个“图生视频模式”开关。菜单只在点击后展开，且只显示当前卡已经实际支持的操作。失败前不显示“重试”。没有后端动作的选项不出现。

## 五种卡片的底部内容

| 卡片 | 底部选择项 | 主执行 |
| --- | --- | --- |
| 剧本 | 文本模型、生产行数 | 执行当前剧本动作 |
| 图片 | 执行器、图片模型、画幅 | 生成图片 |
| 视频 | 执行器、视频模型、画幅、时长 | 生成视频 |
| 音频 | 音频模型、音色、语速 | 生成音频 |
| 最终合成 | 视频管理系统组织归属、当前合成状态 | 合成最终视频 |

## 数据与同步

1. 画布投影节点继续保存 `batchId`、`bookId`、`resourceType`、`resourceId` 和版本号。
2. 卡片操作优先调用现有批量工厂接口，例如书籍覆盖保存、资产图片生成、视频生产、配音计划、合成与发布。
3. 操作返回后调用已有书籍同步接口，重新投影该书的节点、连线、素材、任务状态和发布状态。
4. 画布不保存重复的视频、图片或音频副本；节点仅引用同一本书的已有资源。
5. 失败不禁用后续入口。卡片显示失败状态、原有重试能力和实际失败步骤信息。

## 验收

- 从批量工厂进入一本书的 Agent 画布，五类投影卡都能看到。
- 每张卡只显示该卡可执行的真实操作；不存在的功能没有入口。
- 在画布生成图片、视频、音频或最终合成后，回到批量工厂能看到同一结果和状态。
- 在批量工厂修改提示词、模型、主图或发布状态后，刷新画布能看到同一状态。
- 选择模型、行数、提示词模板、比例或时长后，执行请求使用这些选择。
- 单元测试覆盖菜单操作映射、配置保存和同步；本地嵌入 Go 运行时构建通过，并在浏览器中检查实际卡片。

## 后续阶段

完成本阶段后，单独设计正常剧本模式的资料检索，以及漫画分镜和漫画图片的执行链路。只有后端、状态、结果保存和同步规则确定后，才将它们加入相应卡片菜单。
