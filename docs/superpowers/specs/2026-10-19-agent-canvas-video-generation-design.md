# Agent 画布视频生成闭环设计

日期：2026-10-19  
状态：待用户审阅  
范围：本机 V88，不发布公网。

## 1. 目标

在现有 Agent 画布中，交付真实可追踪的视频生成能力，而不是只增加视频节点样式。

用户可以把项目素材库中的图片放到画布，连接到视频节点；选中视频节点后填写提示词和参数并点击生成。系统创建一条属于当前 Agent 项目的任务，调用现有 Go 视频生成能力，持续显示任务进度。结果生成后先保存为项目素材，用户确认后再把该视频写回画布节点。

## 2. 不做的内容

- 不复制沈浪的品牌、源码、账号、收费、云同步或远端服务。
- 不改已有 MySQL 执行迁移；若存储结构不足，只新增编号更高的追加迁移。
- 不把视频任务塞进浏览器本地状态，也不让浏览器直接持有模型密钥。
- 不发布公网。
- 第一段不做批量生成、音频合成、上传平台或素材回收站。

## 3. 已有能力与采用方式

现有 Agent 画布已经保存节点、连线、节点参数、项目素材和 `agent_executions` 执行记录。现有 Go 路由 `/api/script-video` 已能提交、查询和下载视频任务，支持已配置的视频模型，并会明确告诉前端某个模型是否不支持参考图。

本设计不让 Agent 画布前端直接调用这条兼容路由。新增 Agent 专用的 Go 服务和 API，由它复用同一套视频提供方/本地执行器能力，同时把任务、参数快照、节点关联和保存结果持久化到 Agent 项目范围内。

## 4. 用户界面

### 4.1 图片节点

- 图片节点显示私有素材缩略图、名称和状态。
- 对没有素材的图片节点，保留现有“从素材库添加图片”和上传入口。
- 只有已确认并且能取到图片内容的图片节点，才能作为视频节点的参考图。

### 4.2 视频节点

- 节点显示大预览区；未生成时显示待生成状态，运行时显示进度，成功时显示视频预览。
- 左侧输入端口接收图片或文本节点，右侧输出端口供后续节点使用。
- 一个视频节点只能有一个当前有效任务；运行中的节点不能重复提交。
- 失败节点显示失败原因和“重试”；可取消任务显示“取消”。

### 4.3 选中视频节点后的参数面板

显示并保存以下参数：

- 视频提示词；
- 参考图列表，由所有直接连接到该视频节点的图片节点按连线顺序生成；
- 视频模型，默认使用当前账号已配置且可用的模型；
- 比例、清晰度、时长；
- 参考方式（自动、首帧、首尾帧）。

点击“生成”时，前端只调用 Agent 专用 API。若所选模型不支持参考图，界面必须先明确询问用户是否去掉参考图继续，不能静默丢掉参考图。

## 5. 后端和数据流

### 5.1 任务状态

Agent 视频任务的状态为：

`draft -> preparing -> queued -> running -> result_ready -> awaiting_confirmation -> applied`

异常/结束状态为：`failed`、`canceled`、`abandoned`。

状态含义：

- `preparing`：校验节点、引用素材和模型参数；
- `queued`/`running`：已提交给现有视频提供方或本地执行器；
- `result_ready`：上游已成功，正在保存结果；
- `awaiting_confirmation`：结果已作为 Agent 项目素材落库，可播放，但尚未覆盖视频节点；
- `applied`：用户确认后，视频节点引用新素材并保存新版本；
- `failed`/`canceled`/`abandoned`：保留原因和操作记录，供界面恢复或重试。

### 5.2 提交与查询

新增受现有登录保护的 Agent API：

- `POST /api/agent/tasks/{id}/video-jobs`：校验当前项目、视频节点、图片引用、参数和幂等键后创建任务；
- `GET /api/agent/tasks/{id}/video-jobs/{jobID}`：返回当前状态和可显示的结果；
- `POST /api/agent/tasks/{id}/video-jobs/{jobID}/confirm`：确认把已保存的视频素材回填该节点；
- `POST /api/agent/tasks/{id}/video-jobs/{jobID}/cancel`：按上游能力取消尚未完成的任务；
- `POST /api/agent/tasks/{id}/video-jobs/{jobID}/retry`：只允许失败或异常结束的任务以新幂等键重试。

所有 API 都必须按当前账号和当前 Agent 项目核对归属。任务读取、节点更新和确认回填必须拒绝跨项目、跨账号或旧节点版本的写入。

远端模型不能直接读取浏览器使用的私有素材接口。提交前由 Go 对每个已确认的图片素材生成短时有效的 TOS 读取地址，仅把该地址传给支持参考图的模型；前端不会收到存储密钥，画布仍继续使用项目私有素材接口预览。

### 5.3 执行与结果保存

1. 创建任务时保存参数快照、引用图片素材 ID、视频节点 ID 与节点版本。
2. Go 服务为远端模型生成短时有效的参考图读取地址，并提交到现有视频提供方/本地执行器；Redis 只承担排队、短时进度和锁，不作为事实记录。
3. Worker/轮询取得成功结果后，先下载或接收视频并保存为当前 Agent 项目的私有视频素材。
4. 保存成功后，把任务改为 `awaiting_confirmation`，前端可预览该素材。
5. 用户点击确认时，检查目标节点仍属于该项目且版本未被其他操作替换；通过后写入新 `assetRef`、状态和节点版本，并将任务设为 `applied`。
6. 刷新页面时，前端读取项目任务列表并继续显示运行中、待确认和失败任务；不会丢失结果，也不会自动覆盖节点。

## 6. 数据存储

新增 Agent 视频任务表及必要索引，保存：任务 ID、项目 ID、账号、节点 ID、提交时节点版本、状态、上游任务 ID、模型/参数快照、引用素材列表、结果素材 ID、错误信息、幂等键、创建/更新时间。

`agent_executions` 保留为面向用户的执行日志；视频任务表是可恢复的业务事实。节点内容继续由现有画布存储保存；确认时使用当前画布版本校验，避免覆盖用户在任务运行期间的手动编辑。

## 7. 失败处理

- 参数不完整、图片不可读、模型未配置：提交前直接返回明确错误，不创建假成功任务。
- 不支持参考图：保留任务草稿，要求用户明确选择“无参考图继续”或返回修改模型。
- 上游失败：记录错误，节点标记失败，可从同一参数快照重试。
- 结果下载/保存失败：任务保留 `result_ready` 或失败原因，允许重试保存，不丢弃上游成功结果。
- 取消：只取消未完成任务；已经保存为素材的结果不自动删除。
- 确认冲突：节点版本不一致时不覆盖，提示用户选择重新生成或手动替换。

## 8. 测试与验收

后端测试覆盖：

1. 当前账号/项目校验和跨项目拒绝；
2. 节点类型、参考素材、模型参数与幂等键校验；
3. 提交、轮询、成功结果保存、确认回填、取消、失败重试；
4. 节点版本冲突不覆盖；
5. MySQL 迁移在新库可执行，并在已有数据库上可重复安全执行。

前端测试覆盖：

1. 图片节点和视频节点的正确预览与状态；
2. 参考图从直接连线读取；
3. 不支持参考图时显示明确确认；
4. 生成、取消、重试、确认回填的按钮状态；
5. 刷新后恢复任务状态和待确认结果。

本机验收：创建一个 Agent 项目，上传图片，连接图片到视频节点，提交一次可用模型任务；确认任务记录出现、状态可刷新恢复、成功视频先进入项目素材，再由确认操作回填视频节点。没有配置可用模型时，必须可见明确的配置错误，不能假装成功。
