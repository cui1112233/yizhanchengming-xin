# 微信小程序九功能视觉系统设计

## 目标

以线上 `https://yzcm.site/` 当前主导航为唯一功能清单，重做小程序功能首页的功能卡与插画体系。解决四个问题：功能漏项、功能名称错配、插画模糊、图标主体大小不一致。

本轮先完成九张高清功能插画及其预览验收，再把验收通过的插画接入小程序首页。不得为了主包体积在用户验收前压缩高清原图。

## 唯一功能清单

首页严格保留以下九项，不增加“会员与工具”，也不把多个线上功能合并为一个入口。

### 内容创作

1. 私人定制
2. 小说创作
3. 批量测书

### 生产成片

4. 水货生产
5. 漫剧创作
6. AI-CUT

### AI 与工具

7. CM 画布
8. 配音
9. 插件

`CM 画布` 与 `AI-CUT` 是两个独立功能。现有小程序把 Agent/CM 画布标成 AI-CUT 的错配必须在接入阶段修正。

## 首页布局

采用三组 `3 + 3 + 3`，每组均使用“一张主卡 + 两张小卡”的结构，延续参考图的信息层级，不改成九宫格。

- 内容创作：私人定制为主卡；小说创作、批量测书为小卡。
- 生产成片：漫剧创作为主卡；水货生产、AI-CUT 为小卡。
- AI 与工具：CM 画布为主卡；配音、插件为小卡。
- 底部导航保持产品已经确认的顺序：功能、工作台、任务、我的。
- 底部安全区必须使用不透明深色背景，页面内容不能从 Home Indicator 区域漏出。

## 九张插画的语义

1. 私人定制：打开的魔法书、羽毛笔、青色 AI 晶体。
2. 小说创作：紫蓝色故事书、星光书签、灵感星星。
3. 批量测书：三本叠放书籍、扫描光环、数据勾选标记。
4. 水货生产：发光场记板、播放键、批量生产光轨。
5. 漫剧创作：弧形胶片、动漫画面、播放按钮。
6. AI-CUT：智能剪刀、时间轴胶片、自动剪辑光点。
7. CM 画布：友好 AI 机器人、悬浮流程卡片、节点连接线。
8. 配音：发光麦克风、声波、音符与录音光环。
9. 插件：三块可拼接的立体模块、连接端口、工具星光。

九张图不得共用同一主体，不使用文字、英文字母、Logo、emoji 或 UI 截图作为图标内容。

## 插画统一规格

- 风格：精致可爱的 3D 建模插画，深蓝底适配，青色与紫色霓虹边缘光，少量暖粉高光。
- 原图：每张 `1024 x 1024` PNG，透明背景。
- 主体安全区：主体占画布宽高的 `72%–78%`，视觉重心居中，底部基线一致。
- 视角：统一轻微俯视的三分之四视角，不混用正面扁平图和强透视图。
- 光照：左上柔光，右下青色轮廓光；阴影软、短、方向一致。
- 边缘：保留透明抗锯齿，不带黑边、白边或大面积透明空白。
- 交付：保留九张高清 PNG；另生成一张 `3 x 3` 对照总览图，用于检查主体比例和风格一致性。
- 小程序版本：高清图通过验收后再单独导出适配尺寸，不覆盖高清原图。

## 字体与卡片尺寸

以 390px 宽手机为基准，整体不再使用上一版偏大的字号。

- 页面主标题：`26–28px`，单行。
- 页面副标题：`10–11px`。
- 分区标题：`19–20px`。
- 主卡标题：`18–19px`。
- 小卡标题：`12–13px`。
- 描述文字：`9–10px`。
- 主卡插画可视宽度：卡片宽度的 `58%–64%`。
- 小卡插画：统一 `40–44px` 可视盒，不按图片原始空白自动缩放。
- 卡片圆角：主卡 `20–22px`，小卡 `16–18px`。
- 底部导航内容高度：`44–48px`，再加系统安全区；图标 `19–21px`，文字 `9–10px`。

## 清晰度与主包策略

- 高清验收图不受微信主包限制影响，先以视觉质量为准。
- 接入小程序时，九张图统一从高清源导出，不对已经压缩过的图片再次压缩。
- 若九张适配图导致主包超过 2 MiB，优先使用线上静态资源/CDN或调整分包归属，不把图片压到肉眼发糊。
- 首页首屏关键插画必须有本地兜底，资源加载失败时不能出现空卡。

## 路由边界

本轮生图阶段不改功能页面和后端接口。接入阶段需要单独核对九项功能的真实移动端路由：

- 已存在的功能直接使用真实页面。
- 线上存在但小程序尚无移动端页面的功能，不得偷偷跳到错误页面，也不得用“会员与工具”代替。
- 缺少真实页面时，入口必须明确显示“移动版正在适配”，直到对应页面完成。

## 验收标准

### 插画验收

- 九项功能一项不少、一项不重。
- 九张图在 `3 x 3` 总览里主体大小差异不超过约 `8%`。
- 统一视角、光照、材质、描边和阴影。
- 放大查看清晰，无明显 JPEG 方块、锯齿或透明杂边。
- 用户确认九张高清图后，才进入小程序适配和压缩阶段。

### 页面验收

- 首页功能名称和线上九项一一对应。
- 三个分组完整展示，滚动后可看到全部九项。
- 字号、图标和卡片占比符合本规范。
- 底栏不遮挡内容，安全区不漏出下方卡片。
- 微信开发者工具无黑屏、资源加载错误或页面报错。
