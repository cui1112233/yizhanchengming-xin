# 批量工厂漫画媒体工作台布局设计

## 目标

把批量工厂现有漫画媒体弹窗重组为清晰的左右工作台：左侧只展示当前主漫画，右侧集中作品名称、漫画页与漫画合集切换、候选图、本页参考图、画面内容和生成操作。

本次只调整前端布局与交互层级，不新增后端接口，不改变漫画页、候选图、参考图、原文分段、漫画合集或发布数据。

## 总体布局

弹窗使用固定高度的左右两栏：

- 左栏约占 59%，是纯漫画展示区。
- 右栏约占 41%，是全部功能区。
- 弹窗最大宽度保持适合桌面工作台，不允许内容把弹窗继续撑高。
- 右栏分为固定标题区、固定页签、可滚动内容区和固定底部操作栏。

窄屏下改为上下排列：主漫画在上，功能区在下；功能名称和按钮不得被截断。

## 左侧主漫画展示区

左栏只显示当前漫画页主图：

- 不放作品名、页签、候选图、参考图按钮、原文或生成按钮。
- 使用深色中性背景，让竖屏漫画居中完整显示。
- 图片保持原始比例，使用 `object-fit: contain`，不得裁切漫画内容。
- 主图加载失败时显示明确的失败占位和重试入口，不能退化成空白区域。
- 当前页没有主图时显示“尚未选择主图”，并引导用户在右侧候选图中选择。

## 右侧固定标题区

标题区必须始终可见，包含：

- “媒体库”标识。
- 当前作品名称。
- 当前漫画页名称，例如“漫画页 01”。
- 图片尺寸和主图状态。
- 关闭按钮。
- 主要按钮“生成漫画合集”。

“生成漫画合集”不得藏在滚动区或二级菜单里。点击后继续调用现有合集生成逻辑，按页面顺序收集每页当前主图，不拼成长图，也不自动发布。

当漫画页不足、存在页面未选择主图或正在执行其他互斥操作时，按钮禁用并说明原因。

## 右侧页签

标题区下方固定显示两个页签：

- 漫画页：显示页面数量，默认选中。
- 漫画合集：显示已有合集数量。

切换到“漫画合集”后，右侧可滚动内容区展示现有合集列表、页数、生成时间和发布状态；左侧主漫画保持当前页面，不因切换页签突然消失。

合集生成成功后自动刷新合集数量和列表，但不自动切换页签，不自动发布。

## 漫画页功能区

### 候选图

- 四张候选图在右侧第一段横向等宽排列。
- 缩略图明显小于左侧主漫画。
- 当前主图只使用一次蓝色描边和勾选标记。
- 点击候选图继续调用现有主图选择逻辑；保存成功后左侧立即更新。
- 保存失败时保留原主图并显示错误提示，不允许界面先永久切换到失败结果。

### 本页参考图

- 候选图下方固定出现“本页参考图”。
- 明确显示“上传参考图”入口，不使用只有图标、没有文字的按钮。
- 显示当前参考图数量或“未设置”。
- 已有参考图使用小缩略图展示，支持预览和清除现有手动参考图。
- “应用到全部漫画页”保留为独立选项，并继续使用现有批量应用逻辑。
- 上传、应用到全部或清空期间显示进行中状态，其他互斥操作暂时禁用。

本页参考图只作用于当前页图片生成约束，不替代漫画全局参考图，也不改变画风库默认参考图规则。

### 画面内容

- 参考图区下方显示当前页绑定的连续小说原文段。
- 显示“第 N 段 · X 字”。
- 默认只读并限制预览高度。
- “查看完整原文”打开现有安全拆分弹窗。
- 切换漫画页时，主图、候选图、参考图和画面内容必须一起切换到同一页。

## 右侧固定底部操作栏

底部操作栏始终可见，包含：

- 上一页。
- 当前页码和总页数。
- 下一页。
- “重新生成本页”。

上一页和下一页同时切换左侧主漫画及右侧全部页面数据。“重新生成本页”只生成当前页候选图，不生成整本漫画，不生成合集，也不自动发布。

## 数据与调用关系

继续复用现有数据和操作：

- 漫画页、候选图和主图选择：现有漫画页接口。
- 本页参考图上传、应用到全部和清空：现有参考图接口。
- 画面内容和安全拆分：现有连续原文分段组件与接口。
- 重新生成本页：由页面外层把现有 `generateBookComicPage` 回调传入漫画媒体工作台，不新增后端生成接口。
- 生成漫画合集：现有 `makeCollection` 逻辑。
- 漫画合集列表和发布：现有合集数据与发布弹窗。

布局组件只接收当前页面状态和事件回调，不在组件内部重新请求同一份数据，避免弹窗内出现两套状态。

## 视觉规则

- 使用中性深色工作台，漫画画面是第一视觉重点。
- 只用蓝色表示当前选择和主要操作，绿色只表示成功或已就绪。
- 不使用大面积渐变、装饰光斑或多层卡片嵌套。
- 区块通过留白和细分隔线组织，圆角不超过 8px。
- 按钮使用清楚的图标加中文动作名称；关闭、上一页、下一页允许只显示通用图标，并提供提示。
- 候选图、按钮和状态变化不得造成整体布局跳动。

## 异常状态

- 无候选图：显示等待生成状态，参考图和原文仍可查看。
- 无主图：左侧显示占位，生成合集按钮禁用并说明缺少主图的页数。
- 图片读取失败：失败的缩略图保留位置和名称，支持重新读取。
- 参考图上传失败：保留已有参考图，不清空原状态。
- 合集生成失败：保留已有合集和当前页面，不自动重试或发布。
- 页面数据版本冲突：提示刷新漫画页数据，不覆盖较新的主图或参考图。

## 验收标准

- 左侧从顶部到底部只显示当前主漫画，没有作品名、页签或操作按钮。
- 作品名称、当前页名称和状态全部位于右侧标题区。
- “上传参考图”“漫画合集”“生成漫画合集”打开弹窗即可看见，不需要滚动或进入二级菜单。
- 四张候选图明显小于主漫画，并在一行内稳定显示。
- 右侧内容较多时只滚动中间内容区，标题、页签和底部翻页始终可见。
- 切换页面后，主图、候选图、参考图和画面内容属于同一漫画页。
- 选择候选主图、上传参考图、应用到全部、清空参考图、重新生成本页和生成漫画合集继续调用现有链路。
- 漫画合集页签能查看现有合集并继续打开发布流程。
- 不点击任何生成按钮时，浏览器验收不消耗模型额度。
- 相关前端测试、前端构建、Go 嵌入式构建和本地浏览器检查全部通过。

## 不在本次范围

- 不修改小说连续分段算法。
- 不修改漫画提示词或系统预设词。
- 不修改图片模型、执行器或生成参数。
- 不新增漫画合集、发布或参考图后端接口。
- 不自动生成图片、合集或向漫画后台发布。
