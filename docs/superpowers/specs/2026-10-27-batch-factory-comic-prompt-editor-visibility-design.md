# 批量工厂漫画提示词编辑与开发者可见性设计

## 目标

漫画模式的“漫画提示词”弹窗把可编辑内容和系统最终编译结果明确分开：用户能修改实际参与出图的两段页面描述，但只有开发者能查看系统拼装后的完整出图提示词和参考图调试信息。

## 页面行为

- 查看状态始终显示“分格导演描述”和“本页基础出图描述”。
- 点击“编辑”后，两段内容各自变成独立编辑框，不能再用一个通用输入框替代整个漫画提示词区域。
- 保存时一次写回当前页的 `comicPrompt` 与 `comicImagePrompt`；取消编辑时两段内容都恢复到进入编辑前的值。
- 当前账号 `role === 'dev'` 时，额外显示只读的“最终完整出图提示词”和参考图调试信息。
- 普通用户既不渲染开发者区域，也不请求完整提示词预览接口。

## 权限与数据流

- 前端通过现有 `getCurrentAccount()` 获取账号角色，不硬编码账号名。
- `BatchFactoryNovelList` 保存 `isDeveloper`，并传给 `PromptPanel`。
- `PromptPanel` 仅在漫画模式、页面存在且 `isDeveloper === true` 时调用 `prompt-preview`。
- 后端 `prompt-preview` 再按同一账号资料校验 `role === 'dev'`；普通用户直接调用返回 `403`。
- 真实漫画生成链路不受这个查看权限影响，仍使用保存后的两段内容编译出图提示词。

## 错误处理

- 当前账号读取失败时按普通用户处理，不显示内部提示词。
- 开发者预览读取失败时只在开发者区域显示错误，不影响两段页面描述的编辑与保存。
- 保存任一字段失败时保持编辑状态，避免用户误以为已经保存。

## 验收

- 漫画编辑状态可同时看到并修改两个字段。
- 保存请求同时包含 `comicPrompt` 和 `comicImagePrompt`。
- 普通用户页面没有最终完整提示词区域，接口访问返回 `403`。
- 开发者页面显示完整提示词和参考图信息，接口返回 `200`。
- 视频模式原有提示词编辑行为不变。
