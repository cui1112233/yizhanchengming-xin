# Agent Canvas 统一节点编辑外壳设计

日期：2026-10-25  
状态：设计已由用户确认，等待规格审核  
范围：工作流画布中的节点顶部快捷工具条与节点下方生成编辑框

## 1. 目标

参考 Liblib 画布的浮动编辑体验，优化 V88 Agent Canvas 的节点编辑界面。只借鉴视觉层级、排版、图标表达和交互位置，所有按钮必须连接 V88 已有的真实功能。

本次设计必须做到：

- 文本、图片、视频、音频节点使用同一套编辑外壳。
- 单击节点即可显示顶部快捷工具条和底部编辑框。
- 节点本体继续随画布缩放，工具条与编辑框保持稳定的屏幕尺寸。
- 深色和浅色主题下，背景、文字、边框、悬停、禁用和状态反馈均清晰可见。
- 不新增后端接口，不改变生成任务协议，不触发真实生成任务。
- 不显示没有真实功能链路的假入口，例如积分、角色库或特效。

## 2. 视觉方向

### 2.1 顶部快捷工具条

工具条悬浮在选中节点上方，视觉参考 Liblib：

- 单行横向排列，内容宽度自适应。
- 高度约 38 像素，圆角约 7 像素。
- 使用 1 像素低对比边框、轻阴影和主题背景。
- 每项使用 Lucide 图标加短文字；下载、更多等熟悉操作可只显示图标并提供提示。
- 工具条不会放大节点，也不参与节点内容排版。
- 画布缩放时通过现有反向缩放机制保持屏幕尺寸稳定。
- 窄视口下允许横向滚动，不压缩文字或改变节点尺寸。

### 2.2 底部生成编辑框

编辑框悬浮在节点下方，使用接近 Liblib 的一体式结构，不再呈现明显分割的三张卡片：

- 默认宽度 680 像素，并受画布可视宽度约束。
- 使用一个连续背景、约 15 像素圆角、低对比边框和轻阴影。
- 顶部为当前节点可用的真实功能入口。
- 中部为宽大的提示词输入区域，不显示多余标题和计数干扰。
- 底部为单行连续工具栏：模型、参数摘要、通道与高级设置、任务状态、生成按钮。
- 右下生成按钮使用圆形箭头图标；禁用态必须仍能看清轮廓与图标。
- 生成中、失败、等待确认等状态继续使用当前持久化任务状态，不另建一套状态。
- 候选图片、候选音频、视频处理结果和错误提示仍显示在编辑框内部，并在需要时扩展高度。

## 4. 交互规则

- 单击文本、图片、视频或音频节点的非控件区域，选中节点并打开对应编辑框。
- 点击媒体播放控件、输入框、下拉框、按钮或弹出面板时，不触发节点拖动。
- 节点其他空白区域继续可以拖动，不能恢复成只能拖动左上角手柄。
- 同一时刻只显示一个活动节点编辑框；切换节点时同步切换工具和内容。
- 点击画布空白处关闭活动编辑框，但不清除节点数据。
- 已验证的视频单击打开、不放大节点、浮层保持屏幕尺寸的行为必须保留。
- 工具按钮只调用现有回调与配置更新逻辑；没有可用资源或任务繁忙时进入禁用态。
- “更多”菜单继续承载重试、取消、确认结果、上传视频管理系统等条件性操作。
- 展开编辑框只改变编辑框可见内容空间，不改变节点大小和画布缩放。

## 5. 主题与可见性

现有 `#202020`、`#242424` 等写死的编辑器背景必须改为作用域内的主题变量。

需要增加并统一使用以下语义：

- 编辑框背景
- 工具条背景
- 功能入口背景
- 默认边框和强调边框
- 主要文字、次要文字和弱提示文字
- 悬停背景
- 禁用背景与禁用文字
- 任务成功、警告和失败颜色

深浅主题都要满足：

- 输入文字和占位文字可辨认。
- 图标与背景有足够对比。
- 禁用按钮仍可识别，但不会被误认为可点击。
- 浮层与画布背景之间有明确边界。
- Ant Design 下拉框、Popover 和 Dropdown 与编辑框主题一致。

## 6. 组件边界

保留当前组件职责，避免大范围重写：

- `AgentCanvas.jsx`：节点选中、浮层挂载、顶部快捷工具回调和缩放定位。
- `AgentNodeComposer.jsx`：统一生成框结构、真实操作映射、任务状态和生成按钮。
- `AgentNodeComposerTopActions.jsx`：顶部功能入口与更多菜单。
- `AgentImageTools.jsx`：图片旋转、镜像、拆分和裁剪。
- `AgentVideoTools.jsx`：视频截取、裁剪、提取音频和抽帧。
- `AgentNodeParameterPopover.jsx`：四种节点的真实参数。
- `AgentNodeSettingsPanel.jsx`：通道与高级设置。
- `agent-workspace.css`：统一外观、主题变量、响应式布局和浮层层级。

本次不创建新的通用设计系统，也不迁移整个 Agent Canvas 样式文件。

## 7. 响应式与画布定位

- 桌面端编辑框目标宽度为 680 像素。
- 可视宽度不足时，编辑框宽度不得超出画布容器，并保留最少 16 像素边距。
- 工具条和底部工具栏允许横向滚动，不允许按钮文字相互覆盖。
- 编辑框默认锚定在节点下方；下方空间不足时允许在节点上方显示。
- 工具条默认锚定在节点上方；上方空间不足时允许在节点下方显示。
- 浮层不得被节点、分组框、连线、画布底部工具栏或全局导航遮挡。
- 画布缩放、平移或节点拖动后，浮层必须保持与活动节点的正确位置关系。
