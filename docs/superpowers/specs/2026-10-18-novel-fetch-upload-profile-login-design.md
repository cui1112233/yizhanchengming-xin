# 小说获取默认网站配置档入口设计

日期：2026-10-18

## 目标

把小说获取最常用的“默认网站配置档”放进“视频管理系统登录”管理弹窗，让用户登录后即可同步并选择默认配置档，不再为了日常提交进入配置页末级菜单。

## 页面结构

处理页继续显示“视频管理系统登录”状态和“管理”按钮。点击“管理”后，弹窗按以下顺序展示：

1. 视频管理系统登录状态与当前登录账号。
2. 登录或更换账号表单。
3. 默认网站配置档下拉框。
4. “同步网站配置档”和“同步风格目录”按钮。
5. “调整版本对应关系”入口，跳转到配置页的“版本配置档”。
6. “保存并关闭”按钮。

## 功能边界

- 登录弹窗只管理一个默认网站配置档。
- 原文、AI1、AI2 等版本的单独配置档绑定继续留在配置页。
- 配置页保留完整的版本对应配置功能，不再承担默认配置档的唯一入口。
- 登录弹窗和配置页读写同一份后端提交配置，避免产生两套状态。
- 系统提示词继续由 Go 后端统一提供，前端不新增硬编码提示词。

## 交互规则

- 未登录时，配置档选择、同步按钮和保存按钮不可用，并提示先登录视频管理系统。
- 登录成功后自动同步一次网站配置档；同步失败时保留登录状态并显示可重试提示。
- 用户也可以手动点击“同步网站配置档”和“同步风格目录”。
- 选择默认配置档后，点击“保存并关闭”才写入后端；关闭弹窗不保存未确认的选择。
- 未配置默认网站配置档时，提交准备页明确提示，不静默使用空配置。
- “调整版本对应关系”跳转到 `?tab=config`，并默认打开“版本配置档”分组。

## 数据流

1. 打开弹窗时读取视频管理系统登录会话和提交配置。
2. 登录成功后调用现有配置档同步接口，刷新下拉选项。
3. 保存时调用现有提交配置保存接口，只更新默认配置档字段，不覆盖版本绑定和其他提交设置。
4. 配置页继续读取同一份默认配置档与版本绑定数据。

## 异常处理

- 会话失效：显示“未登录 / 已失效”，禁止同步和保存。
- 配置档同步失败：显示具体错误和“重新同步”，不清空上一次已保存配置。
- 配置档列表为空：显示“未读取到可用配置档”，不允许保存空选择覆盖旧值。
- 保存失败：弹窗保持打开，保留用户当前选择以便重试。

## 验证范围

- 已登录与未登录两种弹窗状态。
- 登录成功后自动同步配置档。
- 手动同步配置档和风格目录。
- 默认配置档保存、重新打开回显。
- 保存默认配置档时不覆盖原文和各 AI 版本绑定。
- “调整版本对应关系”正确进入配置页对应分组。
- 深色与浅色主题下布局、文字和禁用状态可读。
