# 批量工厂统一紧凑排版设计

日期：2026-11-24

## 目标

修正批量工厂单书配置与工作台的视觉问题，同时保证漫画、视频、文本生成继续使用同一套基础样式，避免某一种模式单独生长出不相关的界面。

## 范围

本次只修改本地批量工厂前端样式与文本模式展示，不改接口、数据结构、生产流程和发布逻辑。

包括：

1. 单书配置的排版配置与发布配置改为规整的分组双列布局。
2. 删除字段下方重复、影响视觉的说明文字；必要说明继续放在帮助按钮中。
3. 工作台表头降低上下留白，漫画、视频、文本共用同一高度与字号规则。
4. 文字页预览保持原始 3:4 比例，不裁切，居中并在当前行高内尽量放大。
5. 页面内容与文字页的页头、内容区、翻页栏继续使用同一纵向结构，底部翻页栏对齐。

## 统一样式边界

### 共用基础样式

下列规则属于批量工厂所有生产模式，不允许写成文本模式专用规则：

- 工作台表头高度、内边距、字号和垂直对齐。
- 单书配置卡片边框、圆角、背景和内边距。
- 表单字段标签宽度、控件高度、横纵间距。
- 双列布局与窄屏单列响应方式。
- 开关行、颜色输入、背景选择行的视觉规格。
- 页头、预览区和翻页栏的纵向骨架。

### 模式独有内容

文本模式只负责提供文本独有字段和文字页预览内容，例如单页目标字数、正文字体、整书背景、封面背景。它可以使用额外的语义类名组织内容，但不得重新定义另一套卡片、字段和按钮外观。

## 单书配置布局

采用用户确认的 A 方案：分组双列。

- 每行左右各一个字段，标签列和控件列在整张卡片内严格对齐。
- 正文排版为第一组；背景与标题为第二组，中间用轻量分隔线和小标题区分。
- 背景颜色、背景图库选择和上传按钮放在同一字段行，不再拆成松散的多行控件。
- 发布配置与排版配置使用同一字段网格；上传人、组织归属、网站配置档、书籍分类占普通字段位。
- 自动生成合集、自动上传使用统一开关行；重试次数使用普通字段位。
- “同步网站配置档”保留为明确动作，但放进网站配置档字段的操作区，不单独占一整行。
- 删除“复用已有标红词，本地排版。”等可从字段名和选项直接理解的说明。真正需要解释的内容继续放在帮助按钮中。

## 工作台紧凑规则

- 表头只保留一行文字，减少上下内边距，不改变列宽和横向结构。
- 表头高度调整必须通过工作台共用选择器生效，漫画、视频、文本保持一致。
- 不通过缩小到难以阅读的字号来换取高度；主要减少无意义留白。
- 行内容仍按素材实际内容决定高度，不能因表头紧凑而裁切正文、图片或按钮。

## 文字页预览

- 预览使用 `object-fit: contain`，禁止裁切。
- 预览容器占满可用宽度，图片水平居中。
- 图片最大尺寸受当前行内容区约束，保持 3:4，不将工作台行强行撑高。
- 页头和底部分页条占满列宽，分页条与相邻“页面内容”列对齐。

## 验收标准

1. 1021×901 视口下，排版配置和发布配置字段左右对齐，不出现明显空洞或错位。
2. 字段下不再显示“复用已有标红词，本地排版。”。
3. 工作台表头比当前版本更紧凑，漫画、视频、文本使用同一规则。
4. 文字页预览完整、居中、无裁切，右侧不再留下不合理的大块空白。
5. 页面内容与文字页分页条底边误差为 0。
6. 既有漫画、视频、文本配置字段及操作仍可使用。
7. 前端测试、构建和本地 Go embed 运行验证全部通过。

## 不在本次范围

- 不修改生产任务、上传任务、提示词或后端配置结构。
- 不新增模式专属主题。
- 不推送远端，不部署线上。
