# 手机插件市场与线上能力对应

继续用户已授权的逐功能完整实现。线上26项插件来自frontend/src/user/pages/pluginCatalog.js；当前手机plugins误跳会员工具页。本轮新增分包插件目录，直接复用框架无关的同一目录元数据和本地处理纯函数，防止名称/数量/能力漂移，不复用含系统提示词的前端拼接代码。

手机目录支持搜索和类型分区。五个文字工具独立输入/模型/服务端提示词/结果，系统提示词只读GET/api/plugins/{tool}/config并由后端run应用；本地格式化/字幕合并/文档合并/分镜整理使用同一纯函数，在手机以粘贴文本/多段内容代替文件上传。AI-CUT进入正确手机剪辑页。图片类按原Agent项目/节点/生成/素材合同实现明确的单项编辑与结果，不伪造生成。分段/超分按后台实际能力与手机媒体选择实现。桌面草稿类及线上未接入项保留原功能说明，明确所需桌面环境，不给假执行按钮。

使用已批准紧凑深浅主题、16px边距、14px正文与44px操作。目录/工具返回不丢当前草稿；同步写锁覆盖确认，结果未知不自动重发；账号切换清正文、结果和迟到响应，隐藏停止轮询。保存结果在手机缓存/分享，仅由用户点击，不自动发给第三方。线上只读核对与模拟执行测试、真实生成验收分别记录。
