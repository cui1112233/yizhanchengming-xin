# Agent Canvas 资产引用与截图粘贴设计

## 目标

工作流节点编辑框支持输入 `@` 搜索并引用当前项目资产；工作流画布支持从系统剪贴板直接粘贴截图并创建图片节点。

## 交互

- 光标位于有效的 `@关键词` 后时，在编辑框上方显示资产候选。
- 候选只包含当前节点实际支持的类型：图片节点仅图片，视频节点为图片和视频，音频节点仅音频，文字节点为全部项目资产。
- 选择候选后，将 `@资产名` 插入提示词，并把资产加入节点的 `referenceAssets`。生成仍使用真实资产 ID。
- 已经引用的资产可以再次插入文字标签，但不会重复写入 `referenceAssets`。
- 点击输入框以外区域或按 Escape 关闭候选；加载和失败状态在候选框内显示。
- 当画布获得包含图片的系统粘贴事件时，上传第一张图片到当前项目，并在鼠标最近位置创建图片节点；若没有可用指针位置则放在画布中心。
- 文本输入框自身的普通粘贴保持原样，不被画布截图功能拦截。
- 上传中给出提示；上传失败不创建空节点，并显示明确错误。

## 数据与边界

- 复用 `POST /api/agent/tasks/{id}/assets`，不新增接口和数据库字段。
- `@资产名` 是可读提示文字，真实生成输入仍来自 `config.referenceAssets`。
- 截图上传成功后复用现有 `createNodeAt` 和画布保存链路，确保刷新后仍存在。
- 不自动发起图片、视频、文字或音频生成。

## 验证

- 纯函数测试覆盖触发范围、关键词筛选、插入结果、允许类型和剪贴板图片识别。
- 组件源测试覆盖真实回调接线、弹层和画布粘贴入口。
- 运行相关 Node 测试、前端构建、Go 内嵌构建和本地运行时检查。
- 浏览器只验证显示、选择、粘贴及保存，不点击生成。
