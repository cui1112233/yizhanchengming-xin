# Agent Canvas 模型选项可见性修复

## 目标

让画布节点中的模型下拉菜单完整显示模型名称、提供方和能力说明；节点内的选择框仍保持紧凑，不占用额外画布空间。

## 原因

`AgentModelPicker` 的每个选项已按 260px 的最小宽度渲染，但 Ant Design 的下拉菜单默认会匹配触发选择框的宽度。画布节点中的选择框很窄，导致选项内容被菜单容器裁切，只剩图标可见。

## 方案

1. 在模型选择器上关闭“下拉菜单必须与选择框同宽”的默认行为，让菜单按选项内容展开。
2. 保留现有图标、模型名称、提供方、能力与预计时长的选项结构，不更改可选模型来源、执行器绑定或跨节点同步规则。
3. 为此行为补充一条源码回归检查。
4. 在本地 Go 嵌入运行环境中打开画布，实际展开视频模型菜单并确认模型文字可见、可选择。

## 错误处理与验收

没有可用模型时，维持现有“当前通道没有可用模型”的提示。验收标准为：下拉菜单不再被节点宽度裁切，模型名称和第二行信息均可见；选中模型后仍只触发既有的节点配置更新。
