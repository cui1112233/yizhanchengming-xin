# 漫画提示词审核自动修复设计

## 目标

漫画页提示词被文本模型以暴力、血腥、成人内容或性暗示等原因拒绝时，系统自动修复并继续生产；不修改小说原文，不重新生成已完成页面，不让单页失败连坐整本书。

## 当前问题

现有安全重试只替换暴力、血腥、刀枪等画面词，并原样保留对白。遇到成人内容审核时，敏感叙述或对白仍会进入第二次请求，因此安全重试仍被拒绝，自动化转为人工处理。

## 方案

1. 首次请求保持现有行为。
2. 确认属于内容审核拒绝后，进入安全重试。
3. 安全重试同时处理暴力和成人内容：
   - 非对白叙述改成不露骨、非身体接触的安全视觉表达。
   - 对白从送审文本中替换成稳定编号占位符，例如 `{对白1}`。
   - 系统提示明确要求只生成安全画面，不扩写成人、暴力或血腥细节。
4. 模型返回合法 JSON 后，后端只把原对白恢复到 `screen_prompt` 的文字区域；`image_prompt` 永远不恢复敏感对白或成人视觉内容。
5. 安全重试最多两轮：第一轮执行通用安全化，第二轮进一步收紧为人物分开、日常场景、表情与环境空镜。
6. 两轮仍失败时，只标记当前漫画页需要人工处理，其余页面继续。

## 数据边界

- 小说原文、分页原文和用户保存的内容不改写。
- 安全化文本只存在于本次模型请求内。
- 已生成的漫画提示词和图片不覆盖。
- 自动重试只针对缺失或失败页面。

## 错误与费用保护

- 仅内容审核错误触发安全重试；鉴权、余额、网络和格式错误走各自原有处理。
- 每页最多增加两次文本模型请求，达到上限立即停止，不无限重试。
- 日志区分“首次拒绝”“安全重试成功”“安全重试用尽”。

## 验收

1. 测试复现成人内容首次与现有安全重试均被拒绝。
2. 新安全请求不包含原成人描述和原对白正文，但保留对白占位关系。
3. 返回后 `screen_prompt` 恢复原对白，`image_prompt` 不包含敏感内容。
4. 已完成页面不被重新生成。
5. 本地测试和候选二进制验收通过后上线。
6. 只续跑《爱到此处停止》，页面数从现有 1/27 继续增长。
