# 小程序“我的空间”视觉还原设计

## 目标

本轮只优化底部第四个页面“我的”，视觉唯一基线为：

`docs/design-references/miniprogram-functions-first/04-profile.png`

页面要尽量还原设计图的布局、比例、卡片层级、晚霞背景、深海军蓝玻璃、青紫描边和 3D 图标，同时继续使用服务端真实账号数据。不得把设计图里的“创作者、3、28、760 次”等示例内容写死到小程序。

## 页面结构

### 1. 顶部场景

- 使用和功能页、任务页一致的晚霞背景与一战晟铭彩色 Logo。
- 主标题为“我的空间”。
- 副标题为“账号、资产与创作偏好”。
- 手机安全区、微信胶囊按钮和标题之间保持足够间距。
- 不再额外重复显示一个“我的”标题。

### 2. 创作者身份卡

- 左侧圆形区域显示用户真实头像；没有头像时使用真实名称首字，不伪造人物头像。
- 主标题优先显示真实名称，其次显示用户名。
- 身份徽章显示服务端真实角色或会员身份，不固定写 SVIP、创作者等级等不存在的数据。
- 欢迎语为固定界面文案，不冒充服务端数据。
- “进行中”和“已完成”读取任务中心同一套真实汇总逻辑，保证两个页面数字一致。
- 某个任务来源失败时，使用其他成功来源统计；所有来源失败时显示“暂未读到”，不能显示 0 冒充真实结果。

### 3. 创作额度卡

- 使用皇冠 3D 图标和横向玻璃卡。
- 主数据优先显示服务端返回的月度剩余额度。
- 服务端返回不限额时显示“不限额”。
- 服务端没有额度字段时显示“暂未返回”，不能套用设计图中的 760。
- “查看详情”进入现有用量与制作页面。

### 4. 功能列表

保持设计图的单张纵向列表卡，入口按真实功能对应：

1. 我的资产：切换到现有工作台页面，展示真实项目和正在执行的工作。
2. 创作偏好：打开现有“外观与陪伴”设置面板。
3. 会员与用量：进入现有会员中心详情页 `memberCenter`。
4. 账号与安全：进入现有账号安全详情页 `security`。
5. 帮助与反馈：本轮不新增虚假页面，入口显示“暂未开放”且不跳转。

每一行使用与含义匹配的独立 3D 图标，不能全部复用同一图标。

### 5. 降低透明度

- 保留真实开关和当前本地偏好读写逻辑。
- 开启后增强文字、卡片和背景的对比度。
- 开关状态跨页面和重启保持一致。

### 6. 底部导航

- 保持“功能、工作台、任务、我的”四项。
- “我的”使用青色选中态。
- 导航高度、底部安全区和设计图一致，不遮挡最后一张卡。

## 数据对应

| 界面内容 | 数据来源 | 失败时展示 |
| --- | --- | --- |
| 头像、名称、用户名、角色、团队 | 现有会员资料接口 | 明确的缺失状态 |
| 进行中、已完成 | 任务中心真实任务汇总 | “暂未读到” |
| 月度额度、剩余额度、用量 | 现有会员与用量接口 | “暂未返回” |
| API 服务状态 | 现有账号资料 | 不在首屏重复展示 |
| 降低透明度 | 小程序本地偏好 | 使用默认关闭状态 |

## 手机布局标准

- 以 375px 设计宽度为基线，兼容 320px 至 430px 手机宽度。
- 页面左右边距约 12 至 14px。
- 创作者身份卡保持约 2.8:1 的横向比例，不照搬设计图大画布尺寸。
- 功能列表行高控制在手机一屏可见 3 至 4 行的范围。
- 主标题、卡片标题和说明文字逐级缩小，避免继续出现整体字号过大的问题。
- 超长用户名、团队名使用单行省略，不能顶开卡片或覆盖右侧数据。

## 状态与错误处理

- 加载时保留顶部背景和页面骨架，避免整页黑屏。
- 资料接口失败时展示重试和返回登录，不能渲染假资料。
- 任务统计失败不能阻止账号资料和其他卡片显示。
- 用量接口失败不能阻止功能列表显示。
- 账号切换后丢弃旧账号的迟到响应。

## 验收标准

- 微信开发者工具中页面可正常进入，控制台无运行错误。
- 与 `04-profile.png` 对比时，顶部、身份卡、额度卡、功能列表、透明度开关和底部导航顺序一致。
- 页面不再重复显示“我的”。
- 不写死示例头像、会员身份、任务数量或额度。
- 进行中与已完成数量和任务页来自同一套真实数据。
- 所有入口要么进入真实功能，要么明确显示暂未开放。
- 完整小程序测试和微信小程序构建通过。

## 本轮范围

只修改“我的”首页及其直接需要的数据组合、样式、测试和图标资源。不会顺带重做功能页、工作台、任务页、登录流程或后端业务。
