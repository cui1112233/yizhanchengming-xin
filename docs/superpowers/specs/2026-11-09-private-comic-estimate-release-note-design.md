# 私人定制漫画预计张数公告设计

## 目标

让本地 4001 在本次更新后弹出新的产品更新公告，说明私人定制漫画已增加实时预计张数。

## 根因

本地代码已经更新，但 `backend/current-release.json` 仍指向用户已经看过的 v43 公告。产品更新弹窗按 `releaseId` 每版只展示一次，因此不会再次弹出。

## 方案

- 新增一份 `qiantie-202611090148`、版本号为 v44 的公告 JSON。
- 公告只描述本次已经完成并验证的“私人定制漫画预计张数”功能。
- 将本地 `backend/current-release.json` 的 `releaseId` 指向新公告。
- 保持现有弹窗、已读记录和“一版只弹一次”逻辑不变。
- 重建本地嵌入式 Go 二进制并重启 4001；不构建或部署线上版本。

## 用户可见结果

- 登录本地系统后自动看到 v44 更新公告。
- `/script` 的“漫画生成”页在正文下方显示：`已读取 N 字 · 预计约 X～Y 张`。
- 已经确认过 v44 后不重复弹出。

## 验收

- 后端公告测试通过，并能从 `/api/product-updates/latest` 返回 v44 和新的 `releaseId`。
- 本地运行二进制的 Git SHA 与当前提交一致。
- 内置浏览器刷新后能看到 v44 公告；关闭后进入漫画生成页能看到预计张数。
- 工作树干净，线上不发生任何变化。
