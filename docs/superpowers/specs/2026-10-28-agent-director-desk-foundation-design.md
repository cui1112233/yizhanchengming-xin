# Agent 导演台基础能力设计

## 目标

补齐 Agent 导演台第一阶段的基础拍摄能力，让导演台不再只是截图工具，而是可以为视频支点提供可复用的场景、对象、机位和分镜提示词。

本阶段只增强现有 `director` 节点和现有画布保存链路，不新建项目、任务队列或导演台专用数据库。

## 范围

本阶段包含：

- 场景、人物、道具作为导演台中的独立对象展示和选择；
- 对象移动、旋转、缩放，并保存到 `directorProject`；
- 语义化机位参数：景别、焦段、方位角、俯仰角和当前机位；
- 独立的分镜视频提示词输入，与场景描述分开保存；
- 导演台保存的构图、机位和分镜提示词回填到关联视频支点；
- 保持现有截图回传画布为图片支点的能力。

本阶段不包含：

- 镜头时间线、动画曲线、音频剪辑；
- 灯光、天气、天空、地面和物理效果；
- 骨骼角色、GLB/PMX 模型库；
- PDF、CSV、分镜表导出；
- 改造批量工厂的独立视频生产链路。

## 数据结构

继续使用 `node.data.config.directorProject`，通过版本化结构向后兼容旧导演台数据：

```js
{
  rendererVersion: '3d-v2',
  scene: { assetId, url, name } | null,
  objects: [
    {
      id,
      kind: 'actor' | 'prop',
      assetId,
      position: [x, y, z],
      rotation: [x, y, z],
      scale: [x, y, z]
    }
  ],
  camera: {
    position: [x, y, z],
    target: [x, y, z],
    fov,
    shotSize,
    focalLength,
    azimuth,
    elevation
  },
  shotPrompt: '',
  scenePrompt: '',
  captures: []
}
```

旧的 `actors` 数据继续读取并转换为 `objects` 中的 `actor`，旧的 `scene.prompt` 转换为 `scenePrompt`。保存时只写新结构，不删除旧节点。

## 界面结构

沿用当前全屏导演台布局：左侧工具栏、中间 3D 视口、右侧检查器、底部操作栏。

左侧工具栏增加“道具”入口，并将“场景对象”中的对象类型明确显示为场景、人物、道具。选中对象后，右侧检查器显示对应的变换参数和素材信息。

底部输入区拆为两个明确字段：

- 场景描述：用于整体环境和构图参考；
- 分镜视频提示词：用于视频支点的镜头动作、主体动作和镜头语言。

底部保留保存状态、截图到画布、上传参考图和重置视角。所有按钮继续使用图标和悬浮提示，避免把所有设置长期铺开。

## 机位行为

机位预设继续保留，并增加当前机位的语义参数编辑。修改景别或焦段时，前端更新相机位置和视场角；修改方位角或俯仰角时，围绕当前目标点重新计算相机位置。用户可以把当前视角保存为一个命名机位，并在右侧检查器中切换活动机位。

## 视频支点回填

导演台保存或关闭时，不自动创建视频任务。若导演台节点存在关联的视频目标节点，则将以下内容写入视频节点配置：

- `prompt`：导演台的 `shotPrompt`；
- `directorProject`：当前导演台项目快照；
- `camera`：当前语义机位参数；
- `referenceAssetIds`：场景、人物和道具引用的图片资产 ID。

如果没有关联视频节点，只保存导演台自身状态。截图到画布仍然创建图片节点，不改变现有行为。

回填失败时保留导演台修改，并显示“视频支点尚未同步”，不能提示为已完成。

## 保存与兼容

所有修改继续通过 `DirectorDeskHostAdapter` 进入 Agent Canvas 的节点配置保存队列。导演台关闭前等待保存队列完成；保存失败时保留窗口并显示错误。

不新增后端表，不复制媒体文件，引用继续使用项目素材 ID。现有批量工厂映射节点和普通 Agent 节点不受影响。

## 测试与验收

- 单元测试覆盖旧数据升级、对象变换、语义机位计算、提示词字段和引用资产收集；
- 导演台组件测试覆盖场景/人物/道具选择、两个提示词字段和保存状态；
- Agent Canvas 来源测试覆盖视频支点回填和失败提示；
- 构建前端并重建 Go 内嵌静态资源；
- 浏览器验收：打开导演台，添加人物和道具，移动/旋转/缩放，修改机位和分镜提示词，关闭后刷新，确认状态保留；再确认视频支点能看到提示词、机位和参考图片引用；不提交真实图片或视频生成任务。
