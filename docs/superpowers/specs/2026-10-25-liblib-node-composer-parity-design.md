# Liblib 节点与生成框对标设计

## 目标

将 Agent Canvas 的音频、视频、文本、图片节点和底部生成框统一为 Liblib 风格的深色卡片布局，同时保留现有生成、连接、上传、替换、定位和历史结果逻辑。

## 设计

- 节点共用统一的标题栏：拖动手柄、类型图标、标题、状态/操作入口；左右连接点保持可用。
- 音频节点增加标题、时长、波形区域、播放按钮和起止时间的清晰层级。
- 视频节点使用固定比例预览框，加载、失败和空状态保持相同尺寸，并保留播放控制。
- 图片节点使用固定比例预览框，尺寸和状态作为次级信息，保留点击替换及参考图操作。
- 文本节点把标题、摘要和正文分层，正文保持可读并保留编辑/复制等已有动作。
- 底部生成框按“素材缩略图横条、快捷操作、提示词、模型和参数、生成按钮”排列；窄屏只允许横向滚动工具条，不压缩核心输入区。
- 只调整现有 React 组件和 CSS，不改变后端接口、画布数据结构或生成请求协议。

## 验收标准

1. 四类节点在画布中尺寸稳定、信息分层清楚，连接加号不被内容遮挡。
2. 音频节点可看到波形和播放控制；视频/图片预览不会因资源状态改变而跳动。
3. 底部生成框在桌面和窄屏均能扫描，生成按钮、模型和参数仍可操作。
4. 现有节点连接、生成、上传、替换和定位测试不回归。
