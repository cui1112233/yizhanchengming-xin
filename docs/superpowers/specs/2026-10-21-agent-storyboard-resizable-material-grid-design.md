# 故事板项目素材可调分区设计

## 目标

故事板视图的“项目素材”区保留文本、图片、音频、视频四个分区，但不再固定左 39%、右 61% 以及上下各半。用户可以拖动中间的竖向和横向分隔线，按当前工作内容调整各区的可见空间。

## 范围

- 只作用于 `AgentStoryboardWorkspace` 的项目素材四分区。
- 竖向分隔线控制左列与右列宽度。
- 横向分隔线控制上行与下行高度。
- 鼠标、触控板和触摸设备都使用指针事件完成拖动。
- 每个分区保留最小尺寸，避免素材区被拖到不可用。
- 当前浏览器会话内保留拖动后的比例；刷新后回到默认比例。
- 窄屏布局继续使用现有的纵向素材列表，不显示拖动分隔线。

## 交互

默认比例保持现有视觉：左列 39%、右列 61%，上下各 50%。

鼠标悬停分隔线时显示对应方向的调整光标；拖动期间禁止选中文字，并显示强调状态。松开后立即采用最终比例。分隔线本身不覆盖任何素材卡片的点击区域。

## 实现边界

为项目素材容器增加局部的列宽和行高状态；用 CSS 变量驱动网格轨道，并在两个独立的分隔线元素上处理 `pointerdown`、`pointermove`、`pointerup` 与取消事件。现有素材筛选、收折、拖动排序、批量操作、详情抽屉和素材上传接口都不改动。

## 验证

- 添加状态计算单元测试，覆盖默认值、最小尺寸限制和百分比换算。
- 添加组件源码约束测试，确认竖向、横向分隔线与指针事件存在。
- 在本机故事板页面实际拖动两条分隔线，确认四区随之改变且素材操作仍可用。
- 在窄屏宽度确认页面保持纵向列表，不出现无效拖动把手。
