# 微信小程序功能卡片比例还原设计

## 范围

本轮只调整微信小程序“功能”首页的三个功能分区，不修改顶部主视觉、底部四项导航、九个功能名称、路由或内部功能页。

视觉基准为用户在 2026-11-23 提供的功能区局部截图。该截图宽 418px；实现以 390px 手机宽度为主基准并等比例换算。

## 布局标准

- 页面左右边距：15px。
- 主卡与小卡列间距：9–10px。
- 主卡宽度：可用宽度的约 61%，390px 手机上约 220px。
- 小卡列宽度：可用宽度的约 36%，390px 手机上约 132px。
- 主卡高度：136–140px。
- 单张小卡高度：59–61px；两张之间保留 12–15px 间距。
- “内容创作”左侧为“私人定制”主卡，右侧为“小说创作”和“批量测书”。
- “生产成片”左侧为“水货生产”和“AI-CUT”，右侧为“漫剧创作”主卡。
- “AI 与工具”沿用同一比例：左侧主卡，右侧两张小卡。

使用微信小程序稳定支持的 Flex 布局，不恢复 CSS Grid。不得为了视觉对齐再次引入会造成黑屏或高度塌陷的写法。

## 字体与间距

- 分区标题：19px 左右，粗体。
- 分区说明：9–10px，蓝灰色，单行显示。
- 主卡标题：20–21px，粗体。
- 主卡说明：9–10px。
- 小卡标题：13–14px，粗体。
- 分区标题与卡片之间：14–18px。
- 前一组卡片与下一组标题之间：24–28px。
- 标题左侧青色斜杠、右侧渐隐横线与参考截图保持同一视觉高度。

## 插画标准

- 继续使用已经接入的九张独立 3D 插画，不更换功能语义。
- 主卡插画可视主体占卡片宽度约 65%–72%，贴近右下区域，但不能压住标题。
- 私人定制的书本、羽毛笔和 AI 方块必须完整可见。
- 漫剧创作的胶片弧线、人物画面和播放键必须完整可见。
- 小卡插画可视盒约 44–48px，三张同类卡保持一致，不因素材透明边距产生明显大小差。
- 插画使用 `aspectFit`，不拉伸、不裁切、不二次模糊放大。

## 功能边界

- 九张卡片继续打开各自当前真实路由。
- 最近使用状态和“继续创作”逻辑保持不变。
- 不新增接口，不修改后端、数据库、提示词或任务流程。
- 不上传、不发布、不部署。

## 验收

1. 在微信开发者工具的 iPhone 12/13 宽度下截图。
2. 将实现截图与 418px 参考截图按相同内容区域并排比较。
3. 主卡、小卡宽高和列间距偏差不得超过 5%。
4. 三个分区的字号、标题间距和卡片比例一致。
5. 九个入口全部可见且可点击，底部导航不遮挡最后一组。
6. 控制台无业务代码错误，页面无黑屏。
7. 构建或单元测试通过不能代替微信开发者工具中的同尺寸截图验收。

## 明确不采用

- 不把整张参考图作为不可交互的页面背景。
- 不把一组卡片合成为一张文字图片。
- 不用模糊光效掩盖尺寸差异。
- 不在本轮顺手修改其他页面。
