# V88 Agent 画布右键与素材闭环设计

日期：2026-10-19  
范围：本地 V88 的 `/agent/canvas`；不发布公网。

## 1. 参考产品的实际链路

本设计参考已安装的沈浪超级 AI 画布 1.1.8 的已打包桌面程序，只借鉴交互流程，不复制其代码、品牌、图标、接口或云端服务。

它的画布不是单一的右键菜单，而是以下闭环：

1. 用户在空白画布右键或双击，记录当前屏幕坐标并换算为画布坐标。
2. 一级菜单提供“新建节点、粘贴、重做、撤销”；新建节点打开二级菜单。
3. 二级菜单提供文本、图片、视频节点，以及“从资产库添加”和“本地上传”。
4. 新建或导入的结果被写入项目画布；节点、分组、连线、视图和编辑历史共同更新。
5. 素材先进入素材库，画布节点只保存素材引用；图片、视频和音频的生成结果也回写为素材，再绑定回节点。
6. 项目保存后，重新打开可恢复节点、连线、分组、坐标和素材引用。

该桌面程序在客户端使用 Electron IPC、本地项目文件和本地素材目录。V88 不能使用这些本地文件路径：网页端必须使用 Go API、MySQL 项目数据和 TOS 素材对象。

## 2. V88 的目标

在现有 React Flow Agent 画布中提供与上述使用顺序一致的真实操作：

- 空白画布右键：新建节点子菜单、粘贴、重做、撤销。
- 新建子菜单：文本、图片、视频、从资产库添加、本地上传。
- 节点右键：复制、删除、断开该节点的全部连线、替换素材。
- 多选节点右键：分组、解组、六种对齐和两种等距，复用已存在的画布命令。
- 所有画布结构改变都进入当前项目的历史记录和现有 revision 保存队列，刷新后恢复。

菜单只显示当前可执行的命令。没有可粘贴节点时“粘贴”置灰；没有撤销/重做历史时对应项置灰；素材节点没有素材引用时不显示“替换素材”。

## 3. 节点与素材模型

画布节点继续使用当前的 `agentworkspace.Node`，保持项目、消息、画布和 revision 的一套数据源。

- 文本节点：`type: text`，正文保存在节点摘要字段的有界内容中；标题可编辑。
- 图片和视频节点：`type: image` 或 `type: video`，`assetRef` 保存素材 ID、媒体类型、原始文件名、对象 URL、尺寸或时长等展示所需字段。
- 普通 Agent 结果节点维持现有类型和字段；右键不会错误地把它转换为素材节点。
- 复制节点生成新节点 ID，并复制同一批被选择节点之间的连线；标题追加“副本”，粘贴位置以右键位置为基准偏移，避免完全重叠。

素材本体不写入 Canvas JSON，也不保存浏览器临时 URL 或电脑磁盘路径。Go 服务负责校验媒体类型、大小和项目归属，将文件写入 TOS，并返回可受控访问的素材记录。画布只记录该记录的引用。

## 4. 后端链路

本阶段新增 Agent 专属、按登录用户和项目隔离的 Go 接口：

- 列出当前项目可选择的素材。
- 上传图片或视频到当前项目素材库。
- 查询单个素材并校验其可被当前项目使用。

画布保存仍复用 `PATCH /api/agent/tasks/{id}/canvas` 的 revision 冲突保护；上传成功后前端将素材引用添加为一次普通画布提交。上传失败不创建空节点，也不影响已有画布。

素材记录存 MySQL，二进制文件存 TOS。数据库改动采用高于现有最大编号的全新幂等迁移，绝不修改已执行迁移。

## 5. 前端交互

- `AgentCanvas` 负责捕获空白处、节点和多选节点的右键，阻止浏览器默认菜单，并将菜单限制在画布可视区域内。
- 菜单坐标在打开时转为 React Flow 画布坐标，因此缩放或拖动画布后仍在用户点击的位置创建或粘贴节点。
- 资产库使用抽屉或弹窗选择器，按图片、视频筛选；选择后一次性在当前右键位置加入一个或多个节点。
- 本地上传使用文件选择器。文件传输期间显示明确进度；上传成功才将节点加入画布。
- 节点删除、断开连线、复制、粘贴、替换素材均是一个可撤销步骤。替换素材只改变该节点的 `assetRef`。
- `Esc`、点击画布其他区域、切换项目、开始拖动画布或打开另一个菜单时关闭菜单。

保持当前 V88 颜色、连线动效、工具栏、右侧对话区和窄屏布局；不复制沈浪的品牌色或 CSS。

## 6. 分阶段实施

### 阶段 A：画布操作

实现空白、节点和多选节点的右键菜单；实现文字、图片、视频占位节点，复制、粘贴、删除、断开连线，以及历史、保存和刷新恢复。

### 阶段 B：素材闭环

实现 Go 素材表、追加迁移、TOS 上传、素材库选择器和替换素材。完成后，图片和视频节点才允许绑定真实素材。

### 阶段 C：生成能力接入

将现有图片、视频和声音/视频能力以正式任务接口接到对应素材节点。任务结果先进入素材库，再更新节点；失败、重试和取消必须可见。

阶段 A 与 B 是本次右键菜单的完整可用交付。阶段 C 是“AI 图片生成、AI 视频生成、声音与视频工具”的后续功能，不把未接通的按钮伪装为已实现。

## 7. 错误处理与验收

自动测试覆盖：

- 菜单在正确目标和坐标打开、边缘自动避让、失焦关闭。
- 各菜单项的可用和置灰条件。
- 复制/粘贴的节点、连线、标题和位置。
- 删除节点会删除关联边；撤销和重做恢复完整状态。
- 素材选择、上传失败、项目越权素材、revision 冲突均不留下错误节点。
- 现有分组、对齐、缩放、对话和保存行为不回退。

本地已登录浏览器验收：

1. 在真实 Agent 项目中从空白处右键创建文本、图片、视频节点。
2. 复制、粘贴、删除和撤销/重做，刷新确认恢复。
3. 上传一张图片和一段视频，从素材库加入并替换已有节点素材。
4. 切换项目后确认菜单、剪贴板和保存内容不会串到其他项目。
5. 窄屏确认菜单和选择器不挡住主要输入与操作。
