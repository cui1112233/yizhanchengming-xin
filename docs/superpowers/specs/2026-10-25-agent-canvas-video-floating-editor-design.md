# Agent Canvas 视频浮动编辑器设计

## 目标

视频节点单击后保持原有尺寸，只显示锚定在节点上方的快捷工具条和节点下方的编辑框。画布缩放只改变节点本身的屏幕尺寸，工具条与编辑框通过反向缩放保持稳定、可读、可操作。

## 参考行为

Liblib 在画布缩放约 `46%` 时，选中和未选中的视频节点逻辑宽度均约为 `620px`，单击不会改变节点宽度。顶部工具条和下方编辑框使用约 `1 / 0.46` 的反向缩放，因此它们跟随节点移动，但不会随画布放大或缩小。

## 布局

- 视频节点继续使用当前基础宽度，删除 `is-editor-open` 引起的宽度变化。
- 顶部工具条绝对定位在视频预览上方，以节点中心为水平锚点。
- 下方编辑框绝对定位在视频节点下方，以节点中心为水平锚点。
- 两个浮层都使用 `scale(calc(1 / var(--agent-canvas-zoom)))` 抵消 React Flow 视口缩放。
- 浮层不进入节点普通文档流，不改变 React Flow 对节点宽高的测量，不推动节点、连接点或连线。
- 浮层保留 `nodrag nopan`，其按钮和输入控件正常操作；视频预览空白区域仍可拖动节点。

## 行为

- 单击视频节点：选中节点并打开上下浮层。
- 单击其他节点或画布空白：关闭当前视频浮层。
- 缩放或平移画布：浮层继续锚定视频节点，屏幕显示尺寸保持稳定。
- 快捷工具继续调用现有真实视频处理功能，不增加没有后端能力的按钮。

## 验收

- 单击前后视频节点的 CSS 宽度不变。
- 画布缩放变化时，视频节点屏幕尺寸变化，工具条和编辑框屏幕宽度基本不变。
- 工具条与编辑框不计入节点布局尺寸。
- 视频节点仍能从预览区域拖动，编辑控件仍能点击。
- 不触发真实生成任务。
