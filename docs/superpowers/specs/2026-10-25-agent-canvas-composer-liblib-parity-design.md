# Agent Canvas 画布级生成框与快捷面板设计

## 目标

在现有 Agent Canvas 对话面板中，把生成框明确为画布级浮动组件，并用 Liblib 风格的顶部快捷入口承载已有能力。此次只调整布局、交互和可见状态，不新增后端接口，不触发真实生成，不改变现有任务提交协议。

## 当前能力边界

设计必须复用现有功能：

- 附件：通过隐藏文件选择器读取 TXT、MD、CSV、JSON、图片、视频和音频；文本限制 200 KB，媒体限制 128 MB；不支持或超限时显示错误提示。
- 模式：`创作助手`、`分析拆解`、`修改润色` 三项单选，选择后立即关闭面板并保留当前选中状态。
- 专家：`CM 创作顾问`、`前贴片广告策划`、`短剧编剧` 三项单选；故事板模式继续隐藏该入口。
- 技能：支持“全部 / 平台自带 / 我的技能”筛选，最多选三项；已有技能的选用、取消、模板填入、编辑、删除和新建能力保持不变。
- 找问题：保留现有切换逻辑和输入提示；启用后发送按钮进入找问题状态。
- 连接器：继续显示当前账号未配置的明确提示，不伪造连接器列表。
- 素材引用：保留故事板素材拖入、已选素材缩略图、单项移除和节点引用标签。
- 发送：保留输入为空禁用、发送中 loading、回车发送、Shift+Enter 换行和任务状态反馈。

## 方案与结构

采用“画布容器内定位”的方案。生成框属于对话面板的底部区域，但定位锚点是画布工作区容器，而不是浏览器窗口：

1. 左右面板、故事板分栏和对话面板宽度变化时，生成框使用可用宽度重新计算。
2. 画布缩放只影响生成框的容器定位和视觉比例，输入文字设置最小可读字号和最小高度，避免缩放后不可用。
3. 生成框保持在画布内容之上，不能被节点、连线或底部画布工具条遮挡；在窄屏时回退为面板底部全宽布局。
4. 生成框保留当前空投状态，素材拖入时沿用现有高亮提示。

结构顺序固定为：

- 顶部：已选素材缩略图和附件标签。
- 中部：多行提示词输入及节点提及选择器。
- 底部：快捷入口、当前模式摘要、技能/专家入口、发送按钮。
- 上方浮层：当前快捷入口对应的选择面板。

## 快捷入口与浮层

底部工具条保留加号入口，同时将常用能力放到可识别的快捷按钮中：

- `模式`：打开三项模式选择。
- `添加附件`：直接打开文件选择器；不打开空面板。
- `技能`：打开带筛选和技能卡片的技能面板。
- `专家`：打开专家选择面板；故事板中不显示。
- 加号菜单继续提供 `添加文件`、`模式`、`专家`、`技能`、`找问题`、`连接器`，作为完整能力入口。

浮层规则：

- 浮层始终出现在生成框上方，并与触发按钮对齐；空间不足时向内侧翻转，不能溢出画布容器。
- 同时只允许一个面板打开；切换入口直接替换面板。
- 选择模式或专家后关闭对应面板；技能的多选操作不关闭面板，便于连续选择，点击面板外部或完成后再收起。
- 点击画布空白处、按 Escape 或再次点击当前入口关闭面板。
- 打开浮层不清空输入内容、已选素材、技能标签或附件。
- 连接器未配置时只关闭菜单并显示现有提示，不改变其他选择状态。

## 响应式行为

- 桌面端：生成框在对话区域底部居中，宽度为容器宽度减去固定边距，浮层最大宽度受容器限制。
- 故事板：沿用导演面板宽度调整结果，生成框不跨越故事板主画布与导演面板边界。
- 窄屏：生成框变为面板底部全宽；快捷按钮允许横向滚动，浮层改为贴近生成框的面板，操作按钮保持可点击尺寸。
- 无障碍：每个图标按钮保留 `aria-label` 和 `title`，浮层使用明确的标题和键盘焦点顺序。

## 不在本次范围

- 不新增模型、专家、连接器或素材库数据。
- 不改任务创建、发送、上传接口和后端数据结构。
- 不触发真实图片、视频、音频或模型生成。
- 不在本次同时重做节点卡片、左侧文件夹分组或故事板资源网格。

## 验收标准

1. 桌面和窄屏下生成框都锚定在当前画布/对话容器内，面板切换不跳出容器。
2. 附件、模式、专家、技能、找问题、连接器入口均能走现有真实逻辑。
3. 浮层互斥、可关闭、选择状态可保留，输入和素材引用不丢失。
4. 节点与故事板素材拖入仍能显示已选素材并可移除。
5. 发送按钮的禁用、loading、回车发送和找问题状态不回归。
6. 通过现有画布命令测试、前端构建和 Go 内嵌资源构建；不执行真实生成任务。
