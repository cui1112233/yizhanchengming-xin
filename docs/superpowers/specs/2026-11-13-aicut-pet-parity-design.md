# AI-CUT 持续功能对照与页面宠物服务

用户明确要求继续对照本机洛水安装包（REA）与开源编辑器，不接受空按钮、无结果链路；截图重点为时间线左右工具栏。此前排除数字人、人声分离、AI音乐的决定继续有效。以已有134项剪映与31项开源清单为起点，重新核对当前源码与实际运行，不沿用历史完成数量。

宠物成为当前页面的服务入口。剪辑页复用同一个 AICutAgentPanel 和后端 Agent run/事件/工具/草案服务，不创建另一套关键词分发或通用问答冒充执行。宠物内部完整显示对话剪辑、自动成片、模型、技能、追问、运行步骤、失败、停止等现有能力。原 Agent 快捷入口打开同一个宠物页面服务。工程和时间线变化严格隔离，离开页面注销剪辑服务；没有专属服务的页面沿用已接通的通用 CM bridge，并明确真实能力。

新增小型页面服务注册器，只接受页面自身注册的真实 React 面板，不接收模型任意组件或任意接口地址。当前页面服务随页面生命周期更新，保留项目状态和取消机制。独立 AI-CUT 页面补挂现有站内宠物，遵循登录与宠物显示配置，避免重复宠物实例和重复 Agent 执行器。

时间线工具栏按照用户截图对应已有真实功能，将高频切分、左右裁切、删除、撤销/重做、标记、联动、波纹、吸附、跟随等合理摆放。新增入口必须存在执行处理、适用条件和禁用原因；不能靠名称/图标宣称与剪映等价。预览、保存、撤销与导出关系按实际能力记录。

外部对照仅只读，不运行洛水生成代码，不调用付费服务。开源核查仅依靠原仓库/官方文档；记录明确来源与许可，不整体拷贝第三方引擎。更新差异表时按已实测、已接线待验收、部分、缺失和用户排除分别列出；未实现功能继续作为待办，不把本轮局部实现称为全部功能完成。
