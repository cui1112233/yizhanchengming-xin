# V88 Agent 画布外观与动态连线设计

日期：2026-10-19  
状态：设计已确认，等待用户审阅正式文档  
范围：本地 V88 的 `/agent/canvas`，不发布公网

## 1. 目标

把现有 Agent 画布从通用深色后台工作台，重做为更接近专业创作画布的操作体验。参考沈浪超级 AI 画布的布局密度、浮动工具位置、节点层次、设置组织和动态连线体验；不复制其品牌、Logo、名称、素材或原始样式代码。

保留 V88 当前深色配色、品牌内容、项目数据和 Agent 对话。此次不重置项目，不删除消息、节点、连线、执行记录或已有画布内容。

## 2. 已确认范围

- 保留 V88 当前深色配色，不采用参考产品的绿色主题。
- 重做画布的整体外观：顶部栏、左侧浮动工具栏、中央编辑栏、底部缩放栏、节点卡片、分组框、选中状态、背景和右侧 Agent 面板。
- 动态连线默认开启，沿流程方向流动，帮助用户看清执行关系。
- 新增每个项目独立保存的画布外观设置：连线颜色、连线动效、连线粗细、背景网点和辅助线对齐。
- 不做护眼模式。
- 保留现有节点、连线、多选、分组、对齐、等距、撤销、重做、缩放、自动保存、手动保存和保存冲突处理。

## 3. 页面外观

### 3.1 画布工作区

- 中间画布保持全高度，使用细小低对比网点背景，不使用抢眼渐变或大面积装饰。
- 顶部为紧凑项目栏，放置项目入口、项目名、保存状态、手动保存和右侧对话区开关。
- 左上为窄的悬浮竖向工具栏，保留选择、平移、连线和新增节点；每个图标都有中文悬浮说明。
- 顶部中间为悬浮编辑栏，保留撤销、重做、分组、解组、对齐和等距。
- 底部中间为稳定尺寸的缩放栏，保留缩小、当前比例、放大、适合屏幕和聚焦选中。
- 右侧为可收起的 Agent 对话区。收起后画布立即扩展，不保留无效空白。

### 3.2 节点、分组与状态

- 节点使用更轻的卡片层次：清晰标题、简短摘要、状态和版本，不把一张卡做成大面积后台面板。
- 选中节点使用 V88 强调色描边和轻微投影，失败节点使用既有错误色，避免只依赖颜色表达状态。
- 分组框使用半透明边框和可拖动标题，不遮挡组内节点。
- 工具栏、节点和右侧面板的圆角、边框、阴影和间距统一，保持 V88 当前字体、文字对比度和深色主题。

## 4. 动态连线

- 连线按照 `source -> target` 的方向显示轻量流动效果，默认开启。
- 连线颜色和粗细从项目的画布外观设置读取；设置变化后无需刷新即可立即看到。
- 动效不得创建额外业务任务、额外节点或额外网络请求，只对已存在的画布边做渲染。
- 节点与连线数量较多时，前端自动降低动效频率；浏览器标签不在前台时暂停动画；系统要求减少动画时改为静态连线。
- 动效只用于画布关系表达，不代表任务一定正在运行。运行状态仍由节点文字和状态标识表达。

## 5. 画布外观设置

右侧提供“画布外观”入口。面板按行展示设置，每项有当前值和直接可见的预览结果：

1. 连线颜色：从 V88 适配的预设色中选择，不允许输入任意破坏对比度的颜色。
2. 连线动效：默认开启，可手动关闭。
3. 连线粗细：细、默认、粗三档。
4. 背景网点：显示或隐藏。
5. 辅助线对齐：启用或关闭；启用时仅在拖动节点中显示辅助线。

设置均为当前项目独立数据。项目 A 的画布样式不会影响项目 B；刷新、重新登录或重新打开项目后恢复上次保存值。旧项目没有外观设置时，使用本文定义的默认值并在第一次保存时补齐。

## 6. 数据、接口与兼容

- 现有 `agent_canvases` 已保存项目级视图和 revision。实施时新增一个高于当前最大编号的 Goose 追加迁移，为该表增加 `appearance_json` 字段；不得修改、删除或伪造既有迁移记录。
- Go 的画布读写模型增加可选 `appearance` 字段，包含已确认的五项设置和版本号。
- 保存仍走现有同一套 revision 校验与串行保存队列。外观变更与节点变更同样受冲突保护，不能覆盖另一窗口较新的数据。
- 旧项目、旧接口调用方和没有 `appearance` 字段的请求继续可读。服务端负责补默认值，前端不得依赖本地临时数据作为事实来源。
- 不新建第二套画布、第二套保存接口或旧文件写入路径。

## 7. 响应式与可用性

- 桌面端工具栏不得遮住画布主要区域、节点标题或右侧输入框。
- 窄屏端顶部编辑栏可横向滚动；右侧对话区沿用现有底部抽屉方式，底部缩放栏自动上移避免遮挡。
- 图标按钮必须有工具提示和稳定点击区域。
- 动效、选中、失败和保存状态不能只靠颜色，保留文字和图标提示。

## 8. 测试与验收

自动测试至少覆盖：

- 默认外观配置、旧项目默认值和画布设置序列化。
- Go 读写、revision 冲突和追加迁移重复执行。
- 五项设置切换、保存、刷新和项目隔离。
- 动态连线默认开启、关闭后静态显示、减少动画模式和高负载降级。
- 节点选择、连线、分组、对齐、撤销、重做和保存功能在新外观下仍正常。
- 桌面和窄屏下工具栏、对话区、节点和缩放栏不重叠。

本地已登录浏览器验收：

1. 打开现有真实 Agent 项目，确认原有对话、节点、连线和执行记录仍存在。
2. 观察默认动态连线沿正确方向流动。
3. 分别修改五项外观设置，确认即时生效；刷新后确认恢复。
4. 切换另一个项目，确认其外观设置没有被前一个项目影响。
5. 多选节点、分组、对齐、撤销、重做、缩放、保存，并验证对话收起后画布扩展正常。

不以构建通过、HTTP 200、静态截图或未登录页面代替上述验收。
