# 巨量获取重复书籍高亮设计

## 目标

巨量素材解析完成后，让用户在执行前直接看出哪些素材解析到了同一本书。

## 规则

- 按解析结果中的 Book ID 判断重复，保持与当前实际执行阶段的去重规则一致。
- 第一次出现的 Book ID 正常显示。
- 后续相同 Book ID 的行保留在列表中，但使用橙黄色背景，并显示“重复，将跳过”。
- 仅书名相同、Book ID 不同的行不标记，避免误判。
- 切换一条素材关联的平台书籍时，重复标记立即重新计算。
- 错误行继续使用现有红色样式，不改动错误提示。

## 实现边界

- 在现有巨量素材队列工具中增加一个纯函数，返回重复项的位置，便于真实行为测试。
- 创建批次弹窗使用该结果添加重复样式和标签。
- 样式追加到现有水火生产页面样式表，不改动数据提交和后端逻辑。

## 验证

- 单元测试覆盖：相同 Book ID 的第二条被识别；不同 Book ID 不被识别；空 Book ID 不被误判。
- 运行创建批次弹窗相关测试。
- 运行前端构建，确认 JSX 和样式可正常打包。
