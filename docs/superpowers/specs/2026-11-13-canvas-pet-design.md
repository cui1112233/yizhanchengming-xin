# 创作画布页面宠物服务

用户已明确执行画布对标和页面服务切换。基于现有 AgentCanvas、导演方案接口和页面宠物宿主实现，不创建另一套画布或生成接口。

画布内注册专用服务：读取当前项目、已保存版本和选中卡片；自然语言请求先保存画布，再提交已有导演方案接口；显示真实修改清单，确认后通过后端版本校验应用。图片、视频和音频生成仍在现有卡片编辑器中完成，宠物可打开选中卡片，不能将生成方案当作生成结果。嵌入 AI-CUT 和独立 CM 画布使用同一服务；退出画布恢复剪辑服务。不同账号/项目隔离，异步返回不能串项目；保存失败不得发起请求，旧方案不能覆盖新编辑。

对标记录须区分洛水发布包静态观察、当前产品接线和真实供应商验收。保留未完成项，不宣称完整复刻。系统提示词保留在 Go prompt 模块；前端只发送用户输入和结构化上下文。
