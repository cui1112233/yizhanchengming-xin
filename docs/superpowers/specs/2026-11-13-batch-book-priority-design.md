# 批量工厂书籍插队

用户指定批量工厂生产队列：选中一本书点击插队，当前书做完后优先做这一本。并行时不打断任何已开工书，优先取得下一空闲槽位。范围为当前批次，不改变作品库排序，不启动第二个生产任务。

复用持久化自动生产任务：保存去重的优先书ID和书籍插队标记。调度器取得槽位后才原子选择下一本并标记开始，优先顺序不能被提前选取的旧快照覆盖。未纳入当前任务的本批次新书可加入，沿用当前任务预设；运行中和已完成的书拒绝重复插队。多次点击不同书时，最后一次插队排最前；重复同一本不复制任务。暂停状态保留顺序，恢复后执行。

入口：小说列表每本书操作、工作台选中单本后的插队按钮；显示真实等待状态。后端校验账号/批次/书籍归属。没有活跃队列时提示先启动自动生产，插队本身不擅自调用模型。

验证：受控生产服务用闸门挂住A，等待B/C时插队C，放开A后确认A/C/B顺序；重复请求、并行、完成/运行拒绝、账号隔离、重载保持与新书中途加入。实际页面核验入口，禁止用真实收费生成验收。
