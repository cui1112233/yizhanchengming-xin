# AI-CUT 可调整工作台设计

日期：2026-11-10

## 目标

把现有 AI-CUT 页面补成真正可操作的在线剪辑工作台：用户可以拖动素材和时间线片段，可以拖动分隔线改变区域大小，可以分别收起 Agent、素材区和时间线，并且在已有项目内随时新建项目。上一版已经确认的快捷键也要进入正式页面并真实触发已有操作。

## 交互规则

1. Agent、素材区、预览区保持同一行。Agent 与素材、素材与预览之间各有一条竖向分隔线。
2. 上半区与时间线之间有一条横向分隔线。拖动时只改变 CSS 网格尺寸，不改变项目数据。
3. Agent、素材区、时间线各自独立收起；恢复时使用收起前的尺寸。状态写入 `localStorage`，刷新后恢复。
4. 素材卡可拖到同类型轨道。落点换算为时间线毫秒；无兼容轨道时仍可使用原有“加入时间线”自动建轨逻辑。
5. 时间线片段原有横向拖动继续生效，锁定轨道不能移动或接收素材。
6. 顶栏“新建项目”打开已有创建弹窗，成功后切到新项目；空名称、失败、取消沿用真实接口的现有提示和无副作用规则。
7. 快捷键面板列出并触发保存、导出、播放、撤销、重做、刀片、删除、工作台切换和关闭面板。输入框或文本域获得焦点时，不截获普通文字键。
8. 所有颜色继续使用全站主题变量；预览画布保持黑色。尺寸只有合理的最小/最大边界，不写死主题。

## 输入、输出、边界和失败

- 输入：指针坐标、拖拽素材 ID、目标轨道 ID、键盘事件、新项目名称和画面比例。
- 输出：浏览器布局状态、更新后的本地时间线草稿或后端创建的新项目。
- 边界：Agent 56–520px、素材 220–620px、上半区 260px 至可视区减 220px；锁定轨道拒绝落入；输入控件焦点内只处理 Esc 和组合键。
- 失败：不兼容轨道提示“素材类型与轨道不匹配”；锁定轨道提示“轨道已锁定”；无项目或无选中片段时快捷键不伪造成功；创建项目失败显示后端错误。

## 验收

- 单元测试覆盖布局尺寸夹取、素材落点换算、快捷键动作解析和空/错误边界。
- React 页面源码测试确认三个分隔线、独立收起、新建项目入口和快捷键面板存在。
- 前端相关测试及 Vite 构建通过。
- 本地 Go embed 运行后，在 `http://127.0.0.1:4001/ai-cut` 逐项拖动和点击验证。
