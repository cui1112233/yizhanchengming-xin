# 私人漫画单一模型配置设计

## 问题

私人漫画画布同时提供“配置”弹窗和外部文本/图片模型下拉框。两处并非编辑同一状态：弹窗保存账号级剧本默认值，外部下拉保存当前私人漫画草稿；真正生成时优先使用草稿值。因此用户在弹窗修改模型后，当前漫画仍可能继续使用外部下拉保存的旧模型。

## 目标

- 私人漫画只有一个可编辑入口：“配置”弹窗。
- 画布工具栏只读展示当前漫画实际使用的文本模型和图片模型。
- 漫画模式的弹窗只展示与漫画相关的文本模型、图片生成通道和图片模型。
- 漫画模式保存时更新当前私人漫画草稿，不修改账号级剧本默认值。
- 新的私人漫画草稿在模型字段为空时继承账号默认值；继承后成为当前草稿自己的值，不随默认值继续变化。
- 剧本创作原有统一配置与账号默认值行为保持不变。

## 交互

1. 用户进入私人漫画画布，工具栏看到“文本模型：名称”和“图片模型：名称”的只读摘要。
2. 用户点击“配置”，弹窗从当前私人漫画草稿读取文本模型、图片通道和图片模型。
3. 用户点击“应用到当前漫画”，三个字段写回当前漫画草稿并自动保存。
4. 当前漫画后续的资产提取、漫画提示词和图片生成均读取这三个草稿字段。

## 非目标

- 不改变批量工厂模型配置。
- 不改变剧本创作的账号默认配置。
- 不新增“本次覆盖”或第三套配置优先级。
- 不发布线上；本任务先完成本地源码、测试、嵌入构建和 4001 验证。
