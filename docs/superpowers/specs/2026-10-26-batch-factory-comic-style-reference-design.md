# 批量工厂漫画画风与参考图设计

## 目标

在现有批量工厂漫画生产链中加入雪漫画已确认的 25 套画风预设和原预览图，并把画风文字、漫画提示词、资产参考图、漫画全局参考图、本页参考图分别管理。用户仍在现有统一配置、单书配置、资产设置、分镜卡和媒体库中完成工作，不新增独立漫画工厂。

## 概念边界

- 三套漫画生成提示词：`精品商业条漫版`、`剧情漫画融合版`、`轻量分镜版`。它们决定剧情拆分、页面分格、对白、旁白和页面描述格式。
- 25 套画风预设：决定线稿、上色、材质、人物比例和视觉风格。
- 画风预览图：只帮助用户看图选画风，默认不发送给图片 AI。
- 漫画全局参考图：用户明确设置后，同时用于资产图和漫画页；两个使用范围可分别关闭。
- 资产参考图：提供角色、场景或道具的身份与外观特征。
- 本页参考图：只约束当前漫画页。

## 配置与继承

统一配置提供批量默认值，单书配置可以覆盖统一配置。单个漫画页不能覆盖画风，只能增加本页参考图。

漫画配置保存在现有 `aiPromptConfig.comic` 下：

```json
{
  "style": {
    "presetId": "comic-style-01",
    "presetName": "顶级韩漫风格",
    "presetSlot": "batch.comic-style",
    "presetVersion": 1
  },
  "imagePromptPrefix": "用户填写的全局前缀",
  "imagePromptSuffix": "用户填写的全局后缀",
  "globalReferenceImage": {
    "assetId": "系统媒体编号",
    "url": "可供执行器读取的地址",
    "enabled": true,
    "applyToAssets": true,
    "applyToPages": true
  }
}
```

系统预设正文只保存在 Go 后端 prompt 模块中。前端只保存预设编号、名称、槽位和版本，不硬编码提示词正文。

## 页面设计

### 约束设置

- `画风库`使用图片卡片选择器，展示 25 张 `768x1024` 原预览图、名称和分类。
- `图片描述词全局前缀`和`图片描述词全局后缀`允许用户填写自己的补充要求。
- `漫画全局参考图`提供上传、预览、移除，以及`用于资产图`、`用于漫画页`两个开关。
- 选择画风卡片只保存画风预设，不自动把预览图设为参考图。
- 预览图详情提供显式命令`设为漫画全局参考图`，只有用户执行该命令才进入参考图链路。

### 资产设置

- 保留漫画资产提示词、角色、场景、道具和各自参考图。
- 资产文字提取不发送图片。
- 生成资产图时，发送资产自己的参考图；全局参考图启用`用于资产图`时一并发送。

### 分镜卡与媒体库

- 分镜卡保留漫画页提示词和本页参考图。
- 漫画页生成使用统一画风资产图、全局参考图和本页参考图。
- 候选图、主图、漫画页和漫画合集沿用现有实现。

## 后端提示词编译

当前固定的 Q 版画风锁拆成两类：

1. 固定漫画结构规则：分格、阅读顺序、气泡、旁白、文字避让、水印和乱码限制。
2. 可替换画风规则：由 `batch.comic-style` 预设解析。

资产图提示词顺序：

```text
画风预设 + 用户全局前缀 + 资产描述 + 身份保留/忽略原图画风规则 + 用户全局后缀
```

漫画页提示词顺序：

```text
画风预设 + 用户全局前缀 + 漫画结构规则 + 资产一致性描述 + 当前页描述 + 用户全局后缀 + 负面约束
```

后端是最终提示词的唯一编译地点。前端提交漫画页时只提交当前页内容和配置引用，不自行重复拼接画风正文。

## 参考图发送

用户上传的全局参考图进入现有媒体存储并保存稳定资源编号和地址。生成任务由后端生成有顺序的参考图列表，并按图片模型能力交给执行器：

1. 当前页显式参考图。
2. 当前页使用的角色、场景和道具资产图。
3. 已启用的漫画全局参考图。

支持 URL 的接口发送可访问 URL；需要文件内容的接口由服务端或本地执行器转换为文件/base64。模型不支持参考图时，界面必须明确提示并阻止静默丢弃。

## 配置变化与旧结果

画风、全局前后缀、全局参考图或其适用范围改变后，不删除旧资产图和旧漫画页。系统根据生成快照判断旧结果与当前配置不一致，并显示`配置已变化，建议重新生成`。重新生成仍保留旧候选图，用户可以重新选择主图。

## 验收

- 统一配置和单书配置都能打开 25 张画风卡片并保存选择。
- 25 张预览图与 25 条画风预设一一对应，预览图默认不进入生成请求。
- 三套漫画生成提示词与 25 套画风预设在数据和界面上完全分开。
- 资产图和漫画页最终提示词只由后端编译，且不存在固定 Q 版画风覆盖用户选择。
- 全局参考图可以分别用于资产图和漫画页；不支持参考图的模型会给出明确提示。
- 视频模式不使用漫画画风、漫画前后缀或漫画参考图。
- 使用现有书籍和豆包执行器完成资产图、漫画页候选图、主图、漫画合集的本地验证。
