# 批量工厂文本页工作台对齐设计

日期：2026-11-24

## 目标

让文本生成模式沿用漫画生成的工作台逻辑，同时保持文本特有的正文分配、排版编辑和作品封面能力。

## 工作台布局

文本模式的单书行继续保留两个相邻区域，但职责必须分开：

1. `页面内容`：显示当前页分配到的完整正文、页码和字数，支持上一页、下一页切换，不显示提示词。
2. `文字页`：显示当前页已经选定的成品图片，画幅按文本排版配置展示，支持上一页、下一页切换。点击成品图或“查看 / 调整”按钮才打开文本媒体库，并定位到同一页。

页面尚未生成成品图时，`文字页`显示明确的“尚未生成本页”状态，不用正文或媒体库按钮冒充成品图。自动生产进行时，两个区域按当前书状态定时刷新。

## 单书配置

文本模式的单书配置与统一配置使用相同的三类标签：

- `引擎配置`：文本模型、敏感内容处理、AI 修复模型、失败策略、按关键词标红。
- `排版配置`：单页目标字数、内容截取、画幅、字体、字号、字重、行距、段距、边距、对齐、正文颜色、标红颜色、文字高度、正文背景和封面排版。
- `发布配置`：上传人、组织、网站配置档、书籍分类、自动生成合集、自动上传和上传重试次数。

每个字段继续显示“继承”或“本书覆盖”；恢复继承只清除该字段的单书差异，不改统一配置。

## 封面与合集边界

封面是作品外部展示封面，不是文本合集中的正文图片：

- 封面继续在文本媒体库的`封面`标签中单独生成、上传、恢复和预览。
- 文本合集只包含选定范围内的文字页成品图，顺序从文字页第 1 张开始。
- 发布文本合集时，只上传合集的文字页图片；不得把封面插入图片数组，也不得把封面计入 2 到 35 张的合集数量。
- 封面缺失不应阻止仅整理文本合集；只有实际发布入口需要的外部作品封面规则，才按对应后台协议单独校验。
- 已有合集记录仍可保存封面版本引用用于追踪，但这个引用不能转化为合集图片项。

## 数据与交互

工作台读取现有文字页接口，按页匹配当前激活的成品图。正文格和成品图格共享同一个页下标，任一侧翻页时两侧同步切换，避免正文与图片错页。详细候选版本、上传成品页、拆页、合页和排版调整仍由文本媒体库负责。

合集创建沿用当前文字页清单，只冻结文字页成品图。发布端从合集项目构造上传图片数组，不再把封面放在数组首位。

## 错误处理

- 页面读取失败：正文格和成品图格分别显示可读错误，不用旧数据冒充新结果。
- 当前页没有成品图：显示待生成状态，仍允许进入媒体库处理。
- 翻页期间刷新：按页面编号保持选择；页数减少时回落到最后一页。
- 单书配置保存冲突：提示重新打开核对，不覆盖新版本。
- 发布时文字页不足 2 张或超过 35 张：在提交前阻止并说明范围；封面不参与计数。

## 验收标准

1. 文本验收书的`页面内容`显示当前页完整正文，左右翻页后页码、字数和正文同步变化。
2. 同一行的`文字页`显示对应页的真实成品图片，左右翻页与正文格保持同页。
3. 点击文字页成品图后，文本媒体库打开并定位到该页；表格本身不直接展开媒体库。
4. 文本单书配置显示`引擎配置 / 排版配置 / 发布配置`，并正确保存继承和单书覆盖。
5. 创建与发布三页文本合集时，上传图片数量为 3，不是 4；封面不出现在合集预览和上传图片数组中。
6. 本地 4001 的生产模式保存不再出现“生产模式无效”。

## 测试范围

- 前端：正文与成品图同步翻页、无成品状态、点击定位媒体库、单书配置标签和继承行为。
- 后端：合集只含文字页、发布图片数组排除封面、合集数量校验不计封面。
- 真实验收：使用已有文本验收书在本地 4001 检查三页正文、三张成品图、媒体库定位和一次不含封面的合集发布请求构造。
