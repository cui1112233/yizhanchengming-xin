# 资产图片生成独立设置

## 目标

在批量工厂的“编辑资产”窗口中，让每个人物、场景和道具分别选择图片模型与图片画幅。用户不填写时，继续使用资产页顶部的项目默认设置。

## 页面行为

编辑非音色资产时，在提示词区域下方显示两个选择项：

- 图片模型：只显示已启用的图片模型；可清空。
- 图片画幅：`16:9`、`9:16`、`1:1`；可恢复为“使用项目默认”。

音色资产不显示这两个图片相关设置。

## 保存与继承

资产记录保存 `imageModelId` 和 `imageAspectRatio` 两个可选字段。

生成图片时按以下顺序取值：

1. 当前资产的 `imageModelId` / `imageAspectRatio`；
2. 项目资产页顶部的图片模型 / 图片画幅；
3. 现有系统默认值。

清空资产级设置只清除此资产的覆盖值，不改动项目默认设置，也不影响其他资产。

## 生成链路

单个和批量资产图片生成均在创建任务前按上述顺序解析模型与画幅，并把解析后的值写进任务请求。任务历史继续保留实际使用的模型和画幅，便于排查结果。

## 验收

- 编辑人物、场景、道具时可保存并重新打开看到各自的模型和画幅。
- 一个资产设为 `1:1`，另一个保留默认 `9:16`，批量生成后两项任务各自使用正确画幅。
- 清空资产级设置后，生成任务恢复使用项目默认值。
- 音色资产页面不显示图片模型和图片画幅。
