# 批量工厂 Go 直发与 HTTP 插件拆分设计

日期：2026-10-12  
状态：待用户复核  
范围：第一阶段只覆盖批量工厂及其依赖的小说获取、配置和巨量素材链路。

## 目标

运行时不再依赖 Node.js：

`浏览器 → Go（内嵌前端和 API）→ MySQL / Redis / TOS / 外部 HTTP 插件`

React 仍是前端开发方式；构建产物由 Go 的 `embed` 打进单个后端二进制。Node 不能继续承担页面服务、接口业务或 Go 接口转发。

## 当前问题

当前批量工厂仍存在 Node 业务路由和 Node→Go 转发。例如巨量素材为：

`浏览器 → Node /api/shuihuo-production/giant-material-resolve → Go → 青语`

这使错误、鉴权和部署状态分散在两套运行时中。目标链路改为：

`浏览器 → Go /api/shuihuo-production/giant-material-resolve → 巨量素材 HTTP 插件或青语`

## 目标结构

### 1. Go 主服务

- 提供批量工厂的全部 HTTP API。
- 负责用户鉴权、参数校验、业务流程、任务状态和错误转换。
- 用 `embed` 提供 `frontend` 构建产物；未知的非 API 路径回退至前端入口页，支持页面刷新和直达链接。
- 只在 Go 服务中保存主站配置和数据库连接信息。

### 2. 前端

- 保持 React + Ant Design，不重做批量工厂界面。
- `batchFactoryV11` 请求层保持接口语义，但请求目标统一为同域 Go `/api/...`。
- 不再依赖 Node 特有路由、Node 端配置注入或 Node 转发错误格式。

### 3. HTTP 插件

- 每类无法放进 Go 主服务的外部能力，作为独立 HTTP 服务运行，例如巨量素材解析、Windows 本地执行器、第三方模型适配。
- Go 只调用版本化 HTTP 合约，例如 `POST /v1/resolve`；插件不得读取主站数据库，也不得成为前端 API 网关。
- 合约包含请求标识、超时、可重试错误码、结果状态和最小必要返回字段。
- 插件令牌只保存在插件和 Go 的运行配置中；前端不接触令牌。

## 分阶段迁移

### A. 建立 Go 直发基础

1. 固化前端构建输出目录，并由 Go `embed` 提供静态文件和前端路由回退。
2. 增加启动检查，明确报告嵌入前端版本、数据库、Redis 和插件可用性。
3. 本机仅启动 Go 二进制即可打开 `/batch-factory`。

### B. 迁移批量工厂 API

1. 逐项列出前端 `batchFactoryV11` 的请求，并将每个 Node 路由迁入 Go。
2. 先迁移只读能力：批量列表、批次详情、设置和任务状态。
3. 再迁移写入能力：新建批量、书籍信息更新、自动化计划和重试。
4. 每个接口保持当前前端可识别的响应字段和错误码；接口测试同时覆盖鉴权、正常输入和失败输入。

### C. 拆出巨量素材 HTTP 插件

1. 以现有 Node→Go 桥接接口为行为基线，先写 Go 侧插件客户端和契约测试。
2. 插件提供解析和 OCR/执行任务状态；Go 负责把插件结果写入主站任务状态。
3. 插件故障返回明确的不可用/超时/上游失败状态，不再统一压缩成“解析失败”。

### D. 切换与删除

1. 本机 Go 版完成端到端验收后，停止批量工厂对应 Node 路由的调用。
2. 保留旧 Node 代码到回归完成；不在同一次切换中删除未迁移模块。
3. 批量工厂稳定后，才按同一模板迁移小说获取、剧本、配音和其他页面。
4. 全部模块完成并验收后，删除 Node 运行时、Node 业务路由和 Node 发布链。

## 验收标准

- 只启动 Go 主服务时，`/batch-factory` 可打开、刷新和直达。
- 新建批量、读取原文、保存配置、创建任务、查看状态均由 Go API 成功完成。
- 巨量素材请求路径中没有 Node 进程；Go 只通过 HTTP 插件调用外部能力。
- 主站失败信息能区分主站错误、插件不可用、插件超时和上游失败。
- 自动化任务重启后可从 MySQL/Redis 中恢复，不依赖 Node 内存状态。
- 前端构建、Go 单元/接口测试及一次真实浏览器批量工厂流程均通过。

## 非目标

- 第一阶段不修改批量工厂产品界面，也不改变现有业务流程。
- 第一阶段不发布公网、不删除现有 Docker 基础设施、不删除尚未迁移的 Node 模块。
- 不将插件实现混入 Go 主站业务包；主站与插件只以 HTTP 合约连接。

## 回退

在本机验收期，保留现有 Node 运行路径作为只读对照。Go 版出现接口或插件故障时，恢复到已记录的稳定 Git SHA 和既有运行配置；不以线上临时改文件替代源码修复。
