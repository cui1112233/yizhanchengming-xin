# 批量工厂漫画生产模式设计

> 本规格替代 `2026-10-18-batch-factory-comic-mode-design.md` 中“视频和漫画可并行生产”的部分。后者可保留为历史设计记录，但后续实现以本规格为准。

## 目标

在现有批量工厂中，把一本小说切换为“视频生产”或“漫画生产”之一。漫画生产复用小说导入、单书配置、分镜卡和媒体库，不新增第二套工厂入口。

漫画模式完成以下闭环：漫画资产 -> 漫画分镜提示词 -> 分镜漫画页候选图 -> 主图 -> 漫画合集。本期不实现漫画合集上传后台的接口、文件格式或上传路径。

## 非目标

- 不改变现有小说获取、视频资产、视频分镜、视频任务、视频合成和视频上传链路。
- 不把漫画页拼成长图，不转为视频，不叠加后期文字。
- 不实现上传后台；只保留漫画合集的可上传状态和后续接口位置。
- 不在前端硬编码系统提示词正文；提示词选择和冻结仍由后端提示词模块负责。

## 生产模式与配置

每本书只有一个当前生产模式：`video` 或 `comic`。

单书配置继续显示截图中的两组配置：

- 视频生成开关和视频提示词；
- 漫画生成开关、漫画提示词和图片描述词推导。

开关规则：

1. 默认模式为视频：视频开、漫画关。
2. 打开漫画生成，自动关闭视频生成并将当前模式改为 `comic`。
3. 打开视频生成，自动关闭漫画生成并将当前模式改为 `video`。
4. 两个开关不允许同时打开或同时关闭。
5. 切换模式只改变“当前执行哪条链”，不得删除另一条链已经保存的提示词、资产、候选图、主图或结果。
6. 漫画模式必须已选择漫画提示词，才能提取漫画分镜提示词或生成漫画页。

服务端以一个规范化的书级 `productionMode` 保存最终状态；前端的两个开关只是该字段的互斥表现，不能分别写出矛盾数据。

漫画生成区的配置顺序固定为：

1. 漫画生成开关；
2. 漫画提示词：选择画风、版式、文字 UI 和叙事节奏预设；
3. 图片描述词推导：选择将漫画分镜转换为图片模型 `image_prompt` 的系统推导方案。

图片描述词推导的结果属于每个分镜的漫画页记录，用户可在分镜卡中查看和编辑；点击“生成漫画”时以该结果为图片模型输入。

## 漫画资产

资产编辑弹窗继续复用现有页面、现有“选择资产提示词”下拉框和现有角色/场景/道具页签；不增加额外的“漫画资产提示词”控件。

- 视频模式下，“选择资产提示词”继续显示和使用现有视频资产预设。
- 漫画模式下，同一个下拉框显示可用漫画资产预设，包括“VIP 智能角色推导”这一普通系统提示词选项；它不对应会员、付费或权限判断。
- 视频资产维持当前 `source=director` 和 `source=manual` 行为。
- 漫画资产使用现有 `BookAsset` 模型，但固定 `source=comic`。
- 漫画资产提取只读取所选的“漫画资产提示词”，并独立生成角色、场景、道具；不会覆盖视频资产。
- 漫画资产图继续复用现有候选图、上传图片、选主图、单资产模型和画幅能力，但图片只能归属漫画资产。
- 漫画分镜提示词只可读取 `source=comic` 的漫画资产和它们的主图；视频提示词不读取这些资产。

## 分镜与漫画页

现有导演分镜决定剧情顺序；漫画模式中每一个既有分镜对应一个漫画页，不修改导演分镜库存。

“漫画获取 -> 提取”逐分镜生成并保存 `comicPrompt`。提示词必须只包含漫画资产、漫画风格、分格、动作、表情、旁白和对白要求；不得带入视频时长、运镜、音频、配音或视频模型指令。

分镜卡在漫画模式下：

- 显示并编辑“漫画分镜提示词”；
- 将“生成视频”替换为“生成漫画”；
- 将“重新生成视频”替换为“重新生成漫画”；
- 图片模型为当前分镜的 `comicPrompt` 返回一张或多张候选漫画页；
- 用户可以重试、上传补图，并为该分镜选定唯一主图。

候选图和主图不能复用角色、场景、道具的资产图记录。实现应新增“分镜漫画页”和“漫画页候选图”记录，以 `batchId + bookId + videoId` 绑定到对应分镜，保存提示词快照、图片模型、画幅、存储引用、状态和主图标记。

## 媒体库与漫画合集

媒体库新增“漫画页”和“漫画合集”标签：

- **漫画页**：按分镜顺序显示候选图、主图、重试和补图操作。
- **漫画合集**：不是视频合成。它收集全部分镜的主图，保存小说、书籍、分镜顺序和主图引用，成为一份待上传的漫画作品集合。

漫画模式下，原视频“合成”入口和文案改为“漫画合集”。生成漫画合集前，服务端必须验证当前书每个有效分镜都有主图。缺少主图时返回缺失分镜清单，不可跳过分镜、不可拿候选图代替主图。

漫画合集生成后显示“漫画合集已就绪”。它不进行图片拼接，不调用 FFmpeg，不触发视频合成，也不调用上传后台。本期仅保存合集及其排序快照，给后续上传路径使用。

## 后端边界与持久化

新增或扩展的后端边界：

- 书级生产模式的校验与保存；
- 独立的漫画资产提取阶段；
- 独立的漫画提示词提取阶段；
- 漫画页图片生成、候选图管理、主图选择；
- 漫画合集创建、读取和完整性校验。

MySQL 迁移必须追加，不能修改已经执行的迁移。漫画页候选图的图片二进制继续使用既有本地制品/TOS 边界，MySQL 只保存归属、排序、状态、模型、提示词快照与存储引用。Redis 只用于异步任务、重试、锁和短期状态，不能成为漫画页或漫画合集的事实来源。

## 页面状态和异常

- 漫画模式未选择漫画提示词：提示选择提示词，禁止提取和生成。
- 漫画资产未生成：提示先提取漫画资产，禁止提取漫画分镜提示词。
- 某分镜没有 `comicPrompt`：只禁用该分镜的生成漫画操作，保留编辑和重新提取入口。
- 图片模型不可用或生成失败：记录到该分镜漫画页任务，可针对该分镜重试，不影响其他分镜的主图。
- 漫画合集缺少主图：展示缺失分镜并阻止建立合集。
- 切回视频模式：漫画数据完整保留；视频流程不读取漫画数据。

## 验收标准

1. 默认单书显示视频模式；两个生产开关始终互斥且至少有一个开启。
2. 漫画模式可以选择漫画资产提示词和漫画提示词，并分别冻结后端已发布预设正文。
3. 漫画资产、漫画资产图不覆盖视频资产和视频资产图。
4. 每个分镜可独立保存漫画提示词、候选漫画图和唯一主图。
5. 漫画模式的分镜按钮、媒体库标签和“漫画合集”文案正确，且不创建视频任务。
6. 漫画合集只由全部分镜主图按顺序组成；缺图时不能创建。
7. 视频模式回归通过：视频提示词、视频生成、视频媒体库和视频合成不受影响。
8. 前端构建后通过 Go embed 的单二进制运行路径验证；本期不发布、不调用图片模型、不调用上传后台。
