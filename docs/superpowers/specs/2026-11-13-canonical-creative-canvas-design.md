# 统一创作画布入口

用户已批准：CM作为所有创作项目的总入口；AI-CUT打开当前工程的同一张画布，内容共用，减少重复入口和搬运。

保留现有按用户/剪辑工程确定的画布ID，不迁移、不复制旧数据。AI-CUT保存当前时间线后，确保绑定并进入唯一 `/agent/canvas` 工作区；不再挂第二套画布页面。CM打开绑定项目时，由服务端核实所属剪辑工程，并显示返回剪辑、目标时间线、发送剧本、送入剪辑操作。普通CM项目不显示无目标的交接按钮。

画布只有AgentPageV2的保存队列。交接必须先可靠保存，再从服务端读取实际素材/卡片。发送剧本使用明确选定时间线的最新版本并校验冲突；跨项目返回不能跳转或改另一个项目。工程归属由服务端确定，URL只携带时间线提示；失效目标明确报错，不悄悄写入默认线。历史独立画布链接继续可用。

仅本地v88，不建分支、不推送、不公网发布、不调用付费生成，保护无关dirty修改。
