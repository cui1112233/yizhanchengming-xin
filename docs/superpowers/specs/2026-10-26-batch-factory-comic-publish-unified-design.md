# 批量工厂漫画发布统一设计

## 目标

漫画模式下，“统一配置 -> 发布统一”只展示漫画发布需要的默认值，不再展示视频管理系统的登录、网站配置和视频上传规则。

## 界面

- 制作者管理员账号：手动填写一次，后续每本书自动继承。
- 默认音频分类：可选数字编号，不填写表示漫画发布时不提交音频分类。
- 作品匹配方式：默认按书名自动匹配，也可以改为发布时手动选择。
- 页面明确说明图片顺序、宽高、格式、签名和上传重试均由系统自动处理。

## 保存

漫画发布值保存到统一配置的 `comicPublishSettings`，与现有视频 `publishSettings` 分开，切换生产模式不会互相覆盖。

## 边界

本次只完成统一配置的展示和保存入口，不调用外部上传接口，不上传漫画，不消耗任何生成额度。外部作品匹配和漫画合集上传在后续接入时读取这里的默认值。

## 验收

- 漫画模式的“发布统一”能看到三个漫画字段，且不出现视频管理系统配置。
- 视频模式仍保持现有发布统一内容。
- 保存后重新打开统一配置，已填写的漫画发布值仍然显示。
