# 批量测书剩余功能

沿用用户批准的紧凑手机布局与线上功能一一对应方案。独立的账号选择器只给测书/批量改文请求加线上同名账号头；切换时卸载旧工作区，不能把此选择带进全局任务统计。主管仅管理绑定组员，开发者按线上账号目录，普通成员仅自己。

更多工具增加自动队列、当前批次、知识库。队列开启前说明费用，暂停不冒充停止已运行的单项；计数按当前批次/日期。知识库三类支持按原集合编辑、版本防覆盖、删除确认；优化会调用AI，独立确认。列表分页避免再次因全部绘制而卡住。

当前批次入厂携带明确正文版本、原文和分类来源，先预览再创建待配置批次，绝不自动生产。账号属于非本人时不允许把他人正文导入当前登录人的生产库。启动结果未知持久化并展示最近作业供核对，不用时间猜测自动重试。

检查：契约测试覆盖账号隔离、版本、队列范围和实际正文；交互测试覆盖只读打开、保存与确认；类型/微信编译/全量回归；原生只读，不消耗AI额度。
