# 资产参考页面视觉对标设计

## 目标

保留一战晟铭左侧导航、登录状态和主题系统，把 `/plugins` 内的“资产参考”内容区按用户提供的洛水参考图一比一重做。功能调用仍使用一战晟铭自己的模型目录、Agent 素材和图片生成任务。

## 页面骨架

1. 顶部第一行是返回按钮、`插件市场 > 资产参考` 面包屑，最右是关闭按钮。
2. 第二行是图片图标、标题、说明和绿色 `已授权` 状态，不再使用“已接入一战晟铭”胶囊。
3. 主体左右分栏：左侧结果工作区约占 74%，右侧参数栏约占 26%，二者在桌面宽度下从标题下方一直延伸到底部。
4. 左侧依次为搜索与批量工具条、`生成结果 0/0` 标题、浅灰色大结果画布；空状态垂直居中。
5. 右侧依次为模型、分辨率、六种图片尺寸、数量、参考图片、提示词；`AI生图` 固定在控制栏底部右侧。

## 参考图必须出现的控件

- 搜索框、全选、全部删除、下载、批量删除。
- 模型下拉、1K/2K/4K、16:9/9:16/21:9/1:1/3:4/4:3、数量。
- `预设` 和 `参考库` 两个入口。
- 大尺寸虚线参考图上传框，支持点击、拖拽和粘贴。
- 提示词文本框，文案提示可用 `@` 引用参考库卡片。
- 右下角黑色 `AI生图` 按钮；运行中显示取消操作。

## 交互边界

- `全选` 只选择当前搜索结果。
- `下载` 和 `批量删除` 在没有选择时禁用。
- `全部删除` 在没有结果时禁用，并仅删除本地结果索引，不删除服务器素材。
- 单击结果卡片切换选择；选择状态必须有明显边框和勾选反馈。
- `预设` 打开轻量参数预设弹窗；可保存当前模型、分辨率、比例和数量到浏览器本地。
- `参考库` 展示本工作台已经上传的参考图片并允许再次选用；第一版不复制洛水私有参考库接口。
- 关闭按钮与返回按钮均回到插件市场。

## 视觉规则

- 使用一战晟铭现有主题变量，明亮主题下对齐参考图的白底、浅灰画布、细边框和紧凑间距；深色主题使用同一结构的主题色。
- 内容区最大宽度取消居中卡片感，铺满可用主区。
- 右栏宽度固定在 390 至 420 像素；结果区最小宽度为 640 像素。
- 桌面优先；851–1250 像素保持压缩双栏，宽度不足 850 像素时才改为上下布局，并保持结果区在参数区之前。

## 验收

- 自动结构测试必须验证所有参考图控件和关键类名。
- Vite 生产构建通过。
- 重新嵌入 Go 程序并启动 4001。
- 使用当前登录浏览器，在 `/plugins` 点击资产参考，按参考图核对结构和空状态；不发起付费生图。
