# AI-分段独立实现规格（洛水 v2.9.0 对照）

## 范围和边界

本规格只描述可观察行为和可验证规则，用于在一战晟铭中独立实现 `AI-分段`。不复制洛水原代码、密钥、私有接口、专有资源或原提示词；模型提示词由一战晟铭后端 `prompt` 模块自行编写，前端不保存提示词正文。

当前实现对象是插件市场中的 `AI-分段`，不是 AI-CUT，也不是 momo 画布。

## 用户链路

1. 用户在插件市场点击 `AI-分段`，进入独立工作台。
2. 用户选择以下四种模式之一：
   - 按字幕切割：视频 + SRT。
   - 按剪映主轨道：视频 + 剪映 `draft_content.json`。
   - 按剪映文本轨道：视频 + 剪映 `draft_content.json` + 文本轨道。
   - AI 分段：视频 + 剪映 `draft_content.json` + 剧本 + 文本模型。
3. 系统先解析可切边界并显示预览；AI 模式先让模型建议剧情切点，再把建议校正到真实片段边界。
4. 用户确认后执行切割，获得按集编号的 MP4 压缩包。
5. 运行中显示阶段、百分比和日志；成功显示集数、片段数、字幕数和警告。

## 输入

### 公共输入

- `mode`：`subtitle`、`main-track`、`text-track`、`ai`。
- `video`：可读取的视频文件。切割前必填。
- `outputResolution`：保持原始、1080p、720p；AI 模式默认 1080p。
- `fps`：保持原始、24、25、30；AI 模式默认 30。
- `frontCount`：前段长集数量，默认 2，范围 0-20。
- `frontMin` / `frontMax`：默认 90 / 180 秒。
- `backMin` / `backTarget` / `backMax`：默认 45 / 60 / 90 秒。

### 模式输入

- 按字幕：SRT 文本，至少一条合法字幕。
- 按主轨：剪映草稿 JSON，至少一个视频轨和一个正时长片段。
- 按文本轨：剪映草稿 JSON，并选中一个至少含一段文本的文本轨。
- AI：剪映草稿 JSON、非空剧本、可用文本模型；剧本只向模型发送前 120000 个字符并给出截断警告。

## 输出

分析成功返回：

- `episodes[]`：`index`、`startClip`、`endClip`、`startSeconds`、`endSeconds`、`durationSeconds`、`reason`。
- `clipCount`：主轨片段数。
- `subtitleCount`：可用于理解剧情的字幕数。
- `totalSeconds`：主轨总时长。
- `warnings[]`：字幕缺失、剧本截断、单片段超限、短尾合并等。

切割成功返回 ZIP，文件名为 `第001集.mp4`、`第002集.mp4`……；任何一集失败时整个请求失败，不返回伪成功压缩包。

## 核心规则

1. 所有集连续、无重叠、无遗漏，第一集从第 1 个片段开始，最后一集覆盖最后一个片段。
2. 只能在已解析出的边界切割，绝不切开一个剪映主轨片段。
3. 模型只提出剧情切点，不直接决定最终时间；服务端必须校正、补尾和验证。
4. 建议切点重复、倒序、越界或类型错误时忽略；最终没有有效切点时使用确定性时长规划，不能返回空结果。
5. 尾部短于 `backMin` 时优先并入上一集；若只有一集则保留。
6. 单片段本身超过上限时允许该集超限，并生成明确警告。
7. AI 返回不是合法 JSON 时，以更严格的 JSON 要求重试一次；第二次仍失败才提示失败。

## 边界处理

| 场景 | 处理 |
|---|---|
| 空视频 | 分析可以预览；点击切割时提示“请选择视频文件” |
| 空 SRT / 无合法时间码 | 提示“没有读取到有效字幕” |
| 草稿 JSON 损坏 | 提示“剪映草稿无法解析”并保留已选文件 |
| 草稿没有视频片段 | 提示“主视频轨道没有有效片段” |
| 文本轨为空 | 提示“请选择包含字幕的文本轨道” |
| AI 模式空剧本 | 提示“请先提供剧本文稿” |
| 未选模型 | 提示“请选择模型” |
| 重复点击分析/切割 | 按钮进入运行状态并禁用，不产生第二个任务 |
| 用户关闭/取消 | 尚未开始则直接退出；运行中必须触发请求取消并清理临时文件 |
| FFmpeg 缺失 | 显示项目已有的 FFmpeg 自检错误和安装位置，不吞掉错误 |
| 模型失败 | 提示“文本模型请求失败”，保留输入以便重试 |

## 失败提示

错误必须来自实际失败阶段，并使用用户能处理的中文：输入错误用 400，认证错误沿用统一登录提示，模型不可用用 502/503，FFmpeg 或文件处理失败用 500。前端不得把错误改写成“开发中”或“尚未接入”。

## 对照测试

同一组片段和字幕分别送入规则实现与洛水可观察结果，至少覆盖：

1. 正常：8 个片段，能分成 3 集。
2. 空值：空剧本、空草稿、空字幕、空视频。
3. 重复：重复切点、重复点击分析、重复点击切割。
4. 错误：损坏 JSON、倒序切点、越界切点、模型非 JSON、FFmpeg 缺失。
5. 取消：分析中取消、切割中取消、关闭工作台。
6. 边界：单片段超过 90 秒、最后不足 45 秒、无字幕但有主轨。

完成标准不是“页面能打开”，而是上述输入得到可解释结果、真实导出文件和可复现失败提示。
