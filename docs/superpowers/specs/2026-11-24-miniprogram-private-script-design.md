# 私人定制手机工作区优化

日期：2026-11-24。范围只限私人定制剧本页，不改漫画、AI-CUT或其他模块。

## 当前证据

已在登录后的https://yzcm.site/script只读核对：原文→人物场景→创作结果；可手动添加人物、场景；人物字段名称/身份/外形/性格；场景字段名称/时段/氛围/描述；提取模板、音频匹配、连续/爆款/分段开头、10s/15s、输出模式、约束以及独立剧本历史入口。打开人物与模板弹窗后均取消，未输入正文或保存数据、未收费生成，结束返回原batch-factory页。

## 本轮方案

沿用AI-CUT确定的紧凑中性深浅主题、青色主动作、16px左右留白、14px正文、18px标题。原文与人物场景分成轻量步骤，创作设置收进独立底部面板；原文上保留提取模板/文本模型入口，避免生成前找不到必要选项。大文本滚动、长名称换行；主动作固定底部且留安全区。

人物场景编辑：人物/场景切换，点一个编辑一个；可手动添加、移除，外层应用后才进入当前创作，取消不改变已有内容。新增字段与网页一致，保留旧字段和参考图元数据；选中主角按ID匹配。保留参考图片上传和既有生成接口，不额外引入系统提示词。

创作设置：文本/图片模型、提取模板、开头模式、输出模式、时长均按真实ID/索引选择，不按显示名称查第一条；过滤禁用模型，缺选项明确提示。原文变更清除过期资产/结果；人物和设置变更使旧结果失效，禁止旧分镜沿用新配置。同步锁保护提取/生成/配音，迟到返回和账号切换不能覆盖当前内容。

历史：自己的底部列表读取/api/history，选择后GET具体entry恢复；与总任务页分离，不删除线上记录。未保存内容恢复前确认。结果页保留真实输出、复制与已有视频接口，未生成不伪造结果。

## 验收与边界

模拟接口检查同名模型、双击锁、手动人物、取消/应用、历史恢复、迟到回调与输入失效；全量测试、类型检查、构建和WXSS处理后微信打开。运行只做不收费操作，不新建线上测试历史；真实AI提取/生成/出图仍需专门验收。网页完整改写、智能补全、跨端草稿同步和高级分镜能力不在本轮宣称对齐。
