# 小程序“我的空间”身份卡氛围增强设计

日期：2026-11-24  
范围：微信小程序“我的空间”页面顶部身份卡  
参考：用户提供的紫色晚霞、薰衣草花田、漂浮花瓣身份卡

## 目标

在不改动页面其余卡片和功能的前提下，让顶部身份卡接近参考图的层次与生命力，解决当前卡片背景单薄、视觉焦点弱、缺少动态氛围的问题。

## 明确边界

- 左侧圆形内容始终是当前用户的真实头像；没有头像时继续使用姓名首字母，不换成双龙或虚构人物。
- 名称、角色、团队、进行中数量、已完成数量继续来自真实接口，不把参考图里的 `3`、`28` 等示例数字写进图片或源码。
- 只优化身份卡，不顺带调整创作额度、入口列表、底部导航或其他页面。
- 不上传、不部署，不新增分支。

## 视觉结构

身份卡保持现有横向信息结构，分为四层：

1. 背景层：使用项目现有晚霞与薰衣草视觉资产，在卡片底部保留清晰花田，上半部适度压暗以保证文字对比。
2. 光效层：卡片边缘使用细紫色高光，底部加入柔和粉紫雾光；头像外圈使用紫蓝双层光环与轻微呼吸光。
3. 内容层：左侧为真实头像；右侧依次为名称和角色标记、欢迎语、团队或账号、真实任务统计。
4. 粒子层：6 至 8 枚透明花瓣图片在卡片内缓慢漂移、旋转并淡入淡出。粒子不能遮挡名称、任务数字和点击区域。

## 动效

- 使用小程序支持的 CSS 关键帧，不引入 Canvas 粒子引擎。
- 花瓣分成三条运动轨迹，周期约 9 至 16 秒，起点、大小、透明度和延迟错开，避免机械同步。
- 头像光环周期约 4 秒，只做轻微亮度和阴影变化，不缩放头像本身。
- 粒子容器裁切在身份卡圆角内，且设置为不可点击。

## 性能与无障碍

- 花瓣使用单个小尺寸透明 WebP 资产重复渲染，不生成多张大图。
- 开启“降低透明度”时停止花瓣和头像呼吸动画，并提高卡片底色不透明度。
- 系统启用减少动态效果时停止动画，保持静态花瓣构图。
- 不增加接口请求，不改变任务和账号数据加载流程。

## 交互与异常状态

- 点击头像仍执行原有头像选择和上传流程。
- 头像加载失败或没有头像时显示现有首字母占位，不显示破图。
- 任务统计未返回时继续显示 `—`，真实返回 0 时显示 0。
- 页面加载、登录失效和网络错误状态保持现有逻辑。

## 验收标准

- 微信开发者工具 iPhone 15 视口中，卡片具有明显的晚霞、薰衣草、光环和漂浮花瓣层次。
- 头像仍为当前用户真实头像，名称和任务数据与接口一致。
- 花瓣持续缓慢移动，但不遮挡正文和统计数字。
- 卡片内无文字挤压、头像变形、粒子越界或横向溢出。
- 开启“降低透明度”后动画停止，文字对比度提高。
- 相关单元测试、全量小程序测试和小程序构建通过，并提供微信开发者工具截图作为视觉证据。
