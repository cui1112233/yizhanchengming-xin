# CM Agent 与 Duet 可点击 HTML 原型设计

日期：2026-11-09

状态：待用户审阅

上位设计：

- `2026-11-09-luoshui-v29-v88-parity-master-design.md`
- `2026-11-09-agent-skill-workspace-parity-design.md`

范围：先交付一个不连接真实后端的独立可点击 HTML 原型，用于确认入口、布局、点击链路和状态变化；原型通过后再设计正式 React、Go 和数据服务实施计划。

## 1. 目标

原型必须同时满足两个要求：

1. 对照参考应用 v2.9.0 已确认的工作模式切换、Agent、技能、自动任务、工作区和 Duet 使用链；
2. 延续一战晟铭现有页面的品牌、主题、画布、故事板、素材和任务结构，不复制参考应用的皮肤、Logo、编译代码或系统提示词。

本原型不是静态效果图。用户必须能在浏览器中点击按钮、切换工作模式、打开页面和弹层、改变状态、模拟运行并刷新恢复。

## 2. 交付形态

采用单个独立 `index.html`，CSS、JavaScript 和演示数据都内嵌在文件中；内部使用页面状态模拟路由，不直接修改 `localhost:4001` 的正式页面。

推荐交付位置：

```text
docs/prototypes/cm-agent-duet/index.html
```

约束：

- 双击文件或通过本地静态服务器即可打开；
- 不需要登录、数据库、模型密钥和网络请求；
- 不安装新的业务后端；
- 使用演示数据；
- 使用 `localStorage` 保存原型状态；
- 不读取或包含真实系统提示词、账号数据和参考应用本地数据；
- 原型文件不进入正式 Go embed，除非后续用户明确批准。

## 3. 左上角工作模式切换

### 3.1 固定结构

左侧栏顶部使用工作模式切换器，不再把 Agent 当成普通侧栏菜单。切换器包含三个并列模式：

| 模式 | 作用 |
|---|---|
| 一战晟铭 | 当前内容生产主工作台，保留现有业务导航 |
| Agent代理 | Agent 会话、技能、自动任务和项目工作区 |
| Duet | 频道式短剧制片厂和员工 Agent 协作 |

“一战晟铭”本身就是内容创作模式，不新增“内容创作”这一名称。

### 3.2 点击行为

点击当前模式后展开下拉菜单，显示三项和当前选中标记。选择另一项后：

1. 更新左上角当前模式；
2. 整体替换左侧导航；
3. 切换中央工作区；
4. 恢复该模式上次打开的页面和项目；
5. 保存到 `localStorage`；
6. 关闭下拉菜单。

设置、主题、账号和退出位于侧栏底部，三个模式共用。

## 4. 一战晟铭模式

该模式用于证明工作模式切换不会破坏当前网站结构。原型展示与当前 V88 相符的主要入口，例如首页、私人定制、小说获取、水货生产、配音和设置。

原型不重做这些业务，只需满足：

- 点击导航能切换对应的示意页面；
- 返回 Agent代理或 Duet 后，各自状态仍存在；
- 重新回到一战晟铭时恢复上次选中的导航；
- 品牌和现有业务名称不被参考应用名称替代。

## 5. Agent代理模式

### 5.1 左侧导航

Agent代理模式使用同一条主侧栏，内容替换为：

1. 新 Agent 会话；
2. 自动任务及数量；
3. Agent 技能及数量；
4. 项目标题；
5. 添加工作区；
6. 工作区列表。

不得同时显示一战晟铭业务菜单，也不得再增加第二条固定侧栏挤压主内容。

### 5.2 新 Agent 会话

点击“新 Agent 会话”后显示：

- 工作区选择或新建工作区；
- 创作目标输入；
- 主模型、工作模型和思考强度；
- 计划模式、自动审批、完全运行三档权限；
- 附件、项目文件和素材；
- `/` 技能选择入口；
- `@` 统一引用入口；
- 开始创作按钮；
- 右侧执行计划和运行状态。

原型中的一次完整模拟链为：

```text
输入目标
  → 选择技能和引用
  → 选择权限模式
  → 开始创作
  → 分析需求
  → 生成计划
  → 等待确认
  → 继续执行
  → 生成故事板或画布节点
  → 产物写入项目
```

### 5.3 `/` 与 `@`

输入 `/` 或点击技能按钮后，在输入框上方打开选择器，包含已开启技能、MCP、自动任务和思考强度。选择项目以可删除胶囊形式进入输入区。

输入 `@` 或点击引用按钮后打开统一引用选择器，包含：

- 技能；
- 自动任务；
- MCP；
- 项目文件；
- 项目素材；
- 画布节点；
- 故事板镜头。

选择结果使用稳定演示 ID 保存。刷新后恢复；删除引用后立即从输入区移除。

### 5.4 权限模式

| 模式 | 原型表现 |
|---|---|
| 计划模式 | 生成计划后停止，只显示计划 |
| 自动审批 | 只读步骤自动完成，写入和生成进入等待确认 |
| 完全运行 | 按计划连续模拟执行，但删除、发布和付费生成仍显示确认 |

切换模式后，说明文案和模拟运行的停顿位置必须同步变化。

### 5.5 Agent 技能中心

点击“Agent 技能”进入完整宽屏页面，顶部栏目为：

- Skills；
- MCP；
- Codex。

Skills 栏提供：

- 搜索；
- 分类筛选；
- 全部开启和全部关闭；
- 导入 Skill；
- 管理执行器；
- 技能卡片；
- 使用帮助。

技能卡片显示名称、稳定 ID、版本、说明、来源、作者、运行环境、启用开关和详情入口。点击详情后从右侧打开抽屉，显示用途、触发方式、输入、输出、工具需求和版本，不显示系统提示词正文。

技能启停状态与会话中的 `/` 选择器联动。关闭的技能立即从可选列表消失，重新开启后恢复。

MCP 和 Codex 栏展示连接状态、可用能力、缺少配置和无权限等演示状态，并提供详情交互；原型不发起真实授权或外部连接。

### 5.6 自动任务

自动任务页面展示启用、暂停、运行中和失败状态。用户可以：

- 搜索和筛选；
- 新建自动任务；
- 设置工作区、目标、模型、权限、技能和周期；
- 手动运行；
- 暂停和恢复；
- 查看运行历史；
- 点击一次运行进入对应 Agent 会话。

新建任务使用居中弹窗。保存后任务出现在列表，状态可通过演示按钮变化。

### 5.7 项目工作区

点击项目后进入当前 V88 工作区结构，顶部包含：

- 画布；
- 故事板；
- 素材；
- 任务。

四个视图必须保留技能、权限、附件、`/` 和 `@` 入口。故事板不得隐藏技能和 Agent 操作。

运行结果可以点击定位到演示画布节点、故事板镜头或素材卡片。任务视图展示排队、执行、待确认、成功、失败、取消、继续和重试状态。

### 5.8 执行区

右侧执行区按事件顺序显示：

- 读取项目资料；
- 调用 CM 技能；
- 生成计划；
- 工具调用；
- 等待用户确认；
- 生成故事板或画布节点；
- 产物；
- 失败原因和恢复操作。

按钮包括停止、继续执行、调整后再执行和从失败处重试。每个按钮必须改变可见状态。

## 6. Duet 模式

### 6.1 作用

Duet 是频道式短剧制片厂，不是第二个普通聊天页。使用链为：

```text
项目
  → 工作频道
  → 员工 Agent
  → 分派任务
  → 审核与返工
  → 接力执行
  → 定时任务
  → 产物归档
```

参考产品中的品牌称呼进入 V88 后统一转换为 CM。Duet 总管显示为“CM Duet”，不得出现“洛水”“小洛”或“洛Duet”。

### 6.2 页面结构

Duet 左侧导航包含：

- 项目；
- 频道；
- 员工；
- 任务；
- 接力看板；
- 定时任务。

中央区域展示当前频道的对话、任务卡片和产物。右侧展示员工状态、任务详情或接力进度。

### 6.3 可点击交互

原型至少演示：

- 创建和切换项目；
- 切换剧本生产线、资产工坊、分镜台等频道；
- 查看 CM Duet、编剧、审校、资产和分镜员工；
- 添加任务并选择员工；
- 将任务转交给另一员工；
- 给运行中的任务补充要求；
- 取消、重跑和查看失败原因；
- 审核通过；
- 退回上一棒返工；
- 达到最大返工轮次后等待用户决定；
- 查看接力步骤和已生成文件；
- 新建、暂停和恢复定时任务。

Duet 演示数据与 Agent 项目使用同一组项目 ID 和产物 ID，表现“协作编排和项目生产共用正式项目”，不在原型中制造两套互不相通的数据。

## 7. 页面布局与主题

### 7.1 布局

- 左侧只有一条固定主侧栏；
- 左上角为工作模式切换器；
- 中央为当前模式的主要工作内容；
- 宽屏时右侧显示对话、执行计划或对象详情；
- 窄屏时右侧改为抽屉；
- 技能中心等管理页面可占用完整主区域；
- 主内容不能被固定侧栏、浮层或右侧栏遮挡。

### 7.2 弹层

| 操作 | 形式 |
|---|---|
| 工作模式切换 | 左上角下拉菜单 |
| `/` 与 `@` | 输入框上方浮层 |
| 技能详情 | 右侧抽屉 |
| 新建工作区 | 居中弹窗 |
| 新建自动任务 | 居中弹窗 |
| Duet 新建任务 | 当前频道右侧任务面板 |
| 日志 | 右侧执行区内折叠 |
| 删除、发布、付费和外部发送 | 明确确认弹窗 |

弹层必须支持关闭、Esc 和点击遮罩关闭；危险确认弹窗除外，危险操作必须明确选择取消或确认。

### 7.3 主题

原型延续 V88 主题语言，不复制参考应用颜色和背景。至少演示：

- 深夜黑；
- 明亮白；
- 雪山蓝。

切换主题后立即更新侧栏、卡片、输入框、弹窗、画布背景和状态色，并保存选择。所有文本和边界在三种主题下都必须可辨认。

## 8. 品牌与文案

正式用户可见内容统一使用：

| 参考称呼 | V88 称呼 |
|---|---|
| 洛水 | CM |
| 小洛 | 小Y |
| 洛Duet | CM Duet |

“一战晟铭”“Agent代理”“Duet”是左上角三个工作模式的固定名称。原型不得新增“内容创作”作为第四种或替代名称。

参考原名只允许出现在分析和规格的对照说明中，不得出现在原型页面、演示日志、产物标题和 `localStorage` 演示数据中。

## 9. 演示状态与错误处理

原型使用有限状态模拟真实行为：

```text
idle
  → planning
  → awaiting_approval
  → running
  → succeeded / failed / cancelled
```

规则：

- 运行状态通过短计时器推进；
- 用户可以在允许的位置暂停、继续、取消或触发失败；
- 失败卡片必须有具体演示原因；
- 重试从失败步骤继续，不清空已完成步骤；
- 刷新后恢复模式、页面、项目、主题、启用技能和任务状态；
- 无效引用显示“引用已失效”；
- 没有数据时显示下一步操作，不显示整块空白；
- 不伪装成已连接真实模型、MCP、Codex、数据库或对象存储。

## 10. 原型验收清单

以下项目全部通过，才算可点击原型完成：

1. 左上角能切换一战晟铭、Agent代理和 Duet；
2. 三种模式的左侧导航和主区域同步变化；
3. 再次进入某模式能恢复上次位置；
4. Agent 新会话可走完计划、确认、执行和产物链；
5. `/` 与 `@` 可选择、删除并刷新恢复；
6. 三档权限能改变模拟执行行为；
7. Skills、MCP 和 Codex 可以切换；
8. 技能可搜索、筛选、启停、查看详情和打开导入弹窗；
9. 技能启停与会话选择器联动；
10. 自动任务可创建、运行、暂停、恢复和查看历史；
11. 画布、故事板、素材和任务可以切换；
12. 四个项目视图都有技能、权限和引用入口；
13. 运行可以等待确认、继续、取消、失败和重试；
14. 产物可以定位到画布、故事板或素材；
15. Duet 可以切换项目、频道、员工和任务；
16. Duet 可以演示分派、转交、审核、返工和接力；
17. Duet 可以创建、暂停和恢复定时任务；
18. 三种主题可以即时切换且内容可读；
19. 所有主要按钮有反馈，没有装饰性空按钮；
20. 页面不出现未获豁免的参考品牌名；
21. 原型不发起网络请求、不调用模型、不使用额度；
22. 1366×768 和 1920×1080 下主操作均可见，窄屏右栏可收起。

## 11. 原型与正式实现的边界

原型只确认用户体验和交互状态，不证明真实业务已经实现。以下能力必须在后续正式实现中重新验收：

- Go 后端真实读取技能和后端提示词；
- MySQL 持久化；
- Redis 队列、锁、取消和事件；
- TOS 文件与媒体产物；
- MCP、Codex 和本地执行器连接；
- 真实模型调用；
- Duet 员工并发、转交、审核、返工和定时调度；
- 登录、成员和项目权限；
- Go embed 单二进制运行。

原型通过后，正式实施必须继续沿用本规格的稳定入口、按钮语义、状态和品牌规则；不得以“原型能点击”代替真实后端、保存、恢复和下游产物证据。
