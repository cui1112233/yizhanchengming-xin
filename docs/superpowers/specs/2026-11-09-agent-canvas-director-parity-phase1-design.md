# Agent、画布、分镜与导演台第一期对照设计

日期：2026-11-09

状态：待用户审阅

上位设计：`2026-11-09-luoshui-v29-v88-parity-master-design.md`

实施范围：本地 V88，不发布公网、不调用付费模型

## 1. 第一期目标

在 V88 现有 AgentPageV2、Agent Canvas、AgentStoryboardWorkspace、Director Desk、批量工厂映射和生成任务基础上，补齐洛水 v2.9.0 的 Agent 创作工作台体验。

本期不是重做页面，而是让现有能力形成一条用户能完整走通的链路：

```text
创建项目
  → 导入或编写内容
  → Agent 拆解任务
  → 生成/编辑分镜
  → 分镜投影为画布节点
  → 绑定人物、场景、道具
  → 导演台保存构图和机位
  → 图片/视频节点使用导演结果
  → 查看后台任务和版本
```

## 2. 现状与缺口

### 已有且必须复用

- `/agent`、`/agent/canvas` 正式入口；
- Agent 项目、会话、技能和附件；
- 文本、剧本、图片、视频、音频、导演台节点；
- 画布保存队列、本地草稿和刷新合并；
- 节点连接、右键创建和工具栏；
- 素材抽屉、生成历史和结果采用；
- 分镜工作区和批量建立画布节点；
- 批量工厂书籍与画布映射；
- 导演台场景、人物、道具、机位和视频节点回填；
- 生成任务列表和汇总接口基础。

### 本期重点补齐

- 清晰的“画布 / 分镜 / 素材 / 任务”工作区导航；
- 文件页式素材管理，而不是多个重复抽屉；
- 选中节点、`@` 引用和 Agent 上下文的一致显示；
- 分镜资产绑定与画布节点的双向定位；
- 视频节点逐条提示词和批量生成准备；
- 任务队列的真实状态、失败原因、重试和取消入口；
- 画布助手的悬浮、收起、缩放和停靠；
- 导演台多对象、多机位、画幅和截图/视频节点同步；
- 提示词调用点、版本和结构化输出契约。

## 3. 用户入口与页面布局

### 3.1 `/agent`

项目首页保留现有任务列表，并按项目类型筛选：

- 视频创作；
- 漫剧创作；
- 小说创作；
- 普通 Agent 项目。

项目卡片显示名称、类型、最近更新时间、当前任务状态和最近产物。新建项目只创建空项目，不自动调用模型。

### 3.2 `/agent/canvas`

宽屏采用四区结构：

```text
+------------+------------------------------------+------------------+
| 项目/文件  | 画布 / 分镜 / 素材 / 任务主工作区 | Agent / 属性面板 |
| 220-260px  | 自适应                             | 320-380px        |
+------------+------------------------------------+------------------+
|                 底部输入或任务状态栏                               |
+--------------------------------------------------------------------+
```

- 左栏：项目内容树、文件和素材分类；
- 中央：按顶部切换显示画布、分镜、素材网格或任务列表；
- 右栏：默认显示 Agent，对象选中时可切换属性；
- 底部：Agent 输入、附件、技能、模式和发送/停止；
- 窄屏：左栏和右栏改为抽屉，中央工作区保持完整宽度。

UI 参考洛水的工作区分层，但沿用 V88 现有主题、Ant Design 和 Lucide 图标，不复制洛水品牌皮肤。

### 3.3 多主题体验

现有深色/浅色开关升级为主题选择器。第一期主题目录与总设计保持一致，包含跟随系统、深夜黑、明亮白、纯黑、雾灰白、薄荷绿、雪山蓝、香草黄、樱花粉、鸢尾紫、柳芽黄、象牙白和荷花白。

主题选择器在侧栏底部打开，面板使用小型色卡预览“页面背景、面板、主色和正文”四个关键颜色。设置页提供相同选择，不出现第二套主题配置。

切换时必须同时更新：

- 全局导航、顶栏、弹窗、抽屉和消息提示；
- Agent 对话、输入框、引用标签和技能菜单；
- 画布背景、网点、节点、连线、选择框和右键菜单；
- 分镜卡、素材卡和任务状态；
- 3D 导演台两侧面板、底部控制和视口覆盖文字；
- Ant Design 的输入、选择、按钮、标签和禁用状态。

主题只改变显示，不修改项目内容、画布 `appearance`、媒体资产或生成参数。切换主题时不得触发画布保存、任务提交或模型调用。

技术上由统一 `ThemeDefinition` 生成 CSS 变量和 Ant Design token：

```js
{
  id,
  label,
  colorScheme,
  tokens: {
    background,
    surface,
    surfaceElevated,
    textPrimary,
    textSecondary,
    textMuted,
    border,
    primary,
    success,
    warning,
    danger,
    canvasBackground,
    canvasGrid,
    viewportBackground
  }
}
```

组件不得根据 `mint`、`snow` 等主题名各写一套条件分支；只能读取语义变量。账号偏好保存最终主题 ID，localStorage 只作为首屏缓存和未登录偏好。

## 4. 工作区导航

顶部工作区只保留四个稳定入口：

1. 画布：自由节点和连接；
2. 分镜：按剧本顺序编辑镜头；
3. 素材：项目文件、人物、场景、道具、图片、视频和音频；
4. 任务：生成队列、失败原因、历史版本和批次进度。

切换工作区时：

- 项目和选中节点不丢失；
- URL 中保留 `taskId` 和 `view`；
- 返回画布时恢复视口；
- 从分镜点击“在画布中定位”时切换到画布并聚焦对应节点；
- 从任务点击产物时定位到对应画布节点或分镜。

## 5. 画布交互

### 5.1 节点类型

正式节点类型保持：

- `text`：文本、小说片段、说明；
- `script`：剧本与结构化分镜来源；
- `image`：参考图、角色图、场景图和生成结果；
- `video`：视频提示词、首尾帧、参考视频和生成结果；
- `audio`：配音、音效和 BGM；
- `director`：导演台场景、对象和机位。

不为洛水的每个页面建立新节点类型。业务差异放在节点配置和项目类型中。

### 5.2 基础操作

- 单选、多选、框选；
- 拖动、缩放、适应视图；
- 分组和解除分组；
- 连接和断开；
- 撤销、重做；
- 复制、粘贴、删除；
- 右键新增节点；
- 从连线中点快速插入节点；
- 图片粘贴和文件拖入；
- 自动保存和保存失败提示。

所有浮层挂载到 `document.body`，不能被画布的 `overflow` 裁剪。

### 5.3 多视频节点

一次选中多个视频节点时，任务列表逐条显示：

- 节点名称；
- 独立提示词；
- 模型与时长；
- 参考素材；
- 当前状态；
- 失败原因。

批量操作只是批量入队，不把多个节点合并成一条模型请求。一个节点失败不阻塞其他节点完成。

## 6. 文件页与素材

素材视图统一显示：

- 文本和剧本；
- 人物、场景和道具；
- 图片；
- 视频；
- 音频；
- 导演台截图；
- 批量工厂映射产物。

每个素材保持唯一资产 ID。画布节点、分镜和导演台只保存引用，不复制对象存储文件。

素材卡支持：预览、重命名、引用到输入框、建立画布节点、查看来源和版本。删除前必须检查引用；本期不做“强制删除所有引用”。

## 7. Agent 与上下文引用

### 7.1 模式

- `Chat`：只回答，不自动修改项目；
- `Agent`：可以提出计划、调用已允许的 V88 工具和生成待确认修改；
- `完全运行`：第一期只作为受控批次模式，必须显示将调用的工具和预计任务数量，不等于无限权限；
- `联网搜索`：默认关闭，只有模型路由和账号配置可用时才显示。

### 7.2 `@` 引用

输入框引用来源：

- 当前项目文件；
- 画布节点；
- 人物、场景、道具；
- 分镜；
- 技能；
- 后续阶段再接 MCP 和知识库。

发送前以引用标签显示名称和类型。后端接收稳定 ID，重新读取当前内容，前端不把隐藏系统提示词拼入请求。

### 7.3 选中节点上下文

右侧 Agent 明确展示“正在参考”：

- 当前选中的节点；
- 手工 `@` 引用；
- 当前分镜或导演台对象；
- 用户上传的附件。

取消选择后不继续偷偷携带旧节点上下文。

## 8. 分镜工作区

分镜按剧本节点分组，每条分镜包含：

- 顺序号和标题；
- 剧情/台词；
- 景别、时长和镜头语言；
- 人物、场景、道具引用；
- 图片提示词和视频提示词；
- 图片、视频和音频产物；
- 对应画布节点 ID；
- 当前任务状态。

本期支持：

- 从剧本拆分分镜；
- 手工增删改和排序；
- 批量创建画布节点；
- 从分镜定位画布节点；
- 相邻分镜合并，最长时长可选 10、15、30 秒；
- 合并时按顺序拼接台词和提示词，并合并资产引用；
- 不自动删除已有生成结果，结果作为合并后分镜的历史版本保留。

## 9. 3D 导演台

沿用现有 Director Desk 全屏工作区和 `directorProject` 数据，不新建导演台数据库。

本期用户能力：

- 场景、人物、道具和机位对象树；
- 对象移动、旋转和缩放；
- 导演视角与活动机位视角；
- 景别、焦段、方位角和俯仰角；
- 多机位与活动机位；
- 常用画幅选择和真实取景遮罩；
- 场景描述与分镜视频提示词分开保存；
- 当前构图截图为项目图片，并建立导演节点到图片节点的连接；
- 保存时只向直接连接的视频节点同步提示词、机位、构图快照和参考资产 ID。

本期不做：

- 骨骼和姿势编辑；
- 动画曲线和时间轴；
- 物理模拟；
- 无真实模型支撑的家具/车辆装饰入口；
- 自动提交视频生成。

## 10. 提示词设计

### 10.1 首批提示词定义

| ID | 用途 | 主要输入 | 结构化输出 |
|---|---|---|---|
| `agent.project.plan.v1` | 把用户目标拆成项目步骤 | 项目类型、用户目标、已有素材 | 步骤、依赖、预计产物、需确认项 |
| `agent.selection.diagnose.v1` | 分析选中节点的问题 | 节点文本、上下游摘要 | 问题、严重程度、定位、建议 |
| `storyboard.split.v1` | 剧本拆分分镜 | 剧本、资产索引、时长规则 | 分镜数组和资产引用 |
| `storyboard.merge.v1` | 合并相邻分镜 | 分镜数组、最大时长 | 合并分组和字段合并结果 |
| `asset.extract.v1` | 提取人物场景道具 | 剧本/小说片段 | 资产数组、别名和出现位置 |
| `storyboard.image_prompt.v1` | 生成分镜图提示词 | 分镜、人物、场景、道具、风格 | 正向提示词、负向约束、引用列表 |
| `storyboard.video_prompt.v1` | 生成视频提示词 | 分镜、首尾帧、机位、动作 | 主体动作、镜头动作、时长、提示词 |
| `director.shot_prompt.v1` | 把导演台状态转为镜头描述 | 对象变换、机位、构图、画幅 | 场景描述、镜头描述、参考资产 |

### 10.2 提示词保存位置

所有系统模板进入 `backend/internal/prompt/`。建议按领域拆分：

```text
backend/internal/prompt/
  agent/
  asset/
  storyboard/
  director/
```

每个模板同时提供：

- 稳定 ID；
- 版本；
- 输入结构；
- 输出结构；
- 解析器；
- 脱敏测试样本；
- 失败时的用户提示。

前端只显示“提示词版本”和用户可编辑字段，不返回完整系统提示词。管理员后续可通过管理端启用版本，但本期不新增在线任意编辑系统提示词功能。

### 10.3 与洛水提示词的关系

洛水 181 条提示词用于确认覆盖范围、字段和任务拆分方式。第一期只审阅与 Agent、资产、分镜、画面推理和视频推理相关的条目，整理为上述八个 V88 模板。重复、过时、绑定特定渠道或夹带桌面本地路径的内容不迁移。

## 11. 后端与数据

优先复用：

- `backend/internal/agentworkspace` 的项目、画布、任务、版本和批量工厂投影；
- 现有脚本、素材和媒体服务；
- MySQL 的生成任务和项目记录；
- Redis 的任务协调和锁；
- TOS 的媒体对象；
- 当前 Agent API 路由。

需要补齐的数据关系：

- 分镜 ID ↔ 画布节点 ID；
- 任务 ID ↔ 节点/分镜/资产 ID；
- 结果版本 ↔ 被采用版本；
- 导演节点 ↔ 直接连接的视频节点；
- Prompt ID + version ↔ 生成任务。

不新建 SQLite，不在前端 localStorage 保存正式项目数据。localStorage 只用于尚未同步的画布草稿和界面偏好。

## 12. 任务状态和失败恢复

统一状态：

- `queued`：已排队；
- `running`：执行中；
- `awaiting_confirmation`：等待用户确认；
- `completed`：成功并有持久化结果；
- `failed`：失败并有明确原因；
- `cancelled`：已取消。

规则：

- 页面刷新后从后端恢复状态；
- 只有临时错误允许重试；
- 取消不删除已经完成的产物；
- 采用某个版本不删除其他历史版本；
- 页面不能把“请求已提交”显示成“生成完成”；
- 第一阶段补齐图片和音频协调器、前端状态投影及重启恢复后，才能宣称统一后台队列完成。

- 八个首批 PromptDefinition；
- 模拟模型测试；
- Go embed 构建和已登录浏览器验收。

## 14. 验收清单

### 功能

- 能创建项目并进入四个工作区；
- 六类节点可以创建、编辑、连接和保存；
- 刷新后节点、连线、视口和导演台状态不丢；
- 素材只保存一份，画布和分镜使用引用；
- `@` 引用与选中节点上下文可见、可取消；
- 分镜可批量建节点、合并并双向定位；
- 导演台可保存对象和机位、截图回画布并同步直接视频节点；
- 任务状态、失败原因、重试和取消来自真实后端；
- 提示词 ID、版本和任务记录可追溯。

### UI

- 宽屏三栏不互相覆盖；
- 窄屏抽屉不遮挡中央操作；
- 亮色和暗色主题均清晰；
- 首批 `dark`、`light`、`pureblack`、`mint`、`snow`、`purple` 在全工作台通过对比度验收；
- 其余主题只有通过同一套对比度、禁用态、状态色和弹层验收后才公开；
- 切换主题后项目、画布外观和任务状态不发生数据变更；
- 下拉、气泡和右键菜单不被裁剪；
- 空状态、加载、失败和未同步状态均有明确文字；
- 不出现只有外观没有功能的按钮；
- 浏览器验收包含画布、分镜、素材、任务和导演台截图。

### 工程

- 前端聚焦测试通过；
- `npm run build` 通过；
- Go 聚焦测试通过；
- Go embed 资源重建；
- 本地 `qiantie-local.exe` 重建并只重启确认的 `:4001` 进程；
- `/health` 为 200；
- `/api/runtime-build-info` 对应当前本地构建；
- 不使用真实密钥、不消费付费额度、不发布公网、不推送远端。

### 一致性验收证据

每个功能 ID 至少需要：

- 一条正常流程自动测试；
- 一条失败或边界测试；
- 一次 Go embed 本地运行验证；
- 一次已登录浏览器可见验收；
- 一条刷新或重启后的持久化检查；
- 若涉及提示词，记录 Prompt ID、版本、模拟输入和结构化输出；
- 若标为 `equivalent`，明确记录与洛水的技术差异及为何用户效果等价。

验收结论按功能 ID 汇总。只要任意关键项仍为 `partial`，第一期总状态就不能写“完全对齐”。

## 15. 完成定义

第一期完成不是“页面看起来像洛水”，而是用户能在 V88 中完成一次不依赖重复页面的真实项目流程：内容进入项目，Agent 能理解引用，分镜能落到画布，素材能统一复用，导演台构图能回到图片和视频节点，后台任务和结果版本在刷新或重启后仍可追溯。
