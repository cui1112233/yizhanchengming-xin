# 漫画合集图片下载

## 目标

在批量工厂的每个漫画合集卡片中提供下载操作。用户点击后，系统将该合集的全部主图打包为 ZIP 下载。

## 用户可见行为

- 每个漫画合集卡片的操作区增加“下载图片”按钮。
- ZIP 文件名为经过 Windows 文件名清理后的书名，例如 `迟到的必修课.zip`。
- 图片按合集现有页码顺序命名为 `书名-001.png`、`书名-002.png`，序号至少三位。
- 仅下载该合集已经选定的主图；不下载候选图，也不混入其他合集。
- 合集存在缺页、无主图或图片无法读取时，下载请求失败并指出页码；不返回不完整 ZIP。

## 技术设计

新增受登录保护的 GET 下载接口，按当前用户、批次、书籍和合集 ID 校验归属。接口读取合集项目的主图，按页码排序后由服务端生成 ZIP 并返回文件流。文件扩展名优先沿用图片内容类型或原始文件名，无法识别时使用 `.png`。

前端通过既有带认证下载方式获取 Blob，并触发浏览器下载。按钮仅在合集包含页面时可点击；下载期间只锁定当前合集按钮，并给出“正在打包”状态。

## 错误处理

- 合集、书籍或批次不存在，或不属于当前登录用户：返回现有的未找到响应。
- 无主图、图片引用无效、读取失败：返回可读错误，包含对应页码。
- ZIP 写入失败：返回下载失败，不产生假成功提示。

## 验证

- 后端测试创建包含两页主图的合集，断言返回 ZIP、文件名和内部文件顺序。
- 后端测试验证缺图时拒绝生成 ZIP。
- 前端源码测试验证合集卡片存在下载按钮并调用对应下载方法。
- 在本地 `4001` 打开合集，下载后检查 ZIP 名称及内部图片命名。
