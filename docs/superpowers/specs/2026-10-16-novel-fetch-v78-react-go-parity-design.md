# 小说获取 V78 React + Go 全功能对标设计

## 目标

将 `/novel-fetch` 统一为 React 页面和 Go 后端链路，完整对齐 V78 参考页面的界面、交互、状态、持久化和业务结果。`frontend/public/batch-rewrite` 只作为只读参考，不再作为运行入口，也不把编译产物反向当作源码。

## 成功标准

- V78 页面中的每个可见按钮、选择项、标签页和状态卡在 React 中都有对应行为。
- 每次操作都有真实请求、后端处理和可见状态变化，不能用静态假数据补齐。
- 小说获取、敏感词处理、AI 改文、任务管理、定时任务、121 登录/提交、批量工厂跳转均由 Go 接口完成。
- 页面刷新和标签切换后，配置、任务、进度和失败信息仍从持久化数据恢复。
- React 页面构建后由 Go `embed` 发布；运行时不依赖 Node 后端、iframe 或旧静态入口。
- 旧 V78 页面保留为参考，直到功能逐项验收完成；验收完成后再单独评估清理。

## 功能范围

### 处理页

- 平台选择、文本模型选择、批量输入解析。
- 原文、AI1～AI5 版本选择。
- 各 AI 版本改文方式和配置继承。
- 敏感词 AI 修复开关，关闭时执行直接替换，开启时调用 AI 修复。
- 开始处理、刷新任务、清空输入、版本配置。
- 处理状态统计：总量、已解析、处理中、已完成、失败。
- 原文抓取、AI 文案生成、当前批次和任务状态展示。

### 任务页

- 当前任务、历史批次、日期筛选和刷新状态。
- 查看详情、原文、AI 文案、处理日志和失败原因。
- 失败重试、批量重试、删除选中、删除失败、删除全部。
- 进入批量工厂和提交网络操作。

### 配置、知识库、处理规则、记录

- 配置保存、读取和版本继承。
- 知识库条目新增、编辑、AI 优化、删除和刷新。
- 原文/AI 处理规则预览、AI 建议和阶段追踪。
- 网站提交配置、环境检查、预览提交、开始提交和失败版本重试。
- 操作日志和审计信息可查询。

## 链路设计

1. React 收集页面输入并保存本次处理配置。
2. React 调用 Go 小说获取接口创建任务批次。
3. Go 读取平台配置，抓取原文并保存原文版本、原始长度和处理长度。
4. Go 在分类缺失时按 `121 bookinfo.category + genre` 判断男女频，无法明确时才调用 AI 兜底；用户手工值优先级最高。
5. Go 按用户选择执行原文处理、AI1～AI5 文案和敏感词处理，并为每个阶段记录状态、错误、重试次数和时间。
6. React 通过 Go 查询任务、当前批次和实时日志，渲染统计卡、进度条、状态标签和详情。
7. 进入批量工厂时只传递已持久化的书籍、原文、AI 文案、风格和男女频信息，不重新要求用户填写已有信息。
8. 所有外部提交必须经过 Go 的配置检查、预览和确认流程，并保存每个版本的提交回执。

## 源码边界

- 页面源码：`frontend/src/user/pages/NovelFetchPage.jsx`、`frontend/src/user/pages/novel-fetch.css`。
- 页面 API：`frontend/src/shared/api/novelFetch.js`、`frontend/src/shared/api/novelFetchWorkshop.js`。
- Go 业务：`backend/internal/novelfetchworkshop/` 和对应 `backend/internal/httpapi/` 路由。
- 系统提示词：只允许由 Go prompt 模块提供，React 不硬编码业务提示词。
- `frontend/public/batch-rewrite`、`frontend/dist`、`backend/web/dist` 只作为构建产物或参考，不直接编辑实现功能。

## 兼容与清理策略

- 先让 React + Go 完成所有功能对标，再移除旧静态入口和未使用的 Node 后端路径。
- 不删除仍被测试、构建或运行链路引用的文件。
- 每次清理前用引用搜索和测试证明没有运行时依赖。
- 不修改公网，不向远端 Git 推送；部署前必须获得用户二次确认。

## 验收

- 源码测试覆盖：输入解析、版本选择、敏感词开关、状态映射、日期筛选、任务重试、批量工厂交接。
- 构建测试：React 构建、Go 编译、`embed` 静态资源存在、SPA 路由可回退。
- 本地浏览器验收：逐项点击截图中的控件，确认请求、响应、页面状态和刷新恢复。
- 链路验收：至少完成一条“输入书籍 → 抓取原文 → 分类 → AI/敏感处理 → 查看任务 → 进入批量工厂”的真实本地流程。
