# AI-CUT 对标 Concat 的中文专业编辑器设计

日期：2026-11-10  
状态：待用户最终审阅  
参考对象：Concat 当前公开版本的编辑器布局与交互原则

## 1. 目标

将现有 AI-CUT 从“功能卡片加弹窗”的展示型页面，重构为可以长期扩展的中文专业视频编辑器。编辑器参考 Concat 的工作区划分、直接操作和上下文属性面板，但继续使用一战晟铭现有的 React、Go、MySQL、Redis、TOS 与 FFmpeg 技术体系。

第一阶段必须同时交付：

- 中文专业编辑器骨架；
- 常用滤镜、画面特效、转场和文字预设；
- 真实的语音识别字幕链路；
- 可拖动、可收起、可恢复的工作区；
- 浏览器预览和服务器导出读取同一工程数据；
- AI-CUT Agent 作为浮动助手保留。

## 2. 许可与源码使用边界

Concat 仓库当前采用 AGPL-3.0-or-later，并另行提供书面商业许可。直接把 Concat 或其引擎放入闭源产品，或者基于其源码向网络用户提供修改版服务，需要满足 AGPL 的完整源码提供要求，或先取得其权利人的书面商业许可。

因此本项目采用以下闸门：

1. 默认仅参考公开界面、操作行为和数据规则，独立实现代码。
2. MIT、Apache-2.0、BSD 等与本项目发布方式兼容的独立依赖，经许可证清单确认后可以直接使用。
3. Concat 的 AGPL 核心代码、效果包、模型、字体和专有资源不得直接复制进当前闭源构建。
4. 如果未来取得 Concat 商业许可，或明确决定整个相关产品按 AGPL 发布，再单独制定“直接集成 Concat”方案。
5. 引入任何第三方效果、模型、字体、编解码器前，必须记录名称、版本、来源、许可证和发布义务。

## 3. 编辑器骨架

页面使用一个顶栏、三个上部工作区和一个底部时间线：

```text
┌ 顶栏：返回｜项目名｜撤销/重做｜保存状态｜快捷键｜导出 ┐
├──────────┬────────────────┬───────────┤
│ 中文资源库 │    预览画布     │ 中文属性栏 │
│ 媒体      │  可拖动文字字幕  │ 基础参数   │
│ 文字      │  缩放/旋转/定位  │ 位置尺寸   │
│ 转场      │  安全框/适应画布 │ 滤镜特效   │
│ 特效      │  播放与时间显示  │ 字幕样式   │
│ 滤镜      │                 │ 动画参数   │
│ 模板      │                 │           │
├──────────┴────────────────┴───────────┤
│ 工具栏：选择/分割/删除/吸附/联动/缩放/轨道操作 │
│ 多轨时间线：文字｜效果｜视频｜音频｜字幕          │
└───────────────────────────────────────┘
                            [AI-CUT Agent]
```

### 3.1 顶栏

- 返回一战晟铭；
- 当前项目切换和新建项目；
- 自动保存状态；
- 撤销、重做和快捷键说明；
- 导出入口和导出任务状态；
- 不显示不能执行的装饰按钮。

### 3.2 中文资源库

左侧顶部直接切换“媒体、文字、转场、特效、滤镜、模板”，下方立即展示真实资源，不再经过“功能说明卡片”或大弹窗。

资源项必须具备：

- 稳定内部编号；
- 中文名称和简短用途；
- 缩略预览；
- 收藏和最近使用；
- 搜索和分类；
- 点击试用、双击应用、拖到时间线；
- 不可用时显示明确原因。

### 3.3 预览画布

- 按播放头实时显示全部可见轨道；
- 文字、字幕和画中画可直接框选、拖动、缩放和旋转；
- 提供安全框、适应、填满、原始大小和全屏；
- 点击资源只进入临时预览，点击应用或拖入时间线后才写入工程；
- 取消临时预览不会改变工程；
- 播放和暂停不产生工程历史记录。

### 3.4 中文属性栏

属性栏始终存在，并根据当前选择切换内容：

- 视频/图片：位置、尺寸、旋转、透明度、裁剪、速度、滤镜和效果；
- 文字/字幕：内容、字体、字号、颜色、描边、阴影、底板、位置、动画；
- 音频：音量、淡入淡出、静音和波形；
- 转场：类型、持续时间、方向和强度；
- 效果层：强度、速度、范围、混合方式和启用状态；
- 未选择对象时显示项目和画布参数。

窗口较窄时，属性栏折叠为可展开抽屉，不直接消失。

### 3.5 多轨时间线

- 真实显示文字轨、效果轨、视频轨、音频轨和字幕轨；
- 支持选择、移动、裁剪、分割、复制、删除、锁定、静音和显示；
- 支持吸附、联动移动、水平缩放、滚动和播放头拖动；
- 转场显示在两个片段的连接处；
- 效果层显示自己的生效区间；
- 所有拖动先产生临时预览，松手后形成一次可撤销操作；
- 轨道和面板可调整高度，布局保存到当前用户设置。

## 4. 第一批资源目录

### 4.1 滤镜 16 个

原片、明亮、清晰、自然、暖阳、冷蓝、电影、复古、黑白、高对比、低饱和、青橙、夜景、人像、鲜艳、柔和。

### 4.2 画面特效 12 个

模糊、暗角、发光、颗粒、抖动、呼吸缩放、闪烁、故障、色差、马赛克、鱼眼、锐化。

### 4.3 转场 16 个

交叉溶解、淡入淡出、闪黑、闪白、向左推拉、向右推拉、向上推拉、向下推拉、向左擦除、向右擦除、向上擦除、向下擦除、缩放、模糊、故障、光泄漏。

### 4.4 文字预设 12 个

基础字幕、粗体标题、描边字幕、阴影字幕、底板字幕、逐字高亮、新闻条、下三分之一、漫画字、手写字、竖排字、渐变标题。

每个资源由统一目录描述：

- `id`：稳定英文内部编号；
- `labelZh`：中文名称；
- `category`：滤镜、特效、转场或文字；
- `thumbnail`：缩略预览生成方式；
- `parameters`：参数类型、默认值、最小值、最大值和步长；
- `previewAdapter`：浏览器预览映射；
- `renderAdapter`：Go/FFmpeg 导出映射；
- `supportedKinds`：支持的视频、图片、文字或音频类型；
- `availability`：浏览器、服务器和模型依赖状态。

没有真实预览和导出映射的资源不得进入“可用”目录。

## 5. 识别字幕

### 5.1 入口

“识别字幕”同时出现在：

- 左侧文字/字幕工作区的主操作区；
- 视频和音频素材卡片；
- AI-CUT Agent 可调用技能列表。

没有配置 ASR 模型时入口仍然可见，窗口内显示“前往 API 配置”。

### 5.2 输入

- 一个视频或音频素材；
- 已启用的 ASR 模型；
- 中文、英文或自动检测；
- 当前工程版本；
- 可选的字幕轨名称和样式预设。

### 5.3 输出

- 一条新的字幕轨；
- 带开始时间、结束时间和文本的字幕片段；
- 可见任务记录和最终状态；
- 成功后画布和时间线立即刷新；
- 不覆盖已有手动字幕和 SRT 字幕。

### 5.4 状态和失败处理

- 排队中：显示排队状态和取消按钮；
- 识别中：显示进度和取消按钮；
- 正在取消：禁止再次提交；
- 成功：显示“已写入字幕”；
- 失败：保留错误原因和“重新识别”；
- 已取消：不写入半截字幕，可以重新提交；
- 重复提交：同一素材存在活动任务时拒绝；
- 空结果：提示“没有识别到有效语音”；
- 工程版本冲突：不覆盖新修改，提示刷新后重试；
- 模型不可用：保留任务记录并显示配置或服务错误。

## 6. 数据流

### 6.1 滤镜和特效

```text
资源库选择
→ 临时预览
→ 应用或拖入时间线
→ 写入工程
→ 属性栏调整参数
→ 自动保存
→ 浏览器继续预览
→ Go/FFmpeg 按相同 ID 和参数导出
```

滤镜直接属于视频或图片片段；有持续区间的画面特效属于独立效果层。

### 6.2 转场

转场保存在同一视频轨两个相邻片段的连接位置。以下情况拒绝添加：

- 片段不在同一轨；
- 两片段之间存在空隙；
- 轨道被锁定；
- 没有前一个片段；
- 转场时长超过相邻片段可用范围。

### 6.3 保存和历史

- 用户完成一次拖动、一次参数提交或一次应用动作后形成一个历史记录；
- 临时预览、鼠标悬停和播放不会产生历史；
- 自动保存使用工程版本避免覆盖并发修改；
- 刷新页面后布局、轨道和效果参数保持一致。

## 7. 组件边界

前端拆为以下独立模块：

- `EditorShell`：顶栏和可调整工作区；
- `ResourceLibrary`：六类中文资源；
- `PreviewCanvas`：播放与画布直接操作；
- `InspectorPanel`：上下文属性；
- `TimelineEditor`：轨道和片段交互；
- `CaptionWorkspace`：ASR、SRT、手动字幕和纠错；
- `EffectCatalog`：目录、参数和适配器；
- `AICutAgentLauncher`：浮动 Agent 入口。

后端继续按职责拆分：

- 工程和时间线存取；
- ASR 任务服务；
- FFmpeg 渲染计划；
- 导出任务；
- 后端 prompt 模块；
- 第三方许可证清单。

系统预设提示词只放在 Go 后端 prompt 模块，前端不硬编码完整系统提示词。

## 8. 中文、主题和图标

- 用户可见名称、参数、错误、状态和快捷键全部使用中文；
- 工程内部使用稳定英文 ID，避免中文改名破坏数据；
- 深色、浅色和彩色主题全部使用一战晟铭主题变量；
- Ant Design 浮层、菜单、抽屉和提示必须继承当前主题；
- 图标统一使用项目现有 Lucide 图标；
- 不使用表情符号、Unicode 假图标或风格混杂的图片按钮；
- Concat 品牌名和资源不得出现在产品界面。

## 9. 验收标准

### 9.1 编辑器骨架

- 四个区域可以拖动改变大小；
- 左侧、右侧和时间线可以收起并恢复；
- 窄窗口下属性栏变成抽屉而不是消失；
- 刷新后恢复布局；
- 浅色、深色及至少两个彩色主题可读。

### 9.2 资源功能

- 第一批 16 个滤镜、12 个特效、16 个转场和 12 个文字预设全部有真实入口；
- 点击产生临时预览，取消不改工程；
- 应用后时间线和属性栏能找到对应对象；
- 保存、刷新后参数不丢失；
- 浏览器预览与导出视频逐项对照；
- 不支持的输入显示中文原因，不出现无响应按钮。

### 9.3 字幕识别

- 正常素材能生成新字幕轨；
- 空素材、无模型、重复提交、模型错误、版本冲突和取消均有明确中文结果；
- 失败和取消后可以重试；
- 不生成假字幕；
- 不覆盖已有字幕；
- 未经明确验收授权不发起付费模型调用。

### 9.4 测试

- 前端目录、参数边界、拖动、收起、主题和快捷键测试；
- Go 工程校验、ASR 状态机、重复保护、取消和导出映射测试；
- 同一组视频执行正常、空值、重复、错误和取消对照；
- 构建嵌入 Go 二进制后，检查 `/health`、`/api/runtime-build-info` 和实际浏览器页面；
- 只有源代码测试、生产构建、嵌入运行时和可见浏览器结果同时通过，才算完成。

## 10. 不在第一阶段的范围

- Concat 全部效果包和全部高级调色功能；
- 关键帧曲线编辑器；
- 本地离线模型下载器；
- 背景抠除和人像分割；
- 4K 代理媒体系统；
- 直接集成 Concat AGPL 引擎；
- 公开部署和远端推送。

这些能力后续按照同一目录、时间线和许可闸门逐批扩展。
