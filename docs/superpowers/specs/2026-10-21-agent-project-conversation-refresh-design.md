# Agent 项目对话区改版设计

日期：2026-10-21

## 范围

仅重做 Agent 工作区的“项目对话”面板。工作流顶部工具栏、画布、故事板、素材区、项目数据与后端接口均不修改。

## 目标

以用户提供的 TV Director 参考为视觉方向，把项目对话重组为一个完整的会话工作台，而不是原有侧栏加几个引导入口。没有对话内容时有清晰的创作起点；有消息后仍能持续进行项目对话与导演执行。

## 布局

1. 保留现有的导演模式切换和待确认方案卡片；它们继续使用原有状态与回调，但收纳进对话面板的会话内容区。
2. 对话区顶部采用“新对话/当前项目名 + 小型工具图标”的单行会话头部；不新增或修改工作流顶部工具栏按钮。
3. 当当前项目没有消息时，使用更大的居中导演标识、单句引导语和四个无卡片感的常用入口：画布创作、从素材生成、上传文本改编、优化提示词。
4. 入口只负责填入或聚焦现有输入框，不自动执行、不创建项目、不调用外部接口。
5. 输入区固定在面板底部，改为独立的大圆角编辑区：上层显示输入文本，下层采用参考图的紧凑工具条；发送采用圆形图标按钮，保留 Enter 发送、Shift+Enter 换行。
6. 紧凑工具条从左到右为：`+`（打开更多能力）、主模式下拉（例如“全能创作”）、素材/引用图标、技能图标、专家图标。现有的“找问题”、专家、模式、技能与附件不删除，只收纳进这些图标入口，不再并排显示大文字按钮。
7. 已经存在的消息、执行记录、节点引用、素材引用和待确认方案保持原有显示与行为。

## 适配

- 工作流桌面视图继续使用右侧对话面板。
- 故事板桌面视图继续使用左侧对话面板。
- 窄屏维持现有抽屉式面板规则；空状态入口自动纵向排列，输入区不被遮挡。

## 验收

1. 工作流顶部工具栏没有新增、删除或重排。
2. 会话面板独立呈现完整的顶部、内容区与底部输入区，视觉层级接近参考图但不复用其品牌或文字。
3. 新项目或无消息项目可看到四个引导入口，并且点击后只准备输入内容。
4. 有消息、执行记录或导演方案时，原有流程可继续使用。
5. 浅色与深色主题下文字、按钮、边框都清晰可辨。
6. 工作流和故事板中项目对话均可正常展开、收起和发送。
