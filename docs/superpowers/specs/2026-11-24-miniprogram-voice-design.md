# 手机配音卡片

沿用已批准紧凑手机设计。线上TtsPage.jsx为多个卡片、默认设置、单张与顺序全部生成，小程序目前单段且语速音调范围错误。本轮改为卡片列表：粘贴文本新建、单卡正文、设置弹层、默认设置单独打开；单卡生成、全部顺序队列、停止后续任务、单卡播放暂停/分享本地文件、删除。所有音频参数与网页相同：voice/style六音色五风格，speed 0.5–2，pitch -50–50。保存默认仅POST/api/config的tts偏好，不回传账户密钥或完整配置；正文调用/api/tts并验证音频。

同步锁覆盖付费确认与整个队列，UI说明卡片数/字数和音色；当前请求不伪装为已取消。隐藏停止排队后续、播放停止；账号切换清卡片、停止音频、丢弃迟到输出。未知结果不自动重试，手动重新生成明确可能重复计费。不提供手机上传TXT入口，用粘贴开篇导入。实际配置读取和手机布局只读验收，真实收费生成不自动触发。
