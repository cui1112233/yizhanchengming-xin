# 私人定制手机补齐

沿用已经批准的紧凑编辑器。线上ScriptPage提供根据小说智能补全（/api/chat entity_enrich）、本机草稿和分镜卡片编辑；没有凭空增设一个独立AI改写服务。

人物/场景编辑增加智能补全按钮，先确认费用，服务端负责系统提示词。展示证据、建议和不确定项；仅填空缺，不覆盖用户已有字段。不把切换后的另一个实体改掉。未知结果按实体请求内容锁定，避免无意识重复费用。

原文、设定、设置和结果按真实账号/服务地址保存到手机本地；重开明确恢复，晚到草稿不覆盖正在输入的正文；历史入口优先。缓存失败需明示，不冒充跨端同步。

生成结果支持原文编辑、单个分镜编辑与保存新历史版本。已经提交视频的分镜必须保留原版本；新编辑另存版本和任务，不挪用旧任务百分比。图片生成仍走现有素材链路。

验证线上请求合同、字段保护、草稿隔离、版本保留，手机只读验收；不调用付费生成。
