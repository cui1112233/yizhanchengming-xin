# AI-CUT 全部可见操作真实化设计

日期：2026-11-10

## 目标

把当前 AI-CUT 从高保真展示稿改成可实际剪辑、保存、恢复和导出的在线编辑器。界面只显示已经有完整链路的操作；没有真实能力的入口先隐藏，接通服务并通过验收后再显示。

完整链路统一定义为：

`用户操作 -> 输入检查 -> 时间线/任务状态变化 -> 播放器预览 -> MySQL 保存恢复 -> FFmpeg/模型执行 -> 明确成功或失败`

仅弹出“需要配置服务”、静态切换样式或伪造成功提示，不算完成。

## 当前审计结论

- 左侧工具目录共有 63 个功能卡片，只有约 17 个存在事件映射；其余入口统一落入提示消息。
- 属性栏只有“基础”和“速度”有编辑控件；抠像、蒙版、美化、调色、动画、跟踪是占位内容。
- 关键帧、定格、多时间线是禁用按钮。
- 后端导出已支持素材裁剪、开始时间、播放速度、音量、音频淡入淡出、字幕烧录、画面拼接/覆盖和闪黑/闪白转场。
- 后端尚未读取滤镜、特效、蒙版、关键帧等参数，因此这些内容即使画在前端也不会进入成片。

## 产品规则

### 可见性规则

1. `ready` 不能由前端手写布尔值决定，必须来自统一能力注册表。
2. 一个能力只有同时声明入口、输入条件、执行函数、保存字段和导出支持，才允许显示。
3. 依赖外部模型、版权素材库或未配置供应商的能力默认隐藏。
4. 配置完成但当前素材不适用时可以显示，但必须禁用并说明缺少什么输入，例如“请先选择视频片段”。
5. 不保留“开发中”“即将上线”或点击后只弹提示的卡片。

### 状态规则

- 顶栏保存状态只能显示“有未保存修改”“保存中”“云端已保存”或“保存失败”，不能永远显示已保存。
- 收藏和最近使用必须真实记录；收藏可以切换，最近使用按真正执行成功的时间排序。
- 取消弹窗或文件选择不修改时间线、不创建任务、不显示成功。
- 重复应用同一类效果时更新原参数，不重复堆叠相同记录。

## 第一阶段保留的真实能力

### 工程与素材

- 新建项目、切换项目、上传素材、搜索项目素材、拖入/加入时间线。
- 视频素材：识别字幕、智能切镜、分离音频。
- 素材区收起/展开和宽度拖动。

### 播放与时间线

- 播放/暂停、拖动播放头、适应/填充/100%、安全框、全屏。
- 新增视频/音频/字幕轨；轨道重命名、锁定、静音、删除空轨。
- 片段拖动、吸附、分割、复制、删除、左右裁剪、变速。
- 时间线缩放、收起/展开和高度拖动。
- 撤销、重做、保存、MP4/WebM/MP3/SRT 导出。

### 文本、字幕和转场

- 默认文本、字幕手工添加、SRT 导入/导出、批量替换、字幕纠错、去水词。
- 闪黑、闪白转场。
- 字幕样式、节奏、动画只在播放器和服务端导出都支持对应结果时显示；第一阶段暂时只保留服务端 ASS 已支持的样式字段。

### 首批画面效果

首批只实现 FFmpeg 和浏览器均能稳定复现的参数：

- 亮度：`-1.0..1.0`，默认 `0`。
- 对比度：`0.5..2.0`，默认 `1`。
- 饱和度：`0..3.0`，默认 `1`。
- 模糊：`0..20`，默认 `0`。
- 黑白：布尔值，默认关闭。

这些参数存入片段 `visualEffect`，播放器使用 CSS filter 预览，FFmpeg 使用等价的 `eq`、`gblur`、`hue=s=0` 链导出。参数必须经过后端校验。

第一批预设：原片、明亮、电影冷调、暖色、黑白、柔焦。预设本质是上述参数组合，不引入无法导出的视觉效果。

## 暂时隐藏的能力

- 版权音乐库、音效库、字体库、模板库、贴纸库。
- 人物跟踪、智能抠像、数字人、音色克隆、AI 贴纸、AI 特效、AI 补帧。
- 人声分离、变声、智能调色、画质增强。
- 关键帧、定格、多时间线、蒙版、曲线、HSL、色轮、LUT。
- 没有确定性工具支持的 Agent 包装、参考视频复刻等卡片。

它们不是删除需求，而是进入后续能力清单；只有真实服务和测试齐全后才重新出现在界面。

## 数据规格

片段新增：

```json
{
  "visualEffect": {
    "brightness": 0,
    "contrast": 1,
    "saturation": 1,
    "blur": 0,
    "grayscale": false,
    "preset": "original"
  }
}
```

MySQL `aicut_clips` 新增 `visual_effect_json JSON NULL`。读取旧工程时使用默认值；保存时只接受白名单字段，拒绝 NaN、无穷值和越界值。

## 输入、输出、边界和失败

| 操作 | 输入 | 输出 | 边界 | 失败提示 |
|---|---|---|---|---|
| 应用画面效果 | 已选择的视频/图片片段、合法参数 | 时间线 revision 增加，播放器立即变化 | 锁定轨不可改；参数裁到合法范围 | “请先选择画面片段”/“轨道已锁定”/“效果参数无效” |
| 保存 | 当前 revision 和完整时间线 | MySQL 原子保存、新 revision | 旧 revision 不覆盖新版本 | “时间线已更新，请刷新后重试” |
| 导出 | 已保存时间线、格式 | 可下载文件 | 无画面不能导出视频；无音频不能导出 MP3 | 返回具体缺失项或 FFmpeg 错误 |
| 收藏 | 能力 ID | 本机用户偏好更新 | 只能收藏当前可见能力 | 本地存储失败时提示，不影响工程 |
| 最近使用 | 真正执行成功的能力 ID | 按时间倒序 | 失败和取消不记入 | 不单独打断编辑 |

## 对照测试

每个保留入口至少验证：

1. 正常输入：产生预期状态并可保存恢复。
2. 空值：不修改数据，给出具体提示。
3. 重复操作：结果幂等或明确替换，不重复堆积。
4. 错误操作：锁轨、错素材、越界参数、旧 revision 均保留旧数据。
5. 取消操作：不创建任务、不修改时间线。
6. 导出一致：同一组参数在浏览器预览和 FFmpeg 输出使用同一份结构化数据。

## 开源参考边界

参考 OpenCut 的原则：效果可以作为片段属性或独立时间线元素，预览、属性面板和导出共用同一份数据；不复制其界面、代码、图标或资源。当前项目仍采用 React + Ant Design、Go、MySQL、TOS 和服务端 FFmpeg。

本实现不复制洛水源码、密钥、私有接口、提示词或专有资源。
