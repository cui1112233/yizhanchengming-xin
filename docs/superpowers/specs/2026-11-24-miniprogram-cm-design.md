# CM画布手机端与线上对应

用户已授权持续逐功能完成。沿用已批准的紧凑设计：390px基准、16px边距、14px正文、18px标题、44px操作，一次编辑一项，深浅主题。CM线上AgentPageV2使用/api/agent/tasks，原小程序/api/studio/agent/projects属于其他产品，必须分开。

手机先显示视频/漫画项目列表与新建入口；项目内对话、节点、素材、任务四页签，项目设置和节点编辑用独立弹层。请求逐项依照frontend/src/shared/api/agent.js和Go处理器。画布保留nodes/edges/viewport及revision，局部改稿不丢其他字段，保存冲突保留草稿，服务器确认读回；对话不自动执行返回的动作，媒体生成需明确所选节点、模型、参数和付费确认。真实状态、结果、重试、取消按任务ID对应；未知结果不自动重发。隐藏停止只读轮询、账号切换清理、迟到数据不能覆盖新项目。

主要表单不提供原始JSON编辑；复杂导演/分镜/素材操作先核实合同，再补全手机交互，不用Studio或其他工具代替。保持旧Studio源码作为独立参考，不改其接口。线上只读检查，不新建测试项目或消耗额度；微信实际数据与模拟测试分别记录。
