# AI-CUT 链路修复实施计划

目标：执行已获用户批准的审计修复，按实际输入、处理、保存、预览与成片结果验收，不按按钮数量统计完成。

约束：直接维护v88，不创建分支；保留共享工作区其他改动；Go embed单一运行；不调用收费模型、不公开部署、不推送。已有目录沿用，不进行目录迁移。

## 工作项

- [ ] A 字幕与Agent：修复F01剧本/标记丢失、F07源时间到时间线映射；补F08可用ASR模型和任务状态查询；回归移动、裁剪、倍速、重复素材实例和命名时间线。
- [ ] B 导出一致性：修复F02零音量、F03连续变速、F04效果时间窗口、F10滤镜强度/重复处理、F13渐变文字、F14基础调色运算；F16高位深中间链路保真或明确拒绝不支持组合，不把编码容器位深冒充全流程精度。
- [ ] C 自动成片：修复F05后端选项约束；F06提供实际素材信息并支持在空工程放置真实视频/图片；F15审核显示操作时间、文字、参数、警告，按勾选结果计算时长。缺少字幕/画面分析的素材不得编造对白或声称读懂画面。
- [ ] D 页面预览与参数：补F09效果轨实时预览，F10滤镜参数保存/渲染统一，F11文字字号与不透明度实际生效；F12消除范围据实呈现，禁止声称现有跟踪能消除移动目标；F13渐变文字预览与导出同一规则。
- [ ] E 复查与交付：将审计失败断言转成正式回归；综合前后端测试、真实本地生成测试音视频；本地构建Go embed并验证当前页面；报告逐项已修复、明确限制与未完成，不把限制改名当作功能完成。

## 验收重点

1. 字幕导入不破坏剧本/标记；ASR字幕对应编辑后实际播放位置，必要时按素材实例复制并裁掉不可见部分。
2. 音量0成片静音；连续速度曲线的同一输出时刻消耗相同源时间；1秒效果仅在该秒生效。
3. 素材选择返回真实名称、类型、时长；空工程能生成可执行的放置操作并保存可导出的视频；禁用选项无法越过服务端校验。
4. 前端控件值、保存刷新值、成片参数一致；无法提供的移动消除/HDR全流程按真实范围说明，不冒充已完成。

本计划基于 `docs/audit/2026-11-12-aicut-chain-truth-audit.md`。每个工作项独立实现和复查；不允许多个执行者同时修改同一文件。
