# Novel Fetch Default Upload Profile Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the default website upload profile and its sync actions inside the Novel Fetch video-management login dialog while preserving advanced per-version mappings in the configuration page.

**Architecture:** Keep the existing Go web-submit configuration endpoints as the single source of truth. Add a small frontend merge helper so saving the dialog changes only `selected_profile`, then reuse the existing session, sync, and save API calls from `NovelFetchPage.jsx`.

**Tech Stack:** React 18, Ant Design 5, Node test runner, Vite, Go embedded frontend release path.

## Global Constraints

- Backend remains Go and frontend remains React + Ant Design.
- Do not add a second configuration store or hard-coded system prompt.
- Do not overwrite existing `profile_bindings` or unrelated submission settings when saving the default profile.
- Keep advanced original/AI version mappings in the configuration page.
- Do not commit, push, or deploy without explicit user instruction.
