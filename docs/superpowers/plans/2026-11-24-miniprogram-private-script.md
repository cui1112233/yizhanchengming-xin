# 私人定制手机实现计划

1. 先补失败测试：同名模型按ID选择、禁用模型过滤、重复提取/生成只提交一次、历史入口读取自己的数据。
2. 新增纯人物字段/删除引用整理帮助函数与单资产编辑组件，保留全部未知字段和媒体数据；手动新增不收费。
3. 新增独立历史列表组件，复用原恢复契约；对异常格式、空列表和读取失败分别处理，不把错误显示成无记录。
4. 修改ScriptWorkspace控制布局和同步操作锁、有效选项验证、数据变更后的结果失效；抽出资产组件与设置面板避免继续堆积同屏内容。
5. 沿用紧凑主题，调整字号与留白、弹层/键盘/安全区；测试后构建，WXSS处理结束再跑完整产物检查。
6. 微信核对真实选项与空历史、手动编辑（仅本地且取消）、设置与遮挡情况；不调用收费AI。记录截图与限制，独立本地提交。

## 本轮结果（2026-11-24）

### 修改

- 私人定制入口仍为ScriptWorkspace，未指向漫画或漫剧。正文/人物场景/创作结果使用单层导航，六项创作设置收进独立面板；正文保留文本模型与提取模板快捷入口。
- 模型与模板按真实ID选择，过滤停用模型；修复同名条目总是选到第一项，以及快速双击重复提取/生成。
- 新增可手动添加/移除的人物、场景编辑；字段与线上剧本侧一致，保留未知字段和媒体元数据。一次编辑一个，短字段用单行输入，参考图模型可直接选择；底部固定应用，取消不改变当前创作。
- 移除人物时同步清理主角聚焦和约束中的资产引用。正文/创作设置/人物改变使旧结果失效；视频任务进度更新保留结果正文。
- 独立历史面板读取/api/history，选定后核对具体记录编号再恢复，不跳总任务页、不删除线上记录。恢复错误保留当前内容；账号切换和迟到响应隔离。

### 验证证据

新增14项测试，最终全量133个文件通过、1个跳过；869项通过、3项跳过。本轮相关4个文件28项通过（含已有请求契约测试）。初始新增用例明确复现4项失败：双击重复提取、同名模型误选、停用模型被默认选择、手动添加入口缺失，随后修复通过。开发版最终构建成功（27.74秒），WXSS处理移除48条旧不支持伪类；全量测试在构建与处理结束后运行。类型检查仍有8处原有profile/tasks/workspace/taskPageState错误，本轮文件没有新增类型错误，不宣称全项目类型检查通过。

微信真实运行：打开pages/module-detail/index?key=script，读取真实模型/模板；手动新增测试人物，输入“手动设定测试（未应用）”后取消，再次打开确认“人物0/场景0”；打开独立历史，真实返回暂无历史；创作设置真实包含文本/图片模型、提取模板、开头、输出、时长。截图位于docs/design-references/miniprogram-private-script/{source,entity,settings,history}.png。测试人物只存在于未应用的本地编辑草稿，没有生成或保存到线上。

过程中构建刷新曾使自动化连接超时；完成构建后清编译缓存并重新打开页面，最终截图与操作正常。未以连接超时作为业务页面已黑屏的结论。

### 尚未验收

没有调用收费AI提取/剧本生成/参考图生成/配音，也未创建测试历史或执行视频任务。真实生成与产物下载还需专门验收；跨端草稿同步、未提交正文自动保存、网页智能补全/改写和高级分镜编辑仍未在本轮完成。历史当前为空，只证明读取与展示成功，具体历史恢复由模拟接口测试覆盖。只核对当前开发者工具尺寸下深色显示，浅色与其他机型尚无实机截图证据。
