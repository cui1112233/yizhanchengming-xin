## 输入/输出/边界/错误
1. 批量输入当前项目已保存的集、章节绑定、文本模型、任务（规划/分镜）、规划方式（新/已有/无）、原文开关。输出各集真实结果，逐集刷新。没选集、缺模型、缺必要章节/规划禁止开始。默认不选集、不覆盖成功集；开始前显示额度说明。重复点击同步锁；停止后不启动下一集；离开项目停止后续集，已完成结果保留。不自动重试未知请求，不伪造成功。
2. 检查输入选择集的已保存剧本、实际资产解析档位和模型，三类资产逐项提取。后端MissingOnly使用原提取提示词，原子新增而不覆盖已有同类型同名资产，新增保存。任一类型失败保留之前结果并标失败。取消不提交；执行中停止不启动后续项，已保存保留。
3. 失败按钮展示真实注意事项；另失败记录从持久生成attempts读取，按集聚合最近失败及未确认状态，支持刷新、只看失败、回到该集原准备窗（保留原恢复逻辑），不凭缺分镜猜失败。
4. 检查不是AI艺术质量审核，不承诺原native隐藏算法。无需新增模型/前端硬编码提示词。
