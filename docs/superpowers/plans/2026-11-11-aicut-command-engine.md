# AI-CUT 可用剪辑命令 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把时间线剪刀、复制、删除、移动、吸附、联动、裁剪、撤销、保存和导出改成真实、可测试、彼此一致的剪辑命令。

**Architecture:** 不复制 Concat 的 AGPL 源码，只依据公开行为规则独立实现。所有编辑动作先经过 `aicutTimeline.js` 的纯函数命令，再由页面统一写入撤销栈；预览、保存和导出读取同一份结构化时间线。

**Tech Stack:** React、Ant Design、Node test、Go、MySQL、FFmpeg、Go embed。

## Global Constraints

- 不复制 Concat 源码、名称、图标和资源。
- 不新建分支，不清理或覆盖当前脏工作区，不推送、不部署。
- 可见按钮必须有真实数据变化、明确失败提示和自动化测试。
- 时间线同一普通轨道的媒体片段默认不允许重叠。
- 锁定轨道拒绝所有修改。
- 前端预览、保存与后端导出必须读取同一时间线字段。
