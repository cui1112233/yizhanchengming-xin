# CM漫剧批量、检查与失败入口

## 已实现规则
- 分镜工具栏增加批量、检查、失败记录和失败说明，沿用统一主题与原图标。
- 批量选择已保存剧本集、绑定真实章节，支持只规划/生成分镜，新规划/本集已有规划/无规划及原文开关；逐集使用后端提示词和已配置模型，不在前端写系统提示词。
- 空选择、缺模型、缺必要章节/已有规划、不可用分镜词禁止开始；明确确认后才执行。重复启动有同步保护。
- 停止完成当前集后不启动下一集，已成功结果保留，未开始项明确展示。未确认状态停止后续任务，先核对，避免连续新增不明请求。
- 检查按所选集、人物/场景/道具调用真实提取接口，missingOnly=true；后台新增保护不覆盖同类型同名的用户卡片，包括编号、提示词和版本；并发新增冲突后重新核对，不用覆盖解决。
- 失败记录读取持久化generation attempts，按每集最近状态展示、支持只看失败/取消、刷新及打开原准备窗核对重试。原来成功而后续失败的记录以最新为准；未知不冒充失败。最近50个请求的范围在窗口说明。
- 原版“失败”工具实际是注意事项按钮，不是失败筛选，故另列失败记录入口。
