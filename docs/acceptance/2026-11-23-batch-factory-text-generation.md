## 真实页面链路

1. 上游书城抓取返回确定性失败后，在“编辑内容”中粘贴完整原文。
2. 保存后，数据库中的正式正文和书城原文均为 433 字，原文状态为 `verified`。
3. 点击“重试失败步骤”，系统没有再次请求失败的上游，而是直接继续文本生产。
4. 执行日志依次进入 `text_render`、`text_validate`、`text_collection`，完成 3 / 3 张文字页和 1 个文本合集。
5. 三页内容分别承载连续的完整段落，没有从句子或段落中间直接截断。
6. 文本媒体库可查看 3 张文字页、1 个文本合集，并提供逐页排版调整、重新分页、重新合成和上传入口。
7. 本次任务误选了“生成并上传”，本地缺少文本上传人和组织，因此上传在本地参数校验阶段被阻止；已经生成的合集仍显示为“1 合集就绪”，同时保留“1 异常”，不会把成品隐藏。

## 回归修复

- 文本批次新建弹窗不再使用视频文案，区分“生成文本合集”和“生成文本合集并上传”。
- 文本编辑器使用完整正文，不再继承视频的“生产前 5 行”。
- 人工粘贴完整原文会同时保存正式正文和可验证原文，失败重试可直接继续生产。
- 同一书号抓取失败但已人工补齐完整原文时，重试不再返回 409。
- 上传失败不会抹掉已生成合集，批次顶部同时展示合集就绪和上传异常。
