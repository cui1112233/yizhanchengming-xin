# 插件界面一致性对照审计（第一版 · 2026-11-11）

对照对象：插件市场中有真实面板的条目。
判定口径（按用户要求）：**控件类型不许等价替换；字段顺序、选项集合、默认值、空态文案不同一律判「不一致」**，不得用「功能等价」抵扣。

本文只写有证据的结论。证据类型分三种，正文逐条标注：

- `[截图]`：`F:\脚本测试\work\洛水2026-v2.9.0-反编译分析\shots\` 下的洛水实机截图，或 `docs/acceptance/ui-consistency-2026-11-11/` 下的成对截图（V88 取自 `http://localhost:4001`）。
- `[bundle]`：`F:\脚本测试\work\洛水2026-v2.9.0-反编译分析\recovered\frontend\index-DszfAkKD.js` 行号。
- `[源码]`：V88 前端源码文件 + 行号。

未取得一侧证据的，一律写「待取证」，不写成「已对照」。

## 一、结论摘要

1. 有洛水实机截图可直接对照的 9 条：小说转剧、分镜大师、爆款开头、角色修改、AI-Subtitle、AI-Filler、AI-Upscale、AI-分段、资产参考。
2. 其中 **只有「小说转剧」基本对齐**（形态、字段顺序、占位文案、结果区标题都一致，差异仅主按钮配色）。
3. **形态不一致（最严重）3 条**：AI-Subtitle、AI-Filler、AI-Upscale —— 洛水是「左参数列 + 右结果列」的整页双栏，V88 是 720px 居中单栏工作台。
4. **AI-分段形态不一致**：洛水整页双栏 + 三个分段模式 Tab，V88 是 1080px 固定遮罩弹窗。
5. **V88 多出「并发生成」开关**：洛水只有小说转剧有这一行，分镜大师 / 爆款开头 / 角色修改都没有。
6. 角色修改结果区标题不一致：洛水「修改结果」，V88「生成结果」。
7. 主按钮配色：洛水按插件主题色（小说转剧#14b8a6 系绿、AI-Filler 粉、AI-Subtitle 绿……），V88 统一珊瑚红。
8. 资产参考：形态与列顺序一致（结果在左、参数在右），逐元素对照待补 V88 截图。
9. 剩余 7 条（AI-CUT、AI-Split、AI改文、封面生成、格式化文本、字幕合并、文档合并）洛水侧证据不足，全部标「待取证」，本轮不下结论。
