## 交付

- AI-CUT 内嵌现有真实 AgentCanvas，替换四步引导页；支持故事、角色、场景、道具、分镜卡片，复用节点编辑、连线、生成、媒体上传等已有能力。
- 每个剪辑工程绑定独立服务端创作项目，通过已有 MySQL AgentWorkspace 保存；具备保存队列、版本检查、本机草稿恢复及工程/时间线切换保护。
- “发送剧本”明确选择 1–10 张非空文字卡，按当前时间线版本追加，保留原剧本、轨道和标记。
- “送入剪辑”明确选择 1–30 个真实媒体素材，复制内容到当前剪辑素材库；稳定标识支持重复重试。交接后返回专业剪辑，不擅自重排原有时间线。
- 剪辑 Agent 保留对话剪辑与自动成片，文案明确剪已有素材；画布不再重复嵌入剪辑 Agent。
- 新画布初始缩放调整为 90%；不显示当前宿主未接入的项目对话按钮。
