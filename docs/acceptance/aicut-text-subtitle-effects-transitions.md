# AI-CUT 第一批特效、转场、文字与字幕验收

日期：2026-11-10

## 本批已接通

- 画面特效：原片、明亮、冷色调、暖色调、黑白、模糊、暗角、发光、镜头抖动、呼吸缩放、闪烁、马赛克。强度和速度会写入工程，浏览器预览与 Go/FFmpeg 导出共用稳定 ID。
- 转场：交叉溶解、淡入淡出、黑场、白闪、左/右/上/下推拉、缩放、模糊。仅允许给同一画面轨中无空隙的相邻片段添加。
- 文字：独立文字/字幕片段、普通文本、标题、字幕、描边、阴影、文本框、渐变、竖排；支持拆分、编辑、与下一条合并。
- 字幕：新建字幕轨、手动字幕、SRT 导入/导出、样式、逐词/按句节奏、入场动效、替换、去水词和字幕纠错。
- 识别字幕：入口始终显示。可选视频/音频、ASR 模型和语言；成功后新增字幕轨，不覆盖原字幕；重复任务会拒绝；任务支持取消、失败/取消后重试。未配置 ASR 时明确显示“前往 API 配置”，不会用假结果代替。

## 验收边界

- 本轮没有发起付费 ASR 调用，也没有消耗模型额度；真实语音识别结果需配置一个可用 ASR 模型后再用用户素材验收。
- 特效和转场是浏览器实时近似预览，最终成片由服务器 FFmpeg 渲染；两端使用同一效果 ID 和参数边界。
- 未复制第三方代码、密钥、私有接口或专有素材。
