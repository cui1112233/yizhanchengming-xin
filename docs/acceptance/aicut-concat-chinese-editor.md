# AI-CUT 中文专业剪辑器本地验收

验收日期：2026-11-10  
本地地址：`http://127.0.0.1:4001/ai-cut`

## 已验证

- 页面使用中文六类资源入口：媒体、文字、转场、特效、滤镜、模板。
- 本地运行页实测资源数量：16 个滤镜、12 个特效、16 个转场、12 个文字样式、4 个模板。
- 素材区、属性栏、时间线均有用户可见的收起/恢复按钮；浏览器中完成往返点击。
- 时间线包含字幕、特效、视频和音频轨；吸附、缩放、分割、复制、删除、轨道菜单都绑定到真实处理函数。
- 文字页显示字幕识别、模型配置提示、SRT 导入/导出和手动字幕入口。没有可用 ASR 模型时明确提示前往 API 配置，没有伪造识别结果。
- 16 个滤镜和 12 个特效的稳定 ID 已映射到 Go/FFmpeg；实际逐条执行 27 条非空滤镜链并通过。
- 16 个转场稳定 ID、12 个文字资源 ID、画布位移/缩放/旋转/透明度已进入服务端保存与导出链。
- 页面颜色使用全站主题变量，不把截图中的深色写死为唯一主题。

## 边界

- 本轮未调用付费模型、未消耗语音识别额度。ASR 只有在用户配置可用模型并主动提交后才会执行。
- 没有复制洛水、剪映或 Concat 的源代码、密钥、私有接口及专有资源；实现使用本项目 React、Go 与 FFmpeg 技术链。
- 本轮只更新本机 4001，没有推送远端、没有部署线上。
