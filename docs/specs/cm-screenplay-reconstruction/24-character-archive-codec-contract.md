## 格式结构（针对实际V2样本验证）

1. JSON UTF-8前置签名`LUOSHUI_CHAR_EXPORT_V2_`。
2. zlib压缩；压缩结果逐字节与SHA256(固定格式salt)循环异或。
3. 使用固定格式KEY，随机16字节IV，AES-256-CBC及PKCS7补齐。
4. 将内层IV和密文拼接，再用SHA256(KEY+salt)作外层KEY，独立随机16字节IV，同样AES-CBC/PKCS7。
5. 前4字节是MD5(外层IV+外层密文)的前4字节，然后拼外层IV、外层密文，整体标准Base64。它是格式校验，不是密码学认证。

首次探针只检查异常，误将原解码返回None称为前缀可忽略；Go→原版实际验证失败后已纠正。原函数校验失败会打印错误并返回None，不能只用“没有抛异常”作为成功证据。现已在原生成样本上直接验证前4字节与上述摘要一致，编码与解码必须实现这一校验。
