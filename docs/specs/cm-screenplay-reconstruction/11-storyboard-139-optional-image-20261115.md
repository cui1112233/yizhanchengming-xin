# 139号分镜模板：可选图片提示词的独立实现

## 原版规则

依据special-storyboard-138-139-spec.md：原前端生成返回、显示、编辑/导入/导出均允许缺省或空image_prompt；原前端并不把video_desc复制为图片词。五个派生保存I/O用例通过，但native主parser导入受限而未执行，不宣称原生持久化/供应商已通过。

138号提示词要求分批20%-30%等待继续；现已恢复的“继续”按钮实际为失败场景重试，不能冒充剧情续写，因此仍保持禁用。

## 实现边界

- 保留原63份提示词与冻结catalog字节，139仅在完整正文摘要匹配时应用独立CM协议适配。
- 图片词缺省/空串保持空，不补造；真正提供的图片词、配音角色/情绪/台词、来源元素和视频词保留。
- 生成链仍校验其他必要字段、类型与时长；不因为原前端宽松导入而允许无效模型输出。
- 139未填图片词时，图片生成明确提示补充；画风、核心指令或已有视频描述不能冒充图片词。有用户手填补充可按补充生成，不复制视频描述。
- 旧冻结139不隐式改语义；只在用户明确重新选择时更新已审查协议，旧任务输入和其他模板保持隔离。选择同一ID也明确保存配置，不仅写最近使用记录。
