## 原版行为与CM接线

原版行号均见 [asset-library-spec.md](asset-library-spec.md) 的恢复前端文件：

- A 448899–449117/457859–458020：新增680px窗口中的库选择内嵌展示；旧入口三类均读取角色库，CM保留该规则并明确标明来源。名称和描述只补空值，库提示词、声音不复制。
- B 449683–449711/451523–451803：卡片“更换图片”按当前角色/场景/道具类型选择；确认后只准备目标图片并选择，不更新普通资产文本。取消不写入。
- C 400373–400426/401789–402003：编辑时选择先保留在当前草稿/预览；取消编辑不复制或选择。明确保存后先持久普通资产，再复制库图片到目标作品，最后明确选择；失败保留重试上下文，避免重复新增资产。
- D 177446–177465/178925–178943：新增“保存到角色/场景/道具库”入口保存已经持久化并选中的图片，不替换任何原有“保存图片到本地”的语义。请求带已保存资产版本与用户看到的选中媒体编号；共享来源被拒时显示真实错误。

图标复用恢复的原版目录。库图片预览使用鉴权图片组件，不能把需鉴权URL直接当公开图片。

## 持久图片与权限

目标准备接口 `POST /projects/{id}/asset-library/{entryID}/stage` 要求请求标识、目标资产ID和库版本。服务端按当前账号、项目、目标、库记录和版本生成稳定媒体编号，保存目标对象、剪辑素材记录、Agent素材记录及Media.Items，成功后仍不修改Selected。

部分记录失败、提交回包丢失、复制中取消均可用同一标识核对恢复，不删除可能已提交记录引用的对象。只有后续明确select才让分镜/生图/视频参考图链读取新图片。不复制普通资产的库设定去覆盖目标手写字段。

项目切换立即更新操作代次，旧图片准备回包不继续选图或刷新，不把旧项目图片与错误写到新项目。
