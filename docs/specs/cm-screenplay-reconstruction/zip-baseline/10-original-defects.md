# 已证实的原版缺陷与复刻修正规则

以下结论只针对固定ZIP的已验证输入。用户明确要求不出现假按键、假链路、假功能；因此界面和功能应对应，假成功和数据损坏不能照搬。当前仅登记规格，未改产品。

| 编号 | 原版证据 | CM应保留的规则 |
|---|---|---|
| ZD01 | 配置保存抛错、success=false、缺接口仍提示已保存 | 确认服务端实际成功后才能提示；失败保持编辑内容 |
| ZD02 | 非法文件名创建原生失败，前端仍成功并跳转 | 失败停留在创建窗口，显示原因，不创建虚假条目 |
| ZD03 | 连续同名创建秒级目录碰撞，后者覆盖前者 | 项目身份独立于标题；重复请求不重复创建，不覆盖其他作品 |
| ZD04 | 章节null先写坏旧文件，再返回失败 | 写入前校验；失败不改变原有效数据 |
| ZD05 | 字符串/无效列表项/重复章节id被保存 | 章节结构、唯一ID与版本必须有效 |
| ZD06 | 提示词加载失败只记控制台，仍保留旧候选；无效ID不处理 | 明确加载状态和失效选择，防止误用旧项 |
| ZD07 | 配置字符串可保存重读 | 仅接受有效配置对象与可用字段 |

正常原版行为与修正例外必须分开记录。同名窗口尺寸、图标和点击关系不是为了修复这些数据缺陷就可以自行改设计。尚未全量完成截图和规则对照，不得据此宣布整套复刻完成。

## 本批补充：分镜生成

- ZD08：分镜保存返回失败或抛错，前端仍提示生成完成。保留生成结果，明确显示保存失败，提供只重试保存。
- ZD09：单场重试success=false但failed_scenes=[]时提示已补回。必须先验证接口成功和非空有效镜头，失败项不能清除。
- ZD10：第二场单独重试时，原生摘要索引为1，镜头索引为0；原前端合并后替换了第一场，新进程重开仍错误。CM按稳定来源场景身份合并，成功后核对目标场及非目标场。
- 风险记录：直接并发调用原生成函数两次会发两次请求；实际按钮loading能否拦截尚待DOM验证，不列为已证实的按钮缺陷。CM任务仍需阻止重复执行。

## 资产与画风

- ZD11：公开资产保存接受非法类型并清空旧资产；应校验对象并区分更新单类和替换全部。
- ZD12：成功加载空资产时旧页面仍保留；应刷新为空，加载失败则明确提示并保留旧数据。
- ZD13：画风保存success=false仍提示已切换；应区分临时选择与已保存状态。
- ZD14：图片入口明确返回失败后，原生成Agent返回success=true/0张；应按实际成果和失败清单显示状态。

## 主Agent调度

- ZD15：部分失败乃至空内容导致四步全失败，外层仍success=true/所有Agent执行完成；必须汇总所选步骤的真实状态。
- ZD16：未知步骤静默跳过仍报完成；应校验流程值，区分只有输入与真实生成。
- 重复步骤和整流程再提交均会再次调用模型；不直接认定合法重复步骤是缺陷，但同一待完成任务重复提交应防止重复计费。
