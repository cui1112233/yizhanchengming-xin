# B04：单独资产重新解析，第一批实现（2026-11-18）

来源：固定ZIP，规格zip-baseline/13，原生asset-parse-v4.json模型边界。主Agent流程属于独立CD01，尚未实施；本批不关闭A03/B04，不把四档解析改名冒充主Agent。

## 可验证规则

- 输入：POST项目assets/extract，mode=standalone，type=character/scene/prop，content为完整输入，confirmed保留既有确认机制。原四档入口mode为空保持既有行为，未知mode明确拒绝。
- 模型：只读当前作品已保存ModelID，不采纳请求model；未配置直接报“请先在作品模型配置中选择文字模型”，不硬编码第三方默认模型。
- 提示词：后端prompt/luoshui/native_assets保存三个原生system和三个user前缀；直接从原生捕获JSON字符串写入UTF8，避免文本文件CRLF改变摘要。系统摘要测试严格比对规格13三个SHA256，完整正文不拼画风；温度1、输出上限20000、单次传输，仍由本站模型配置解析器承接。
- 输出：解析对应数组后保存本站资产，页面刷新可读；新生成文字更新同名资产，保留原资产ID及已有媒体引用。文字模型不能替换已选图片。
- 边界：空正文、未知类型、缺模型在网络前拒绝；非法JSON/空结果报错，保留旧资产；取消后晚到结果不写入。独立解析锁拒绝并发重复；已完成后用户再次明确确认属于新的有费用操作，不声称持久请求编号防重已完成。
- UI：原资产分析及解析程度保留；补独立“重新解析”按钮及有费用确认，明确本次不使用解析程度/出图画风。按钮在忙碌、只读或无正文时不可提交。这是明确补充入口，不宣称像素一比一通过。
