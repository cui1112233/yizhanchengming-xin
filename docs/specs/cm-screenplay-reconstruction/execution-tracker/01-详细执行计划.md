### 每个B步骤统一执行清单

- [ ] 建立records/编号.md，写输入、原证据、精确文件/函数/接口和案例。
- [ ] 先复现当前差异；保存原版与CM的请求/数据/截图，必要行为测试应先失败。
- [ ] 只修改本步相关产品代码；保留既有用户数据和无关修改。
- [ ] 验证正常、空值、非法、重复、错误、取消、保存重开；逐条写结果，不能只写“通过”。
- [ ] 同一输入对比最终请求与实际保存结果，UI同视口检查；受控测试与供应商实测分开。
- [ ] 检查本次差异，保存本地提交和证据；写明产品已改但4001尚未验证的状态。
- [ ] 本地4001安全更新/验证后，才能勾该步4001栏；无法更新时保持待验，不算完成。
