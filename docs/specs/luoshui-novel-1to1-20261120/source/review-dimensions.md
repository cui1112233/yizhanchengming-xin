# 原版37维审稿

来源：docs/reverse-engineering/novel-review-dimensions-20261119/catalog.json；原件字节证据见同目录provenance.json。默认29项启用。

| 序号 | 名称 | 内置说明 | 默认启用 |
|---|---|---|---|
| 1 | OOC检查 | 角色言行是否偏离已建立的性格底色与行为模式。 | True |
| 2 | 时间线检查 | 事件顺序、时间跨度与前后章节是否矛盾。 | True |
| 3 | 设定冲突 | 世界观、规则、设定是否与前文或设定文档冲突。 | True |
| 4 | 战力崩坏 | 战力、能力层级是否无理由暴涨或崩坏。 | True |
| 5 | 数值检查 | 数值、等级、资源等量化设定是否前后一致。 | True |
| 6 | 伏笔检查 | 伏笔是否按节奏回收，是否存在长期悬空或逻辑硬伤。 | True |
| 7 | 节奏检查 | 本章是否有推进、冲突、钩子与情绪起伏，避免空转注水。 | True |
| 8 | 文风检查 | 叙述口吻、修辞密度是否与全书文风指南一致。 | True |
| 9 | 信息越界 | 角色是否获知超出其信息边界的知识。 | True |
| 10 | 词汇疲劳 | 高疲劳词与 AI 标记词是否过密重复。 | True |
| 11 | 利益链断裂 | 角色动机与利益链是否断裂或不合理。 | True |
| 12 | 年代考据 | 时代背景、器物、称谓是否符合考据约束。 | True |
| 13 | 配角降智 | 配角是否无故降智以衬托主角。 | True |
| 14 | 配角工具人化 | 配角是否沦为只为主角服务的工具人。 | True |
| 15 | 爽点虚化 | 爽点是否虚化，情绪缺口与兑现是否到位。 | True |
| 16 | 台词失真 | 台词是否符合人物身份、语境与口语习惯。 | True |
| 17 | 流水账 | 是否陷入只记事件、缺少戏剧张力的流水账。 | True |
| 18 | 知识库污染 | 是否混入与本书无关的知识库或外部设定污染。 | True |
| 19 | 视角一致性 | 视角切换是否有过渡，是否与设定视角一致。 | True |
| 20 | 段落等长 | 段落长度是否过于均匀，缺乏节奏变化。 | True |
| 21 | 套话密度 | 陈词滥调、模板化表达是否过密。 | True |
| 22 | 公式化转折 | 转折是否公式化、可预测。 | True |
| 23 | 列表式结构 | 正文是否呈现列表式、条目化结构。 | True |
| 24 | 支线停滞 | 支线是否长期停滞或只被重复提及无推进。 | True |
| 25 | 弧线平坦 | 主要角色情绪弧线是否长期平坦无变化。 | True |
| 26 | 节奏单调 | 近期章节类型是否单调，高潮与释放是否缺席。 | True |
| 27 | 敏感词检查 | 是否触及需规避的敏感内容。 | True |
| 28 | 正传事件冲突 | 番外事件是否与正传正典约束矛盾。 | False |
| 29 | 未来信息泄露 | 是否泄露分歧点之后才应揭示的未来信息。 | False |
| 30 | 世界规则跨书一致性 | 番外是否违反正传世界规则（力量、地理、阵营）。 | False |
| 31 | 番外伏笔隔离 | 番外是否越权回收正传伏笔。 | False |
| 32 | 读者期待管理 | 章尾是否重燃好奇，读者期待是否在累积或被满足。 | True |
| 33 | 章节备忘偏离 | 成稿是否兑现本章 memo 中的目标与段落要求。 | True |
| 34 | 角色还原度 | 角色语癖、行为是否与同人正典档案一致。 | False |
| 35 | 世界规则遵守 | 是否违反同人正典中的世界规则。 | False |
| 36 | 关系动态 | 角色关系互动是否合理、符合档案或发展逻辑。 | False |
| 37 | 正典事件一致性 | 是否与同人正典关键事件时间线矛盾。 | False |
