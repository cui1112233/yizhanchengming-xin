## 本轮只修的使用差异：短篇原创

目标操作顺序：

1. 点击“短篇原创”，出现短篇讨论输入区；不弹建书或参数表单，不创建作品或调用模型。
2. 输入故事想法，点击“发送”；真正创建short_original讨论并发送讨论消息。信息不足时继续讨论，不创建作品。
3. 返回short_run时显示“确认生成短篇”；只有明确确认才建立独立短篇任务并打开短篇结果。short讨论不能接受create_book长篇建议。
4. 切回“长篇原创”，恢复长篇自己的未发送草稿；再次切回恢复短篇草稿。
5. “新建会话”只创建当前模式的讨论，不打开建书表单；会话列表按当前模式分开。
6. 选择旧短篇会话后刷新，保留短篇身份及其草稿，不被全局长篇选择覆盖。

后端prompt模块新增v4协议约束；所用模型仍来自我们自己的配置。旧长篇草稿和缓存键保留，短篇新增独立草稿、会话选择和创建恢复键。确认/未知结果/账号隔离保护沿用，不取消。
