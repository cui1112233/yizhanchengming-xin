## 1. 六维拆书

- 输入：参考原文。实际附加偏好、参考资料和字数的 builder 参数须从调用处确认。
- 输出：Markdown 拆书报告，六个维度为情绪曲线、人物关系与人设、核心价值观、底层情绪渴望、核心逻辑、金句手法。情绪图谱包含阶段、事件、情绪、强度和情绪引擎。
- 边界：分析“为什么上头”，不把拆书结果当新正文；金句是手法参考，不得流入新作当成原创句子。
- 失败：缺维度、空报告、原文缺失要有可定位错误。除“仿写短篇需要参考原文”已在原生 run 观察到，其余具体原版报错文案尚未确认，CM验收要求不能冒称原版既有行为。
- 原版证据：Constant 4/6，字节4016745..4018078。
- CM缺口：ShortSourceAnalysis 只要求 `{"content":"不超过4000字元的分析"}`，没有这六维输出合同或逐维完整性验证。不能仅修改名称就称迁移完成。

## 2. 仿写方向

- 输入：拆书核心价值观、情绪功能等资料；最终 builder 字段待调用函数补证。
- 输出：三个明显不同题材/时代/设定的方向。每个包含题材、设定、150–250字概要、价值观沿用、爽点与虐点；使用 DIRECTION 1/2/3 区块。
- 边界：方向共享核心价值观，事件与设定拉开差距。原生_produce确认：有selectedDirection用传入值，否则取第一个方向（证据文件:233–355）。前端是否提供人工选择界面仍需单独验证，不能自动新增一个必选弹窗后称一比一。
- 失败：缺方向、区块重复、数量不符、选择不存在方向，CM应保留原结果并提示；原版精确解析与失败文案待验证。
- 原版证据：Constant 11，字节4018348..4018938。
- CM缺口：当前 shortSource → ShortOutline 没有专用的三方向对象和选择结果记录。

## 3. 仿写蓝图

- 输入：参考拆解和选定方向；目标字数及其他上下文进入方式待 builder 调用确认。
- 输出：放大后的情绪曲线、新人物关系、情绪功能到新事件映射、新金句、角色命名、5–8段规划、防抄袭元素对照。
- 边界：保留情绪功能而更换事件；人名、地名、年代、事件与台词逐项列替代方案。分段预计字数合计落在目标区间。
- 失败：蓝图缺项、映射缺新事件、目标字数不相符时不应直接进入正文并假装通过；原版校验器、容错规则及提示未全部恢复，待逐项取证。

- CM缺口：通用 ShortOutline 只保证 title/summary/chapters（number/title/summary）；不是上述七项专用蓝图。

## 4. 仿写写作约束与编辑终审

- 输入：正文，以及仿写专用约束和前置材料。_produce已确认在内部ShortFictionRunner.run之后读取finalMarkdownPath，再进入可用最终文本的编辑审核分支（:1132、:1912–2038）。缺失最终文本有跳过路径，不声称原版每次都强制审核。
- 输出：编辑审核意见单，包含总评级、逐维度审核、2–3个标题、简介与定位修改清单，包在 REVIEW START/END 内。
- 边界：原包约束包括同价值观、增强情绪、替换主线事件、改写金句、第一人称及口语短句等；这些只属于原版仿写合同，不得未经模式区分强制到所有原创作品。查重不能凭模型一句“原创”就当精确查重已执行。
- 失败：缺总评级/区块、空正文、终审未通过不能显示“已验收完成”；CM需区分生成成功与编辑验收。原版的具体通过/失败状态转换继续取证。
- 原版证据：Constant 33（字节4020317..4020796）、42（4021145..4021753）。
- CM缺口：通用 score/issues 短篇审核不能替代专用编辑报告、标题建议和防抄袭对照。已修复的审核轮数/阈值控制不代表此终审合同已迁移。
