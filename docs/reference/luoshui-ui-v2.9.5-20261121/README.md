# 洛水原版页面参考与 Mock

打开 [index.html](index.html) 或 [mock.html](mock.html)，点击左侧页面，或“全部缩略图”。支持搜索页面/控件、原尺寸、原图与页面热点跳转。

当前 101 个已确认实拍状态；覆盖记录见 [coverage.md](coverage.md)，原始控件及页面文字在 states/，完整截图在 screenshots/。

界面来自原版 2.9.5 实拍，未重新设计。此 mock 用于核对布局和入口，不连接模型或原版后台，不保存作品。它不等于产品已完成复刻。

复采：在已授权的原版 CDP 9226 上使用 scripts/capture-luoshui-ui.mjs；更新后运行 scripts/build-luoshui-ui-mock.mjs，再运行 scripts/document-luoshui-ui.mjs。
