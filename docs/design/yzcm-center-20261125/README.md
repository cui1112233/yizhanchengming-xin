日期：2026-11-25。设计依据：已确认的 YZCM 托管模型与团队账号方案。

本目录是独立设计原型，不接真实接口、不创建账号、不保存 Key、不充值、不扣款；不替换本地4001或线上页面。打开 `index.html` 即可查看，也可通过本机4783端口预览。图片归档在项目 `_local-archive-20261028/yzcm-center-design-20261125/`，避免图片产物堆进源码。

## 统一视觉

- 延续现有个人中心的侧栏和深色工作台；使用项目 `v88-tokens.css` 的12px卡片圆角及8/16/24px间距层级。
- 本稿深色调色板：底色 `#111820`，卡片 `#1b252f`，边线 `#35424d`，正文 `#f3f6f8`，主操作 `#70dec2`；正式接入时映射到现有主题语义变量，不向其他页面硬编码深色。
- 字体：Microsoft YaHei / Noto Sans SC；金额使用等宽数字。统一字段高度、按钮和表格密度。
- 1150px以下收紧侧栏及留白；850px以下主内容分栏变单列；560px以下侧栏改为顶部导航。表格在自身容器横向滚动，避免撑大整个页面。
- 弹窗内容滚动，标题和底部操作保留可见。待核账使用琥珀色，不显示虚构金额；失败和已收费分别展示。
