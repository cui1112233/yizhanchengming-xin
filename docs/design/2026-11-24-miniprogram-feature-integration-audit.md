## 手机布局要求

### 已找到的独立业务依据

- 小说创作：`frontend/src/shared/api/novelCreation.js`，使用 `/api/novel-creation/projects`、项目 sessions、session messages/snapshot、project chapters、runs 的 retry/cancel/confirm、项目 settings/materials/export。手机端应覆盖作品 → 会话/章节 → 执行 → 读回，不能只有大纲输入框。
- AI-CUT：`frontend/src/user/pages/AICutPage.jsx` 引用独立 `aicut.js`、`aicutTimelines.js`，已有项目、素材、时间线、导出任务等客户端。移动端时间线为适配设计，尚未验证微信环境可用性。
- 插件：`frontend/src/user/pages/pluginCatalog.js` 区分提示词工具、桌面工具、本地处理、工作区、草稿、超分等类型；手机不支持的桌面能力需要明确说明，不能给一个通用按钮假装可用。

- 保持晚霞、深蓝底、紫青玻璃体系；内页顶部约 100px，主要空间留给操作。
- 390px 作为设计基准，兼容 360–430px；左右 16px，卡片间 12px。
- 页面标题约 20px，正文 14px，说明 11–12px；点击区域至少 44px。
- 设置用单项行与专属选择面板，不把整套设置重复塞进每个入口。
- 底部主按钮考虑安全区；键盘弹起时输入可见；内页不重复放两套流程导航。
- 每项有自己的语义图标。模型、提示词目录与权限取服务端；数字、状态与百分比由真实数据渲染。
- 生图用于评审，不能把整页图片当作可操作界面。样稿里的内容只用于展示布局。

## 实施顺序

逐项闭环：私人定制 → 小说创作 → 批量测书 → 水货生产 → 漫剧创作 → AI-CUT → CM 画布 → 配音 → 插件。

每项核对入口、配置读取、输入、提交、任务恢复、失败重试和结果，再交付该页手机截图。真实生成可能消耗额度，界面验收不自动发起付费生成或发布。
