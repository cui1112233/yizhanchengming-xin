# 小程序九功能高清插画

本目录保存线上九项功能的设计源图。`source/` 是 ImageGen 输出的透明高清 PNG，`normalized/` 是统一主体占比后的审核版本，`nine-functions-board.png` 是 3×3 总览。

统一风格：可爱的精品 3D 建模、轻微俯视三分之四视角、左上柔光、青色轮廓光、紫色补光和少量暖粉高光。源图不得包含文字、字母、Logo、emoji、手机框或 UI 截图。

## 文件顺序

1. 私人定制
2. 小说创作
3. 批量测书
4. 水货生产
5. 漫剧创作
6. AI-CUT
7. CM 画布
8. 配音
9. 插件
