## 必须保留的验收证据

- 输入错误不写入任务，不进入队列，不调用模型。
- 保存成功、到点、执行中、失败、恢复、完成各有真实持久化状态。
- 用受控上游记录次数：重试只补缺失版本；已生成正文不重取；未知提交先回查；已经确认的版本不重传。
- 当前实际 overdue 故障必须绑定具体任务 ID 和环境；本地账号快照不能代替线上结论。
- 本地 4001 的新二进制身份与接口结果验证通过后，才能将同一提交部署线上。

禁止用“测试全绿”“接口数量对上”“页面有按钮”来表示整套完成。每个单元单独记录已验收和剩余项。
