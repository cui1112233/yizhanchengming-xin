# AI-CUT 编辑器第三方边界

## 实现方式

AI-CUT 编辑器按本项目的数据结构、React 前端和 Go/FFmpeg 导出链独立实现。设计时只参考通用非线性编辑器的交互习惯，没有复制洛水、剪映或 Concat 的源代码、密钥、私有接口、商标素材和专有资源包。

## 运行依赖

- React、Ant Design：页面与交互组件，沿用本项目现有依赖和许可证。
- FFmpeg：服务端媒体渲染。部署环境需要提供可执行文件；实际分发时按 FFmpeg 构建所包含组件的许可证履行义务。
- Lucide React：界面图标，沿用本项目现有依赖和许可证。

## 资源规则

滤镜、特效、转场和文字模板只保存本项目定义的稳定 ID 与参数。预览由浏览器 CSS/DOM 实现，最终导出由 Go 生成 FFmpeg 参数；不内置第三方付费素材、字体、音乐或模型密钥。
