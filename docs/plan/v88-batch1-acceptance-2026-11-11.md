## 1. 错误文案（1-1 ~ 1-5）

### 1-1 批量工厂兜底文案
- **操作**：水货生产 → 选一本已建的书 → 把该批次的图片模型渠道 Key 临时改错（或在 API 配置里填一个错 Key）→ 点「生成」。
- **期望**：界面主文案是中文，形如「图片通道调用失败，请检查渠道配置」；不出现 `invalid input` / `temporary upstream failure` / `HTTP 400` 作为主文案；展开「原始信息」能看到上游原文。
- **失败长什么样**：Toast 或红条直接显示英文前缀 / 裸 JSON / `错误: {"error":...}`。

### 1-2 漫画页提示词文案
- **操作**：进入某本书的漫画页列表 → 清空某一页的提示词 → 点该页的「生成提示词」；再制造一次模型返回空（选一个不存在的模型 ID）。
- **期望**：
  1. 提示词为空 → 中文提示「请先填写提示词」类；
  2. 模型返回空 → 提示「模型返回为空」，不是裸错误；
  3. 上游拒绝 → 中文说明 + 可展开原文。
  
- **失败长什么样**：三种情况文案相同、或出现 `empty completion` / `prompt required` 等英文。

### 1-3 图片通道 4xx
- **操作**：API 配置里把图片模型 Key 改成 `sk-invalid-xxx` → 回漫画页生成一页。
- **期望**：主文案为中文且指向「通道鉴权失败」；不出现 `image provider returned HTTP 400`；上游响应体只在展开区。
- **失败长什么样**：主文案是拼接英文串，或把上游整个 401/400 响应当提示。

### 1-4 文本模型请求失败
- **操作**：分别触发三条链路——(a) 插件中心 → 封面生成 → 「生成提示词」；(b) Agent 对话发一条消息；(c) 配音页提交一小段文本。
- **期望**：三条链路各自给中文分类文案（未配置 / 返回为空 / 上游错误），措辞可区分。
- **失败长什么样**：三条都弹同一句「请求失败」，或直接显示 `Post "https://...": dial tcp ...`。

### 1-5 状态行中文
- **操作**：水货生产 → 打开任务抽屉 → 观察每条任务的状态；再到自动化面板看书本状态。
- **期望**：所有状态徽标为中文（排队中/生成中/已完成/失败/已跳过）。
- **失败长什么样**：出现 `pending` / `running` / `failed` / `succeeded` 裸串，或中英混排。

## 2. 前端重复扣钱与丢成品（1-6 ~ 1-11）

### 1-6 API 配置 Key 半截落库
- **操作**：个人中心 → API 配置 → 文本模型组 → 新建/编辑自定义渠道 → 在 Key 输入框里逐字符慢慢输入 `sk-abcdef123456` → 输到一半**刷新页面** → 回读该渠道。
- **期望**：刷新后该字段为空或恢复为上一次完整保存值，不出现 `sk-abc` 这种半截值。
- **失败长什么样**：回读到半截 Key；或用该渠道生成时报鉴权失败但界面显示 Key 已保存。

### 1-7 配音重复下单与失败保旧音频
- **操作**：配音页输入 50 字文本 → 选音色 → 连续快速点击「生成」5 次；等成功后再把渠道 Key 改错，对同一段文本重新生成。
- **期望**：
  1. 连点只产生 1 条任务（任务列表/计费记录只有 1 条）；
  2. 失败后原音频仍可播放、可下载，文件未被清空。
  
- **失败长什么样**：5 条任务 / 5 次计费；失败后播放器变空、旧音频 404。

### 1-8 小说抓取等待与误判
- **操作**：小说获取页 → 提交一个正常 URL → 等完成；再提交一个不存在的 URL；再把本地网络断开后提交一次。
- **期望**：正常成功；不存在 URL 在 1 个轮询周期内显示明确失败原因；断网时显示网络错误，不无限转圈。
- **失败长什么样**：三种情况都停在「等待中」；或正常任务被误判为失败。

### 1-9 封面无限轮询
- **操作**：插件中心 → 封面生成 → 用错误 Key 触发生成 → 保持 DevTools Network 面板打开观察 60 秒 → 再切换到别的页面。
- **期望**：失败后 30 秒内不再新增请求；切页后无残留请求。
- **失败长什么样**：Network 里 `/cover` 类请求每 2-3 秒持续新增，切页后仍在打。

### 1-10 素材参考跨账号可见
- **操作**：账号 A 上传一张素材，记下其 ID；账号 B（无该素材）调用 `GET` 该素材地址 / 用该 ID 引用生成。
- **期望**：返回 403 或 404，不返回图片二进制；生成接口拒绝该引用。
- **失败长什么样**：B 能直接看到图片或成功引用。

### 1-11 AI 剪辑草案重复应用
- **操作**：AI-CUT → 生成一份自动剪辑草案 → 点「应用」→ 立刻再点一次「应用」（或按 F5 后重复提交同一个草案 ID）。
- **期望**：时间轴只变化一次；第二次点击无效或提示「已应用」；刷新后时间轴与第一次一致。
- **失败长什么样**：片段数量翻倍、时长翻倍、或同一片段叠加两层。
