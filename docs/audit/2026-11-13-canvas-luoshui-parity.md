## 当前功能与边界

| 项目 | 当前落地 | 仍不能宣称什么 |
| --- | --- | --- |
| 卡片、连线、定位与编辑 | 复用真实 AgentCanvas；宠物可定位和打开选中卡片编辑器 | 不能据界面相似断言全部洛水交互等价 |
| 页面宠物 | 独立CM画布和AI-CUT嵌入画布注册同一画布服务；专业剪辑恢复原剪辑服务 | 尚未把全站每个业务都变成专用宠物服务 |
| 画布创作方案 | 保存后提交真实chat接口，后端读取所属项目卡片和最近对话；先展示方案，再确认写入；版本冲突拒绝 | 自然语言效果取决于已配置文本模型，本轮没有付费供应商验收 |
| 创建/修改/连线/移动/移除节点 | 复用已验证的导演结构命令和实际保存接口；移除节点不删除素材 | 方案中的生成步骤不会被伪装成已生成；含此类步骤的整份方案不会作为结构方案直接应用 |
| 素材生成 | 保留图片、视频、音频卡片的已有模型、执行与结果入口 | 不新增假生成按钮；没有逐个供应商实测 |
| 项目素材和生成历史 | 独立工作区已有素材、任务/结果管理；嵌入画布可送素材到剪辑 | 洛水的全局分类资产库不等同于本项目的工程素材列表；跨项目完整分类/引用仍未逐项对齐 |
| 剧本及素材交接 | 已有发送剧本、送入剪辑和返回编辑的真实接口，本次保留 | 不是所有卡片自动变成时间线，也不将文本方案当作成片 |
