## 仿写短篇：本次截图的精确合同

原版 `NovelImitationShortDialog.readable.js:24—165` 和 `NovelStudioPage.readable.js:855—916`：

- 标题可空，提交时去首尾空白；空标题交由后续生成。
- 参考原文必填。非空白UTF16单位计数至少100；必须在追加备忘录之前检查，不能靠备注凑够原文字数。
- 支持TXT/DOCX文件选择与读取；取消文件选择不改变内容；同路径去重；读失败提示文件错误。
- 默认总字数13000；快捷10000、11000、12000、13000、15000、20000。原前端归一化：非法或小于1000回13000，取整、上限500000。这只是前端接受规则，不能当作已证明原生能稳定生成50万字；CM能力边界须单列且显式提示。
- 默认篇章1；原前端归一化非法/小于1回1，取整、上限50。
- 偏好快捷项：轻松搞笑、热血爽文、智斗权谋、悬疑惊悚、甜宠治愈；灵感标签、补充要求、关联保存和知识书籍也有独立字段。
- 提交字段：referenceText、title、targetWordCount、targetChapters、chapters、supplementaryInfo、readerPreferences、inspirationTags、styleName、linkedSaveId、knowledgeBookIds；父层加sessionId与model，桥接调用novels_run_imitation_short。
- 父层先创建/选中imitation-short会话，显示工具阶段。失败写error并展示message；cancelled不再额外弹普通失败。awaitingConfirmation进入检查点并保留storyId；完成后按storyId读取短篇，不以某章非空当完成。
- 原版提交后重置表单并关闭。CM若保留草稿恢复，必须登记为明确的可靠性适配，不能声称复刻此重置行为。

当前反例：入口只切activeMode；白名单只有referenceText；没有上述总字数、篇章、偏好、灵感、关联等完整短篇DTO；modeUsesCheckpoint短篇返回false；GetShortResult返回ChapterVersion；所以仅添加专用弹窗不足以修复。

必须增加的验收：0/99/100非空白单位；空格/换行/emoji计数；无标题；目标字数非法/下界/上界；重复偏好；取消文件选择；重复提交；切模式/切账号返回；等待确认后修改文件再继续；失败与结果未知；保存后刷新；没有产物时禁止假导出。
