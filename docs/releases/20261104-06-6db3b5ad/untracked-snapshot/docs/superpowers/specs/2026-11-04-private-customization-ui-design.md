# 私人定制统一创作工作台设计

## 已确认方向

- 继续使用深色主题，保持与现有产品一致，但降低边框噪音、减少密集按钮。
- 剧本创作和漫画生成使用同一套“双栏统一工作台”：左侧输入与素材，右侧配置与结果。
- 顶部保留工作区切换；左侧工作区标题、输入框、当前步骤和素材；右侧工作区标题、紧凑配置、生成操作和结果预览。
- 现有功能和接口不改，只调整信息层级、间距、卡片、状态标签和响应式行为。

## 视觉原则

1. 一眼能分清“我现在在哪一步”和“下一步要点什么”。
2. 主要操作只保留一个高亮按钮，次要操作降级为普通按钮或文字按钮。
3. 模型、画风、时长、约束等配置集中在一条工具栏，避免散落在结果区。
4. 资产、人物、场景和分镜使用统一的卡片语言；状态用短标签表达，不用大段说明抢占空间。
5. 小屏幕下自动变成单列，不能出现横向滚动。

## 参考方向

- 写作工作室常见的“素材 / 编辑 / AI结果”空间层级。
- 故事板编辑器的镜头编号、卡片和拖动顺序暗示。
- 开源 dashboard 常见的低对比边框、紧凑控件和有限强调色。

- 剧本和漫画沿用现有 DOM、状态、接口和按钮行为。
- 完成后运行私人定制相关的源代码检查和前端构建检查。
